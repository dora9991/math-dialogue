# 授業ナビ 標準版（hyojun-navi）

公立中学校の標準時数（中1 年140コマ・中2 年105コマ・中3 年140コマ）のうち、定期テスト・学期のまとめ・予備をのぞいた、**授業 297時間**（中1 110・中2 85・中3 102）ぶんの、年間計画と教材。

- 毎時間に、授業構想・板書計画・ワークシート・演習プリント（両面）・小テスト・スライド（ワークシートから自動で組み立てる）がある。
- 軸：生徒が主体的に取り組み、思考・判断・表現する授業。毎時間に「考える問い」「表現する場面」「自分で選ぶ場面」を1つずつ入れる。
- 全部を課題解決にはしない。6つの型（課題解決／例題と練習／ゲーム・活動／習熟・教え合い／活用・表現／まとめ）を単元の中で組み合わせる。
- **作り方**：文章と問題は、作者の方針と指示のもとで、AI（Claude）を使って作成した。教科書・指導書・市販の問題集の文章や問題を、写したり、要約したりして入れないように作っている（くわしくは下の「作り方と、見くらべの検査」）。
- **まだのこと**：作者による全部の読み直し、実際のプリンタでの印刷、電子黒板でのスライド、授業での試用は、まだ（2026年10月時点）。まちがいが残っているかもしれない。授業で使う前に、内容を確かめる。
- 作りはじめ：2026-10-02

## 検査

```bash
python3 tools/verify.py seifu                       # 答えの検算・点の合計・授業構想の形
python3 tools/hc.py check '^seifu-' ws dr qz sl --base   # 行あふれ・はみ出し・図の字の重なり
```

必要なもの：Python 3 と sympy、Node.js。`hc.py` は Mac の Google Chrome、`pdfview.py` は PyMuPDF を使う。

### AI のエージェントによる点検（2026-10-02）

公開したすぐあとに、AI のエージェントに、3つの見方で読ませた。出た指摘は、別のエージェントに「反証するつもりで」確かめさせ、成り立ったものを直した。

| 見方 | 見た範囲 | 直した数 |
|---|---|---|
| 機械の確かめがない解答例・穴うめの読み直し | 検算のない記入欄 1,768 と、穴うめのある 420 のまとまり | 16件 |
| 授業構想・板書計画と、ワークシートの食いちがい | 全297時間 | 23件 |
| 公開面の監査（個人情報・内部向けのメモ・出どころの書き方・実在のもの・場面の適切さ） | 公開先に出している全ファイル | 15件（個人情報は、見つからなかった） |

（同じ種類の直しは、1件に数えた。）GitHub に入れる前にも、同じやり方で、README と `tools/` を点検した。

おもな直し：
- 答えのまちがい：平面図形 第2時 演習（正六角形の平行移動。「ない」→ ③ と ⑤）。図のまちがい：三平方の定理 第11時（接点の位置）、円 第7時 小テスト（2本の弦がどちらも直径になっていた）、空間図形 第6時（投影図の、かくれた辺の点線）。
- 「相似といえない例」が、実は相似になる数だった（相似 第3時 例題1（4））。料金のきまりの文が、グラフや答えと合わない（関数 y＝ax² 第12時 演習）。まだ習っていない用語を空らんにしていた（文字と式 第5時 演習）。
- 授業構想の「考える問い」が、ワークシートの【考えよう】と少しちがう文になっていた（中1の88時間）→ 同じ文にそろえ、`verify.py` が見るようにした。板書の答えの直しもれ（三平方の定理 第5時・第12時）。
- 演習プリントの裏の見出し「入試問題」→「入試に挑戦」。入試でよく出る形に合わせてつくった問題で、実際の入試問題ではないため。
- 「進め方」の出どころの文の、言い切りすぎていたところを直した。使っていない CSS と、作る人向けのコメントを消した。
- 場面の直し：男子・女子の平均点 → 1組・2組／人の体重の変化 → 子犬／忘れ物を届ける母 → 家の人／シドニー（1月は夏時間で +2）→ グアム。

**まだ見ていないところ**：`py` の 2,685 の、紙面の答えの読み直し。演習プリント・小テストと、授業構想との見くらべ（見くらべたのはワークシートだけ）。作者による読み直しと、授業での試用。

## 書き方のきまり

- 記入欄は `{{答え}}`、分数は `[[1/2]]`、累乗は `x^2`、マイナスは `−`（U+2212）。根号は `√{…}`。単位の m・g は `\\m`・`\\g`（そのまま書くと、変数と同じ斜体になる）。
- 計算問題の答えには、検算（`calc`・`num`・`py` など）をつける（つけていない記入欄が、まだ 1,768 ある）。答えの欄に、考えている途中のことばを書かない。
- 段組（C2）の中に、2列以上の小問（QS・RN）を入れない（印刷されない。`verify.py` が指摘する）。小問は4列まで。番号つきの問いの下にならべる小問は、`QS(…, '①')` で ①②… にする。
- ワークシートに「まとめ・振り返り」の欄は入れない。下を空けず、紙面をバランスよく埋める。
- 図は、長さを点線の弧で結んで中に数字、頂点に●はつけない。
- 授業構想（`PL.card`）は goal・flow・think・say・see・tips・board（3列）・matome をそろえる。ゲーム・活動は prep（準備するもの）も書く。think は、ワークシートの【考えよう】と同じ文にする。

### 作り方と、見くらべの検査

- 書くときは、教科書・指導書・市販の問題集を開かず、学習指導要領に示された内容と、数学そのもの（定義・定理・よく知られた考え方）から組み立てた。
- ただし、この教材を書いた AI の作業は、書きはじめる前の別の作業で、作者の手元の資料（作者が指導書を読んで、授業準備用にまとめたもの。公開していない）の一部を読んでいた（正の数・負の数の第1〜3時のワークシートのはじめの部分と、ほか十数時間ぶんの見出しなど）。そのとき読んだ場面は、使わないようにして書いた。
- 書いたあとで、単元ごとに、その手元の資料と、同じ文字のならび（12文字以上）がないかを、機械で見くらべた（`tools/overlap.py`）。当たったものの大半は、用語の定義・計算法則・「□にあてはまる数を求めなさい」のような決まり文句だった。場面・数値のならび・発問が重なっていたところは、別のものに差しかえた。相手の資料がある 18単元のうち、14単元で差しかえた。相手の資料がない 4単元（中2 平行と合同・三角形と四角形・確率・データの比較）は、単元に関係なく読むファイルとだけ見くらべた。
- 教科書そのものとは、見くらべていない。
- てんびんで考える等式の性質や、面積が 2 の正方形のように、昔から広く使われている題材や考え方は、ふくまれている。「かける数を1ずつ小さくしていく」乗法の導入（正の数・負の数 第10時）のように、数学の考え方そのものは、ほかの教材と同じ形になっているところがある。
- 似ているところに気づいたときは、直す。

```bash
python3 tools/overlap.py seifu 12 20    # くらべる相手の場所は tools/overlap.local.json に書く（git には入れない）
```
