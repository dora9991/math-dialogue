# アドリブ・ラボ

**コードを打ちこむ → 伴奏が鳴る → コードの役割がわかる → 合うリックが楽譜と音で出てくる**、アドリブ練習アプリ。
ブラウザだけで動く（インストールもサーバーも不要）。音は、ブラウザの中で合成している（音源ファイルなし）。

## できること

| | |
|---|---|
| **① コード譜** | iReal Pro のように、`| Dm7 | G7 | Cmaj7 | % |` と打つと伴奏（ピアノ・ベース・ドラム）が鳴る。伴奏スタイル16種（ジャズ・ロック・ブルース・ソウル・ファンク・ヒップホップ・ディスコ・ボサノバ・サンバ・サルサ・レゲエ…）、**ノリ**（ストレート／8分シャッフル／16分シャッフルと、その強さ）、コードパレット、サンプル40曲、キー（まるごと移調）、テンポ、ループ回数（1〜12回・無限）、カウントイン、メトロノーム、範囲くり返し、楽器の切りかえ |
| **コードの役割** | コードをタップすると、そのコードの役割を**いくつでも**読みとって説明する（ii・V・I／ターンアラウンド／セカンダリー・ドミナント／裏コード／バックドア／借用和音／経過のディミニッシュ／モーダル／ブルース…）。合うスケール（音名つき・試聴つき）も出る |
| **リックの提案** | 選んだコード（かたまり）に合うリックを、楽譜つきで提案。▶で伴奏つきで聴けて、「ソロに採用」で差しかえられる |
| **② ソロ** | コード進行を読んで、辞典のリックをつなげたソロを自動で作る。楽譜（コード記号つき）に再生カーソルが走る。楽器（アルト・テナー・トランペット・フルート・クラリネット・トロンボーン・ギター・ピアノ…）ごとの音域と**移調譜**に対応。難しさ・音の多さ・**ブレイク（間）の多さ**も選べる（やさしい＝8分音符が中心／ふつう＝3連符・16分音符・シンコペーションが混ざる／むずかしい＝16分のランが多い）。階段のように順に上がり下がりするだけにならないよう、跳ぶ・ジグザグの動きを混ぜ、ひとフレーズ弾いたら息継ぎをする。「毎回あたらしいソロ」にすると、コーラスごとに別のソロが流れる |
| **③ リック辞典** | **950本**。コード1つ（ドミナント・オルタード・リディアン♭7・7sus4・ブルース・maj7・リディアン maj7♯11・m7・m6・m(maj7)・m7♭5・dim7。それぞれに、16分音符・3連符・シンコペーション・付点・間を使った**リズムの濃いリックが10本ずつ**と、1度→5度→オクターブと跳ぶ・3度のジグザグ・進んでは戻る・跳んでからジグザグで降りる、といった**音の動きの形で聞かせるリックが10本ずつ**）、2コード（V→I・ii–V・♭II7→I・バックドア…）、3コード（ii–V–I・ii–V–i・裏コードの ii–V–I・バックドア ii–V）、ターンアラウンド4種。12キー・楽器の移調譜に対応、度数の表示、検索・難しさ・特徴タグでの絞りこみ |
| **④ 音と書き出し** | ミキサー（音量・残響・消音）。**WAV**／**MIDI**（伴奏＋ソロ＋ドラム）／**MusicXML**（ソロ譜。MuseScore などで開ける）／印刷・PDF／コード譜のテキスト／**共有リンク**（コード譜・スタイル・テンポ・ソロの条件・差しかえたリックまで同じに開く） |

共有リンクは、リンクを作った版のソロの作り方で再現されます。ソロの作り方を変えた更新（リズムの濃いリックの追加、跳ぶ・ジグザグのリックと息継ぎの追加）より前に作ったリンクは、コード譜・スタイル・テンポは同じでも、ソロは別のものになります（差しかえたリックは、いまの版でその場所に置けるものだけ引きつぎます）。

## 開き方

- いちばん簡単：公開先 **https://dora9991.github.io/math-dialogue/adlib/** をブラウザで開く（インストール不要）。
- ファイルで持つなら：**`adlib-all-in-one.html`**（全部を1つにまとめたファイル）をダウンロードして、ダブルクリックでブラウザで開く。
- フォルダごとあるとき：`index.html` をブラウザで開く（ビルドもサーバーも不要）。
- サーバーで開くなら：`python3 -m http.server 8788 --directory adlib` → http://localhost:8788/
- スマホ・タブレットの幅に合わせた画面にしてある（iPhone の消音スイッチがオンでも鳴るよう設定してあるが、実機では未確認）。

`adlib-all-in-one.html` は `node adlib/tools/bundle.cjs` で作りなおせる（`js/` や `css/` を直したら実行する。できたファイルは手で直さない）。

## 公開先

https://dora9991.github.io/math-dialogue/adlib/ （GitHub Pages。`gh-pages` ブランチの `adlib/index.html` は、`adlib-all-in-one.html` をそのまま置いたもの）

更新するとき：`node adlib/tools/bundle.cjs` で `adlib-all-in-one.html` を作りなおし、`gh-pages` ブランチの `adlib/index.html` だけを差しかえる（ほかの公開物は変えない）。`npm run deploy` は `gh-pages` を丸ごと入れかえるので、ここでは使わない。

## 伴奏スタイルとノリ

| なかま | スタイル |
|---|---|
| ジャズ | スウィング（4ビート）・2ビート・スウィング・バラード・ジャズワルツ（3/4） |
| ロック・ポップス | ロック（8ビート）・ポップ・バラード（8ビート） |
| ブルース・ソウル | ブルース・シャッフル・スロー・ブルース（12/8）・ソウル／モータウン |
| ファンク・ダンス | ファンク（16ビート）・ヒップホップ（16分シャッフル）・ディスコ（4つ打ち） |
| ラテン・レゲエ | ボサノバ・サンバ・サルサ（ラテン）・レゲエ（ワンドロップ） |

スタイルを選ぶと、合うテンポ・ノリ・楽器（エレキベース、ロックのドラムなど）になる（自分で選びなおした楽器はそのまま）。ソロも、スタイルに合う語彙から作る（ロックならペンタトニック・ブルース寄り。サンバ・サルサでは16分音符を使わない）。

**ノリ**は、スタイルの標準のままでも、自分でも選べる（コード譜のタブとソロのタブの両方にある）。

- **ストレート**：8分音符も16分音符も均等。
- **8分シャッフル**：8分音符の裏拍をうしろにずらす（スウィング、ブルースのシャッフル）。
- **16分シャッフル**：16分音符の裏だけをうしろにずらす。8分音符は動かない（ヒップホップ、ハーフタイム・シャッフル）。
- **強さ**：50〜75%（拍の前半が占める割合）。かるい 57%／ふつう 62%／**3連符 67%**／強い 71%／**付点 75%**（付点8分＋16分の長さ）。

MIDI の書き出しも、同じノリで出る。

## コード譜の書き方

| 書き方 | 意味 |
|---|---|
| `| Dm7 | G7 | Cmaj7 | % |` | 縦線で小節を区切る。`%` は前の小節のくり返し |
| `| Dm7 G7 |` | 1小節に複数のコード（均等に分ける。2つなら2拍ずつ） |
| `| C . . G |` | `.` は前のコードを1拍のばす |
| `|: A :|`、`[1`、`[2` | くり返し記号、1番・2番かっこ |
| `*A` `*B` | セクション名 |
| `N.C.`、`C/E`、`Dm7/G` | ノーコード、スラッシュコード |
| `// メモ` | 行末までコメント |

コード：`Cmaj7 Dm7 G7 G7b9 G7#9 G7#11 G7b13 G7alt Bm7b5 Bo7 C6 Cm6 Cm(maj7) Cmaj7#11 C9 C13 G7sus4 Csus4 Caug F#m7b5` など。縦線がまったく無いときは、1語を1小節として読む。
スタイル「ジャズワルツ」は3拍子（1小節＝3拍）。

## しくみ

```
コード譜の文字 ──chart.js──> 小節・コードの枠 ──analysis.js──> キー・かたまり・役割
                                   │                              │
                          comping.js（伴奏の作曲）         solo.js（リックを選んでつなぐ）← licks*.js（リック辞典）
                                   │                              │
                          synth.js（音の合成）  ←  player.js（スケジュール）   notation.js（楽譜の SVG）
```

- **キー推定**（`analysis.js`）：ダイアトニックへの当てはまり、ドミナント→トニックの終止、ii–V–I、12小節ブルースの型、解決先のない ii–V などを点数にして選ぶ。違うときは「キーの読みかえ」で変えられる。
- **かたまり（パターン）の発見**：ii–V–I、ii–V–i、ii–♭II7–I、バックドア、ターンアラウンド（I–vi–ii–V など）、V→I、♭II7→I…。長いかたまりを優先して敷きつめる。
- **役割**：キー内の働き（ローマ数字・T/SD/D）、パターンの一員、セカンダリー・ドミナント、裏コード、バックドア、偽終止、借用和音、ディミニッシュ、モーダル、ブルース。1つのコードに複数つく。
- **リック辞典**：「C の調で、楽譜を読むように」音名で書いたデータ。読みこむときにコードのルートからの**度数**に直し、どのキーにも**綴りを崩さず**移調する（G7 の ♭9 は A♭、♯9 は A♯）。書き間違いは `test/licks.js`（長さ・音域・とび・スケール外の音・12キーに置いたときの綴り）が見つける。
- **ソロの自動作成**（`solo.js`）：かたまりごとに、長さの合うリックを選び（難しさ・直前の音との近さ・重複を点数に）、前の音に近いオクターブで置く。決めた内容は「フレーズの並び」として持つので、差しかえても他は変わらない。
  - **音の動きの形**：リックごとに、とび（4度より広い音程）の数・向きの変わり目・5音以上つづく階段を数える。階段ばかりのリックは選びにくく、跳ぶ・ジグザグのリックは選びやすくし、同じ型（同じリズムで同じ動き）は1コーラスのなかでくり返さない。
  - **息継ぎ（ブレイク）**：ひとフレーズぶん弾いたら休む。フレーズの長さと休みの長さは「ブレイク（間）」で決まる（少なめ＝9〜16拍弾いて1〜2拍休む／ふつう＝5〜9拍弾いて1〜3拍休む／たっぷり＝3.5〜6.5拍弾いて2〜4拍休む。ときどき、1小節ぶんの大きなブレイク）。最後の長い音は1拍短く切って、そのぶんも間にする。休んだあとは、ii–V–I の途中からでも、V–I などの短いかたまりのリックで入りなおす。
  - 「音の多さ」は、1フレーズのなかの音の数（のばす音の多いリック／16分音符のつまったリック）を選ぶ。
- **伴奏**：ガイドトーン（3度・7度）中心のボイシングを、なめらかに声部がつながるように選ぶ。ウォーキングベースは次のコードのルートへ半音で入る。スタイルごとに、コードの刻み・ベースの型（ルート弾き、ブギー、オクターブ、トゥンバオ…）・ドラムの型（クラーベ、カウベル、コンガなどの打楽器も）を持つ。
- **ノリ**（`player.js`）：楽譜どおりの位置を、再生するときにずらして出す。8分シャッフルは8分の裏、16分シャッフルは16分の裏。3連符は動かさない。8分シャッフルのとき、ソロの16分音符のランがある拍はストレートで弾き、「付点8分＋16分」だけの拍は、16分をシャッフルの裏拍の位置で弾く（スウィングの譜面の読み方と同じ）。伴奏の音は、楽譜どおりの拍の位置（`t`）と、ロール・小さなゆらぎ（`off`）を分けて持ち、ノリを入れたあとで `off` を足す（混ぜると、3連符の刻みがハイハットとずれる）。
- **音**：PeriodicWave・フィルター・FM・Karplus-Strong などによる合成。リバーブとコンプレッサーを通す。
- **楽譜**：自前の SVG 描画（五線・調号・拍子・連桁・3連符・タイ・臨時記号・ヘ音記号・移調譜・コード記号）。音符の形は Bravura の字形。

ソロは、機械学習ではなく、辞典のリックと音楽理論のルールでつないだもの。
「このコードにはこれが弾ける」という**素材と型**を、楽譜と音で示すための道具で、即興そのものの代わりではない。

## リックを足すには

`js/licks-*.js` に、次のように書く（詳しくは `js/licks.js` の冒頭）。

```js
L.pack({ ctx: 'dom7', ref: 'C7', segs: [4], lvl: 1 }, [
  ['ビバップ・スケール下降（根音から）', 'C5 B4 Bb4 A4 G4 F4 E4 D4', '説明文', { tags: ['bebop', 'scale'] }],
  ['3連符のアルペジオ', 'C4:t E4:t G4:t Bb4:t C5:t Bb4:t G4:q E4:q', '説明文', { tags: ['triplet'], lvl: 2 }],
]);
```

音名＋オクターブ（`C4` が真ん中のド）、長さは `:q`（4分）`:h`（2分）`:e`（8分）`:s`（16分）`:t`（3連の8分）`.`（付点）、休符は `r`、小節線は `|`、タイは `~`。`@s`／`@e` は、そのあとの音の既定の長さを16分／8分に切りかえる（16分のランを書くとき）。
書いたら `node adlib/test/licks.js` で検査する（長さの合わない行・スケール外の音・大きすぎるとびを知らせる）。

リックの番号（共有リンクに入る）は、コードの種類ごとに「読みこんだ順」で決まる。番号が動かないよう、既存のファイルの途中には足さず、あとから読みこまれる新しいファイル（`licks-z-*.js`）に足す。

跳ぶ・ジグザグのリック（`js/licks-zz-contour.js`）だけは、手で書かずに `tools/gen-contour.js` が書き出す。「スケールの何番目の音か」で書いた型（1→5→オクターブ、3度のジグザグ、…）を、12種類のコード・スケールの音に当てはめ、名前と解説の度数を音から数えて入れる。どのコードにどの型を使うかは `tools/contour-overrides.js`。型を足したら `node adlib/tools/gen-contour.js list` で候補と検査結果を見て、`node adlib/tools/gen-contour.js` で書き出す（番号が動かないよう、使う型は各コードの最後に足す）。

```

  js/
    theory.js           音楽理論（綴り・度数・コード・スケール・移調）
    chart.js            コード譜の読みとり（小節・くり返し・展開・移調）
    analysis.js         解析（キー・パターン・役割・スケール・フレーズの区切り）
    licks.js            リック辞典のしくみ（記法・検査・検索・移調）
    licks-*.js          リックのデータ（dom／chords／251／turn／waltz／z-rhythm＝リズムの濃いリック／zz-contour＝跳ぶ・ジグザグのリック）
    solo.js             ソロの自動作成・差しかえ

    synth.js player.js  音の合成／再生のスケジュール・ノリ（シャッフル）・WAV 書き出し
    glyphs.js notation.js  楽譜（Bravura の字形・SVG 描画）
    presets.js          サンプルのコード進行（40曲）
    export.js           MIDI・MusicXML
    ui-*.js app.js boot.js  画面
  test/                 検査（下）
  tools/                bundle.cjs（1ファイル化）／gen-contour.js・contour-overrides.js（跳ぶ・ジグザグのリックを作る）／shot-*.js（見た目の確認）／show-licks.js（リックの確認）
```

## 検査

```sh
for t in theory chart analysis licks solo comping presets export fuzz player render; do node adlib/test/$t.js; done
NODE_PATH=$(npm root -g) node adlib/test/audio.js    # 音の検査（ヘッドレス Chromium：音程・音量・ノリ・全スタイルの合成・打楽器）
NODE_PATH=$(npm root -g) node adlib/test/e2e.js      # 画面の操作の検査（再生・ソロの差しかえ・ブレイク・ノリ・スタイル・辞典・書き出し・全サンプル・共有リンク）
```

`e2e.js` は、Playwright と Chromium が要る。`ADLIB_FILE=adlib/adlib-all-in-one.html` をつけると、1ファイル版を検査できる。

`solo.js` の検査は、ソロが破綻しないことに加えて、音の動きの形（とびの割合・向きの変わり目・階段の割合）と、ブレイクの量（鳴っている拍の割合・休みの数・弾きつづける長さ）を、たくさんの曲と乱数の種で数えて確かめる。
