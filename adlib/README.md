# アドリブ・ラボ

**コードを打ちこむ → 伴奏が鳴る → コードの役割がわかる → 合うリックが楽譜と音で出てくる**、アドリブ練習アプリ。
ブラウザだけで動く（インストールもサーバーも不要）。音は、ブラウザの中で合成している（音源ファイルなし）。

## できること

| | |
|---|---|
| **① コード譜** | iReal Pro のように、`| Dm7 | G7 | Cmaj7 | % |` と打つと伴奏（ピアノ・ベース・ドラム）が鳴る。コードパレット、サンプル30曲、キー（まるごと移調）、テンポ、スウィングの深さ、ループ回数（1〜12回・無限）、カウントイン、メトロノーム、範囲くり返し、楽器の切りかえ |
| **コードの役割** | コードをタップすると、そのコードの役割を**いくつでも**読みとって説明する（ii・V・I／ターンアラウンド／セカンダリー・ドミナント／裏コード／バックドア／借用和音／経過のディミニッシュ／モーダル／ブルース…）。合うスケール（音名つき・試聴つき）も出る |
| **リックの提案** | 選んだコード（かたまり）に合うリックを、楽譜つきで提案。▶で伴奏つきで聴けて、「ソロに採用」で差しかえられる |
| **② ソロ** | コード進行を読んで、辞典のリックをつなげたソロを自動で作る。楽譜（コード記号つき）に再生カーソルが走る。楽器（アルト・テナー・トランペット・フルート・クラリネット・トロンボーン・ギター・ピアノ…）ごとの音域と**移調譜**に対応。難しさ・音の多さも選べる（やさしい＝8分音符が中心／ふつう＝3連符・16分音符・シンコペーションが混ざる／むずかしい＝16分のランが多い）。「毎回あたらしいソロ」にすると、コーラスごとに別のソロが流れる |
| **③ リック辞典** | **830本**。コード1つ（ドミナント・オルタード・リディアン♭7・7sus4・ブルース・maj7・リディアン maj7♯11・m7・m6・m(maj7)・m7♭5・dim7。それぞれに、16分音符・3連符・シンコペーション・付点・間を使った**リズムの濃いリックが10本ずつ**）、2コード（V→I・ii–V・♭II7→I・バックドア…）、3コード（ii–V–I・ii–V–i・裏コードの ii–V–I・バックドア ii–V）、ターンアラウンド4種。12キー・楽器の移調譜に対応、度数の表示、検索・難しさ・特徴タグでの絞りこみ |
| **④ 音と書き出し** | ミキサー（音量・残響・消音）。**WAV**／**MIDI**（伴奏＋ソロ＋ドラム）／**MusicXML**（ソロ譜。MuseScore などで開ける）／印刷・PDF／コード譜のテキスト／**共有リンク**（コード譜・スタイル・テンポ・ソロの条件・差しかえたリックまで同じに開く） |

共有リンクは、リンクを作った版のソロの作り方で再現されます。リズムの濃いリックを足した更新より前に作ったリンクは、コード譜・スタイル・テンポは同じでも、ソロは別のものになります（差しかえたリックは、いまの版でその場所に置けるものだけ引きつぎます）。

## 開き方

- いちばん簡単：公開先 **https://dora9991.github.io/math-dialogue/adlib/** をブラウザで開く（インストール不要）。
- ファイルで持つなら：**`adlib-all-in-one.html`**（全部を1つにまとめたファイル）をダウンロードして、ダブルクリックでブラウザで開く。
- フォルダごとあるとき：`index.html` をブラウザで開く（ビルドもサーバーも不要）。
- サーバーで開くなら：`python3 -m http.server 8786 --directory adlib` → http://localhost:8786/
- スマホ・タブレットの幅に合わせた画面にしてある（iPhone の消音スイッチがオンでも鳴るよう設定してあるが、実機では未確認）。

`adlib-all-in-one.html` は `node adlib/tools/bundle.cjs` で作りなおせる（`js/` や `css/` を直したら実行する。できたファイルは手で直さない）。

## 公開先

https://dora9991.github.io/math-dialogue/adlib/ （GitHub Pages。`gh-pages` ブランチの `adlib/index.html` は、`adlib-all-in-one.html` をそのまま置いたもの）

## コード譜の書き方

| 書き方 | 意味 |
|---|---|
| `| Dm7 | G7 | Cmaj7 | % |` | 縦線で小節を区切る。`%` は前の小節のくり返し |
| `| Dm7 G7 |` | 1小節に複数のコード（均等に分ける。2つなら2拍ずつ） |
| `| C . . G |` | `.` は前のコードを1拍のばす |
| `|: A :|`、`[1`、`[2` | くり返し記号、1番・2番かっこ |
| `*A` `*B` | セクション名 |
| `N.C.`、`C/E`、`Dm7/G` | ノーコード、スラッシュコード |
| `// メモ` | 行末までコメント |

コード：`Cmaj7 Dm7 G7 G7b9 G7#9 G7#11 G7b13 G7alt Bm7b5 Bo7 C6 Cm6 Cm(maj7) Cmaj7#11 C9 C13 G7sus4 Csus4 Caug F#m7b5` など。縦線がまったく無いときは、1語を1小節として読む。
スタイル「ジャズワルツ」は3拍子（1小節＝3拍）。

## しくみ

```
コード譜の文字 ──chart.js──> 小節・コードの枠 ──analysis.js──> キー・かたまり・役割
                                   │                              │
                          comping.js（伴奏の作曲）         solo.js（リックを選んでつなぐ）← licks*.js（リック辞典）
                                   │                              │
                          synth.js（音の合成）  ←  player.js（スケジュール）   notation.js（楽譜の SVG）
```

- **キー推定**（`analysis.js`）：ダイアトニックへの当てはまり、ドミナント→トニックの終止、ii–V–I、12小節ブルースの型、解決先のない ii–V などを点数にして選ぶ。違うときは「キーの読みかえ」で変えられる。
- **かたまり（パターン）の発見**：ii–V–I、ii–V–i、ii–♭II7–I、バックドア、ターンアラウンド（I–vi–ii–V など）、V→I、♭II7→I…。長いかたまりを優先して敷きつめる。
- **役割**：キー内の働き（ローマ数字・T/SD/D）、パターンの一員、セカンダリー・ドミナント、裏コード、バックドア、偽終止、借用和音、ディミニッシュ、モーダル、ブルース。1つのコードに複数つく。
- **リック辞典**：「C の調で、楽譜を読むように」音名で書いたデータ。読みこむときにコードのルートからの**度数**に直し、どのキーにも**綴りを崩さず**移調する（G7 の ♭9 は A♭、♯9 は A♯）。書き間違いは `test/licks.js`（長さ・音域・とび・スケール外の音・12キーに置いたときの綴り）が見つける。
- **ソロの自動作成**：かたまりごとに、長さの合うリックを選び（難しさ・直前の音との近さ・重複を点数に）、前の音に近いオクターブで置く。コードが長いときは、リックを何本かつなぐか、間（休符）をとる。決めた内容は「フレーズの並び」として持つので、差しかえても他は変わらない。
- **伴奏**：ガイドトーン（3度・7度）中心のボイシングを、なめらかに声部がつながるように選ぶ。ウォーキングベースは次のコードのルートへ半音で入る。スウィングは再生時に8分音符の裏拍をずらして出す（3連符は動かさない。16分音符を含む拍は、ずらさずにストレートで弾く）。
- **音**：PeriodicWave・フィルター・FM・Karplus-Strong などによる合成。リバーブとコンプレッサーを通す。
- **楽譜**：自前の SVG 描画（五線・調号・拍子・連桁・3連符・タイ・臨時記号・ヘ音記号・移調譜・コード記号）。音符の形は Bravura の字形。

ソロは、機械学習ではなく、辞典のリックと音楽理論のルールでつないだもの。
「このコードにはこれが弾ける」という**素材と型**を、楽譜と音で示すための道具で、即興そのものの代わりではない。

## リックを足すには

`js/licks-*.js` に、次のように書く（詳しくは `js/licks.js` の冒頭）。

```js
L.pack({ ctx: 'dom7', ref: 'C7', segs: [4], lvl: 1 }, [
  ['ビバップ・スケール下降（根音から）', 'C5 B4 Bb4 A4 G4 F4 E4 D4', '説明文', { tags: ['bebop', 'scale'] }],
  ['3連符のアルペジオ', 'C4:t E4:t G4:t Bb4:t C5:t Bb4:t G4:q E4:q', '説明文', { tags: ['triplet'], lvl: 2 }],
]);
```

音名＋オクターブ（`C4` が真ん中のド）、長さは `:q`（4分）`:h`（2分）`:e`（8分）`:s`（16分）`:t`（3連の8分）`.`（付点）、休符は `r`、小節線は `|`、タイは `~`。`@s`／`@e` は、そのあとの音の既定の長さを16分／8分に切りかえる（16分のランを書くとき）。
書いたら `node adlib/test/licks.js` で検査する（長さの合わない行・スケール外の音・大きすぎるとびを知らせる）。

リックの番号（共有リンクに入る）は、コードの種類ごとに「読みこんだ順」で決まる。番号が動かないよう、既存のファイルの途中には足さず、あとから読みこまれる新しいファイル（`licks-z-*.js`）に足す。

## ファイルのならび

```
adlib/
  index.html            画面
  adlib-all-in-one.html 全部を1つにまとめたもの（tools/bundle.cjs で作る）
  css/adlib.css
  js/
    theory.js           音楽理論（綴り・度数・コード・スケール・移調）
    chart.js            コード譜の読みとり（小節・くり返し・展開・移調）
    analysis.js         解析（キー・パターン・役割・スケール・フレーズの区切り）
    licks.js            リック辞典のしくみ（記法・検査・検索・移調）
    licks-*.js          リックのデータ（dom／chords／251／turn／waltz／z-rhythm＝リズムの濃いリック）
    solo.js             ソロの自動作成・差しかえ
    comping.js          伴奏（ボイシング・コンピング・ベース・ドラム）
    synth.js player.js  音の合成／再生のスケジュール・WAV 書き出し
    glyphs.js notation.js  楽譜（Bravura の字形・SVG 描画）
    presets.js          サンプルのコード進行（30曲）
    export.js           MIDI・MusicXML
    ui-*.js app.js boot.js  画面
  test/                 検査（下）
  tools/                bundle.cjs（1ファイル化）／shot-*.js（見た目の確認）／show-licks.js（リックの確認）
```

## 検査

```sh
for t in theory chart analysis licks solo comping presets export fuzz player render; do node adlib/test/$t.js; done
NODE_PATH=$(npm root -g) node adlib/test/audio.js    # 音の検査（ヘッドレス Chromium：音程・音量・スウィング）
NODE_PATH=$(npm root -g) node adlib/test/e2e.js      # 画面の操作の検査（再生・ソロの差しかえ・辞典・書き出し・全サンプル）
```

`e2e.js` は、Playwright と Chromium が要る。`ADLIB_FILE=adlib/adlib-all-in-one.html` をつけると、1ファイル版を検査できる。
