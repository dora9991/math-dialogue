# xserver-hub：Xserver で動く「LINE配信ハブ」と会員連携の土台

会員サイト（ジーニー）と LINE公式アカウントを結んで得た情報を、**自分の Xserver の中に置いて**、
プロライン的な配信（ステップ配信・タグ・絞り込み一斉配信・チャット・アンケート・イベント・動画特典）を動かすための土台です。

- [line-hub](https://github.com/dora9991/line-hub-demo)（Node.js + Postgres）を、**PHP + MariaDB（Xserver の標準）に移したもの**です。
  管理画面（`line-hub-admin.js`）は **1文字も変えずに** そのまま使っています。操作（RPC）の約束ごとも同じです。
- Xserver に常駐プロセスは置けないので、「毎分の cron」と「Webhook を受けたその場」で動きます。
- 個人情報を守るための仕組み（暗号化・二段階認証・操作の記録・バックアップ・本人からの求めへの対応・事故のときの手順）を、最初から組み込んであります。

## できること

| 分野 | 中身 |
|---|---|
| 配信 | ステップ配信（シナリオ）／ルール（キーワード・友だち追加・ポストバック）／絞り込み一斉配信（タグ・属性・会員プラン・友だち情報）／個別チャット／テスト送信 |
| 集める | アンケート（属性・タグに反映）／イベントの申込とリマインド／Zoom の出欠／動画特典 |
| 守る | 月間の通数上限と、会員通知のための取り置き／停止スイッチ／練習モード（送らずに記録だけ）／送信の関所（すべての送信が1か所を通る） |
| 会員連携 | 6桁コードで LINE と会員番号を結ぶ／会員サイトからプラン・項目を受け取る／会員への通知を LINE で届ける（二重に送らない）／連携の解除・退会 |
| 運用 | 毎日の自動バックアップ（暗号化）／毎朝の報告メール／健康診断（`doctor`）／保存期間を過ぎた記録の片づけ／鍵の入れ替え／本人の情報の書き出し・消去 |

## 安全のための仕組み（要点）

- **公開フォルダには入口（`index.php`）と画面の部品だけ**。プログラム・設定・秘密・ログ・バックアップは、公開フォルダの外（`~/hub`）。
- **トーク本文・Webhook の中身・送信内容・メモ・Zoom の名前とメールは、列ごとに暗号化**（AES-256-GCM。鍵は設定ファイル。入れ替えられる）。
- **管理画面は二段階認証が必須**。役割（オーナー／管理者／担当者／閲覧のみ）ごとに、できることを分けています。
- **操作の記録は「鎖」でつないであり、書き換えると気づけます**。個人の情報を「見た」ことも記録します。
- **会員サイトとの通信は、サーバー同士の署名つき**（時刻・使い捨ての nonce・権限・IP の制限）。LINE の userId は会員サイトへ返しません。
- 詳しくは [docs/03_安全管理措置.md](docs/03_安全管理措置.md)（個人情報保護法の安全管理措置との対応表）。

## フォルダの形

```
xserver-hub/
  app/                 プログラム（サーバーでは ~/hub/app。公開しない）
    bin/hub            コマンド（init・migrate・tick・doctor・backup・person:export など）
    migrations/        データベースの形（MariaDB 10.5 以上）
    src/               Kernel（土台）・Line（配信エンジン）・Member（会員連携）・Web（管理画面）・Ops（運用）・Cli
  public/              公開フォルダに置くもの（index.php・.htaccess・画面の部品）
  config/              設定の見本（本物の config.php は、サーバーの ~/hub/config/ にだけ置く）
  clients/             会員サイト側の見本（JS：Supabase Edge Functions／Node、PHP）
  tools/deploy.sh      Xserver に置く・更新する
  tests/               自動テスト（php tests/run.php）
  docs/                手順書
```

## いまの状態

- バージョン 0.1.0。自動テスト 58本（MariaDB 10.11 と 10.5 の両方で通過）。ブラウザでの通し確認（ログイン→二段階認証→全タブ→チャット送信）済み。
- **まだ本物の Xserver では動かしていません**。サーバーごとの違い（PHP・MariaDB のバージョン、WAF、`fastcgi_finish_request` の有無など）は、
  `bin/hub doctor --online` で確かめられるようにしてあります。初回は練習モード（`dry_run`）で始めてください。
