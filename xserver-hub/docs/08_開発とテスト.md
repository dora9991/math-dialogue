# 08 開発とテスト

## 手元で動かす

要るもの：PHP 8.1 以上（`pdo_mysql`・`openssl`・`curl`・`mbstring`。あれば `intl`）、MariaDB 10.5 以上（Xserver に近いのは 10.5 か 10.11）。

```bash
# DB とユーザー（手元専用のパスワード）
sudo mysql -e "CREATE DATABASE hub_dev CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'hub'@'localhost' IDENTIFIED BY 'hub-local-dev-only';
  GRANT ALL ON hub_dev.* TO 'hub'@'localhost';"

# 設定（リポジトリの外に置く）
cp config/config.example.php ~/hub-dev-config.php
#   app.base_url = 'http://127.0.0.1:8080'、app.env = 'development'、db を上の値に、
#   keys は php app/bin/hub keys:generate で4つ作って入れる、alert.dry_run = true（メールを送らない）
export HUB_CONFIG=~/hub-dev-config.php

php app/bin/hub migrate
php app/bin/hub admin:create-owner you@example.test
php -S 127.0.0.1:8080 -t public tools/dev-router.php     # → http://127.0.0.1:8080/admin/login
```

- `app.env` が `production` 以外のときは、https の強制・ホスト名の確認・`__Host-` クッキーを緩めます（手元の http で動かすため）。**本番は必ず `production`**
- LINE につながずに試すときは、`config.php` に `'line' => ['api_base' => 'http://127.0.0.1:9090', …]` を入れて、模擬の LINE サーバーに向けます（line-hub の `dev/mock-line-core.js` を HTTP で包めば作れます）
- 毎分の処理は、手で `php app/bin/hub tick --verbose`

## テスト

```bash
# テスト用の DB（中身は毎回消える。本番の DB を指さないこと）
sudo mysql -e "CREATE DATABASE hub_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  GRANT ALL ON hub_test.* TO 'hub'@'localhost';"

php tests/run.php            # 全部
php tests/run.php Member     # ファイル名の一部で絞る
```

接続先は環境変数で変えられます：`HUB_TEST_DB_HOST`・`HUB_TEST_DB_PORT`・`HUB_TEST_DB_NAME`・`HUB_TEST_DB_USER`・`HUB_TEST_DB_PASS`。

MariaDB 10.5（古い Xserver に近い）でも確かめるとき：

```bash
docker run -d --name mdb105 -p 127.0.0.1:3307:3306 -e MARIADB_ROOT_PASSWORD=root-local-only mariadb:10.5
docker exec mdb105 mariadb -uroot -proot-local-only -e "CREATE DATABASE hub_test CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
  CREATE USER 'hub'@'%' IDENTIFIED BY 'hub-local-dev-only'; GRANT ALL ON hub_test.* TO 'hub'@'%';"
HUB_TEST_DB_PORT=3307 php tests/run.php
```

| ファイル | 確かめていること |
|---|---|
| `EngineTest.php` | 配信エンジン：友だち追加・同じイベントの二重処理・Webhook の署名・キーワード・送信の関所（停止・練習モード・上限・429/5xx のやり直し）・ステップ配信・一斉配信・チャット（返信とプッシュ）・アンケート・動画特典・イベント・日程ボタン・失敗したイベントのやり直し |
| `SecurityTest.php` | 暗号化（列のすり替え・改ざん・古い鍵）・二段階認証（RFC 6238）・パスワード・操作の記録の鎖・回数制限と貸出・日本時間の計算・SQL の区切り・ログの伏せ字 |
| `WebTest.php` | 管理画面：ログイン・二段階認証・回復コード・セッション・CSRF・権限・本番の設定（ホスト名・https・`__Host-`） |
| `MemberTest.php` | 会員連携：署名つき API・連携コード・通知（二重にしない）・解除・退会・会員サイトへの知らせ |
| `RpcTest.php` | 管理画面の操作：権限の表・入力の検証・閲覧の記録・運営メンバー・ひな形 |
| `OpsTest.php` | 運用：バックアップと復元・本人の情報の書き出しと消去・鍵の入れ替え・毎日の仕事・メンテナンス中・取り込み・健康診断 |
| `ZoomTest.php` | Zoom の出欠：URL の確認・署名・入退室（名前とメールは暗号化）・確定（参加／欠席のタグ）・結びつけ・消去 |
| `ClientsTest.php` | 会員サイト用の見本（PHP・JS）が、ハブと同じ署名を作り、知らせを確かめられる（JS は node があれば） |

LINE は `FakeLine`（`app/src/Line/FakeLine.php`）に置き換えて、ネットワークなしで動かします。時計も `Clock` で進められます（「31分後に期限切れ」などを待たずに確かめる）。

### line-hub 側が変わったら

- 管理画面：`line-hub-admin.js` をそのまま写す。`RpcTest` が「管理画面が呼ぶ操作が全部あるか」を確かめます
- ひな形：`node tools/export-templates.mjs <line-hub の src> > app/data/templates.json`
- エンジンの振る舞い：対応する `.php` を直し、`EngineTest` に同じ場面を足す

## DB の書き方の決まり（MariaDB 10.5 で動かすため）

- 使わない：`SKIP LOCKED`・`UPDATE … RETURNING`・`JSON_TABLE`・`LATERAL`（10.6 以降）
- 時刻は `DATETIME(3)` の UTC。日本時間への読み替えは PHP で
- 文字数は `CHAR_LENGTH`（`LENGTH` はバイト数）
- 二重に入れない：`INSERT … ON DUPLICATE KEY UPDATE id = id`（影響行数 1 なら新しく入った）
- 同じ処理を重ねない：`hub_locks` のリース（`Kernel/Lease.php`）
- 表を変えるときは、`app/migrations/` に新しい番号のファイルを足す（流したものは書き換えない）

## Xserver に置いて確かめる（手元で）

`tools/deploy.sh` は `HOME` を変えれば、手元でも Xserver と同じ形に置けます。

```bash
HOME=/tmp/fakehome bash tools/deploy.sh --public-dir=/tmp/fakehome/example.com/public_html/hub
```
