# 07 データ台帳

ハブが持つ情報の一覧です。「何を・どこに・どう守って・いつまで」。
**🔒 暗号化**＝列ごとに AES-256-GCM（鍵は `config.php`。DB だけが持ち出されても読めない）。**#️⃣ 指紋**＝HMAC（元に戻せない）。

## LINE の友だち

| 情報 | 表（列） | 守り | いつまで | 備考 |
|---|---|---|---|---|
| userId・表示名・アイコンの URL・言語・友だち／ブロック | `line_friends` | 平文 | 消去の求めまで | 一覧・検索・絞り込みに使う |
| 会員番号・プラン・ランク | `line_friends.member_*` | 平文 | 連携の解除・退会まで | 絞り込みに使う |
| 運営のメモ | `line_friends.note` | 🔒 | 消去の求めまで | |
| タグ・属性（タグの種類） | `line_tags`・`line_friend_tags`・`line_tag_groups` | 平文 | 消去の求めまで | **人に知られたくない情報を入れない** |
| 友だち情報（項目と値。会員サイトの `member.*` も） | `line_friend_fields` | 平文 | 消去の求め・連携の解除まで | 同上 |
| トーク（受け取った・送った本文、要約） | `line_message_log`（`text_preview`・`body`・`messages`） | 🔒 | **365日**（`chat_retention_days`） | 管理画面で開くと「閲覧の記録」に残る |
| 受け取った Webhook の中身 | `line_events.payload` | 🔒 | **30日**（`log_retention_days`） | 二重処理の防止とやり直しのため |
| 送信の中身・宛先 | `line_outbox`（`messages` は 🔒、`to_user_ids` は平文） | 一部 🔒 | 送り終わってから **365日** | 一斉配信は500人ずつの行 |
| チャットの状態（未読・返信の鍵） | `line_chat_state` | 平文 | 友だちの間 | 返信の鍵（reply token）は短い期限のみ有効 |
| アンケートの回答 | `line_survey_responses.answers` | 平文 | 消去の求めまで | 属性・タグに反映するため。**自由記述で機微な情報を聞かない** |
| イベントの申込 | `line_event_participants` | 平文 | 消去の求めまで | |
| ステップ配信の登録 | `line_enrollments`・`line_enrollment_steps` | 平文 | 消去の求めまで | |
| 動画特典の視聴 | `line_video_views` | 平文 | 消去の求めまで | |
| Zoom の出欠（参加者の名前・メール） | `line_zoom_log`・`line_event_attendance`（`user_name`・`email`） | 🔒 | 消去の求めまで | |
| Zoom の名前と LINE の結びつけ | `line_zoom_aliases.alias_key` | #️⃣ | 消去の求めまで | |
| 今月の通数 | `line_usage` | 個人を含まない | | |

## 会員サイトとの連携

| 情報 | 表（列） | 守り | いつまで | 備考 |
|---|---|---|---|---|
| 会員番号・プラン・ランク・項目（fields） | `hub_members` | 平文 | 退会（`DELETE /api/v1/members/…`）まで | 会員サイトから送られたもの |
| 連携コード | `hub_link_codes.code_hash` | #️⃣ | 使ったら30日・使わなければ期限の1日後 | コードそのものは持たない。`used_by` に LINE の userId |
| 会員サイトへの知らせ | `hub_site_events`（会員番号と時刻） | 平文 | 届いてから30日 | |
| API の使い捨て nonce | `hub_api_nonces` | 個人を含まない | 約11分 | 使い回しの防止 |

会員サイトへ送るのは、**会員番号と「連携できた時刻」だけ**です（LINE の userId・表示名・トークは送らない）。

| `deploy.env`（公開フォルダの場所） | 600 |

## もし DB だけが持ち出されたら

- 🔒 の列（トーク・Webhook の中身・送信の中身・メモ・Zoom の名前とメール・二段階認証の秘密）は、**鍵が無ければ読めません**
- 平文の列（userId・表示名・タグ・友だち情報・アンケートの回答・会員番号・プラン・運営のメール）は読めます → それを前提に「何を平文に置くか」を決めています（機微な情報を入れない）
- `config.php` も一緒に持ち出されたら、すべて読めると考えます（[05](05_事故が起きたら.md) の B）
