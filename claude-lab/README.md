# Claudeラボ（claude-lab）

Claudeの使い方を、**使いながら学ぶ**練習場。段階（レベル）ごとに、指示に「材料」を少しずつ足して送り、**どんな結果が返ってくるか**を見くらべる。

- 個人が作った**非公式**の学習ツール。Anthropic社の公式教材ではない。
- 画面に出る「結果」は、**あらかじめ用意した見本**（`data/` に手で書いたもの）。本物のClaudeを呼び出してはいない。実際のClaudeは、同じ指示でも毎回少しちがう答えを返す。見本は、傾向をつかむためのもので、実際の応答の記録ではない。
- そのかわり、各ミッションの最後に、指示をコピーして**本物のClaudeで試す**ための欄がある。ここが「使いながら学ぶ」の本番。
- ビルド不要・依存なし。`index.html` をそのまま開いても動く。進み具合・メモは、そのブラウザの中（localStorage）にだけ保存する。

## 開き方

```bash
python3 -m http.server 8793 --directory claude-lab
```

→ http://127.0.0.1:8793/

## いまあるもの

| レベル | ミッション | 内容 |
|---|---|---|
| 1 話しかける | 1-1 | ざっくり質問を、学年・好み・条件を足して具体的にする |
| 2 指示を具体的にする | 2-1 | 「誰に・何のために・どんな形で」（お知らせ文） |
| | 2-2 | 説明しにくい“らしさ”は、見本を見せて伝える（振り返りへのコメント） |
| 3 材料を渡す | 3-1 | 走り書きのメモを議事録にする。整えるほど消える「あいまいさ」に気づく |
| 4 対話で磨く | 4-1 | 返事を下書きと考え、ひとことで直す（やわらかく・短く・別案・ここだけ・理由） |
| 5〜7 | — | 準備中（役割と形式／ためておく・道具にする／任せる） |

## 作りの考え方

- **中身（`data/`）と画面（`js/` `css/`）を分ける。** レッスンを足すのは、`data/` にファイルを1つ置くだけ。他の先生が、自分の現場の場面（学級通信、保護者対応、教材づくり…）を持ち寄って足せるようにするため。
- **どのミッションも「指示を足す → 結果が変わる」を、手を動かして見る。** 読むだけのページにしない。

## レッスンを足す

1. `data/` に `lvN_名前.js` を作る（`lv1_hanasu.js` が見本）。
2. `index.html` の `<script src="data/…">` に1行足す。

レベルは `window.CLAB_LEVELS` に `push` する。ミッションの形は2種類。

### `type: "ladder"`（材料を足していく）

```js
{
  id: "2-1",                       // URLにも使う（#/m/2-1）
  title: "…", scene: "…",
  type: "ladder",
  base:  { label: "ざっくり", text: "最初の指示", result: "その結果（見本）", tip: "気づき" },
  steps: [                          // 順番に足していく材料。k個目まで足した指示が、k個目の結果に対応する
    { label: "ボタンの名前", add: "指示に足す文", result: "その結果", tip: "何が変わったか" },
  ],
  tryIt:   { intro: "本物で試すときの案内", caution: "個人情報などの注意（任意）" },
  reflect: "ふりかえりの問い",
}
```

- メモや文章を貼りつける場面は、ミッションに `material: { label, text }` を持たせ、貼りつけたい材料に `attach: true` を付ける。
- `steps` の順番が大事。材料は「ここまで足す」という累積で、飛ばして足すことはできない（見本の結果が、足した順に対応しているため）。

### `type: "followups"`（下書きに、ひとことを送る）

```js
{
  id: "4-1", title: "…", scene: "…",
  type: "followups",
  baseFrom: "2-1",                  // 別ミッションの完成形を、最初の下書きとして借りる（base を直接書いてもよい）
  steps: [ { label: "…", text: "追加のひとこと", result: "…", tip: "…" } ],
  tryIt: { intro: "…", copy: "本物で試すときにコピーさせたい文（任意）" },
}
```

### 見本を書くときの約束

- 結果は、実際のClaudeが返しそうな**傾向**に沿って書く。うまくいきすぎる見本にしない（3-1 のように、整えるほどあいまいさが消える落とし穴も、ちゃんと見せる）。
- 渡していない事実（日付・人名・数字）を、結果の中で勝手に増やさない。
- 実在の生徒・保護者の名前や、個人が特定できる内容を入れない。

## これから

- 見本ではなく、**本物のClaudeの応答**を出す「ライブ」モード。APIキーを持つ中継サーバーが要る（このリポジトリの `scripts/teacher-server.mjs` と同じ考え方）。公開サイトには、キーを置かない。
- Lv.5〜7 のミッション。
- 見本を、実際のClaudeで取り直した記録に差しかえる。
