# つくるナビ（tsukuru-navi）

「作りたいものはあるけど、Claudeにどう頼めばいいかわからない」「何から勉強すればいいかわからない」人のための、指示書づくりの道具。
質問に答えたり、例を押したりすると、Claudeにそのまま渡せる指示文ができる。1枚のHTMLで、インストールもログインもいらない。

## 画面

| タブ | できること |
|---|---|
| つくる | ジャンル（サイト／ゲーム／教材／業務・校務／まだぼんやり）を選び、例を押すか問1〜問12に答えると、右に指示書ができる。頼み方は4つ：**作ってもらう／まず質問してもらう／設計図だけ／学び方を聞く** |
| 育てる | できたものを直すための指示。「今は → こうしてほしい → 理由」の3点で組み立てる。実際にこのリポジトリで出した指示（座席ルーレットの指定席、キーボードのパネル化、Lv1000以降の1.5倍など）を例として入れてある |
| まなぶ | 最初の4歩、claude.ai と Claude Code の使い分け、ジャンル別の「知っておくと指示が伝わることば」。ことばごとに「Claudeに聞く」で例え話の説明を開ける |
| 指示ノート | うまくいった指示を保存。「すべてコピー」で同僚に渡せる |

## Claudeとのつなぎ方

- 「Claudeで開く」は `https://claude.ai/new?q=<指示文>` を開く（指示文が入った状態で始まる）。同時にクリップボードにもコピーする。
- URLが8000文字をこえるときは、コピーだけして `https://claude.ai/new` を開き、貼りつけてもらう（長いURLは途中で切れることがあるため）。
- 「まだぼんやり」を選ぶと、頼み方が「まず質問してもらう」に切りかわる。Claudeが1問ずつ選択肢つきで質問し、最後に指示書と学ぶとよいこと3つをまとめる流れ。

## 例のデータ

`index.html` の中の `EXAMPLES`（つくる）と `GROW_EXAMPLES`（育てる）。`real: true` のものは、このリポジトリで実際にClaudeと作ったもの（感想ひろば・授業ナビ・数学ラボ・メカバトル・小テスト・数式キーボード・座席ルーレットなど）。
例を足すときは、同じ形のオブジェクトを1つ足すだけでよい。

## 開き方

`index.html` をダブルクリックで開けば動く。公開は他のツールと同じく `npm run deploy`（`public/` の中身がそのまま GitHub Pages に出る）→ `/math-dialogue/tsukuru-navi/`。

入力した内容と指示ノートは、そのブラウザの localStorage にだけ保存される。外部に送るのは「Claudeで開く」を押したときの claude.ai だけ。
