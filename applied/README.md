# 応用チャレンジ（1年 4章 比例と反比例）

ワークシートの各めあてに対応した「入試・実力レベルの応用問題」に、QR コードから挑戦できるツール。
既存の小テストツール（`../quiz/`）と同じ土台で、Supabase は数学ラボ2プロジェクトに `applied_` 接頭辞で相乗りしている。

## 画面

| ファイル | 役割 |
|---|---|
| `index.html` | **めあて一覧＋QR**。先生が投影する。めあてをクリックすると、その内容の応用問題（`challenge.html?set=…`）へ飛ぶ QR コードが出る。 |
| `challenge.html` | **生徒の応用チャレンジ**。`?set=M1-04-3` で単元を指定。学籍番号を選び、記述式で解答 → 提出すると答え合わせ＋解説。何度でも挑戦できる。 |
| `teacher.html` | **先生用ダッシュボード**。PIN ログイン。セット別／**問題別（間違い情報）**／生徒別。誰がどの問題で何を書いて間違えたかが一覧できる。Excel 出力あり。 |

## データ

- `problems.js` … 8 セット（ワークシート 4章1〜8限目）× 各 5〜10 問。
  出典は `pipeline/p_pr/contents.jsonl`（比例・反比例 150 問）から入試寄りのものを引用＋不足分は自作。
- `engine.js` … 数式パーサ＋採点＋方眼SVG（`quiz/quizdata.js` から抽出）。表記ゆれ（`2/5` と `0.4`、`y=3x` と `3x` など）を同値判定する。
- `vendor/qrcode.js` … QR 生成（qrcode-generator 1.4.4, MIT）。

## セットアップ

1. **config.js** … `SUPABASE_URL` と `SUPABASE_ANON_KEY` を設定（数学ラボ2の publishable キー。quiz ツールと同一で設定済み）。
2. **schema.sql** … Supabase の SQL Editor に貼って Run。`applied_attempts` / `applied_attempt_rows` / `applied_settings` と RPC が作られる。
   - 既存の `quiz_*` / `attempts` / `feedback` 等とは衝突しない。
3. **教師 PIN** … 初期値は `0000`。変更は SQL Editor で
   `select applied_set_pin('0000', '新しいPIN');`（4〜8桁の数字）。

## 設計メモ

- 小テスト（`quiz/`）との違い：**配布 ON/OFF ゲートなし**（QR を読めばいつでも挑戦可）、**1日1回制限なし**（何度でも挑戦でき、そのつど記録 → 伸びを追える）。
- 採点はブラウザ内（数式パーサはサーバー移植が非現実的なため）。サーバーは提出結果だけを保存する。
- 個人情報は保存しない（学籍番号＝4桁の数字のみ）。RLS 有効＋ポリシーなし＝直接アクセス全拒否、`security definer` RPC のみ。
