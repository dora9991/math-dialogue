# バスケ育成チャット（basket-coach）

困っていること・うまくなりたいことを**ことばで書くと**、
**考えられる原因 → 改善の視点（見るポイント）→ 練習メニュー → 関係する戦術 → 手元の解説動画**が出るアプリ。
「60分の練習メニューを作って」と書くと、練習プランも組む。

- 困りごと **79**・改善の視点 **87**・練習メニュー **107**・戦術 **53**（作戦図つき）。すべて id でつながっている
- **手元の動画フォルダとつなぐ**と、フォルダ名・ファイル名から、困りごと・視点・練習・戦術に**自動で紐付け**、チャットの答えに出る。手で直すこともできる
- インストール不要・ビルド不要。**動画も会話も、その端末の中だけで扱い、どこにも送らない**
- 作りはじめ：2026-10-24

## 開き方

| どこで | どうする |
|---|---|
| 手元のパソコン（おすすめ） | `basket-coach-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り。インターネットにつながっていなくても動く。字の形だけ、つながっているときにきれいになる） |
| フォルダごと | `index.html` をブラウザで開く |
| Claude の Artifact | `node tools/bundle.cjs --artifact` でできる `dist/artifact.html` を公開する（動画の再生は、Artifact の中ではできないことがある） |

GitHub では、`basket-coach-all-in-one.html` を開いて、右上の「Download raw file」（↓のボタン）で保存できる。
**動画フォルダとつなぐなら、パソコンの Chrome か Edge** がいちばん使いやすい（次からは1回押すだけでつながる）。

## 使い方

### チャット
- 下の欄に、困っていることを書いて送る（例：「試合になるとシュートが入らない」「ゾーンをされると攻め方がわからない」「うまい子とはじめての子の差が大きい」）
- 答えに出るもの：受け止めのひとこと・考え方 → **絞りこむ問い**（大きな困りごとだけ。押すと、もっと近い困りごとへ）→ **考えられる原因**と確かめ方 → **改善の視点** → **おすすめの練習メニュー**（条件に合うものから）→ 関係する戦術 → **動画** → ひとこと
- 「**この内容で練習プランを作る**」を押すと、その困りごとを中心に 60 分のプランを組む。時間（30〜120分）と人数（ひとり・2〜4人・チーム）は、その場で切りかえられる。「テキストでコピー」で LINE などに貼れる
- 文に「ひとりで」「家で」「ミニバス」「中学」「30分」などを書くと、その回だけ条件が変わる（例：「家でひとりで30分の練習メニューを作って」）
- 右上の「**条件**」で、ふだんの条件（選手か指導者か・レベル・人数）を決めておける
- 練習・視点・戦術を押すと、中身のシートが開く（手順・ポイント・よくある失敗と直し方・やさしく／むずかしく・作戦図・動画）。☆ でお気に入り

### 図鑑
困りごと・改善の視点・練習メニュー・戦術を、テーマ（16）ごとに一覧で。ことばで探せる。★ お気に入りもここ。

### 動画（手元のフォルダとの紐付け）
1. 「動画」のタブ →「**動画フォルダを選ぶ**」→ 解説動画の入ったフォルダを選ぶ（サブフォルダの中も探す）
2. フォルダ名とファイル名に、困りごと・視点・練習・戦術の**名前か別名**が入っていると、自動で紐付く。テーマの言葉（シュート・ドリブル・リバウンドなど）だけなら「同じテーマ」として出る
   - `シュート/フォームシューティングの基本.mp4` → 練習「フォームシューティング」
   - `練習メニュー/マイカンドリル 左右交互.mov` → 練習「マイカンドリル」
   - `戦術/ピック&ロール 解説.mp4` → 戦術「ピック＆ロール」
   - `2-3ゾーン攻略.mp4` → 戦術「2-3ゾーン」
3. 合わないものは、動画を開いて「**紐付けを直す**」で外す・足す。練習や戦術のシートの「この〇〇に動画を紐付ける」からもできる
4. 手で直した紐付けは、その端末のブラウザに残る。「書き出す」→ 動画フォルダのいちばん上に **`basket-coach-links.json`** という名前で置くと、どの端末でもフォルダをつないだときに自動で読みこむ（Chrome・Edge なら「動画フォルダに保存」で直接書ける）
5. YouTube などの **URL の動画**も、題名つきで足せる（題名で自動の紐付け）

| ブラウザ | フォルダ |
|---|---|
| パソコンの Chrome・Edge | 「前のフォルダにつなぐ」で、次から1回でつながる |
| そのほか（Safari・Firefox） | ページを開くたびにフォルダを選ぶ |
| スマホ | 「動画ファイルを選ぶ」で、動画を何本か選ぶ |

再生できるのは、ブラウザが読める形式（MP4・MOV（H.264）・WebM など）。AVI・WMV などは一覧には出るが、再生できないことがある。

## データ

| 種類 | 数 | ファイル | 中身 |
|---|---|---|---|
| 困りごと（`i-`） | 79 | `data/issues-player.js`・`data/issues-team.js` | ことば（言いかえ）・受け止め・考え方・絞りこむ問い・原因と確かめ方・視点・練習・戦術・ひとこと |
| 改善の視点（`v-`） | 87 | `data/views-skills.js`・`data/views-team.js` | なぜ大事か・見るポイント（チェックリスト）・うまくいっている状態・よくある崩れと直し方・合言葉・練習 |
| 練習メニュー（`d-`） | 107 | `data/drills-*.js`（4つ） | ねらい・人数・時間・場所・レベル・きつさ・準備・進め方・ポイント・よくある失敗・やさしく／むずかしく・図 |
| 戦術（`t-`） | 53 | `data/tactics-offense.js`・`data/tactics-defense.js` | 動き方・ポイント・強み／弱み・されたときの対策・注意（ルール）・作戦図（場面を ◀ ▶ で進める） |

テーマ（技能）は 16：シュート・フィニッシュ・ドリブル・パス／キャッチ・フットワーク・1対1の攻め・オフボール・リバウンド・1対1の守り・チームの守り・トランジション・チームの攻め・判断・からだづくり・メンタル・指導／チームづくり（`data/skills.js`）。

## データの足し方・直し方

- データの形は **`js/core.js` の先頭のコメント**がすべて。項目の一覧（id と名前と書くファイル）は `tools/registry.cjs`
- 足すときは、`tools/registry.cjs` に id と名前を足してから、そのファイルに書く。ほかの項目は id で指す（`drills: ['d-mikan']` など）
- `alias` は**そのものを指す名前だけ**（動画のファイル名と照らすので、「シュート」のような広い言葉は入れない）。`words` はチャットの文に出そうな言葉のかけら（動詞は「取られ」「外し」のように語尾を落とすと、活用がちがっても当たる）
- 作戦図は、場所の名前（`top`・`lw`・`re`・`rim` など、`BC.spots`）か `[x, y]`（m。ゴールが上、エンドラインが y=0、ハーフラインが 14）。場面（`frames`）ごとに人の位置と動き（`pass`・`cut`・`dribble`・`screen`・`handoff`・`move`）を書く。コーンは `cones`

```js
BC.drill({
  id: 'd-mikan', name: 'マイカンドリル', alias: ['マイカン', 'Mikan Drill'], words: ['ゴール下', '左右交互'],
  skills: ['finish', 'foot'], level: 1, n: 1, minutes: 5, phase: 'warmup', intensity: 2, place: 'hoop',
  aim: 'ゴール下で左右の手を交互に使い、…', steps: ['…'], points: ['…'], ng: [['失敗', '直し方']],
  easier: ['…'], harder: ['…'], views: ['v-fin-hand'], tactics: [],
});
```

## 検査

```bash
node tools/check.cjs                       # データ：id・項目名・つながり・値・作戦図。どこからも指されていない練習・視点も出す
node tools/talk.cjs                        # チャット：困りごとの言いかえ文から、意図した困りごとが1位になるか
NODE_PATH=$(npm root -g) node tools/look.cjs [HTML] [--videos=動画のフォルダ]
                                           # ブラウザ：全項目のシート・作戦図・スマホの幅・チャット・練習プラン・図鑑・動画の紐付け・画像（tools/_out/）
node tools/bundle.cjs                      # 1ファイル版（basket-coach-all-in-one.html）を作り直す
```

`look.cjs` は playwright を使う。playwright でフォルダを渡すとき、いちばん上のフォルダの名前が日本語だと渡せない（playwright の制約）。中のフォルダ・ファイルの名前は日本語でよい。

## 作り方と、まだのこと

- 文章は、作者の方針と指示のもとで、AI（Claude）を使って書いた。一般に知られている練習法・戦術の考え方をもとに新しく書いたもので、特定の本や動画の文章を写したものではない。
- ルールの数字（3秒・8秒・24秒など）は確かなものだけを書き、日本の大会に関わるもの（U12・U15 のマンツーマン推進＝ゾーンの禁止、ミニバスの用具など）には「大会の要項・最新のルールを確認」を添えた。
- からだ・ケガ・心の項目は、一般的な注意にとどめている。**痛みが続く・腫れ・しびれは医療機関へ**。
- チャットは、ことばの一致と近さで困りごとを選ぶしくみ（AI ではない）。うまく選ばれないときは、テーマのボタンか図鑑から探せる。言いかえを足すときは、困りごとの `alias`・`words` に足して `node tools/talk.cjs` で確かめる。
- **まだのこと**：指導者（作者・クラブのコーチ）による全体の読み直し、実際の練習での試用、作戦図の細かい位置の確認。まちがいや、チームに合わないところが残っているかもしれない。
