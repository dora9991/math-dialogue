# バスケ・グロウ（basket-coach）

**小学生・中学生が、自分で使って上達していく**ためのバスケットボールのアプリ。
毎日の「きょうのメニュー」をこなすと経験値がたまってレベルが上がり、動画で自分の動きをチェックでき、ケガをしたときの手当てとテーピングも見られる。
クラブで使うと、**コーチがつくった級（10級〜1級）にチャレンジ**して、写真をつけて送り、コーチから合格と「8級 認定」などを返してもらえる。がんばったことは、クラブの「ひろば」で見せあって いいね できる。

- **ホーム**：きょうのメニュー（10〜30分。目標と練習する場所・人数から毎日自動で組む）→ タイマーで進めて「できた・まあまあ・むずかしかった」を記録。なやみを書いてさがす。今週の練習した日・つづけた日数
- **れんしゅう**：わざ（16）ごとに、体のある人のアニメーション・ここがポイント（合言葉）・なやみ・練習メニュー。練習プランをつくる・ずかん
- **クラブ**：コーチが **級と課題・回数** を自由につくる → 子どもが練習して、できた数と写真を送る → コーチが見て「合格／もう少し」とひとこと → 級の課題がそろったら、コーチが「8級 認定」などを返す。クラブの **ひろば** で、がんばったことを見せあって スタンプ（いいね など）
- **チェック（動画分析）**：スマホでとった動画を、この端末の中の AI（MediaPipe）が調べる
  - **じぶんの動き**：シュート（しずみこみ・セットのひじ・腕ののび・フォロースルー・まっすぐ跳べているか・はなすタイミング）／ドリブル（腰の低さ・顔が上がっているか・頭の高さ・ボールの高さ・回数）／ディフェンス（腰の低さ・足の幅・足の交差・頭のはね）／着地（ひざで吸収・ひざが内に入らないか・体のかたむき）を ◎○△ で
  - **チームの動き**：コートの4点をタップ → 人を見つけてコートの上の位置に → ユニフォームの色でチーム分け → 広がり・ペイントの人数・コーナーの使い方・だんご・守りのまとまり
- **きろく**：レベル・経験値・練習した日のカレンダー・わざごとの星・バッジ（20）・動画チェックの結果・さいきんの練習
- **もっと**（右上のボタン）：コーチにそうだん（チャット）・ずかん・**ケガ・テーピング**（14のケガの手当て・4つのテーピングを図で1ステップずつ）・せってい・おとなの方へ
- 困りごと **79**・見るポイント **87**・練習メニュー **108**・戦術 **53**・人の動き **45**・ケガ **14**・テーピング **4**
- インストール不要・ビルド不要。**記録も動画も、その端末の中だけで扱う。動画は どこにも送らない**（AI の部品とフォントだけ、インターネットから読みこむ）。**クラブを使うときだけ**、提出した数・写真・ひとことと ひろばの投稿を、クラブのサーバー（Supabase）に送る
- 公開ページ：**https://dora9991.github.io/math-dialogue/basket-coach/** （更新は `node tools/publish-pages.cjs`。gh-pages の `basket-coach/index.html` だけを差し替え、ほかの公開物には触らない）

- ほかのアプリから、ずかんの検索を開ける：`https://dora9991.github.io/math-dialogue/basket-coach/#q/ことば`（例：`#q/ヘルプ`。[バスケ得点クリップ](https://dora9991.github.io/math-dialogue/basket-clips/)のコメント帳の「📘 バスケ・グロウ」から使う。はじめての人は、先にプロフィールを聞く）

## 使い方

### きょうのメニューと、成長
- ホームの「きょうのメニュー」：目標のわざを日がわりで中心にして、じゅんび → メイン → ゲーム →（20分以上なら）ストレッチ を組む。「ほかのメニュー」で組みなおす
- 「▶ スタート」でタイマー（残り時間・アニメーション・ポイント・やりかた・つぎ）。時間になると音とバイブで知らせて、次へ。おわったら顔のボタンで記録し、ひとことメモも残せる
- 練習メニューのページの「✓ やった！」でも記録できる（何分やったか・できた度合い）。見るポイントのチェックリストをぜんぶ ✓ にしても少し経験値
- 経験値（XP）：練習メニュー 6〜30（時間とできた度合い）・きょうのメニューをやりきる 20・動画チェック 15・見るポイント 5。レベル n に必要な合計は 25×n×(n−1)（50・150・300・500…）。呼び名は ルーキー → ジュニア → レギュラー → エース → キャプテン → レジェンド
- バッジ：はじめの一歩・3日／1週間／30日れんぞく・10回／50回・いろいろ10しゅるい・300分・ビデオ・アナリスト・◎5こ・シューター・ドリブラー・ディフェンダー・オールラウンダー・朝れん・レギュラー・エース
- 点数や順位で他の人とくらべる機能はない（自分の成長だけを見る）。クラブの合格は +10・級の認定は +50（バッジ「はじめての級」「5つの級」）

### クラブ（級・写真の提出・ひろば）
- **はじめかた（コーチ）**：「クラブ」→「クラブを つくる」（クラブの名前・自分の名前・コーチの合言葉）→ 6文字の **クラブコード** ができる。ほかのコーチは、クラブコード＋合言葉＋自分の名前でログインする（10人まで）
- **子どものアカウント**：コーチが「メンバー」でニックネームと学年を入れると、**ばんごう** と **6けたの あいことば** ができる →「ログインカード」を印刷して配る（メールアドレスは いらない）。あいことばを忘れたら、コーチが作り直す
- **級をつくる**：はじめは 10級〜1級（各4つの課題）のひな形。級の名前・色と、課題（練習メニューとつなげる・回数・単位・「連続」「10本中」「以内」など・やりかた・写真が 必要／あれば／なし）を、コーチが自由に変える（回数は ± で）
- **子ども**：いまの級の課題 → 練習して、できた数・写真・ひとこと（動画チェックの結果もつけられる）を送る → コーチの「合格」「もう少し」と ひとことが届く → 級の課題がぜんぶ合格すると、コーチが **級を認定**（お祝いの画面）
- **コーチ**：「確認」で写真を見て、合格／もう少し と ひとこと（よく使うことばのボタンあり）。「認定できる子」がまとまって出る。メンバーのページで、級をつけたり外したりできる
- **ひろば**：がんばったこと（文・写真・「きょうのメニューをやりきった」「○日つづけた」などのシェア）を、クラブの中だけで見せあう。反応は スタンプ（👍いいね・👏ナイス・🌟すごい・💪がんばれ）だけで、子どもどうしは文を送りあわない。級の認定は、お祝いの投稿になる（せっていで切れる）
- **安全のしくみ**：本名・メール・電話は持たない（ニックネームと学年の目安だけ）／提出の写真は本人とコーチだけが見られる／ひろばの写真は、コーチが見てから出す（せっていで変えられる。文もコーチの確認のあとにできる）／悪口・URL・電話番号のような数字は のせられない／投稿はコーチがかくせる／提出の写真は評価から45日で消える／メンバーを消すと、その子の記録・写真・投稿も消える／ログインのまちがいが続くと、しばらく入れない

### 動画でチェック
- 「チェック」→ 種類をえらぶ → とり方の説明（横から／前から・何秒）→ 動画をえらぶ（スマホではその場でとるか、写真から）→ 調べる範囲 → 人が何人か映っていたら、調べる人をタップ
- 結果：動画の上に骨格と角度、場面ボタン（しずむ・セット・はなす・着地 など）、◎○△ のカード（理由・アドバイス・おすすめの練習）、点数、グラフ、正しい形のアニメーションとくらべる。保存すると「きろく」に残る
- チームの動き：高い所から固定してとった動画で、コートの4つの角（ペイントかハーフコート）をタップ → 2チームの色 → 攻めているチーム。上から見たコートで、みんなの動きが動画と同時に動く
- しくみ：`js/analyze.js`（骨格の読みとり・追いかけ・角度・場面の見つけ方・判定、コートの位置＝ホモグラフィー、色、チームの計算）と `js/check.js`（画面）。動画は端末の中だけで処理する。はじめの1回だけ、AI の部品（MediaPipe Tasks Vision 0.10.21・約10MB）を cdn.jsdelivr.net と storage.googleapis.com から読みこむ（そのあとはブラウザに残る）

### ケガ・テーピング
- 「もっと」→「ケガ・テーピング」（ホームの「ケガをしたら」からも）。119・#8000・#7119 の電話ボタン、どこが どうした？ で探せる
- ケガごとに：すぐ119のサイン・その場でやること・やってはいけないこと・病院へ行くサイン・練習にもどるまで・関係するテーピング
- テーピング（足首・指・親指・手首）：用意するもの・巻く前に・**巻きかたを図で1ステップずつ**（今のテープが巻く向きにのびる）・巻いたあとに確かめること・注意
- 診断や治療の代わりにはならない。いたみが強いとき・心配なときは、大人に伝えて病院へ

### 練習プラン・そうだん・ずかん
- **プランをつくる**：テーマ（なやみ・わざ）・時間（30〜120分）・人数・レベル・場所から、ウォームアップ → 技術 → 対人・ゲーム → しめくくり。入れかえ・時間の調整・ほぞん・文字でコピー・タイマー
- **コーチにそうだん**：なやみを文で書くと、受け止め・考え方・絞りこむ問い・見るポイント・おすすめの練習を答える（ことばの一致と近さで選ぶしくみ。AI ではない）
- **ずかん**：なやみ・見るポイント・練習メニュー・戦術を、わざごとに。ことばで探せる。★ お気に入り

## クラブのサーバー（Supabase）

- 中身は **`club/schema.sql`**（テーブル 11・関数）。接続先は `js/club-config.js`（URL と publishable キー。アプリに書いてよい公開用のキー）
- 数学ラボの Supabase プロジェクト（math-labo-second）に相乗りしている。ほかのアプリとまざらないよう、テーブルも関数も **`bg_`**（内部用は `_bg_`）ではじまる名前だけを足す。ほかのテーブルには さわらない
- テーブルには直接さわれない（RLS ＋ anon・authenticated の権限の取り消し）。アプリは `bg_*` の関数（security definer）だけを呼び、関数がトークンで「だれか」を確かめる。あいことば・合言葉は bcrypt、トークンは SHA-256 で保存。ログイン・提出・投稿には回数の制限
- 入れかた：Supabase の **SQL Editor に `club/schema.sql` を貼って Run**（何回 Run してもよい。すでにある `bg_` のデータは消えない）
- 上限（1クラブ）：子ども 200人・コーチ 10人・写真 300枚。写真は端末で小さくしてから送る（長い辺 960px まで・300KB まで。JPEG・PNG・WebP）
- 関数がまだ入っていないときは、画面に「クラブの サーバーを じゅんびしています」と出る

## 作り方と、まだのこと

- 文章は、作者の方針と指示のもとで、AI（Claude）を使って書いた。一般に知られている練習法・戦術・手当ての考え方をもとに新しく書いたもので、特定の本や動画の文章を写したものではない。
- ケガ・テーピングは、子ども向けの一般的な手当てにとどめた。日数の目安・治療の名前・細かい手技は書いていない。**痛みが続く・腫れ・しびれは医療機関へ**。
- 動画分析の判定（角度・高さの目安）は、一般的なフォームの考え方からの目安で、カメラの向きや距離で変わる。◎○△ は「見るきっかけ」として使う。
- クラブの級のひな形（10級〜1級の課題と回数）は、たたき台。クラブの年齢やレベルに合わせて、コーチが直して使う。
- クラブで子どもの写真を あつかうときは、**保護者に、写真を送ること・だれが見るか・いつ消えるかを伝えて、了解をもらってから** 使う。顔が写らない とり方（手元・足元・うしろから）も すすめる。
- **まだのこと**：指導者による全体の読み直し、実際の子どもたちでの試用（とくに動画チェックの判定の目安・クラブの級の回数）、作戦図の細かい位置の確認。
