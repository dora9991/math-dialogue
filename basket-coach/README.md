# バスケ・グロウ（basket-coach）

**小学生・中学生が、自分で使って上達していく**ためのバスケットボールのアプリ。
毎日の「きょうのメニュー」をこなすと経験値がたまってレベルが上がり、動画で自分の動きをチェックでき、ケガをしたときの手当てとテーピングも見られる。
**1週間に「これ1つ」だけ** のびしろをえらび、30秒で「いまの自分」を測って、1週間後にもう一度。くらべる相手は **きのうの自分だけ**（ほかの人とは くらべない）。
クラブで使うと、**コーチがつくった級（総合と、ドリブル・シュートなど スキルごとの 10級〜1級）にチャレンジ**して、写真をつけて送り、コーチから合格と「ドリブル 8級 認定」などを返してもらえる。コーチが出す **自主練**（何を・何回・いつまでに）を1回ずつ きろくして クリアをめざし、コーチは 👏拍手・👍いいね・😠怒り で返事する。がんばったことは、クラブの「ひろば」で見せあって いいね できる。練習試合・大会などの **参加の申し込み** と、保護者からの **体験・入団の申し込み** も受けつけられる。

- **ホーム**：**今週の これ1つ**（のびしろ3つ → 30秒チャレンジ → 1週間後に測りなおして「のび」を見る）・今週の日数と **週ゴール（ふつう週3日）**・きょうのメニュー（10〜30分。目標と練習する場所・人数から毎日自動で組む。これ1つが あれば、その練習が中心）→ タイマーで進めて「できた・まあまあ・むずかしかった」を記録。なやみを書いてさがす。今週の練習した日・つづけた日数
- **れんしゅう**：わざ（16）ごとに、体のある人のアニメーション・ここがポイント（合言葉）・なやみ・練習メニュー。練習プランをつくる・ずかん
- **クラブ**：コーチが **級（総合＋スキルごと）と課題・回数** を自由につくる → 子どもが練習して、できた数と写真を送る → コーチが見て「合格／もう少し」とひとこと → 級の課題がそろったら、コーチが「ドリブル 8級 認定」などを返す。**自主練**（コーチが出す宿題。1回ずつ きろくして クリア）・**ひろば**（がんばったことを見せあって スタンプ。コーチは 拍手・いいね・怒り）・**予定**（参加する・しない）・**体験／入団の申し込み**（保護者がリンクから）
- **チェック（動画分析）**：スマホでとった動画を、この端末の中の AI（MediaPipe）が調べる
  - **じぶんの動き**：シュート（しずみこみ・セットのひじ・腕ののび・フォロースルー・まっすぐ跳べているか・はなすタイミング）／ドリブル（腰の低さ・顔が上がっているか・頭の高さ・ボールの高さ・回数）／ディフェンス（腰の低さ・足の幅・足の交差・頭のはね）／着地（ひざで吸収・ひざが内に入らないか・体のかたむき）を ◎○△ で
  - **チームの動き**：コートの4点をタップ → 人を見つけてコートの上の位置に → ユニフォームの色でチーム分け → 広がり・ペイントの人数・コーナーの使い方・だんご・守りのまとまり
- **きろく**：レベル・経験値・練習した日のカレンダー・わざごとの星・これ1つの のび・バッジ（27）・動画チェックの結果・さいきんの練習
- **もっと**（右上のボタン）：コーチにそうだん（チャット）・ずかん・**ケガ・テーピング**（14のケガの手当て・4つのテーピングを図で1ステップずつ）・せってい・おとなの方へ
- 困りごと **79**・見るポイント **87**・練習メニュー **108**・戦術 **53**・人の動き **45**・ケガ **14**・テーピング **4**
- インストール不要・ビルド不要。**記録も動画も、その端末の中だけで扱う。動画は どこにも送らない**（AI の部品とフォントだけ、インターネットから読みこむ）。**クラブを使うときだけ**、提出した数・写真・ひとことと ひろばの投稿を、クラブのサーバー（Supabase）に送る
- 公開ページ：**https://dora9991.github.io/math-dialogue/basket-coach/** （更新は `node tools/publish-pages.cjs`。gh-pages の `basket-coach/index.html` だけを差し替え、ほかの公開物には触らない）

- **クラブで使う アプリの入口**：このアプリから、**試合の記録と場面の切り出し**（[バスケ タップ記録](https://dora9991.github.io/math-dialogue/basket-tap/)）と **保護者会**（[部活保護者会アプリ](https://dora9991.github.io/hogosha-app/)：予定・出欠・配車・お弁当・連絡・会計）へ行ける（下の「クラブで使う アプリ（入口）」）
- ほかのアプリから、ずかんの検索を開ける：`https://dora9991.github.io/math-dialogue/basket-coach/#q/ことば`（例：`#q/ヘルプ`。[バスケ得点クリップ](https://dora9991.github.io/math-dialogue/basket-clips/)のコメント帳の「📘 バスケ・グロウ」から使う。はじめての人は、先にプロフィールを聞く）

## 開き方

| どこで | どうする |
|---|---|
| 公開ページ（おすすめ） | https://dora9991.github.io/math-dialogue/basket-coach/ を開く（スマホは「共有」→「ホーム画面に追加」） |
| 手元のパソコン | `basket-coach-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り。動画チェックの AI の部品だけは、はじめにインターネットから読む） |
| フォルダごと | `index.html` をブラウザで開く |

はじめて開くと、ニックネーム・学年・うまくなりたいこと（3つまで）・練習する場所・人数を聞く（あとで「もっと」→「せってい」で変えられる）。学年でメニューのレベル（ミニバス／中学・高校）が決まる。「おとな」を選ぶと、指導者向けのなやみも出る。

## 使い方

### きょうのメニューと、成長
- ホームの「きょうのメニュー」：目標のわざを日がわりで中心にして、じゅんび → メイン → ゲーム →（20分以上なら）ストレッチ を組む。「ほかのメニュー」で組みなおす
- 「▶ スタート」でタイマー（残り時間・アニメーション・ポイント・やりかた・つぎ）。時間になると音とバイブで知らせて、次へ。おわったら顔のボタンで記録し、ひとことメモも残せる
- 練習メニューのページの「✓ やった！」でも記録できる（何分やったか・できた度合い）。見るポイントのチェックリストをぜんぶ ✓ にしても少し経験値
- 経験値（XP）：練習メニュー 6〜30（時間とできた度合い）・きょうのメニューをやりきる 20・動画チェック 15・見るポイント 5。レベル n に必要な合計は 25×n×(n−1)（50・150・300・500…）。呼び名は ルーキー → ジュニア → レギュラー → エース → キャプテン → レジェンド
- バッジ：はじめの一歩・3日／1週間／30日れんぞく・10回／50回・いろいろ10しゅるい・300分・ビデオ・アナリスト・◎5こ・シューター・ドリブラー・ディフェンダー・オールラウンダー・朝れん・レギュラー・エース
- 点数や順位で他の人とくらべる機能はない（自分の成長だけを見る）。クラブの合格は +10・級の認定は +50（バッジ「はじめての級」「5つの級」）・自主練の きろく +5・自主練のクリア +30（バッジ「自主練クリア」「自主練マスター」）

### 今週の これ1つ（きのうの自分を こえる）
1週間（月〜日）で1周する。**3つの入口（数・コーチの返事・なかま）のうち、「数」で燃える子** にも「自分の伸び」が見えるようにするしくみ。

1. **決める**（ホーム →「これ1つを きめる」）
   - **のびしろを3つ** 出す：動画チェックで △ だったところ（30日いない）・「むずかしかった」が続いた技能（2週間）・そうだんした なやみ・ともくひょう・ごぶさた（10日以上）・先週あと少しだったもの。どれも理由つき（「動画チェックで『腰の低さ』が △ だったよ」）。「ほかの技能から えらぶ」もできる。ゴールがない家の人には、ゴールがいるテストは出さない
   - **30秒チャレンジで いまの自分を測る**（きじゅん）：ポンドドリブル（右手・左手）・クロスオーバー・ボディサークル（タイム）・ジグザグ（タイム）・2ボール（落とさず何秒）・フリースロー・フォームシュート・5か所シューティング・レイアップ（右・左）・マイカン・かべパス・まとあて・足ぶみ・ジャンプストップ・ドライブ→レイアップ・ディフェンススライド・ひくいかまえ・かべジャンプキャッチ・プランク・スクワット・片足立ち（全23。`data/focus.js`）。3・2・1 → 30秒タイマー（音とバイブ）／ストップウォッチ／「10本中 いくつ」。数は あとから直せる
   - **目標**：いまの数から「むりなく届く」目標を自動で提案（回数は +10%・タイムは 5% はやく・N本中は +1〜2）。± で直せる
2. **やる**：ホームの「きょうのメニュー」が、**これ1つの練習を中心** に組まれる（「これ1つ」のバッジ。「むずかしかった」が2回続いたら「かんたんにする」やり方から）。「5分だけ これ1つ」ボタンもある。練習のおわりに **ふり返り（30秒）**：「できたこと」と「つぎに意識すること」を1つずつ えらぶ（1日1つ。書きかえできる）→ 次の日、ホームに「前の ふり返りから：ひざを まげる」と出る
3. **のびを見る**（ホーム →「測りなおす」）：もう一度測って、**「38回 → 44回（+6回）」**・目標クリア・**自己ベスト**・のびのグラフ・ふり返りの一覧。へったときも せめない（「きょうは ちょっと へったね。でも だいじょうぶ」）。「コーチ・おうちの人に 見せる」（共有 or コピー）・クラブに入っていれば **「ひろばに のせる」**。「つぎの これ1つ」か「同じテストでつづける」へ
- 目標を たっせいした技能は、つぎの週は すぐには すすめない（べつの技能を ためす）。先週あと少しだったものは「もういちど」を すすめる。まん点（10本中10本）のテストは つぎの測り方へ
- きろくのページに「これ1つの のび」（1週間ごとの 一覧と 自己ベスト）。経験値：これ1つを決める +10・測りなおし +10・自己ベスト +20・ふり返り +5。バッジ：「これ1つ」「自己ベスト」「ふり返り5回」「週ゴール」「週ゴール4週」
- **週ゴール**：「毎日」ではなく「1週間で 目標の日数（ふつう3日。せっていで 2〜5日）」。ホームの上のカードと下の点に「今週 2/3日」。たっせいした週が つづくと「3週つづけて クリア」。連続日数（バッジ「3日れんぞく」など）は そのまま のこしている。測っただけの日も 練習した日に数える
- しくみ：`js/focus.js`（週・目標の提案・自己ベスト・のびしろ・きょうのメニューへ。DOMなし）・`js/focus-ui.js`（画面）・`data/focus.js`（測るテスト）・`js/grow.js`（週ゴール・経験値・バッジ・メニュー）。記録は端末の `bc.focus`（書き出し・読みこみに入る）。診断や順位ではなく、「自分の前の記録」とのくらべだけ

### クラブ（級・写真の提出・自主練・ひろば・予定・申し込み）
- **はじめかた（コーチ）**：「クラブ」→「クラブを つくる」（クラブの名前・自分の名前・コーチの合言葉）→ 6文字の **クラブコード** ができる。ほかのコーチは、クラブコード＋合言葉＋自分の名前でログインする（10人まで）
- **子どものアカウント**：コーチが「メンバー」でニックネームと学年を入れると、**ばんごう** と **6けたの あいことば** ができる →「ログインカード」を印刷して配る（メールアドレスは いらない）。あいことばを忘れたら、コーチが作り直す
- **級をつくる**：はじめは 10級〜1級（各4つの課題）のひな形。級の名前・色と、課題（練習メニューとつなげる・回数・単位・「連続」「10本中」「以内」など・やりかた・写真が 必要／あれば／なし）を、コーチが自由に変える（回数は ± で）
- **子ども**：いまの級の課題 → 練習して、できた数・写真・ひとこと（動画チェックの結果もつけられる）を送る → コーチの「合格」「もう少し」と ひとことが届く → 級の課題がぜんぶ合格すると、コーチが **級を認定**（お祝いの画面）
- **コーチ**：「確認」で写真を見て、合格／もう少し と ひとこと（よく使うことばのボタンあり）。「認定できる子」がまとまって出る。メンバーのページで、級をつけたり外したりできる
- **ひろば**：がんばったこと（文・写真・「きょうのメニューをやりきった」「○日つづけた」などのシェア）を、クラブの中だけで見せあう。反応は スタンプ（👍いいね・👏ナイス・🌟すごい・💪がんばれ）だけで、子どもどうしは文を送りあわない。級の認定と 自主練のクリアは、お祝いの投稿になる（せっていで切れる）
- **スキルごとの級**：クラブをつくるときに「総合」に くわえて ドリブル・シュート・パス・ディフェンス（各10級・課題2つずつ）を えらべる。「級をつくる」で 種類を足す・名前を変える・しまう（8種類まで）。子どもは「級」のタブで 種類をえらんで チャレンジし、種類ごとに「ドリブル 7級」のように 級がつく。いちばん左の種類（メイン）の級が、名前のとなりや ホームに出る
- **自主練**（コーチ →「自主練を 出す」）：なにを（練習メニューとつなげられる）・1回で何回・期間の中で何回やるか・期間（92日まで）・写真の要否・だれに（全員／えらぶ）。子どもは「自主練」のタブから 1回ずつ きろく（数・写真・ひとこと。1日3回まで）→ 決めた回数に とどくと **クリア**（お祝い・経験値）。コーチは 子どもごとの回数と きろくを見て、きろくごとに **👏拍手・👍いいね・😠怒り**（ひとことも）を返す
- **コーチの 拍手・いいね・怒り**：自主練の きろくと、ひろばの投稿に つけられる（コーチ1人に1つ。押しなおすと かわる・はずれる）。**みんなに見える**
- **予定と 参加の申し込み**（コーチ →「予定を 出す」）：練習試合・大会・合宿・体験会など（日・時間・場所・お知らせ・しめきり・定員・だれに）。子どもは「予定」のタブで **参加する／まだ わからない／参加しない** を答える（しめきりまで変えられる。定員をこえると「参加する」は押せない）。コーチは 答えの一覧を見て、○×△ で かわりに入れたり（電話や口で聞いたとき）、一覧を文字でコピーしたりできる
- **体験・入団の申し込み**（コーチ →「体験・入団の申し込み」）：受けつけを オンにすると、**申し込みのリンク**（クラブコードとは べつの 8文字のコード。ログインには使えない）ができる。保護者は アプリを使ったことがなくても リンクから開いて、子どもの名前・学年・保護者の名前・連絡先（電話かメール）・メッセージを送れる。コーチは 一覧から 電話・メールし、「連絡した」「おわり」「メンバーにする」（ニックネームに直して 登録 → ログインカード）。申し込みは **コーチだけが見られ、90日で消える**。1つの所から1時間に5件・1クラブ1日30件まで
- **安全のしくみ**：本名・メール・電話は持たない（ニックネームと学年の目安だけ）／提出の写真は本人とコーチだけが見られる／ひろばの写真は、コーチが見てから出す（せっていで変えられる。文もコーチの確認のあとにできる）／悪口・URL・電話番号のような数字は のせられない／投稿はコーチがかくせる／提出の写真は評価から45日で消える／メンバーを消すと、その子の記録・写真・投稿も消える／ログインのまちがいが続くと、しばらく入れない

### 動画でチェック
- 「チェック」→ 種類をえらぶ → とり方の説明（横から／前から・何秒）→ 動画をえらぶ（スマホではその場でとるか、写真から）→ 調べる範囲 → 人が何人か映っていたら、調べる人をタップ
- 結果：動画の上に骨格と角度、場面ボタン（しずむ・セット・はなす・着地 など）、◎○△ のカード（理由・アドバイス・おすすめの練習）、点数、グラフ、正しい形のアニメーションとくらべる。保存すると「きろく」に残る
- チームの動き：高い所から固定してとった動画で、コートの4つの角（ペイントかハーフコート）をタップ → 2チームの色 → 攻めているチーム。上から見たコートで、みんなの動きが動画と同時に動く
- しくみ：`js/analyze.js`（骨格の読みとり・追いかけ・角度・場面の見つけ方・判定、コートの位置＝ホモグラフィー、色、チームの計算）と `js/check.js`（画面）。動画は端末の中だけで処理する。はじめの1回だけ、AI の部品（MediaPipe Tasks Vision 0.10.21・約10MB）を cdn.jsdelivr.net と storage.googleapis.com から読みこむ（そのあとはブラウザに残る）

### ケガ・テーピング
- 「もっと」→「ケガ・テーピング」（ホームの「ケガをしたら」からも）。119・#8000・#7119 の電話ボタン、どこが どうした？ で探せる
- ケガごとに：すぐ119のサイン・その場でやること・やってはいけないこと・病院へ行くサイン・練習にもどるまで・関係するテーピング
- テーピング（足首・指・親指・手首）：用意するもの・巻く前に・**巻きかたを図で1ステップずつ**（今のテープが巻く向きにのびる）・巻いたあとに確かめること・注意
- 診断や治療の代わりにはならない。いたみが強いとき・心配なときは、大人に伝えて病院へ

### 練習プラン・そうだん・ずかん
- **プランをつくる**：テーマ（なやみ・わざ）・時間（30〜120分）・人数・レベル・場所から、ウォームアップ → 技術 → 対人・ゲーム → しめくくり。入れかえ・時間の調整・ほぞん・文字でコピー・タイマー
- **コーチにそうだん**：なやみを文で書くと、受け止め・考え方・絞りこむ問い・見るポイント・おすすめの練習を答える（ことばの一致と近さで選ぶしくみ。AI ではない）
- **ずかん**：なやみ・見るポイント・練習メニュー・戦術を、わざごとに。ことばで探せる。★ お気に入り

| どこに出すか | だれに | 行き先 |

| ホームの「クラブで使う（コーチ・保護者の方）」 | コーチとしてログイン中・学年「おとな」の人だけ（子どもには まぎらわしいので出さない） | タップ記録（`?from=grow-home`）・保護者会 |

### リアルな人と動き（1つ目：低いドリブル）

はじめの画面（ようこそ）にも出る **低いドリブル（ポンド）** だけ、絵と動きを作り直した（ためしの1つ目。ほかの 44 は 今までの絵のまま）。

- **絵**（`js/motion-real.js`。動きに `look: 'real'` と書くと使う。横からの動きだけ）：骨格は同じで、描き方だけちがう。横顔（鼻・口・あご・耳・髪）・首・胸と背中のある胴・先細りの手足（太もも・ふくらはぎ）・手のひらと指・ハイカットのシューズとくつ下・そでなしのユニフォーム。どの部品も「かげの色の形」に「明るい面」を重ねて、立体に見せる（光は上・少し前から）。ボールは 線が回り、床で少しつぶれ、床に影が出る
- **動き**（`data/motions-base.js` の `pound`）：キーを手で置くのではなく、式から細かいキーを作る。ボールは 手の中で なめらかに加速 → 重力で落ちる → はね返る（係数 0.8）→ 指でうけて吸収。手は 指の腹が ボールにのり、押すときに手首が返り、はなれたあとも床へのびる。押すときに 手前の肩が少し下がる。頭の高さと向きは 変えない（腰の高さで つり合わせる）
- **よくない形**（× 腰が高い）：手が届かない分だけ、ボールも手について上がる（床では ずれない）
- 動画チェックの基準（腰の低さ・顔・頭の高さ・手首が腰より下）を 満たすように作ってある（`tools/analyze-test.cjs`）。本物の AI（MediaPipe）も、この人を 全部のコマで 人として見つける（`tools/check-test.cjs`）
- エンジンに足したもの（どれも なくてもよい項目。ほかの動きは変わらない）：手のひらの向き `rw`・`lw`、指の曲げ `rc`・`lc`、手前の肩のずれ `rs`、ボールの回転 `rot`・つぶれ `sq`・手のずれに ついていく `f`／`w`

## クラブのサーバー（Supabase）

- 中身は **`club/schema.sql`**（テーブル 18・関数。v1 のあとに 足した v2〔級の種類・自主練・コーチの反応・予定・申し込み〕も 同じファイルで、何回 Run しても 同じになる）。接続先は `js/club-config.js`（URL と publishable キー。アプリに書いてよい公開用のキー）
- 数学ラボの Supabase プロジェクト（math-labo-second）に相乗りしている。ほかのアプリとまざらないよう、テーブルも関数も **`bg_`**（内部用は `_bg_`）ではじまる名前だけを足す。ほかのテーブルには さわらない
- テーブルには直接さわれない（RLS ＋ anon・authenticated の権限の取り消し）。アプリは `bg_*` の関数（security definer）だけを呼び、関数がトークンで「だれか」を確かめる。あいことば・合言葉は bcrypt、トークンは SHA-256 で保存。ログイン・提出・投稿には回数の制限
- 入れかた：Supabase の **SQL Editor に `club/schema.sql` を貼って Run**（何回 Run してもよい。すでにある `bg_` のデータは消えない）
- 上限（1クラブ）：子ども 200人・コーチ 10人・写真 300枚・級の種類 8・出している自主練 30・これからの予定 60。写真は端末で小さくしてから送る（長い辺 960px まで・300KB まで。JPEG・PNG・WebP）
- 消えるもの：提出の写真は 評価から45日・自主練の写真は 45日・体験／入団の申し込みは 90日で 自動で消える。メンバーやクラブを消すと、その きろく・写真・投稿・答えも 消える
- 関数がまだ入っていないときは、画面に「クラブの サーバーを じゅんびしています」と出る

## 作り方と、まだのこと

- 文章は、作者の方針と指示のもとで、AI（Claude）を使って書いた。一般に知られている練習法・戦術・手当ての考え方をもとに新しく書いたもので、特定の本や動画の文章を写したものではない。
- ケガ・テーピングは、子ども向けの一般的な手当てにとどめた。日数の目安・治療の名前・細かい手技は書いていない。**痛みが続く・腫れ・しびれは医療機関へ**。
- 動画分析の判定（角度・高さの目安）は、一般的なフォームの考え方からの目安で、カメラの向きや距離で変わる。◎○△ は「見るきっかけ」として使う。
- クラブの級のひな形（10級〜1級の課題と回数）は、たたき台。クラブの年齢やレベルに合わせて、コーチが直して使う。
- クラブで子どもの写真を あつかうときは、**保護者に、写真を送ること・だれが見るか・いつ消えるかを伝えて、了解をもらってから** 使う。顔が写らない とり方（手元・足元・うしろから）も すすめる。
- コーチの「怒り」は、ひろばでも **みんなに見える**（いまの設定）。みんなの前での 怒りは つづける気持ちを くじくこともあるので、理由をひとこと そえる・本人の自主練のきろくに つける など、使い方は クラブで 話しあって決める。
- 体験・入団の申し込みは、保護者の 名前と連絡先（個人情報）を あずかる。リンクを 配るときに、使いみち（連絡のため）・見る人（コーチだけ）・消える日（90日）を 伝える。
- 「これ1つ」の目標の自動提案（+10%など）と、測るテストの やり方・数の目安は、一般的な考え方からの たたき台。いたい日・つかれた日は むりをしない（画面にも書いている）。実際の子どもたちで 試して、直していく。
- リアルな人と動きは、まだ「低いドリブル」の1つだけ。ほかの動きに広げるには、動きごとに 手の向きや ボールの動きを 作る必要がある。前から見た人（クロスオーバーなど）の リアルな絵は、まだない。
- **まだのこと**：指導者による全体の読み直し、実際の子どもたちでの試用（とくに動画チェックの判定の目安・クラブの級の回数）、作戦図の細かい位置の確認。
