# フレーズポケット（英会話ノート）

Claude と英会話をしながら、**使った表現**と**つまずいたところ**を自動でノートにためて、
忘れかけたころに練習できるアプリ。数学ラボの別ツール（`tangocho/` などと同じ並び）。

- 公開先（claude.ai の Artifact）：https://claude.ai/artifact/1WgMTtTL5sQHMH5MWbvmw2
- **API キーは要らない**。claude.ai の中で動き、会話はその人の Claude アカウントで行う。
- ノートは claude.ai の「その人専用の保存場所」に入る。スマホでもPCでも同じノートが見られる。

## なぜ作ったか

Claude との英会話は、わからないところをその場で聞けるので学びやすい。
ただ、一度出てきた表現を忘れたり、あとで履歴をさかのぼって探したりするのが面倒で、復習が続かない。
そこで「会話するだけで、復習の材料が勝手にたまっていく」形にした。

## 4つの画面

| 画面 | できること |
|---|---|
| **話す** | 場面（フリートーク・自己紹介・旅行・学校/仕事・家族・趣味/音楽・お店、または自分で書く）を選んで Claude と英会話。日本語で「〜って英語で何て言う？」と聞いてもよい。返事のたびに、Claude が下の5種類を拾ってノートに入れる。🔊で返事を読み上げ。 |
| **ノート** | たまった表現を日付ごとに一覧。種類でしぼりこみ・検索。「会話を見る」で、その表現が出た会話にもどれる。 |
| **練習** | 今日の分（最大10問）を単語カード形式で。書いても、声に出すだけでもOK。「Claudeに見てもらう」で答えを判定してもらえる。「まだ／おしい／言えた！」で次に出る日が決まる。つまずいた表現を、いつもの claude.ai チャットで練習するための文もコピーできる。 |
| **取り込む** | claude.ai のふつうのチャットでした英会話を貼ると、表現とつまずきを拾ってノートに入れる。長い会話は、チャットの最後に「まとめ」を頼む文（コピーできる）を送ってから、そのまとめを貼ると確実。 |

### 自動で拾う5種類

| 種類 | 中身 |
|---|---|
| 言い直し | 自分の英語の誤り・不自然なところ（前の言い方 → 自然な言い方・理由） |
| 言えなかった | 日本語で言った／「英語で何て言う？」と聞いたこと |
| わからなかった | 意味をたずねた表現 |
| 拾った表現 | Claude の返事に出てきた、覚えておくと便利な表現 |
| 使えた！ | 自分がうまく使えた表現（練習中の表現を会話で使えたら、自動でレベルアップ） |

### 練習の間かくの決め方

単語カードの「箱」（0〜6）で管理する。

- 言えた！ → 箱が1つ上がる。次に出るのは 1日後 → 3日後 → 7日後 → 14日後 → 30日後。箱6で「覚えた」。
- おしい → 箱はそのまま、あしたもう一度。
- まだ → 箱0にもどる。同じ回の最後にもう一度出る。
- 会話の中で、同じところでまたつまずいたら箱0にもどる。うまく使えたら箱が1つ上がる。
- 「ノートの表現を使ってみる」で会話を始めると、Claude が練習中の表現を使う場面をつくってくれる。

## しくみ（ファイル）

`index.html` 1枚だけ。claude.ai の Artifact として公開する前提で書いている（`<html>` や `<head>` は公開時に自動で付く）。

| 使っている claude.ai の機能 | 用途 |
|---|---|
| `sample` | ページから Claude に話しかける（会話・取り込み・答えの判定） |
| `db` + `user` | ノートと会話の記録を、その人専用の場所（`data/users/<その人のid>/`）に保存 |

データの置き場所（すべて `data/users/<id>/pocket` の下）：

| パス | 中身 |
|---|---|
| `pocket`（ドキュメント） | 設定（レベル・返事の速さ・Claudeに伝えておくこと） |
| `pocket/items/<id>` | ノートの1項目（種類・英語・日本語・前の言い方・メモ・例文・箱・次に出る日など） |
| `pocket/sessions/<id>` | 会話の一覧用の情報（場面・日時・往復数・拾った項目） |
| `pocket/logs/<id>` | 会話の中身（取り込みの場合は貼った文章） |

各会話の返事は「英語の返事 → `###NOTES###` の行 → 拾った項目の JSON」という形で Claude に書いてもらい、
画面には返事だけを出して、JSON をノートに入れている。

### Claude からノートを読む

Claude Code など、Artifact のデータを読めるセッションでは、`data/users/me/pocket/items` を読めば自分のノートが見られる
（`me` は自分の id に置きかわる）。「今週つまずいた表現から小テストを作って」のような使い方ができる。

### claude.ai の外で開いたとき

claude.ai の外（ファイルを直接開く等）では Claude につながらないので、会話と取り込みは使えない。
ノートはそのブラウザの中だけ（localStorage）に保存され、練習は自己採点で使える。

## 更新のしかた

`index.html` を直したら、Claude Code で同じファイルを Artifact として公開しなおす（同じURLのまま更新される）。
ためたノートは公開しなおしても消えない。
