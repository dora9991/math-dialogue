# 連立方程式の黒板（renritsu）

電子黒板に映して、**図やグラフを動かしながら**考える「連立方程式」（中2）の授業ページ。1時間＝1ページ、13時間ぶん。
授業の流れは ikkan の `ikkan/data/lesson_renritsu_new_NN.js` とそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。考えようは答えを出さず、スライダーなどの「調べる道具」だけ。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。全単元の総目次は `../kokuban/index.html`。
画面の土台は `../kukan/js/k3.js`・`../kukan/css/board.css`・`../katsuyo/js/chart.js` を使うので、公開するときはいっしょに置く。

## 13時間

| 時間 | ページ | 題 |
|---|---|---|
| 第1時 | `01.html` | 2つの文字をふくむ方程式の解をさがし、連立方程式の解を見つけよう |
| 第2時 | `02.html` | 2つの式をたしたりひいたりして、文字を1つ消そう |
| 第3時 | `03.html` | 式を何倍かして係数をそろえ、加減法で連立方程式を解こう |
| 第4時 | `04.html` | 式を式に代入して、文字を1つ消そう |
| 第5時 | `05.html` | かっこや小数・分数のある連立方程式を解こう |
| 第6時 | `06.html` | A＝B＝C の形の方程式を解こう |
| 第7時 | `07.html` | 加減法と代入法をくらべて、解き方を選ぼう |
| 第8時 | `08.html` | 代金と個数の問題を、連立方程式をつくって解こう |
| 第9時 | `09.html` | 道のり・速さ・時間の問題を、表に整理して解こう |
| 第10時 | `10.html` | 割合の問題を、表に整理して解こう |
| 第11時 | `11.html` | 条件を変えると、解はどうなるだろう |
| 第12時 | `12.html` | 連立方程式に合う問題をつくって、解き合おう |
| 第13時 | `13.html` | 「連立方程式」で学んだことを、整理して確かめよう |

## 操作

空間図形の黒板（`../kukan/README.md`）と同じ：→・Enter・Space でつぎへ（問い → 答え → 次の問い）、← でもどる、R でもう一度動かす、F で全画面。下にスライダーが出る場面は、手で値を変えられる。URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる。

## つくり（作り手向け）

- 1ページ＝1つの HTML（外部ライブラリなし）。`K3.run({ flat: true, steps: [...] })` を呼ぶだけ。ステップの書き方は `../kukan/README.md`。
- グラフ・表・数直線・カード・タイルは `../katsuyo/js/chart.js`（CH.*）。分数は `CH.fr`（文の中の [1/2]）・`CH.frac`（図の中）、√ は `CH.root`、負の数は `CH.mnum`。
- 答えや表の数は、ページの中で計算し直して照らし合わせている（`CH.check`）。ちがうと、ブラウザのコンソールに「答えがちがう：…」と出る。
- × と ÷ は、黒板の字体だと x と見分けにくいので、土台が自動で見分けやすい字体にする。
- データ・場面は ikkan の数値か、自作（各ページの頭のコメントに書いてある）。
