# ikkan：板書型ワークシート

黒板に書く授業のためのワークシート。**問題の下は、図・グラフ以外は空欄**にしてあり、生徒は板書を写して使う。
「**解答を表示**」を押すと、教師が板書する内容と、問題の中の空欄（数字）が**赤**で出る。

`hyojun-navi/`（授業ナビ 標準版）とは別のもの。既存のワークシートには手を入れていない。

## 紙面の形（A4・ドット罫 7mm・37行）

1. いちばん上：日付・名前
2. めあて
3. 学習課題・例題（1〜3問）。それぞれ「問題文（枠）＋板書を写す空欄の罫＋図」
   - **1問目**は、問題文も図の長さも、すべて印刷する。
   - **2問目以降**は、数字のいくつかを空欄にして、先に問題が解けないようにする（問題文の中も、図の長さの字も）。
     板書で数字を伝えながら、生徒が書き入れる。
   - 問題と問題のあいだは、図・グラフ以外は空欄（板書を写す罫）。

## 使い方

`index.html` をブラウザで開く（ビルド不要。サーバーも不要）。

| 操作 | |
|---|---|
| 一覧から授業をえらぶ | `#/<授業のID>` |
| 解答を表示／かくす | 上の「解答を表示」ボタン、またはキーボードの `a` |
| 解答を表示した状態で開く | `#/<授業のID>/ans` |
| 全体を見る／幅に合わせる | 上のボタン（電子黒板に映すとき、1枚が画面に収まる） |
| 印刷 | 上の「印刷」。**いま表示している状態**で印刷される（生徒用なら、解答をかくしてから。教師用なら、解答を表示してから） |

## ワークシートを書き足す

`data/ws_<単元>.js` に、`IK.add(ID, { 授業の情報 }, [ブロック…])` で 1 授業ぶんを書く。見本は `data/ws_kukan.js`。
単元を足すときは `data/lessons.js` に `IK.unit(…)` を足し、`index.html` に `<script src="data/ws_<単元>.js">` を足す。

```js
const { M, K, B, G, F, C2, SO, NET } = IK.b;
IK.add('kukan-xx', { unit: 'kukan', unitName: '空間図形', title: '…', head: '空間図形', checks: [ 'near(…, …)' ] }, [
  M('めあて'),
  C2([
    K('学習課題', '問題文（数字もすべて書く）', 3),          // 枠。第3引数は行数
    B(6, '板書1行目\n板書2行目 …')                         // 板書を写す罫。2つ目は、解答を表示したときだけ出る教師の板書（1行＝罫1行）
  ], [ F(9, SO({ shape: 'cone', a: 4, c: 9.165, dims: 'r 4cm\nl 10cm' })) ], '3:2'),   // 右に図。'3:2'＝左右の幅の比
  G(1),
  C2([ K('例題1', '底面の半径が {{3}}cm の…', 2), B(5, '…') ], [ F(7, SO({ …, dims: 'r {{3}}cm' })) ], '3:2')   // {{3}}＝数字の空欄
]);
```

| 書き方 | 意味 |
|---|---|
| `{{3}}` | 空欄（解答を表示すると、中の字が赤で出る）。問題文でも、図の長さの字でも同じ |
| `[[1/2]]`・`x^2`・`**太字**`・`√{12}` | 分数・累乗・太字・根号 |
| `\\m` | 立体（斜体にしない）にする文字。1〜3文字の小文字は、ふつう数式の文字として斜体になる（`cm` などの単位は立体のまま） |
| `M(めあて)` | めあて |
| `K(ラベル, 問題文, 行数)` | 学習課題・例題の枠（ラベルは「学習課題」「例題1」など） |
| `B(行数, 板書)` | 板書を写す空欄の罫 |
| `F(行数, 図…)` | 図（印刷される）。複数なら横にならぶ（`w` で幅の比） |
| `C2(左, 右, 比)` | 2段組。左に問題と板書、右に図 |
| `G(行数)`・`BR()` | すき間・改ページ |

図：

| 図 | 書き方 |
|---|---|
| 立体の見取図 | `SO({ shape: 'cube' / 'cuboid' / 'prism' / 'pyramid' / 'cylinder' / 'cone' / 'sphere' / 'hemisphere', a, b, c, n, labels, dims })` |
| 円錐の展開図 | `NET({ R: 母線, r: 半径, lR, lr, ansAngle, ansArc })`。`ansAngle`・`ansArc` は解答を表示したときだけ赤で出る |
| 自由な図 | `SVG((W, H, h) => '<svg の中身（単位 mm）>')`。`h.ans(…)` でかこんだものは、解答を表示したときだけ出る |

## 検査

```bash
node tools/verify.cjs                                         # 検算（checks）・行数・板書の行数・空欄のきまり（1問目は空欄なし／2問目以降は空欄あり）
NODE_PATH=$(npm root -g) node tools/check.cjs [出力先]         # 見た目：はみ出しの検査と、紙面の画像（生徒用・解答つき）。playwright が必要
```

`checks` には、その授業の数値の検算を JavaScript の式で書く（`PI`＝π、`near(a, b)`＝ほぼ等しい）。
板書の答えを直したら、ここも直す。

## ファイル

```
index.html        画面（一覧・ワークシート）
css/ikkan.css     紙面と画面の見た目、印刷
js/core.js        紙面をつくる道具（文字・図・ブロック）。画面を持たない
js/app.js         画面（一覧・解答の切りかえ・印刷）
data/lessons.js   単元の一覧
data/ws_kukan.js  中1 空間図形のワークシート
tools/            検査（verify.cjs・check.cjs）
```

## 注意

- 問題・数値・板書は、このワークシートのために新しく作った。授業で使う前に、内容を確かめてほしい（検算は機械でしているが、読み直しはまだ）。
- ビルドは要らない。このフォルダをそのまま静的サイトとして公開できる（Cloudflare Pages など）。
