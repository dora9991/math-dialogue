# 空間図形 演習バンク（解説ごとの演習 300問）

中1「空間図形」の解説（動画）15本それぞれに、**簡単・普通・難しい・入試レベル** の4段階 × 5問、合わせて **300問** の演習です。
コツコツくんの固定問題（J1 の DB 問題）と同じ形（`{ id, u, s, d, q, c, e, h }`）で書き出してあります。

- 確認ページ：`review.html`（ブラウザで開くと、解説・段階で絞って300問を見られます）
- 問題データ：`bank.json`（300問）／`meta.json`（各問題が、ikkan のどのテンプレートから来たか）
- 既存の演習150問の振り分け案：`existing-redistribution.json`

## 何をどう作ったか

| 項目 | 内容 |
|---|---|
| 元 | `ikkan/kotsu/content/kukan-01〜15.js` の問題テンプレート（313個。解説の授業ごと、4段階） |
| 正解 | テンプレートが計算で出したもの。手では書いていません |
| 段階（`d`） | 1＝簡単（基礎）／2＝普通（標準）／3＝難しい（応用）／4＝入試レベル。ikkan の4段階（基礎・標準・応用・入試レベル）と同じ |
| 解説の紐づけ | `l`＝`kukan-01`〜`kukan-15`、`s`＝`J1-SP-K01`〜`J1-SP-K15`、`id`＝`J1-SP-K{解説}-L{段階}-{1〜5}` |
| 選択肢 | 4択。もとが数値入力の問題は、誤答を作って4択にしました（下の「誤答」） |
| 文字 | 数式は TeX をやめ、既存の問題と同じ平文（² ³ π × ÷）にしています |

### 誤答（4択の、まちがいの選択肢）

数値の答えの問題は、次の順で誤答をつくっています。

1. **よくあるまちがい**（理由つき）：円柱・円錐・球などの公式を、問題文の数字で計算し直し、「底面を足し忘れた」「1/3 をかけ忘れた」「直径を半径にした」などの値を出す。正しい式で計算し直した答えが、テンプレートの答えと合わないときは使いません
2. **途中の計算結果**（理由つき）：解説の途中の値を、最後まで計算せずに答えにしてしまった、という誤答
3. **答えに近い数**（理由なし）：1・2 で足りないぶんを埋める

もとから4択のテンプレート（立体の名前、位置関係など）は、その選択肢をそのまま使っています。
900個の誤答のうち、まちがえ方の理由がついたのは 180個（20%）です。残りは、問題ごとに手で書かないと理由は付きません。
`m`（まちがいの種類の ID）は、`SP-surface-02`（底面を足し忘れ）、`SP-volume-01`（1/3 の扱い）、`SP-volume-02`（母線と高さの取り違え）、`SHP-radius-01`（直径を半径に）、`SLIP-calc-02`（途中の値）の5種類だけ付けています。

## 確かめたこと

- `node ikkan/kukan-bank/verify.mjs`：15解説 × 4段階 × 5問がそろっているか、選択肢が4つで正解がちょうど1つか、文面の重なり、TeX の残り、正解と誤答が「数として同じ」でないか、同じ解説の中で問題文が重ならないか。**エラーなし**（警告1件：K13-L4-05 の解説に「0.5」でなく「1/2」と書かれている）
- **解き直し**：正解を伏せた300問を、別々の5つの解き手（AI）に自力で解かせ、問題集の答えと突き合わせました。**300問中299問が一致**。食い違った1問（`J1-SP-K04-L4-05`）は、「交わる別々の2直線に垂直ならば、平面に垂直」という定理のとおり、問題集の答えが正しいことを確かめました。
  AI による解き直しなので、人の目による確認の代わりにはなりません。授業で使う前に、先生の目で `review.html` を通して見てください。

## 作り直し・検査のしかた

```bash
node ikkan/kukan-bank/build.mjs          # bank.json, meta.json を書く（乱数の種が決まっているので、同じ結果になる）
node ikkan/kukan-bank/verify.mjs         # 機械検査
node ikkan/kukan-bank/redistribute.mjs   # 既存150問の振り分け案
node ikkan/kukan-bank/make-review.mjs    # review.html
DEBUG_FAILS=1 node ikkan/kukan-bank/build.mjs   # 問題にできなかったテンプレートと、その理由
```

問題にできなかったテンプレート：`14d02`（答えが小数の問題。この版では扱わない）、`12q05`（誤答が3つ作れない場合がある）。いずれも、その解説の別のテンプレートで5問そろっています。

## コツコツくんに入れるときの注意（要確認）

コツコツくんの本体（ソース）はこのリポジトリに無く、公開版（gh-pages のビルド済みファイル）にしか無いので、取り込みはしていません。入れるときに確かめてほしいことです。

1. **難易度 `d=4`（入試レベル）**：公開版で確認できたのは d=1〜3 までです。d=4 を受けつけるか、受けつけない場合は d=3 に寄せるかを決める必要があります。
2. **解説との紐づけ（`l`）**：既存の問題には解説の番号を持つ項目がありません。`l`（または `s`）で解説に結びつける仕組みを、アプリ側に足す必要があります。
3. **誤答の理由（`w`）と種類（`m`）**：既存の問題と同じ項目名にしてあります。`m` が無い誤答は、`w` だけです。
4. **既存の演習150問**：消さずに、小単元の復習として残す前提です。解説への振り分け案は `existing-redistribution.json`（解説 01・06・08・12・14・15 には、付けられる既存問題がありません）。

## 判断が分かれたところ

- 柱体の体積（J1-SP-001〜020）は、小学校で学ぶので専用の解説が無く、体積・表面積をまとめて練習する解説13に置きました。
- 回転体の体積（J1-SP-089〜100、147、150）は、錐体の公式（解説11）を使うので、回転の形を学ぶ解説05ではなく13に置きました。
- 展開図で「縦」「横」と言うときは、ikkan の教材に合わせ、縦＝高さ、横＝底面のまわり、としています。
