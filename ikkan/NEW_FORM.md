先生（kazu）が、授業で「量が多い・余白が少ない・圧迫感・何をするかわからない」と言ったのを受けて組みかえた形。
見本は **`data/lesson_kukan_new_01.js`**（空間図形 第1時。試作 shisaku-01 を、そのまま第1時にした）。**はじめに、これを全部読む。**
2026-10-29 に先生が言ったこと：「他の14時間も同じ形で作って」「余裕があれば第7章データの活用も」「さらに余裕があれば、正の数・負の数〜平面図形の3点セットも」。

## 1. 紙面のきまり（罫は 8mm・1ページ 33行・ドット罫線）

### ① ワークシート：A4 1枚（約12分）。`BR()` は使わない

上から、この順（33行におさめる。見本は 30行）。

| 部品 | 中身 |
|---|---|
| `M(めあて)` | 1行 |
| `K('今日の問い', …, 1〜2)` | **問いは1つだけ**。自分で観点を決める・予想する・きまりを見つける、など、考えて書ける問い。数字・図は**全部印刷**（空欄 `{{ }}` を使わない）。図があれば `F(行数, 図…)` |
| `T('①', '自分の考え（3分）…', 1)` ＋ `B(3〜4, '（例）…')` | 個人で考える。`B` の中身（解答を表示したときだけ赤）は、先生の板書の例。「（例）」から書く |
| `T('②', 'ペアの考え（3分）…', 1)` ＋ `B(2〜3, '')` | ペアで、自分とちがう考えを書く |
| `WD('…{{ことば}}…', 3〜4, { label: 'ことば（教科書で調べよう）' })` | 重要語句の穴埋め（`{{ }}` は、解答のとき赤）。教科書で調べさせる |
| `K('例題', …, 1〜2)` ＋ 表 `TB(…)` か図 | **空欄 `{{ }}` を入れる**（表のセル・問題文・図の字）。先に解けないように |
| `T('', '【…のくふう】…', 1)` ＋ `B(3, '…')` | 例題の考え方・数え方を書く欄（あってもなくてもよい） |

- **考えよう・発展・友達の説明・振り返りの欄は、ワークシートに入れない**（考えようは、演習プリントの「ひろげる」へ）。
- 流れは、個人3分 → ペア3分 → ことば → 例題（教師の説明つき）。この順にしたがう。計算技能の授業でも、「今日の問い」を「次の計算をして、きまりを見つけよう」のような問いにして、形をそろえる。

### ② 演習プリント：A4 表裏。問題は（1）〜（8）の 8問

| 面 | 見出し（`HD(見出し, 文)`） | 問題 | 中身 |
|---|---|---|---|
| 表 | `確かめる` | （1）（2） | まず `WD(…, 4, { label: 'ことば' })` で ①〜④ の穴埋め。つぎに `C2([T('（1）',…), B(…)], [T('（2）',…), B(…)], '1:1')` の 2問（基本）。そのあと `MA('【説明】…を、隣の人に説明しよう。\n説明できた ☐　　聞いてくれた人（　　　　　　）', 2)`（学び合い） |
| 表 | `使ってみる` | （3）（4）（5）（6） | `C2` を 2段（左右 2問ずつ＝4問）。**ここまでできたら今日の合格**：最後に `T('', '★ ここまでできたら、今日の合格！　　合格 ☐', 1)` |
| ── | `BR()` | | |
| 裏 | `ひろげる` | （7） | 見出しの文は「**考えよう：**…」で始める。`T('（7）', …)` ＋ 表・図 ＋ 「気づいたこと」「ほかのもので確かめる」などの記述欄（`B(n, '')`）。**答えは載せない**（`B` の答えは空にする） |
| 裏 | `チャレンジ★★` | （8） | 入試レベル。`C2([T('（8）',…), B(…, '答え')], [MA('①…\n②…', 5, { label: 'ヒントカード' })], '1:1')`。ヒントカードは、答えを言わず、問いかけで着眼点を示す |

- 表・裏とも 33行におさめる。見出し・問題・罫のすきまは、見本のとおり。
- **図が要る授業**：図は、「確かめる」の `WD`（ことば）の下、（1）（2）の前に、`F(行数, 図1, 図2, 図3)` で**横にならべる**（`SO`・`POLY`・`GEO`・`SVG` に `caption: '図1'` をつける）。問題文は「図1で、…」と書く。2段組の半分の幅（約 90mm）に入らない図を、`C2` の中に置かない（図1つだけが、ある1問にしか使われないときは、`C2` の右に置いてよい）。
- **`WD` の字数**：`label` をつけると、本文は全角 約25字／行。つけないと 約32字／行（全幅の `T` は約37字）。
- 問題の番号は、表から裏へ（1）〜（8）。同じ番号を 2回使わない（記録ページの問題IDになる）。

### ③ 小テスト：A4 1枚・5分・10点満点（見本の `qz` と同じ形）

- `HD('小テスト', '5分で解こう。　　　　　　　　　　　　　得点（　　　　／10点）')`、`G(1)`、問題 4問ほど（点数 `（3点）` を書く。合計 10点）、`G(1)`、`HD('チャレンジ', '入試レベル（別枠）。正解なら、ほかがまちがっていても 10点。　　正解 ☐')`、チャレンジ 1問（点数は書かない）。
- どの問題にも、すぐ下に `B(…, '答え')` をつける。
- この時間の内容。次の時間のはじめに使う。前の時間の「考えよう」の答えは、授業の終わりに先生が方向性を伝えるだけなので、小テスト（解答つき）の答えが、考えようの答えと重なってもよい（演習プリントの（7）と、ワークシート・スライドには、答えを書かない）。**33行におさめる**（旧形式の小テストを移すときは、罫が 7mm → 8mm でふえた分、`B` の行数や `G` をつめる）。

## 3. 文章・記法のきまり

- 生徒に話しかける文。「〜しよう。」「〜を答えよう。」「〜はどうなるだろう。」。難しい漢字・言い回しをさける。**問題・数値・図は、新しく自作**（教科書・市販問題集の問題文は、写さない・要約しない）。
- 量をへらし、書きこむ余白を広くする（先生のスタイル）。問題文は短く。
- **考えよう（ひろげる）の答え・想定される見方は、どこにも書かない**（`B` の答えは空。ヒントカードは、答えを言わない問いかけ）。
- 記法：`{{3}}`＝空欄（解答で赤）／`[[1/2]]`＝分数／`x^2`＝累乗／`√{12}`／`**太字**`／`\\m`＝立体（斜体にしない）にする文字。1〜3文字の小文字は、ふつう数式の文字（斜体）になる（`cm` `kg` などの単位は立体のまま）。
- 文字の使い分け（見本のとおり）：式の `＝`（全角）・`×`・`÷`・`−`（U+2212）・`+`。`n` `x` などの文字は、`2n＝12` のように、数と文字のあいだは空けない。
- 1行に入る字数のめやす（罫 8mm）：全幅の `T` で、全角 約37字。`C2(…, '1:1')` の半分の幅で、全角 約16字。`T(ラベル, 文, 行数)` の行数は、文を**折り返した行数ちょうど**にする（足りないとき `check.cjs` が指摘する。多めにとっても指摘されないが、33行をむだにする。書きこむ余白は、あとの `B(n, '')` の罫でとる）。`B(行数, 答え)` は、答えの行数（`\n` で区切る）が、行数以下になるようにする。
- 33行の使いかたの例（ワークシート）：めあて 1＋今日の問い 1〜2＋図 4〜5＋①（1＋3〜4）＋②（1＋3）＋すき間 1＋ことば 4＋すき間 1＋例題 1＋表・図 4〜5＋くふう（1＋3）＝ 30〜33。足りなければ、図の行数・記述欄の行をへらす。
- 板書の答え（`B` の中）は、先生が板書する内容（式・文・図の読み取り）。解答欄が空欄のままの `B(n, '')` は、生徒が書く余白。

## 4. 過去に見つかった型（かならず避ける。人の目の確認で、致命になったもの）

1. **答えがまちがい**／正解が2つ以上に読める／正解がない／問題文だけでは答えが決まらない（条件の書きもれ。「何個か」だけでは、2通りになる、など）。
2. 問題文・解説が崩れる：名前の置き換えの失敗（ア・イ・ウ、A・B・C のかさなり）、符号・かっこのまちがい、同じ式が2回出る。問題文の数と答えの数が同じになって、答えが見えてしまう（避けられるときは避ける。符号をつけて表す問題など、つくりから避けられないものは、気にしない）。
3. **考えようの答え**が、ワークシート・演習プリント・解答（`B`）のどこかに出ている。
4. 図の字が、線や別の字と重なって読めない／切れる。点の名前が、頂点と変数でぶつかる。
5. 正解がいつも同じ・答えの種類が少なすぎる（毎回 2 など）。
6. 現実にあわない場面の数字（時速 300km の自転車、など）。
7. ワークシートの 1問目（今日の問い）のまわり（`K`・図・`T`・`B` の答えも）に `{{ }}` がある／例題に `{{ }}` がない（例題の空欄は、`K` の文・表・図のどれかに入れる。`T`・`B` の中の `{{ }}` は、数えない）。小テストの点数の合計が 10 でない。
8. 習っていない文字・記号・ことばを使う（正の数・負の数で、まだ習っていない文字 A・B を「ある数」にする、など）。使うときは、問題文のなかで、ことわる。

## 5. 検査（作ったら、かならず通す）

```bash
node tools/verify.cjs kukan_new-02 kukan_new-03          # 検算（checks）・形。授業のID（か、単元のキー）を指定する。「指摘 0」にする
NODE_PATH=$(npm root -g) node tools/check.cjs <画像の出力先> kukan_new-02 kukan_new-03   # 見た目：行・はみ出し・3点セットの印刷ページ数・QR。「指摘 0」にする
```

- `checks`：授業の数値（ワークシート・演習プリント・小テストの、**数の答えすべて**）を、**答えを写さず、別の式で**計算して確かめる JavaScript の式（文字列）。`near(a, b)`＝ほぼ等しい、`PI`＝π。1式に `&&` でつないでよい。何の検算か、前の行に `//` で書く。作り手が、答えを独立に出し直したことの証拠になる。
- 画像（`<出力先>/<授業のID>_ws_ans_p1.png` など）は、**図のある授業だけ、ワークシートの解答つき 1枚と、演習プリントの裏 1枚を見る**（すべての画像を見ない。字のはみ出し・行数は、`check.cjs` が見る）。
- 他の人が、同じ `data/` に、別の授業を書きかけているかもしれない。他の人のファイルの指摘は、無視する（自分の授業だけを指定して検査する）。
- 検査の道具（`tools/`）が、おかしいと思ったら、直さずに、報告にだけ書く。

## 6. 図の部品

書き方は `README.md` の表と、各ファイルの冒頭。`F(行数, 図…)` の中に書く（横にならぶ）。

| 図 | 書き方 | 冒頭を読むファイル |
|---|---|---|
| 立体の見取図 | `SO({ shape, a, b, c, n, caption … })`・`POLY({ solid, V, … })`（凸多面体） | `js/core.js`（SO）・`js/figs3d.js`（POLY） |
| 数直線・座標平面・ヒストグラム・おうぎ形・てんびん・長方形 | `NL`・`CO`・`HIST`・`SEC`・`BAL`・`RECT`。数直線は `NL({ min, max, step: 0.5, labelStep: 1, dots: [3], pts: [{ at: -2.5, name: 'A', a: '−2.5' }], arrows, marks })`（`step`＝半目もりなど、`dots`＝最初から出す点、`pts`＝名前つきの点：名前は黒・`a` は解答のとき赤） | `js/figs.js` |
| 平面図形（角・平行線・三角形・合同・作図の線） | `GEO({ pts, poly, segs, vl, ang, tick, par, dots, txt, a })` | `js/geo.js`（冒頭に、全部の書き方） |
| 自由な図 | `SVG((W, H, h) => '<svg の中身（単位 mm）>')`。`h.ln`・`h.tx`・`h.ans(…)`（解答のときだけ出す） | 見本 `data/lesson_kukan_02.js`（図の関数の例） |

図は、枠（`F` の行数 × 幅）におさまるように描かれる。字が小さくなりすぎないよう、行数は 4〜7 行をめやすに。

## 8. やらないこと

- `git` の操作（add・commit・push など）。コミットは、こちらでする。
- 自分の授業のファイル以外の書きかえ（`index.html`・`data/lessons.js`・`data/lesson_*.js`の他の人のもの・`js/`・`tools/`・README）。
- 授業計画（`plan:`）・スライド・コツコツくん形式の問題の作成。
- 見た目を直すためだけに、何度も画像を見ること（`check.cjs` の指摘が 0 なら、十分）。

## 9. 終わったら、こう報告する（25行以内）

- 作ったファイル（授業のID）と、`verify.cjs`・`check.cjs` の最後の行（指摘 0 か）。
- 前の形・授業ナビから、変えた数値・答え（まちがいを見つけたとき）。
- **確認していないこと**・自信のないところ（正解が 2つに読めそうな問題、図のずれ、など）。あれば、授業のID・問題番号つきで。
