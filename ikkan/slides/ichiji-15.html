学習課題

市民プールには、3つの料金プランがある。
1か月に x回利用したときの料金を y円とする。
A … 1回ごとに 300円
B … 月会費 600円と、1回ごとに 100円
C … 月会費 1400円で、何回でも利用できる。
右の図は、A、B、C のグラフ（縦の 1目もりは 100円）。
どのプランが得か、調べよう。

【式】A、B、C の式を書こう。　【グラフから】回数ごとに、いちばん安いプランは？

一次関数　第15時　3つの料金プランを、グラフでくらべよう

【解説 4分・学習課題】めあてを書く。3つのプランの式を書き、図のグラフを見て、回数ごとにいちばん安いプランを調べる。発問：どのプランが得だと思う？ 何がわかれば決められる？／グラフが下にあるのは、どういうこと？　想定される反応：A：y＝300x、B：y＝100x+600、C：y＝1400。x＝3、8 で交点。　留意：縦の 1目もり＝100円を言う。回数で変わることを、ここで気づかせる。

学習課題のまとめ

第15時　3つの料金プランを、グラフでくらべよう

3つのプランの式と、回数ごとに、いちばん安いプラン。

【式】

A　y＝300x

B　y＝100x+600

C　y＝1400

【グラフから】

1・2回 … A　　3回 … A と B が同じ
4〜7回 … B　　8回 … B と C が同じ
9回以上 … C

（交点は 300x＝100x+600 を解いても x＝3 と求められる）

【解説 4分・学習課題のまとめ】板書の順：3つの式 → グラフの交点（x＝3、x＝8）→ グラフがいちばん下のプランが安い → 回数ごとに分ける（1・2回 A、3回 A と B が同じ、4〜7回 B、8回 B と C が同じ、9回以上 C）。赤い字は、先生の板書。交点は、2つの式を等しいとおいて解いても求められる。
