# ikkan の空間図形の問題 → コツコツくん（数学ラボ ソロ）の問題テンプレート

ikkan（授業準備ツール）の空間図形（全15時）の演習プリント・小テストの問題を、**コツコツくんの問題データと同じ形**（毎回数字が変わるテンプレート）にして置いたものです。

## いまの数（全15時）

- テンプレート **313 本**（1授業＝1単元、`J1-kk01`〜`J1-kk15`）。ikkan の演習プリント・小テスト 225 問のうち、**224 問を移した**（1問は、投影図をかく作図で、`SKIPPED` に理由つき）。
- 作ったあと、作った人とは別の人が、問題文の数字だけから答えを解き直して確かめ（第1・2回。数十万問分）、見つかった問題（正解が2つに読める選択肢、ヒントが答えを言っている、問題文が図に頼っている など）を直してある。直したあとも、検査（`verify.mjs`）は、エラー 0。
- 見本（テンプレートごとに2問、答え・ヒント・解説つき）：`node ikkan/kotsu/preview.mjs 出力先.html`。

## 位置づけ（いま、どこまでできているか）

- コツコツくんの本番（`/solo/`）のソースは、このリポジトリに無い（公開された `solo/` の中身だけが `gh-pages` にある）ので、**コツコツくんの中には、まだ入れていません**。
  ここにあるのは、コツコツくんの問題データの書き方（`src/solo/content/` の `UNITS`／`t(id, build)`。`docs/solo-問題データの書き方.md`）にそろえた、**取りこむだけの形のデータ**です。
- 問題は、`kit.js`（コツコツくんの本物と同じ道具）だけで動くので、コツコツくんのソースに置けば、そのまま動くはずです（まだ、本物の中では動かしていません）。

node ikkan/kotsu/preview.mjs [出力先.html]                                             # 見本の HTML

## ikkan の問題との対応（問題ID）

- テンプレート id＝「授業の番号 2けた」＋ `d`（演習プリント）／`q`（小テスト）／`w`（ワークシート。任意）／`x`（ikkan にない補い問題）＋ 問題の番号 2けた（＋ a, b…）。
  例：`03d04` ＝ ikkan の `kukan-03.dr.4`（記録ページの問題IDと同じ）。ikkan の記録ページ（結果コード・集計）の問題IDで、コツコツくんの問題とつながります。
- ikkan の演習プリント・小テストの問題（（1）（2）…）は、**1問のこらず**「移した」か「`SKIPPED` に理由つき」のどちらかです（`verify.mjs` が、もれをエラーにする）。

## 移し方の約束

- コツコツくんの答えは、**数値の入力**か**4択**だけ。図は出せない。そこで、
  - 数・長さ・面積・体積 → 数値入力（円周率が出るときは、既存の中1空間図形と同じ「□π cm²。□は？」）
  - 「すべて答えよう」 → 「何本か」の数の問い、または「次のうち…はどれか」の4択
  - 名前・用語・性質 → 4択
  - 図が必要な問題 → 文章だけで言い切れるものは文章にして移す。言い切れないものは `SKIPPED`
  - 説明・記述・作図 → 概念をたずねるものは、正しい説明を選ぶ4択。それもできないものは `SKIPPED`
- 辺・面の関係や面辺頂点の数は、`solids.js` で**計算**している（手で書いた答えを埋めこまない）。
- ikkan の問題は 1 つの例なので、テンプレートは、その型の**数字（立体）が変わる問題**にしてある。ikkan にある数字そのままの問題は、数字の範囲にふくまれるが、毎回出るわけではない。

## コツコツくんに取りこむとき

1. `content/*.js`・`solids.js`・`kukan-kit.js` を、`src/solo/content/jhs/` のあたりに置く（`../kit.js` の読み込みは、本物の `kit.js` に合わせて直す）。
2. 単元（`J1-kk01`〜）は、`chapterId: "ikkan-kukan"`・`chapterName: "空間図形（ikkan の授業）"` を持つ。中学の単元は章でまとめる決まりなので、本物の章の持ち方に合わせる（既存の `J1-k1`〜`k4` と同じ章にまとめるか、別の章にするか）。`prereqs` は、既存の単元（`E6-kakuchu`・`J1-k2`〜`k4`・`J1-z3` など）につないである。
3. 単元の要点（`points`）は、講義の代わりの 2〜4行。ホー先生の解説（講義データ）は、まだ無い。
4. 本物の検査（`solo-verify.mjs`）を通す。`ikkan` フィールドと、`fixed` は、本物のアプリには使われない（あっても害はない）。
5. ikkan の記録ページ（結果コード）とのつなぎ：テンプレート id の「授業番号＋d/q＋問題番号」が、記録ページの問題ID（`kukan-03.dr.4`）に対応する。コツコツくん側で学習記録を持つとき、この id を一緒に残すと、授業の理解度と、コツコツくんの習熟が、同じ問題でつながる。

## 注意

- 答えの正しさは、機械の検査（書式・選択肢・数値の誤差）と、別の目での解き直し（独立の確認）で確かめています。実際の授業・生徒に出す前に、サンプル（`preview.mjs`）を見て、問題文の言い回しを確かめてください。
- 図が出せないので、立体の頂点の名前（A〜H）は、問題文の頭に文章で約束しています。
