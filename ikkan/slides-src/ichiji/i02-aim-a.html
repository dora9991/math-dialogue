学習課題のまとめ

第2時　一次関数かどうかを、式の形で判断しよう

ア〜キの式のうち、y が x の一次関数であるものを選ぼう。

ア、ウ、オ、キ

（y＝ax+b の形で、x の項があるもの）

イ … x が分母にある。

エ … x² がある。

カ … x の項がない。

キ　y＝7−3x は、ならべかえて y＝−3x+7 と見る。

ウ　y＝−x は、y＝−1×x+0 と見る。

一次関数　第2時　一次関数かどうかを、式の形で判断しよう

【解説 4分・学習課題のまとめ】いくつかのペアの考えを聞いて、板書にまとめる。観点は1つに決めず、出た考えを集める。一次関数は、ア、ウ、オ、キ（y＝ax+b の形で、x の項があるもの）。イは x が分母にある、エは x² がある、カは x の項がない。キはならべかえて y＝−3x+7、ウは y＝−1×x+0 と見る。赤い字は、先生の板書。
