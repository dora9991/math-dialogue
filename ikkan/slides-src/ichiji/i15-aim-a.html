学習課題のまとめ

第15時　3つの料金プランを、グラフでくらべよう

3つのプランの式と、回数ごとに、いちばん安いプラン。

【式】

A　y＝300x

B　y＝100x+600

C　y＝1400

【グラフから】

A と B の交点は x＝3、B と C の交点は x＝8
グラフがいちばん下のプランが安い

1・2回 … A　　3回 … A と B が同じ
4〜7回 … B　　8回 … B と C が同じ
9回以上 … C

（交点は 300x＝100x+600 を解いても x＝3 と求められる）

一次関数　第15時　3つの料金プランを、グラフでくらべよう

【解説 4分・学習課題のまとめ】板書の順：3つの式 → グラフの交点（x＝3、x＝8）→ グラフがいちばん下のプランが安い → 回数ごとに分ける（1・2回 A、3回 A と B が同じ、4〜7回 B、8回 B と C が同じ、9回以上 C）。赤い字は、先生の板書。交点は、2つの式を等しいとおいて解いても求められる。
