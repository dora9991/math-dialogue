第16時　図形の中を動く点がつくる面積を調べよう

点 P の速さを、毎秒 2cm に変えたとする。
x と y の関係を表すグラフは、どう変わるだろう。

①

P が B に着くのは何秒後か。
C に着くのは何秒後か。

②

y を x の式で表そう。x の変域も書こう。

③

新しいグラフを、右の図にかこう。
（もとのグラフは、かいてある）

④

もとのグラフとくらべて、気づいたことを書こう。
そのわけも説明しよう。

発展

演習まで解き終わった人は、考えてみよう！　点 P が、A を出発して、辺 AD、DC の上を、毎秒 1cm で C まで動くとする。三角形 APC の面積 y を、x の式で表し、グラフをかこう。もとのグラフと、くらべてみよう。

【演習 23分・考えよう】進め方：演習① 考えようの提示 2分（ゴールは「考えよう」＝ワークシート裏を、全員が説明できること。立ち歩きOK、解答は教卓。考えようの答えはない。「できた人が教える」ではなく「説明できるようになる」と伝える）→ 演習② 基礎 5分（個人。解いたら、教卓の解答で答え合わせ。早く終わったら、考えようへ。図に長さを書きこませる）→ 演習③ 考えよう＋標準 14分（学び合い。立ち歩きで、教え合い・説明し合い。先生は回って、気づきの言葉を拾い、必要なら判断して短く全体に戻す）→ 演習④ 方向性 2分。問い：点 P の速さを、毎秒 2cm に変えたとする。x と y の関係を表すグラフは、どう変わるだろう。ヒントを出す順：1）P が B、C に着くのは、何秒後だろう。2）2倍の速さで x 秒後に進む長さは？ AP や PC を x で表す。3）もとのグラフと、ならべてかいて、くらべる。判断：時刻が出ない→図に、AP や PC の長さを書かせる／止まる→ヒント1／くらべない→ヒント3／残り5分→指名。答えは言わない。方向性（演習④ 最後に一言）：「速さを変えると、グラフの形がどう変わるか。ほかの速さでも、ためしてみよう。次は、単元のまとめだよ。」　発展は、演習まで解き終わった人向け。
