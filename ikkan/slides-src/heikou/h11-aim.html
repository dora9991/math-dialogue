「正しい」ことを、だれもが納得できるように伝えるには

学習課題

右の図で、線分 AB と CD が点 O で交わり、
AO＝BO、CO＝DO である。
AC と BD の長さについて、調べよう。

①

AC と BD を、ものさしではかって、くらべよう。

②

ほかの図でも、いつでも AC＝BD といえるだろうか。
はからずに、だれもが納得できるように、説明しよう。

平行と合同　第11時　「正しい」ことを、だれもが納得できるように伝えるには

【解説 4分・学習課題】めあてを書く。AC と BD をはかって比べ、「はからずに、いつでも等しいといえるか」を、個人→ペアで考える。発問：AC と BD は、等しかった。ほかの図でも、いえるだろうか。／はからずに説明するには、どの三角形に目をつけるだろう。　想定される反応：△AOC と △BOD の合同に目をつけ、等しい辺・角をあげて説明する。留意：はかるのは短く。説明は板書でまとめ、1行ごとに「なぜ？」と聞く。ものさしは、班に1本。
