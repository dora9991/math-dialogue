整数 … 正の整数、0、負の整数のこと。
　（3.5 や 2⁄3 のような小数・分数は、整数ではない。）

n を整数とすると、3の倍数は 3n、5の倍数は 5n と表される。

n の次の整数は n+1、n の前の整数は n−1 と表される。

数の性質の説明は、次の順に書く。
　きまりを見つける → 文字でおく → 式を変形する → 式を読む
　（式を読む … 「（　）は整数だから、〜の倍数である」と、
　　結論を書く。）

【解説 3分・ことば（答え）】空欄の答え。先生が言い切ってから、書かせる。重要語句（整数・倍数・文字でおく・式を変形する・式を読む）は、先生が言い切る。
