第8時　偶数・奇数や2けたの自然数の性質を、文字で説明しよう

n を整数とすると

　偶数 … 2n　　奇数 … 2n+1　　3の倍数 … 3n

十の位の数が a、一の位の数が b の2けたの自然数 … 10a+b

　（例）37＝10×3+7

説明の進め方 …
　きまりを見つける → 文字でおく → 式を変形する → 式を読む

式の計算　第8時　偶数・奇数や2けたの自然数の性質を、文字で説明しよう

【解説 3分・ことば（答え）】空欄の答え。先生が言い切ってから、書かせる。（例）37＝10×3+7 の「10×3+7」の形から、10a+b を確かめる。重要語句は、先生が言い切る。
