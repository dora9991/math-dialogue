式の計算　第9時　カレンダーの数からきまりを見つけて、文字で説明しよう

【演習 23分・考えよう】進め方：活動の提示（2分）→ 基礎（個人、5分。カレンダーの数を n で表す。解いたら教卓の解答で答え合わせ）→ 終わった人から考えようへ（きまりを見つける・学び合い 14分。立ち歩きOK）→ 方向性（2分）。解答は教卓（考えようの答えはない）。「見つけて終わり」でなく「説明できる」ことが目標と伝える。流れ：形を決める → 計算で予想 → n でおく → 式を変形 → 読む。ヒントを出す順：1）まず、縦3つ・横3つなど、かんたんな形を囲んで、和を計算する。2）基準にする数を、まん中か左上など、1つ決めて n とおく。3）囲んだ数を n で表し、和や差を計算して、式を読む。判断：形が決まらない→ヒント1／止まる→ヒント2・3／残り4分→指名。答えは言わない。方向性（最後に一言）：「見つけたきまりを、自分の文字式で確かめられた。ほかの数の表でも、自分で調べてみよう。次の時間は、式の使い方をもう1つ学ぶよ。」
