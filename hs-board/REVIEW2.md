# 入試の類題②：数学の点検（確かめ役むけ）

類題②（`scenes/<ID>.js`）は、問題の小問の答えは別の人が解き直して確かめてある。**まだ確かめていないのは、解説の途中（黒板の式・字幕）と、発問（4択）・考えてみよう**。ここを1本ずつ、自分で計算して確かめる。

**約束：リポジトリのファイルは書きかえない（読むだけ）。ファイルを消さない・動かさない（`rm`・`mv` は使わない）。** 書くのは、指示された報告ファイル1つと、scratchpad の自分の作業フォルダの中だけ。インターネットは使わない。

## 見るもの（1本ずつ、`scenes/<ID>.js` を全部読む）

台本は `HB.lesson({ problem, steps:[…] })`。`steps` の番号は 0 から数える（報告にはこの番号と `part` を書く）。

1. **発問（`ask.type === 'choice'`）**：`q`（問い）・`opts`（選択肢 0〜3）・`ok`（正解の番号）・`why`（まちがいの選択肢ごとの理由）・`good`（正解の説明）。
   - 問いを **自分で解いて**（python3・sympy で確かめてよい）、正しい選択肢を決める。`ok` と合っているか。
   - **正解が2つ以上ないか**（別の形で同じ値・同じ内容、条件しだいで正しくなる選択肢、問いの読み方しだいで正しくなる選択肢）。**正解が1つもない** ことはないか。
   - 問いの文が、答えと かみ合っているか（「正しくないものは？」なのに正しいものが答え、など）。
   - `why`・`good` の説明が数学として正しいか、その選択肢の説明になっているか。
2. **考えてみよう（`ask.type === 'think'`）**：`q`・`hint`・`ans`・`after` が正しいか（自分で解く）。
3. **黒板の式と字幕**（各ステップの `add` の `tex`・`text`・表、`say`）：1行ずつ追って、式変形・符号・係数・不等号の向き・場合分け・定義域・極限・積分の計算が正しいか。前の行から次の行が本当に出るか。字幕（`say`）が黒板の式と合っているか。
4. **図**（`t:'fig'` の `items`、`draw`）：点の座標・曲線の式・名前・長さが、問題文・解説の数と合っているか（例：問題が A(2, 0, 1) なのに図は別の点、接点の位置がちがう、など）。
5. **問題文（`problem`）と、まとめ（`POINTS`）**：解説の結論と合っているか。条件の書きもれで答えが決まらなくならないか。

## 報告の書き方

**本当のまちがい・あいまいさだけ** を書く（言い回しの好み・「もっとよい説明がある」は書かない）。見つけたら、python で確かめてから書く。

報告ファイル（指示されたパス）に、1本ごとに：
```
## <ID>
- 確かめた数：発問 n 問・考えてみよう n 問・ステップ n
- 【誤り／複数正解／正解なし／あいまい／図のくいちがい】 steps[k]（part）：「…（台本の文をそのまま）…」
  - どこがちがうか：…
  - 確かめ：…（計算・python の結果）
  - 直す案：…
（なければ「問題なし」）
```
最後の返事は短く：本ごとの指摘の数と、いちばん重いもの。
