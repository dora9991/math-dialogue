# 高校数学 黒板解説（hs-board）

黒板に1行ずつ書きながら解説するブラウザ教材。中学の「ホー先生とポンタ」（lesson-navi/video/talk）の高校版で、**キャラクターなし・声なし**。途中に「発問」（4択・誤答ごとの理由）と「考えてみよう」（ヒント → 答え → ◎△× の自己評価）が入る。

- 目次：`index.html`（タブ＝コース、章 → 節 → カード）　再生：`play.html?s=<ID>`
- 手元で見る：プレビュー名 `hs-board`（`python3 -m http.server 8830 --directory hs-board`）。file:// で開いても動く。
- 数式は KaTeX（`vendor/katex` に同梱・MIT）。黒板の字は Google Fonts の Klee One（つながらないときは丸ゴシック）。

## 再生の機能（ホー先生の会話アプリと同じ）
| 操作 | キー | ボタン | 中身 |
|---|---|---|---|
| つぎへ／もどる | Enter・→／← | つぎへ・もどる | 書いている途中の Enter は、まず書き終える |
| 自動で進める | A | 自動 | 読み終わるころに次へ。発問・考えてみようでは止まって答えを待つ |
| 動画モード | W | 開始カード | 発問も少し待ってから答えを出し、最後まで流れる（成績カードのかわりに「おしまい」） |
| 一時停止 | P | ⏸ 停止 | その瞬間で止まる（書くアニメ・待ち時間とも）。黒板タッチでも再開 |
| 速さ | S | 速さ | ×1 → 1.25 → 1.5 → 2 → 0.75（書く速さと自動の待ち時間）。端末がおぼえる |
| 小数 | D | 小数 | 数字だけの分数の横に小数（=0.5／≒0.333）。台本の `noDec:true` で使わない |
| もう一度 | R | ↻ | このステップを書き直す |
| 問題・例題 | Q | 📄 | 問題文（例題の一覧）をいつでも |
| ヒント | H | 💡 | 発問・考えてみようのヒント |

- URL：`?auto=1`・`?watch=1`・`?speed=1.5`・`?dec=1`・`?embed=1`（目次を隠し、進み具合を postMessage `{src:'hs-board', ev, …}` で親へ）・`?step=N`（検査用）。
- 目次の「開きかた」（ふつう／自動／動画モード）は端末がおぼえ、リンクに付く。最後の成績カードに「つぎの解説へ」（同じコースの次の READY）。
- 途中で目次へもどると、場所と答えをおぼえていて「つづきから」が出る（動画モード・埋めこみ・検査では記録しない）。
- 時間は「動画の時計」で数える（一時停止で止まり、倍速で速く進む）。画面が裏に回っても進む。

## 台本の書き方
`AUTHORING.md`（執筆担当むけの決まり・部品の一覧・検査のしかた）。見本は `scenes/m1a-01.js`（式）・`m1a-10.js`（数直線）・`m1b-02.js`（ベン図）・`ku-calc-01.js`（関数のグラフ）。

## 検査（音なし・ヘッドレス Chrome）
```bash
node hs-board/tools/check.mjs                 # 台本ファイルがあるもの全部
node hs-board/tools/check.mjs m1a-01 --shots <フォルダ>   # 1本＋各ステップの写真と1枚まとめ
```
数式エラー・黒板からのはみ出し・字幕にかくれる所（小数表示を入れた形で測る）・通しテスト（正解／まちがい／もどる／動画モードで最後まで）を調べる。✗ と ⚠ を全部なくしてから READY に入れる。

## 公開
