# 黒板解説（hs-board）の台本の書き方 ─ 執筆担当むけ

声なし・キャラクターなしの「黒板で1行ずつ書いていく解説」を、`scenes/<ID>.js` に1本ずつ書く。Enter で進み、途中に **発問（4択）** と **考えてみよう**（ノートで解いてから答えを見る）が入る。自動再生・動画モード・倍速・一時停止・小数表示は、プレーヤーが全部やる（台本は気にしなくてよい）。

## 0. 守ること（最重要）
1. **著作権**：例・例題・数値・場面・ことばは **すべて自分で作る**。教科書・問題集・入試問題・サイトの文や数値をうつさない（「よくある例題の数字だけ変える」もしない）。数学の定義・定理・公式・用語は自由に使ってよい。
2. **触ってよいのは、担当の `scenes/<ID>.js` だけ**。`js/`・`css/`・`index.html`・`play.html`・`js/lessons.js`・`tools/`・ほかの台本は **書きかえない**。足りない図の部品は、いまある部品の組み合わせで作る（どうしても無理なら、報告に書く）。git・公開（deploy）は **しない**。
3. **音を出さない**。検査はヘッドレス（下のコマンド）だけ。
4. **数学の正しさ**：答え・途中式・図の座標は、必ず `python3`（sympy 可）で検算する。誤答の選択肢は、高校生が実際にしがちなまちがい（符号・係数のかけ忘れ・不等号の向き・場合分けもれ など）から作り、`why` で「なぜちがうか」を言う。
5. 学習指導要領（2022〜）の数学Ⅰの範囲で書く。
   - 三角比：角は度（$30^\\circ$）。$\\sin\\theta$ のように `\\sin` `\\cos` `\\tan` `\\theta` を使う。弧度法・加法定理は数学Ⅱなので使わない。三角比の表の値を使うときは小数第4位まで（例：$\\sin 35^\\circ=0.5736$）。
   - 数学A：順列・組合せは教科書の書き方 `{}_n\\mathrm{P}_r`・`{}_n\\mathrm{C}_r`（例：`'{}_5\\mathrm{C}_2=10'`）、階乗 `n!`、確率 `P(A)`、条件付き確率 `P_A(B)`。期待値は数学A（2022〜）にふくまれる。整数は「a を b で割った商 q・余り r」で `a=bq+r\\ (0\\le r<b)`、合同式は使わない（発展あつかい）。図形の性質の証明は、教科書のように根拠（「円周角の定理より」など）を言葉でそえる。
   - データの分析：四分位数は教科書の方法（データを小さい順に並べ、中央値で前半・後半に分け（個数が奇数なら中央値は前半・後半に入れない）、前半の中央値が Q1、後半の中央値が Q3）。numpy の既定（補間）は使わない。分散は **n で割る**（不偏分散ではない）。外れ値は「Q1−1.5×(四分位範囲) 以下、Q3＋1.5×(四分位範囲) 以上」。相関係数 $r=\\dfrac{s_{xy}}{s_xs_y}$。仮説検定は「基準となる確率 5%」と、コイン投げなどの自作のシミュレーション結果（度数の表）で判断する形。
3次の乗法公式・因数分解（$(a+b)^3$、$a^3+b^3$）は数学Ⅱなので **使わない**。集合の要素の個数 $n(A)$ は数学Aなので、数学Ⅰの授業では使わない（数学Aの授業では使う）。

## 1. 場所とコマンド（すべて `math-dialogue/` で）
```bash
node --check hs-board/scenes/<ID>.js
TMPDIR=<自分の作業用フォルダ> node hs-board/tools/check.mjs <ID> [<ID>…] --shots <自分の作業用フォルダ>/shots
```
- 検査は：数式エラー（KaTeX）・黒板からのはみ出し・字幕にかくれる所・字幕が高すぎる所・通しテスト（正解／まちがい／もどる／動画モード）。**✗ と ⚠ は全部なくす**。
- `--shots` の `<ID>.sheet.jpg`（全ステップの写真を1枚にまとめたもの）を **Read で必ず見て**、図の重なり・字のかぶり・空きすぎ・文字の小ささを直す。気になるステップは `<ID>/NNN.jpg`（1600×900）を見る。
- 手元で開く：`http://localhost:8830/play.html?s=<ID>`（プレビュー名 hs-board）、`?step=N` でそのステップへ直接。

## 2. 台本の骨組み（見本：`scenes/m1a-01.js`（式）・`scenes/m1a-10.js`（数直線）・`scenes/m1b-02.js`（ベン図）・`scenes/ku-calc-01.js`（関数のグラフ））
```js
(function () {
  const POINTS = ['ポイント1', 'ポイント2', 'ポイント3'];          // まとめのページと成績カードに出る（3つ）
  HB.lesson({
    id: 'm1a-04', field: '数学Ⅰ　数と式', title: '（js/lessons.js と同じ題名）', level: '1節 式の計算', time: '目安 7分',
    noDec: false,                                    // 小数表示（D）で答えがばれる授業（循環小数など）は true
    problem: { label: '例題', lead: 'この時間の例題', parts: ['(1)　…', '(2)　…'] },   // Q キーで見られる例題の一覧
    points: POINTS,
    cols: [0.56, 0.44],                              // 左右の列の幅（左＝説明と式、右＝図・表）。[1] で1列
    steps: [
      { part: 'めあて', say: '字幕', add: [{ t: 'box', c: 'y', label: 'めあて', text: '…' }] },
      { clear: true, part: '見出し', say: '…', add: [ … ] },   // clear＝新しいページ（黒板を消す）
      { say: '…', add: [ … ], draw: [{ fig: '図のid', items: [ … ] }] },
      { ask: { type: 'choice', q: '発問', opts: ['…', '…', '…', '…'], ok: 0,
               why: { 1: 'この誤答の理由', 2: '…', 3: '…' }, good: '正解の説明', add: [答えたあと黒板に足す物], draw: [ … ] } },
      { ask: { type: 'think', q: '考えてみよう', hint: 'ヒント', ans: '答え', after: '補足', add: [ … ] } },
      { clear: true, cols: [1], part: 'まとめ', lab: 'まとめ', say: 'まとめです。…',
        add: [{ t: 'h', text: 'この時間のポイント' }].concat(POINTS.map((s, i) => ({ t: 'box', c: ['y', 'p', 'b'][i], label: '①②③'[i], text: s }))) },
      { end: true, say: 'おつかれさまでした。例題（Q キー）を見ながら、ノートで自分でもう一度やってみましょう。' }
    ]
  });
})();
```

## 3. 1本の大きさと流れ（授業の解説）
- **14〜22 ステップ**、**発問（choice）3〜5 問**、**考えてみよう 1〜2 問**。動画モードで ×1 の速さで 4〜7 分。
- 流れ：**めあて** → 用語・考え方の説明（図・表で）→ **例題を1行ずつ** → 発問で確かめ → 少しひねった問い（考えてみよう）→ **まとめ**（POINTS）→ end。
- 前の時間・次の時間とのつながりを一言入れる（「前の時間の〇〇を使います」「次の時間は〇〇」）。中学の内容を思い出させる導入も歓迎。
- 例題は、教科書の例題のように「定義 → 典型 → 少しひねり」の順。数値は自作。
- 4択の正解の位置は、本ごとに 0〜3 をばらす（いつも 1 番にしない）。2択（○×）も使ってよい。

## 4. ことば
- `say`（字幕）は **2行（だいたい 90 字）まで**、多くても3行。長くなるならステップを分ける。高校生向けの、ていねいで短い文。「です・ます」。
- 発問の `why` と `good` は、それぞれ 1 文（合わせて 90 字くらいまで）。字幕が高くなると黒板の下がかくれる（検査が ⚠ を出す）。
- 字の中：`$…$` 数式（KaTeX）、`{{…}}` 桃色、`[[y:…]]` `[[b:…]]` `[[g:…]]` 黄・青・緑、`**…**` 太字、`\n` 改行。数式の中は `\ans{}`（桃）`\hy{}`（黄）`\hb{}`（青）`\hg{}`（緑）で色。
- JS の文字列は `'…'`。中に `'` を書くときは `"…"` でかこむ（例：`"$f'(x)$"`）。バックスラッシュは2つ（`'\\frac{1}{2}'`）。
- 数式の中に日本語を入れるときは `\\text{…}`（例：`'x\\text{ について 次数 }3'`）。なるべく数式の外に書く。
- 分数は `\\dfrac`（文中で大きく見せたいとき）／`\\frac`。ベクトルなどは使わない（数学Ⅰ）。
- 数式の中に ①②③ を書かない（ブラウザの警告になる）。番号は数式の外か note に。枠の見出し（label）は数式が使えない。
- 関数の式の `-x**2`・`-(x+3)**2` は、プレーヤーが自動で `-(x**2)` の形に直す（JS ではそのままだと文法エラー）。かっこでくくって書いておけば確実。
- 選択肢の数式は、ボタン1つの幅（約250px）をこえると折り返す。長いときは「y=」を省くなど短くする。

## 5. 黒板（`add` と `draw`）
- 黒板の物 `add: [...]`（`col: 0` 左／`col: 1` 右）：
  - `{t:'h', text}` 見出し（黄・下線）　`{t:'m', tex, note}` 数式の行（note＝右の小さい青いメモ）　`{t:'p', text}` 文
  - `{t:'box', c:'y'|'p'|'b'|'g', label, text|tex}` 枠　`{t:'ans', label:'答', text|tex}` 答えの枠（桃）
  - `{t:'tbl', rows:[[…],[…]]}` 表（1行目・1列目が黄。`cls:'rowh'` で1行目だけ黄）　`{t:'gap', h}` すきま
  - `{t:'fig', id, view:[x0,y0,x1,y1], w, h, items:[…]}` 図。**w:h は view の縦横比にそろえる**（ずらすと形がゆがむ。関数のグラフは y を縮めてよい）
  - 共通：`size:'sm'|'xs'|'lg'`、`c`（色）、`id`（`hl:['id']` で光らせる・`dim:['id']` でうすく）、`style`（CSS）
  - 複数行の式は `'\\begin{aligned} … &= … \\\\ &= … \\end{aligned}'`。場合分けは `\\begin{cases}`。
- 黒板の高さは 640px。字幕（下）にかからないよう、**1ページの物は上から 560px くらいまで**。足りなければ `clear:true` でページを分ける。左の列は 8〜9 行まで。
- 図の部品（`items` と `draw` の中。座標は数学の座標、y が上）：
  - `{k:'axes', tx:[1,2,[3,'3']], ty:[…], xl:'x', yl:'y'}` 座標軸と目もり
  - `{k:'fn', f:'x**2-4*x+3', a, b, label, lat:[x,y], la:'start'|'end'}` 関数のグラフ（JS の式。`**` はべき乗、`sqrt()` `abs()` 可）
  - `{k:'line', m, n}`（y＝mx＋n）／`{k:'line', x:c, dash:true}`（縦線）　`{k:'area', f, g, a, b, c, alpha, label, lat}` 2つのグラフの間をぬる
  - `{k:'seg', a:[x,y], b:[x,y], c, wd, dash, arrow}`　`{k:'vec', …}`（矢印）　`{k:'poly', pts:[[x,y],…], close, fill, alpha}`
  - `{k:'pt', at:[x,y], name, dir:'n'|'ne'|'e'|…, off, dx, dy, open:true（白ぬき）, c, size}`　`{k:'dot', at}` 小さい点
  - `{k:'label', at:[x,y], text, size, anchor:'start'|'middle'|'end', dx, dy, plain:true（英字を斜体にしない）}`（`plain` はどの部品のラベルにも使える。「15 m」など単位があるとき）
  - `{k:'arc', o, r|rp, a1, a2, label}` 弧　`{k:'circle', o, r|rp, fill, alpha, label, lat}` 円
  - `{k:'numline', step:1 | ticks:[…]}` 数直線（`view` の y の範囲は −0.6〜1.4 くらい、h は 170。下にも書くなら −1.6〜1.4 で h 255）
  - `{k:'range', from, to, fromIn, toIn, h, c, label}` 不等式の解（数直線の上のはね上がった線。from/to が null で「どこまでも」。●＝ふくむ、○＝ふくまない）
  - `{k:'dim', a, b, dy, label}` 2点間の長さ（両はし矢印。dy は上下のずらし px、上がマイナス）
  - `{k:'venn', A:{o,r}, B:{o,r}, shade:['AB','Ab','aB','ab'], fc, alpha, U:false, names:['U','A','B']}` ベン図（AB＝A∩B、Ab＝Aだけ、aB＝Bだけ、ab＝どちらでもない）
  - `{k:'axes', at:[150,40], grid:true, xaxis:false, yaxis:false, xl:'身長', yl:'体重'}`：軸が交わる点を `at` で（データの図など原点が図の外のとき）。`grid` でうすい方眼、`yaxis:false` で y 軸をかかない（箱ひげ図）。2字以上の軸の名前は矢印の上・右に出る
  - `{k:'right', o, a, b, s}` 直角の印（o＝直角の頂点、a・b＝2辺の上の点）　`{k:'angle', o, a, b, rp, label, n}` 角の弧（180° 以下の側。n:2 で二重の弧）
  - `{k:'bars', bins:[[左,右,度数],…], labels:true, fill, alpha}` ヒストグラムの柱（y が度数）
  - `{k:'box', v:[最小,Q1,中央値,Q3,最大], y, h, mean, out:[外れ値…], label, c, fill}` 横向きの箱ひげ図（mean は＋印、out は○）
  - `{k:'pts', list:[[x,y],…], r, c}` 散布図の点をまとめて
- 図のラベルは KaTeX が使えない（ふつうの字）。英字は数式の斜体、数字・− √ π ° などは数式の立体の字体で自動的に出る（`-` も `−` に直る）。`\n` で改行できる。図の部品にも `id` をつけると、ステップの `dim:['id']` でうすく、`hl:['id']` で光らせられる。上つき・下つきは `x²` `a₁` のような文字で。マイナスは `−`（U+2212）。
- 2次不等式などで x 軸の区間を示すときは、`seg`（`wd: 6`、色つき）を y=0 に引き、端に `pt`（`open:true` で白ぬき）。
- 前のステップの図に足すときは `draw: [{ fig: '図のid', items: [...] }]`。図はページごと（`clear` で消える）なので、新しいページでは図を作り直す（関数を作っておくと楽：見本の `small()` `venn()` `NL()`）。

## 6. 終わったら

2. 報告（20行以内）：作った ID、各本のステップ数・発問数、数学的にあやしい所・図がむずかしかった所・ほしかった図の部品。
