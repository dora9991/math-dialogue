# 保存領域チェック（storage-check）

`dora9991.github.io` で公開しているアプリが、ブラウザの保存領域をどれだけ使っているかを調べる1ファイルのページ。**何も消さない**（あと何 KB 入るかを調べるために、一時的な項目を書いてすぐ消すだけ）。

## なぜ必要か

- ブラウザの **localStorage は、サイトごとに約 5MB**（iPhone の Safari）。iPhone 本体の空き容量とは関係がない
- `dora9991.github.io/math-dialogue/…` のアプリは、ブラウザから見ると**全部同じサイト**なので、**この約 5MB を分け合っている**
- どれか1つのアプリ（たとえば画像を localStorage に入れる「みせびらき」、動画チェックの画像や会話を入れる「バスケ・グロウ」、試合をためる「バスケ タップ記録」）がたくさん保存すると、**ほかのアプリでも「容量がいっぱい」「保存できません」になる**
- 撮影した動画など（IndexedDB）は別の、ずっと大きな入れ物（iOS 17 からは端末の容量に合わせて大きい）

## 出すもの

- localStorage の使用量・あと何 KB 入るか（実際に書いて確かめる）・「まだ入る／残りわずか／いっぱい」
- アプリごとの量（キーのはじまりでアプリを見分ける。分からないキーは名前のまま）と、大きい項目
- IndexedDB の使用量・上限（`navigator.storage.estimate()`）とデータベースの名前
- 結果のテキスト（コピーして送れる。データの中身は入れない）

## 公開

```
bash storage-check/deploy-ghpages.sh     # gh-pages の storage-check/ だけを入れかえる（force push しない）
```

公開先：https://dora9991.github.io/math-dialogue/storage-check/ 。アプリを使っているのと同じブラウザで開くこと（ホーム画面に追加したアプリは、Safari とは別の保存場所を持つ）。
