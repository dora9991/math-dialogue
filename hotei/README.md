# 方程式の黒板（hotei）

電子黒板に映して、**図やグラフを動かしながら**考える「方程式」（中1）の授業ページ。1時間＝1ページ、14時間ぶん。
授業の流れは ikkan の `ikkan/data/lesson_hotei_NN.js` とそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。考えようは答えを出さず、スライダーなどの「調べる道具」だけ。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。全単元の総目次は `../kokuban/index.html`。
画面の土台は `../kukan/js/k3.js`・`../kukan/css/board.css`・`../katsuyo/js/chart.js` を使うので、公開するときはいっしょに置く。

## 14時間

| 時間 | ページ | 題 |
|---|---|---|
| 第1時 | `01.html` | あてはまる数を、式を使ってさがそう |
| 第2時 | `02.html` | てんびんのつり合いから、方程式の解き方を考えよう |
| 第3時 | `03.html` | 移項を使って、方程式をすばやく解こう |
| 第4時 | `04.html` | かっこや小数のある方程式を解こう |
| 第5時 | `05.html` | 分数のある方程式を、分母をはらって解こう |
| 第6時 | `06.html` | 方程式リレーで、解き方をつなごう |
| 第7時 | `07.html` | わからない数量を x として、問題を解決しよう |
| 第8時 | `08.html` | 「余る」「たりない」の問題を、方程式で解こう |
| 第9時 | `09.html` | 「追いつく」「出会う」の問題を、図に整理して解こう |
| 第10時 | `10.html` | 方程式の解は、いつも問題の答えになるだろうか |
| 第11時 | `11.html` | 比が等しいことを式に表して、x の値を求めよう |
| 第12時 | `12.html` | 比例式を使って、身のまわりの量を求めよう |
| 第13時 | `13.html` | 方程式に合う問題をつくって、解き合おう |
| 第14時 | `14.html` | 「方程式」で学んだことを、整理して確かめよう |

## 操作

空間図形の黒板（`../kukan/README.md`）と同じ：→・Enter・Space でつぎへ（問い → 答え → 次の問い）、← でもどる、R でもう一度動かす、F で全画面。下にスライダーが出る場面は、手で値を変えられる。URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる。

## つくり（作り手向け）

- 1ページ＝1つの HTML（外部ライブラリなし）。`K3.run({ flat: true, steps: [...] })` を呼ぶだけ。ステップの書き方は `../kukan/README.md`。
- グラフ・表・数直線・カード・タイルは `../katsuyo/js/chart.js`（CH.*）。分数は `CH.fr`（文の中の [1/2]）・`CH.frac`（図の中）、√ は `CH.root`、負の数は `CH.mnum`。
- 答えや表の数は、ページの中で計算し直して照らし合わせている（`CH.check`）。ちがうと、ブラウザのコンソールに「答えがちがう：…」と出る。
- × と ÷ は、黒板の字体だと x と見分けにくいので、土台が自動で見分けやすい字体にする。
- データ・場面は ikkan の数値か、自作（各ページの頭のコメントに書いてある）。
