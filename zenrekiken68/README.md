# 全歴研 第68回 佐賀大会 サイト（試作）

静的HTMLだけのサイト。サーバー不要で、中身は **`data/site-data.js` だけ** を書き換えれば反映される。

```bash
python3 -m http.server 8795 --directory zenrekiken68   # http://localhost:8795/
```

## 中身の入れ方

- `【要入力】` で始まる文字は画面で黄色くマークされる。確定した情報に差し替えると消える。
- 動画：`archive.videos` の `id` に YouTube の動画ID（`watch?v=` の後ろ11文字）を入れる。空なら「公開準備中」表示。
- 再生リスト／チャンネル：`playlistId` と `channelUrl` を入れるとボタン・リンクが出る。
- リンク類（申込フォーム・地図など）は `https://` から始まる完全なURL。空なら「準備中」表示。
- 動画は `youtube-nocookie.com` で埋め込み、閉じると再生が止まる。サイト側にサーバー処理はない。

## 公開前チェック

1. `draft` を `false` にする（上部の「試作版」の帯が消える）
2. 画面に黄色の【要入力】が1つも残っていないか確認する
3. `index.html` の `<meta name="robots" content="noindex,nofollow">` を消す
4. **大会側（主催者）の了承を得てから**公式として公開する
5. 参加者名簿・個人情報はこのフォルダ／リポジトリに入れない（無料の GitHub Pages はリポジトリが公開になる）

## 公開のしかた（推奨）

- このフォルダを**専用リポジトリ**（できれば Organization 名義）に移し、GitHub Pages で公開する。
- 独自ドメインを使い、**ドメインの名義と GitHub の管理者権限は大会側に渡す**。作った人がいなくなっても運用できる形にしておく。
- 参加登録など送信が必要な機能は、Google フォームなど外部サービスにリンクする。
