# 全歴研 第68回 研究大会（佐賀大会）サイト（試作）

静的HTMLだけのサイト。サーバー不要。

```
index.html        本文とCSS（ほぼここだけ編集する）
data/archive.js   アーカイブ配信（YouTube）の一覧
js/archive.js     アーカイブの表示と動画プレーヤー（基本は触らない）
```

```bash
python3 -m http.server 8795 --directory zenrekiken68   # http://localhost:8795/
```

## 内容の出どころ

文章・日程の例・過去の大会のリンクは、全歴研の公開情報をもとにした案内サイト（参考として受け取った HTML）から引いている。**日程・会場・参加費・過去大会の日付などは、公開前に全歴研の公式発表（note・理事会報告）と突き合わせること。**

## 更新のしかた

- 決まっていない項目は `<span class="tbd">調整中</span>` になっている。`class="tbd"` で検索して、決まったものから書き換える（日程・会場・テーマ・後援・記念講演・申込URL・参加費・問い合わせ先など）。
- 過去の大会は `#past`、全歴研の紹介リンクは `#about` にある。
- **アーカイブ配信**は `data/archive.js` の `videos` に1行足すだけ。
  - `id` は YouTube の動画ID（`watch?v=` の後ろ11文字）。形式が違う行は表示されない。
  - `group` が同じものは絞り込みボタンにまとまる（ボタンは出てくる順）。
  - `playlistId`・`channelUrl` を入れると、再生リストのボタンとチャンネルへのリンクが出る。
  - `videos` が空のあいだは「現在公開中のアーカイブはありません」と表示される。
  - 動画は `youtube-nocookie.com` で埋め込み、閉じる（×・Esc・背景クリック）と再生が止まる。

## 公開前チェック

1. 上部の「試作版」バナー（`class="draft"`）と、`<meta name="robots" content="noindex,nofollow">` を消す
2. `class="tbd"` が、公開時点で残っていてよいものだけか確認する
3. 日程・会場などを公式発表と突き合わせる（上の「内容の出どころ」）
4. **主催者（全歴研）の了承を得る**
5. アーカイブを出す場合は、登壇者・発表者の了承と、映像に映る方の同意を主催者側で確認する。参考の案内では「すべて対面で開催」となっているので、映像公開をするかどうか自体も主催者の判断になる
6. 参加者名簿・個人情報はこのフォルダ／リポジトリに入れない（無料の GitHub Pages はリポジトリが公開になる）

## 公開のしかた（推奨）

- このフォルダを**専用リポジトリ**（できれば Organization 名義）に移し、GitHub Pages で公開する。
- 独自ドメインを使い、**ドメインの名義と GitHub の管理者権限は大会側に渡す**。作った人がいなくなっても運用できる形にしておく。
- 参加申込など送信が必要な機能は、Peatix や Google フォームなど外部サービスにリンクする。

## 表示について

- 見出しなどの縦書き（`.vt`）は、OS に標準の日本語フォントがあれば正しく表示される。縦書き用の字送りを持たないフォントしかない環境（一部の Linux など）では、タイトルの文字が重なって見えることがある。
- フォントは Google Fonts（Zen Old Mincho / Zen Kaku Gothic New）を読み込み、読めない場合は OS の日本語フォントになる。
