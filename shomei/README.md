# 証明パターン集（shomei）

中2「平行と合同」「三角形と四角形」の証明を、**図を見ながら1行ずつ組み立てる**黒板ページ。難易度別に44題。

| 難易度 | 題 | 中身 |
|---|---|---|
| ★ | k01〜k10 | 根拠を答える（基本の合同：中点・共通な辺・対頂角・平行線の角・角の二等分線・垂直二等分線） |
| ★★ | s01〜s12 | 等しい組を自分で見つける（共通な角・角の和と差・合同から平行・重なった三角形・合同を2回） |
| ★★★ | t01〜t12 | 図形の性質を使う（二等辺三角形・正三角形・直角三角形の合同・角の二等分線・平行四辺形の性質と条件・ひし形） |
| ★★★★ | h01〜h10 | 発展（回転型の正三角形・正方形、二段の合同、補助線、折り返し、等積） |

## 開き方

`index.html`（一覧）をダブルクリック。1題は `p.html?id=k01` のように開く（前・次のボタンで順にめくれる）。全単元の総目次は `../kokuban/index.html`。
土台は `../kukan/js/k3.js`・`../kukan/css/board.css`・`../katsuyo/js/chart.js`・`../heikou/js/geo.js`。

## 進み方

問題（仮定・結論）→ 方針（どの三角形に目をつけるか）→ 証明の行を1行ずつ（★ は根拠をたずね、★★ 以上は等しい組と根拠をたずねる）→ 合同条件 → 合同（三角形が動いて重なる）→ 結論 → ふり返り。
行に出てくる辺・角・三角形が図で光る。右の板書に、証明が上から順にたまる。

## 証明を足すとき（作り手向け）

- `data1.js`（★・★★）・`data2.js`（★★★・★★★★）の `SHOMEI.push({...})` に1題ずつ書く。書き方は `../heikou/js/geo.js` の `GE.proof` の説明。
- 図の座標は、仮定が正確に成り立つように計算して決める。行に書いた「＝」「≡」「∽」「∥」、比の式、図の印（等しい辺・角、平行、直角）は、ページを開くと座標で検算され、ちがえばコンソールに「答えがちがう」と出る。面積の等しさは自動では確かめないので、データの中で計算して確かめる。
