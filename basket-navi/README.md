# basket-navi：バスケ指導ナビ

購入したバスケ動画（指導法・戦術・トレーニング）を、**自分用・指導用に、いつでも使える形**にする道具。
動画は今までどおり OneDrive に置いたまま、その上に「棚と地図」をかぶせる。

**動画を見る →「ここに印をつける」で見どころが貯まる → 練習メニューとして「今日の練習」に並べる → 体育館で「実施モード」（大きなタイマー）→ ふりかえり**
という流れで、学びと練習をひとつにつなぐ。

## ★ このリポジトリに入れないもの（先に読む）

このリポジトリは**公開**されている。購入した動画に関わるものは、ここに入れない（git に上げない）。

- 動画ファイルそのもの
- 動画の名前・要約・自分のメモを入れた **`library.js`**
- 記録のバックアップ（`basket-navi-backup-*.json`）

`.gitignore` で守ってある（`basket-navi/library.js`、`basket-navi/data/library.js`、動画の拡張子など）。
ここに入っているのは「道具（コード）」と「サンプル（形の見本）」だけ。さらに安心したいなら、このフォルダだけ非公開のリポジトリに移してもよい。

## いちばん簡単な始め方（Mac・パソコン）

動画を入れたフォルダ（iCloud Drive でも OneDrive でもよい）に対して、**ターミナルで1行**。`basket-navi` フォルダに移ってから：

```bash
# iCloud Drive の「バスケ動画」フォルダなら
python3 tools/make_library.py setup --icloud "バスケ動画" --probe --open

# フォルダ名がわからないとき（iCloud Drive の中で、動画のあるフォルダを探して並べる）
python3 tools/make_library.py setup --icloud

# それ以外（OneDrive など）
python3 tools/make_library.py setup "/Users/○○/Library/CloudStorage/OneDrive-Personal/バスケ動画" --open
```

これで、**動画フォルダの中**に `library.js`（動画の一覧）と `basket-navi.html`（アプリ）ができて、ブラウザで開く。
次からは、そのフォルダの `basket-navi.html` をダブルクリックするだけ（ブラウザは **Chrome か Edge** がおすすめ）。
新しい動画を足したら、同じコマンドをもう一度（手で書いた要約・見どころは消えない）。

最新のコードは、`git fetch origin && git checkout claude/basketball-video-learning-8itlq0 && git pull`（PR がマージされたあとは `main`）。

手で置くこともできる：`basket-navi.html` をダウンロード（GitHub で開いて、右上の「Download raw file」）→ 動画のフォルダ（または、その上のフォルダ）に置く → 開く。`library.js` がなければ「サンプル」が出る。

### iCloud Drive について

- Mac の iCloud Drive の場所は `~/Library/Mobile Documents/com~apple~CloudDocs/`。`--icloud` はここを見に行くので、長いパスを打たなくてよい。
- **「Mac のストレージを最適化」**がオンだと、動画が iCloud 上だけにあって、Mac には無いことがある（Finder では雲のマーク）。`setup` は、そういう動画を数えて知らせる。再生するには、Finder で動画（またはフォルダ）を右クリック →「今すぐダウンロード」。
  未ダウンロードの動画の「長さ」は、調べるとダウンロードが始まってしまうので、わざと調べない。ダウンロード後に `--probe` 付きでもう一度実行すると入る。
- 初回に、ブラウザが iCloud Drive にアクセスしてよいか、Mac が聞いてくることがある。許可する（断ったときは、システム設定の「プライバシーとセキュリティ」→「ファイルとフォルダ」で許可）。
- **iPhone / iPad**：ファイルアプリの中から `basket-navi.html` を動かすことはできない（ローカルの HTML は、動画つきでは開けない）。使いたいときは相談してほしい（案：アプリ本体だけを置く場所を用意し、`library.js` を取りこみ、動画はファイルを選んで再生）。

## 画面

| 画面 | できること |
|---|---|
| ライブラリ | 指導法／戦術／トレーニングで絞る。タグ・★お気に入り・未視聴で絞る。名前・要点・メモ・見どころの中まで検索 |
| 動画 | OneDrive のフォルダの動画をそのまま再生（再生速度・±10秒・続きから）。要点・見どころ・自分のメモ。**「ここに印をつける」**（`M`キー）で、いまの位置を見どころとして貯める |
| 練習メニュー | 全動画の見どころを横断して探す（練習／プレー／ポイント）。「＋ 今日の練習」で計画に入れる |
| 今日の練習 | 並べる・分を調整・順番を入れかえ。合計と「使える時間」の差、開始時刻を入れると時刻表示。**印刷（A4）**・テキストでコピー（LINE などに貼れる）。計画は日付ごとに複製・保存 |
| 実施モード | 体育館用。大きなタイマー（時間になると赤く点滅・音・バイブ）、前へ／次へ、±1分、**そのメニューの動画をその場面から開く**。終わったら「実践」として記録され、ふりかえりが残る |
| 設定 | 動画の場所、ライブラリの取り込み（スマホ・タブレット用）、バックアップ |

「見どころ」には、種類が3つある。**ポイント**（コツ・気づき）／**練習**（メニューにできる。目安の分つき）／**プレー**（戦術・セット）。

## 自分の動画を入れる

`library.js` を作る。**手でも書けるが、道具で作るのが速い**（`tools/make_library.py`。Python 3 だけで動く。Excel を読むときだけ `pip3 install openpyxl`）。

### ① フォルダを走査する（一覧がなくてもできる）

```bash
python3 tools/make_library.py scan "/Users/○○/Library/CloudStorage/OneDrive-Personal/バスケ動画" --probe
```

- 動画ファイル（mp4・mov・webm・avi など）を見つけて、1本ずつ項目にする。`library.js` は動画フォルダの中にできる。
- フォルダ名・ファイル名から、**分類（指導法／戦術／トレーニング）を当たりづけ**する。迷うものは「未分類」にしておく（まちがえて入れない）。フォルダ名はタグになる。
- `--probe` で、`ffprobe` があれば動画の長さも入れる。
- **何度でも実行してよい**。新しい動画を足すだけで、手で書いた要約・見どころ・タグは消えない（実行前に `library.js.bak` に控えを作る）。

### ② Excel / CSV の一覧から作る（まとめの文章・OneDrive のリンクも入る）

```bash
python3 tools/make_library.py list "バスケ動画一覧.xlsx" --videos "<動画フォルダ>"
```

- シートが複数あれば全部読む（シート名が「戦術」などなら、分類に使う）。
- 見出しは「タイトル／動画名」「内容／まとめ／概要」「カテゴリ／分類」「リンク／URL」「タグ」「講師／購入元」などを自動で判定する。合わないときは `--map title=動画名,summary=内容`。
- ハイパーリンクや `=HYPERLINK(...)` のリンクは、OneDrive の共有リンクとして取りこむ。
- `--videos` を付けると、一覧にファイルの場所がなくても、**名前が一致する動画**を探してひも付ける。
- Word や PDF の一覧は、Excel か CSV に貼りなおすのがいちばん確実。

### `library.js` の形（手で書くとき）

見本は `data/sample.js` の先頭のコメントにある。1本の動画は `id`・`title`・`category`・`file`（動画のパス）・`url`（OneDrive の共有リンク）・`tags`・`summary`・`clips`（見どころ）。
`id` は、メモや計画がひも付くので、**あとから変えない**。見どころの時刻は、秒でも `"12:30"` でもよい。

## 使うときの注意

- **OneDrive は「この端末に常に保持」に**：オンラインのみだと、再生が始まらない（フォルダを右クリックして、常にこのデバイスに保持）。
- **形式**：mp4（H.264）がいちばん確実。`.mov` / `.avi` / `.wmv` はブラウザで再生できないことがある。変換するなら `ffmpeg -i 元.avi -c:v libx264 -c:a aac 先.mp4`。
- **記録の置き場所**：お気に入り・視聴済み・メモ・印・計画・実践の記録は、**そのブラウザの中**（localStorage）にだけ入る。ブラウザの掃除や別の端末では消える／移らないので、**ときどき設定の「書き出す」でバックアップ**する（14日たつと、設定で案内が出る）。
- **スマホ・タブレット**：端末に置いた HTML では OneDrive のファイルを直接読めない。`library.js` の `url` に OneDrive の共有リンクを入れておくと「OneDrive などで開く」ボタンで動画を開ける。`library.js` は設定の「ライブラリの取り込み」で端末に入れる（中身は端末の中にだけ入り、どこにも送られない）。ただし、アプリ本体を開く場所（HTML を置く場所）は、まだ用意していない。
- **動かして確かめたもの**：Chromium（ヘッドレス）で、サンプル表示・`library.js` 表示・動画の再生と見どころへのジャンプ・印・計画・印刷表示・実施モード・バックアップ・スマホ幅・暗い画面。iCloud Drive 向けの処理（`setup`・フォルダの自動検出・未ダウンロードの目印ファイル）は、疑似的なフォルダで確認した。**未確認**：実際の Mac と iCloud Drive、Safari、Windows、実際の OneDrive 同期フォルダ。

## 作り直す・確かめる（開発用）

| やりたいこと | コマンド |
|---|---|
| 1つにまとめた HTML を作り直す（コードを直したら） | `node tools/bundle.cjs`（`basket-navi.html` ができる。**`library.js` は含めない**） |
| 動作の検査（画面の画像も出す） | `NODE_PATH=$(npm root -g) node tools/check.cjs [画像の出力先]`（playwright と python3 が必要。ffmpeg があれば動画の再生も調べる） |
| 開発中に見る | `python3 -m http.server 8793 --directory basket-navi`（Claude Code なら `basket-navi` プレビュー） |

```
basket-navi/
├── basket-navi.html      ← 配る用の 1 ファイル（bundle.cjs で作る。コードだけ。動画の中身は入らない）
├── index.html            ← 開発用（分割したファイルを読む）
├── css/navi.css
├── js/store.js           ← 記録の保存（localStorage）
├── js/app.js             ← 画面とふるまい
├── data/sample.js        ← サンプル（形の見本。library.js があれば出ない）
├── data/library.js       ← ★自分の動画の一覧（git に上げない。開発中だけここに置く）
└── tools/
    ├── make_library.py   ← フォルダ／Excel／CSV から library.js をつくる
    ├── bundle.cjs        ← 1 ファイルにまとめる
    └── check.cjs         ← 動作の検査
```
