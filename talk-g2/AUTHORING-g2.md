## 3. ことばの書き方
- 字幕（`sub`）は、ふつうの日本語で書く。**読み上げは字幕から自動でつくる**。式は `y＝2x＋1`、分数は `[[2/3]]`（→「3分の2」）、累乗は `x²`（`x^2`でも）、単位は `cm²` `cm³`、角度は `60°`、円周率は `π`、三角形は `△ABC`、プライムは `A′`（U+2032）、不等号は `＜ ＞ ≦ ≧`。
- 負の数：数や文字の前の `−` は「マイナス」、2つの数のあいだの `−` は「ひく」と読む。まぎらわしい所は `say:` で上書き。
- 読みがおかしくなりそうな所（長い式・特殊な語・固有名詞）は、`T('字幕…', { say: 'ひらがなまじりの読み…' })` で読みを直接書く。`.check/<ID>.say.txt` を読んで、読みを確かめる。数字は `say` の中でも数字のままでよい。小数点は「3.2」と書けば「3点に」と読む。
- JS の文字列は `'…'`。中に `'`（半角アポストロフィ）を入れない（`′` を使う）。字幕の中の `{{…}}` は色つき（答え）、`**…**` は太字。
- 「ポンタ」「ホー先生」の名前は、そのまま書く。

## 4. 黒板（`add` と `draw`）
- `add: [要素…]`：そのステップで黒板に足す物。`col: 0` が左（めあて・メモ・式）、`col: 1` が右（図・表）。
  - `{ col:0, type:'box', color:'y'|'p'|'b'|'g', size:'xs'|'sm'|'lg', label:'めあて', text:'…\n…', t:4.0 }`（枠つき）／`{ col:0, type:'text', size:'xs', label:'式', text:'…', t:3.0 }`（枠なし）。`t` はその物が出る長さの目安（秒）。左の列は **10行ていどまで**（左下のホー先生の頭より上）。
  - 表：`tbl([[…],[…]], { style:'font-size:38px; align-self:center; margin-top:10px', t:1.0 })`（先頭の行と列が黄色の見出し）。セルの `{{…}}` は色つき。
  - 図：`FIG('id', [x0,y0,x1,y1], w, h, [], { col:1, plane:[…] })` を `Object.assign(f1,{prims:[]})` で `add` する。**図はページごとに別**。
- `draw: [{ fig:'id', items:[…] }]`：図に描き足す物（アニメで描かれる）。`temp:true` を付けた物は、そのステップだけ表示される。
- 図の部品（`talk.js` の primitives）：`{k:'seg',a,b,c,wd,dash,arrow}`／`{k:'segs',list:[[a,b],…]}`／`{k:'poly',pts,close,c,fill,alpha,wd,dash}`（close なしは折れ線）／`{k:'pt',at,name,dir,off,c,r}`（点と名前）／`{k:'pts',list,c,r}`／`{k:'label',at,text,c,size,anchor,dx,dy}`／`{k:'ell',o,rx,ry,a1,a2,c,wd,dash,fill,alpha}`（円・弧・だ円。角度は反時計まわり）／`{k:'right',at,u,v,s}`（直角の印）／`{k:'plane',lab,size}`（座標軸と目もり）／`{k:'fn',a,b,c,label,lat,lanchor,size}`（直線 y＝ax＋b）。色は `w`（白）`y`（黄）`p`（桃）`b`（青）`g`（緑）`d`（うす）。
  - ショートカット（`KL.`）：`FIG` `lbl(x,y,text,o)` `rect(x0,y0,x1,y1,o)` `poly(pts,o)` `seg(a,b,o)` `arc(x,y,r,a1,a2,o)` `pt(x,y,name,dir,o)` `circle` `sector(x,y,r,a1,a2,o)` `arrow(a,b,o)` `cells` `hist({x0,y0,cw,hu,freqs,bounds,ymax,ystep,…})`（ヒストグラム）`tbl` と立体 `S3.*`。
  - 図のラベルの文字は `{{ }}` や `[[1/2]]` が使えない（普通の文字だけ）。分数は `1/2` と書く。
- **サイズ**：図の `w×h` と `view` の縦横比をそろえる（そろっていないと、はみ出しや小さい図になる）。図だけなら `1180×600` まで。表の下に図を置くときは図の高さを `480` くらいに。ホー先生（左下）・ポンタ（右下）・字幕（下）に隠れないよう、図は黒板の上 3/4 に。
- 分岐（`Q` の誤答の解説）の中の `draw` は、その選択肢を選んだときだけ出る。後ろの共通のステップで必要な図は、共通のステップで描く。
- ページを変える：`T('…', { clear: true, cols: [0.34, 0.66], part: '…', add: […] })`。ページごとに左右の列・図がリセットされる。

## 5. 授業の種類ごとの書き方
- **探**（発見）：身近な場面→予想（4択）→確かめ→きまりを言葉にする。
- **例**（例題）：問題→ホー先生が1つずつ解く→ポンタがつまずく→類題を4択で。
- **遊**（ゲーム）：クイズ番組・ゲーム仕立て。ポンタが挑戦者。4択を連続で。
- **練**（練習）：まちがい探し・速さ・正確さ。ポンタの誤答を直す役に。
- **活**（活用）：身のまわりの場面の問題を、図・表・式で解く。「根拠を言う」。
- **確**（まとめ）：その章のまとめクイズ。ことば・公式・典型問題を4択で総ざらい。
- **応用問題**（ID が `ch◯-o01〜o10`）：その章の重要な考え方を1つ選び、自作の1問を、問いを分けて（3〜5問の4択で）解説。**入試レベル**（`ch◯-n01〜n03`）は、2つの考え方を組み合わせる少しむずかしい自作問題。誤答の理由を丁寧に。
- 見本は下の「見本」の節。問題の一覧は `problems/g2-ouyou.md`。
