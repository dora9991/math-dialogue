## Mac での手順

> 作業中の Mac の作業ツリー（未コミットの `lesson-navi/` など）には触らず、このブランチを別の場所に取り出してから使う。

```bash
# 1. このブランチの talk-g2/ だけを、一時フォルダに取り出す（作業ツリーは変わらない）
cd "<math-dialogue のリポジトリ>"
git fetch origin claude/eloquent-hypatia-j3tgfl
mkdir -p /tmp/g2 && git archive FETCH_HEAD talk-g2 | tar -x -C /tmp/g2

# 2. 台本を scenes/ にコピー（既にあるファイルは上書きしない）
sh /tmp/g2/talk-g2/install-g2.sh "<…>/lesson-navi/video/talk"

# 3. lessons.js に行を足す（ready:false）。/tmp/g2/talk-g2/lessons-g2-rows.txt の行を、既存の行の形と見くらべて貼る
```

4. 1本ずつ検査（音なし）：`node check.mjs <ID> --shots`（⚠・✗ をなくす）。**図のある授業は `python3 sheet.py <ID>` で写真を見る**（下の「図の確認」）。`.check/<ID>.say.txt` の読み上げも見る。
5. 台本が最終になったものから `sh voice-queue.sh <ID> …`（**`build-play.mjs` を直接実行しない**。既存の147本の順番待ちの後ろに並ぶ。急ぐ授業を先に入れる）。
6. 声ができたら `python3 sync_ready.py`、`node test-play.mjs <ID>`（音なしの通しテスト）。
7. **公開（math-talk へのデプロイ）は、ユーザーが決めてから**。

## 図の確認（3章のグラフ・ほか）

`plane` を使うのは 25本：`g2u3-04〜17`、`g2ch3-n01〜n03`、`g2ch3-o03〜o10`。クラウドでは、旧パイプラインの `player.js` の描画を写した簡易プレビューでしか見ていない（実際の `talk.js` では未確認）。確認してほしい点：

- `FIG` の `view` と `w×h` の縦軸・横軸、目もり数字・点・ラベル・凡例の重なり（`g2u3-04`・`g2u3-06` の2ページ目、`g2ch3-o08` の右外のラベル）。
- 縦軸を割った図が2つ：`g2ch3-o10`（縦＝y÷12）と `g2ch3-n03`（縦＝y÷100）。`plane` の `lab:100` で数字を消して自作の `label` で数を付けている。
- 点線（`dash:true`）が実線に見えないか。
- `g2ch3-n02` の動く点 P は `temp:true`、長方形は `plane` なし。
- 表（`tbl`）を `col` 指定なしで使っている所（`g2u3-10〜12`・`g2u3-14`）が、右の列に出るか。
- 図があるその他の授業：`g2u1-04`（畑の長方形2枚）、`g2u2-09`（線分図）、`g2ch1-n02`（円 `ell`、花だん）。

## 耳で確認してほしい読み（各担当の報告から）

`say:` を付けた行は 計約640行。付けていない行で、読みがこわれやすそうなもの：

- 「切片」「傾き」「変域」「同類項」「加減法」「代入法」「係数」「最小公倍数」「両辺」「移項」（`移項`＝「いこう」が「行こう」に聞こえないか）。
- 式の中の「−」（「マイナス」と「ひく」の読み分け）：`y＝−3x＋5`、`2×(−1)−1`、`①−②`、`−4a²` と `(−4a)²` の読み分け（`g2ch1-o05`）、`÷(−3)`。
- 文字が続く所：`xy²`・`ab²`（b だけが2乗に聞こえないか）・`12ab`、`a^7`・`m^4n²`。
- 座標「（2，3）」、不等号 `≦`（`say:` なしの行：`g2ch3-o07`、`g2ch3-n02` の説明）、丸数字「①②」、大文字の点名（A・B・P）と `△APD`。
- 小数（0.5、3.5、`0.05x`、`1.1x`）、`g2u3-14` の `0.5x＋4`。
- 分数：字幕・黒板の `[[x/2]]`（文字 ÷ 数）は使っている。**分子や分母が式の分数は `[[ ]]` を避け、`（2x−y）÷3` か `say:` にしてある**。4択の選択肢の分数は `1/4`・`x/2` と書いた（選択肢で `[[ ]]` が使えるか未確認）。`g2u1-03` の第4問は `(a＋5b)/6` と横書き。
- 黒板の `[[x/2]]` が「小数 ON」でどう出るか（`g2u2-05`・`09`・`13`、`g2u1`）。

## 判断が分かれるところ（ユーザーが決める）

1. **入試レベル `g2ch1-n02`（花だんの道の面積）・`g2ch1-n03`（連続する2つの奇数の2乗の差）**：（r＋a）²・（2n±1）² の「かっこの中を2回かけて整理」が出てくる。実質は多項式×多項式（中3の展開）。「展開」「乗法公式」は使わず、4つの積の表で足し合わせる形で説明している。中2の範囲として許すか、題材を変えるか。
2. `g2u3-13`（連立方程式と交点）に「平行なら交点なし」の一言、`g2u3-12` に「x＝−2 は y が x の関数ではないがグラフは直線」の一言、`g2u3-10` の最後に連立方程式で求める方法の紹介がある（やや先取り・発展。不要なら削る）。
3. `g2u2-07`（解き方くらべ）の「いちばん速い道具」は授業の中で基準を決めて出題している（主観を含む）。
4. `g2ch1-o09` は「一の位は0でない」の条件を付けた。`g2u1-08` は b＝0 で入れかえた数が1けたになる場合に触れていない。
5. 作った3つの検査は、構造と算数だけ。**授業としての面白さ・テンポ**（ポンタのボケ、ホー先生の返し）は、実際に再生して確かめていない。
