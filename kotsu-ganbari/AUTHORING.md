# 解説動画の「場面」の書き方（がんばりまっしょいプリント）

期末テスト対策プリント（問1〜問42）の解説を、**音声なしの動画**にします。
図が1手ずつかかれていき、字幕（ホー先生🦉のひとこと）と、式が出ます。生徒（中1）が、**自分で解いたあとに答え合わせ**で見ます。

1問につき、場面ファイル `q/qNN.js`（NN は2けた。問9 → `q09.js`）を **1つ**書きます。
見本：`q/q09.js`（作図）、`q/q27.js`（計算）。**まずこの2つを読んで、同じ作りで書いてください。**

## 触ってよいファイル
- **自分の担当の `q/qNN.js` だけ**を書く。`dsl.js`・`player.js`・`geo.js`・`app.js`・`style.css`・`tools/*`・`manifest.json` は**書きかえない**（ほかの人も使っている）。
- 足りない部品があれば、自分の `q/qNN.js` の中で関数を書いてよい。エンジンに足してほしいことは、最後の報告に書く。

## 場面の形
```js
import { P, seg, line, poly, arc, circ, ang, rt, arrow, path, ell, txt, dot, geo, polar, dirDeg, oblique, solid } from "../dsl.js";
export default {
  n: 9,                                   // 問の番号（ファイル名と同じ）
  title: "角の二等分線の作図",              // 一覧に出る題（12〜20字ほど）
  problem: "問題文（印刷どおり。(1)(2)は \n で改行）",
  answer: "答え（ことばで。(1)(2)をすべて。単位つき）",   // 最後に「答え」の箱に出る。検算にも使う
  view: [0, 20, 400, 250],                // 図の見える範囲 [左x, 上y, 幅, 高さ]。図のまわりに20ほど余白
  grid: { x:0, y:0, nx:10, ny:8, s:30 },  // 方眼（任意）。左上(x,y)、横nx×たてny マス、1マスs
  steps: [ /* 下 */ ],
};
```
- 座標は SVG と同じ（**x は右へ、y は下へ増える**）。角度は**度**で、**画面で反時計まわり**に増える（0°＝右、90°＝上、180°＝左、270°＝下）。
- 図の大きさは自由（印刷物の図の写真を見て、ピクセル感覚で座標を決めてよい）。幅 400〜520 くらい、**縦横比は 4:3 前後**がおすすめ。

## コマ（steps）
```js
{ cap: "字幕。1つの考えを1コマで。",       // 必須
  add: [ 要素… ],                          // このコマで出す図形（前のコマの図は残る）
  eq:  ["## 見出し", "式1", "=> 答えの行", "// 小さな注"],   // 式のボード（前のコマの式も残る）
  hl:  ["id"],                             // このコマで、いま注目する要素（オレンジ）
  hide: ["id"],                            // このコマで消す要素（id が必要）
  clear: true,                             // これ以外の「かいた線」をぜんぶ消す（steps[0] の図は消えない）
  eqClear: true,                           // 式のボードを空にする（(1)→(2) に切りかえるとき）
  together: true,                          // add の要素を、順番にではなく同時に出す
  fin: true,                               // 「答え」の箱を出すコマ（省略すると最後のコマ）
  dur: 4000 }                              // 長さ(ms)。省略すると、字幕・式・図の量から自動
```
- **steps[0] ＝問題の図**（与えられた図・条件。ここに add した要素は「base」として黒で出て、`clear` でも消えない）。
- いま出した要素は、そのコマのあいだ**オレンジ**で見える（次のコマで、本来の色に落ち着く）。`c:'a'`（赤）はオレンジにならない。
- 要素は **`add` の順に、1つずつかかれていく**（線はすーっと伸びる）。コンパスの円は、円弧がかかれていくので、順番を意識して並べる。

## 要素（dsl.js の関数）
| 関数 | 意味 | 主なオプション |
|---|---|---|
| `P(id,x,y,label=id,pos='ne',o)` | 点と名前 | `pos`: n ne e se s sw w nw。`label:''`で名前なし。`dot:false`で点なし。`dx,dy`で名前の位置をずらす |
| `seg(a,b,o)` | 線分（a,b は点の id か [x,y]） | `dash:true`で点線、`tick:1\|2\|3`で等しい長さの印、`w`太さ |
| `line(a,b,o)` | 直線（図のはしまでのびる） | |
| `poly(pts,o)` | 多角形（pts は点の id か [x,y] の配列） | `fill:'b'\|'a'\|'y'\|'#色'\|'hatch'`（面の色ぬり・斜線）、`close:false`で折れ線、`w:0`で枠なし |
| `arc(ctr,r,from,to,o)` / `circ(ctr,r,o)` | 円の一部／円（ctr は id か [x,y]。from→to は反時計まわり） | `fill`（おうぎ形をぬる） |
| `ell(ctr,rx,ry,from,to,o)` | 楕円（円柱・円錐の底面。下半分 180→360、うしろ半分 0→180 は `dash:true`） | `fill` |
| `ang(at,from,to,o)` | 角の印（弧）。小さいほうの角 | `l:'(ア)'`名前、`r`半径、`fill:true`、`m:1`等しい角の印、`big:true`大きいほう |
| `rt(at,from,to,o)` | 直角の印 □ | `s`大きさ |
| `arrow(a,b,o)` | 矢印 | |
| `path(d,o)` | SVG の path をそのまま | `fill`（evenodd） |
| `txt(x,y,s,o)` | 文字（`\n`で改行） | `size`(14以上)、`anchor`、`bold:false` |
| `dot(x,y,o)` | 名前のない点 | |

共通オプション：`id`（`hl`/`hide`で使う名前）、`c`（色：`'g'`黒＝与えられた図、`'b'`緑＝かいた線、`'a'`赤＝答え、`'k'`灰、`'y'`黄、`'p'`紫、または CSS 色。省略すると steps[0] は黒、ほかは緑）、`w`（線の太さ。ふつう2）、`dash`、`o`（透明度）、`d`（出はじめを遅らせる ms）。
**注意：`arc`/`ell` の中心は第1引数 `ctr`（オプションの `c` は「色」）。**

### 計算の道具（`geo`、座標は [x,y]）
`geo.mid(a,b)` `geo.lerp(a,b,t)` `geo.dist(a,b)` `geo.rot(p,center,deg)`（画面で反時計まわりに回す）`geo.foot(p,a,b)`（垂線の足）`geo.reflect(p,a,b)`（対称移動）`geo.interLL(a,b,c,d)`（直線どうしの交点）`geo.interCC(c1,r1,c2,r2)`（円どうしの交点。2つ返す）`geo.interLC(a,b,c,r)`（直線と円）`geo.bisectDir(at,from,to)`（角の二等分線の向き）`geo.circumcenter(a,b,c)` `geo.incenter(a,b,c)`、`polar(c,r,deg)`（中心から角度 deg・距離 r の点）、`dirDeg(a,b)`（a から b を見た向き）。
**作図の点は、目分量ではなく、計算で出す**（見本 q09 のように、`geo` で交点を出す）。そうすると、図が正確で、作図の手順どおりに円がぴったり交わる。

### 立体（斜投影）
`const pr = oblique(ox, oy, 0.5, 40)`（原点の画面位置、奥行きの縮み、奥へ進む向き）。3次元の点 `[x(右), y(おく), z(上)]` を `pr([x,y,z])` で画面の点に。
`solid(pr, verts, edges, hiddenEdges, {lp})` が、頂点（名前つき）と辺（見えない辺は点線）の要素 `els` と、画面座標 `pt` を返す。使い方の例：
```js
const pr = oblique(60, 230, 0.5, 40);
const cube = solid(pr, { A:[0,0,0], B:[110,0,0], C:[110,110,0], D:[0,110,0], E:[0,0,110], F:[110,0,110], G:[110,110,110], H:[0,110,110] },
  [["A","B"],["B","C"],["E","F"],["F","G"],["G","H"],["H","E"],["A","E"],["B","F"],["C","G"]],   // 見える辺
  [["A","D"],["D","C"],["D","H"]],                                                                // 見えない辺（点線）
  { lp: { A:"sw", B:"se", C:"e", D:"nw", E:"nw", F:"ne", G:"ne", H:"n" } });                      // 名前の向き
// steps[0].add に ...cube.els。切り口の面などは poly(["B","D","G"], { fill:"y" }) で足す。
```
**印刷物の図と、見える辺・見えない辺・頂点の名前の位置を同じに**してください（生徒が、手元のプリントと見くらべます）。

## 字幕・式の書き方
- **字幕（cap）**：ホー先生の、やさしい口調（「〜だよ」「〜しよう」「〜だね」）。**1コマ＝1つの考え**。ふつう **70字以内**（110字まで）。大事なことばは `**太字**`。
- **式（eq）**：見出し `"## (1)"`、ふつうの行、答えの行 `"=> (1) 54π cm³"`（黄色の枠）、小さな注 `"// 〜"`。
- 飾り：`[[1|3]]` 分数、`**太字**`、`^{2}` 上つき、`_{n}` 下つき、`{{赤い強調}}`。記号は文字で：`π × ÷ ∠ △ ⊥ ∥ ° ² ³ √ ≡ ＝`。
- 外部のライブラリ・画像・音声は使わない。

## どう「わかりやすく」するか（大事）
1. **最初のコマ**：問題の図と「何を求めるか」。
2. **考え方（なぜそうするか）を先に**言う。手順だけ・式だけにしない（例：作図は「どんな図形の性質を使うか」）。
3. 作図は、**コンパスの円（弧）を1つずつ**かき、点に名前（P, Q, R…）をつけて、**順番を①②③**で字幕と式に残す。最後の線は**赤**。「なぜそれで正しいか」を1コマ。
4. 計算は、式を**1行ずつ**ボードに出す（公式 → 数を入れる → 計算 → 答え＋単位）。πは文字のまま。
5. **ひっかけ・まちがえやすい点**（直径と半径、底面積に×1/3 を忘れる、など）を1コマで注意。
6. 「すべて答えなさい」「正しいものを選びなさい」は、**候補を1つずつ確かめる**（○×を図で見せる）。
7. (1)(2)(3)が分かれる問題は、1本の動画にまとめ、切りかえで `eqClear:true`、図は `hide`/`clear` で整える。ボードに「## (1)」の見出し。
8. 最後のコマで、答えをもう一度。確かめ算ができる問題は、確かめも1コマ。
9. **コマ数 6〜18、全体 45〜150秒**が目安（`node tools/check.mjs N` が秒数を表示する）。字幕が長いコマは、2つに分ける。
10. 色の約束：与えられた図＝黒、かいた線・補助線＝緑、答え＝赤、見てほしい所＝`hl`。

## 印刷物への忠実さ（とても大事）
- 印刷物の**図の形・向き・文字の位置・数値**を、そのまま写す（写真は4枚。`/…/scratchpad/print/` に置いてある）。数値は問題文と図の両方を見て、**拡大して**確かめる。写真に透けて見える**うらの面の文字は無視**する。
- 読みとりに迷う所（図の線がどこに行くか、角の位置、ラベルの位置など）は、**拡大して見る**。それでも決められない所は、**勝手に決めず**、報告に書く。
- 問題文が曖昧で、答えが解釈で変わるときは、**動画の中で、どの解釈か**を言い、`answer` にも**両方**書く。
