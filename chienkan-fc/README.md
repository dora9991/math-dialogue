# 致遠館FC ホームページ（下書き）

佐賀市・中学生のための地域サッカークラブ「致遠館FC」のホームページの下書き。
もとにしたのは「致遠館FC 構想まとめ」（2027年6月始動予定）。

**1つのファイル（`index.html`）だけで動く。** ダブルクリックでブラウザで開ける。サーバーもビルドも要らない。

| ページの中身 | |
|---|---|
| ヒーロー | 「部活動のような身近さと、クラブチームの専門性を。」と、**放課後の時間割**（18時に始まる練習との比べ） |
| 思い | 構想の「基本コンセプト」「目指す姿」から |
| 3つの柱 | 時間・指導・運営。平日の1日の流れ（16:30／17:00／18:30） |
| 活動カレンダー | 月の表示＋その日の予定＋これからの予定。祝日は自動で入る |
| 照明プロジェクト | 佐賀市の「空が暗くなる時刻」と練習時間を重ねたグラフ／クラウドファンディングの進み具合（今は準備中） |
| パートナー | 協賛のメニュー（オフィシャル・サポート・応援団・照明）と、協賛企業の一覧 |
| Q&A・概要 | 決まっていないことには「調整中」の印がつく |
| 相談ボタン | 今はボタンだけ。URLが空のあいだは「相談窓口は準備中です」と出る |

## 更新のしかた：コードを触らない（おすすめ）

運営する人（代表・コーチ）が、**スプレッドシートを書きかえるだけ**で、予定・相談窓口・照明プロジェクトの数字・パートナーが変わるようにしてある。
ホームページを作った人がいなくても回る形にするため。

### はじめに1回だけ

1. Googleスプレッドシートを新しく作り、シートを2枚にする（名前は「予定」「設定」）。
2. `templates/予定.csv` と `templates/設定.csv` を、それぞれのシートに読みこむ（ファイル → インポート → アップロード → 「現在のシートを置換」）。
3. ファイル → 共有 → **ウェブに公開** → 「予定」シート・**カンマ区切り形式（.csv）** を選んで公開 → 出てきたURLをコピー。「設定」シートも同じようにする。
4. `index.html` の下のほう（`const CONFIG = {` のところ）の2か所に貼る。

```js
scheduleCsvUrl: "https://docs.google.com/spreadsheets/d/e/……/pub?gid=0&single=true&output=csv",
settingsCsvUrl: "https://docs.google.com/spreadsheets/d/e/……/pub?gid=123456&single=true&output=csv",
```

これで終わり。以後はスプレッドシートを直すだけでよい（ページに出るまで数分かかることがある）。
※「ウェブに公開」したシートは、URLを知っていればだれでも見られる。**個人名・電話番号・子どもの名前は書かない。**

### 「予定」シートの書き方

1行＝1つの予定。見出し（1行目）は変えない。

| 書きたいこと | 書き方の例 |
|---|---|
| 1日だけの予定 | `日付`＝2027-07-10、`開始`＝13:00、`終了`＝16:00、`種別`＝試合、`内容`＝練習試合 |
| 何日か続く予定（お休みなど） | `日付`＝2027-06-21、`終了日`＝2027-06-25、`種別`＝休み、`内容`＝テスト前のお休み |
| 毎週のきまり（ふだんの練習） | `曜日`＝月水金、`日付`＝始まる日、`終了日`＝終わる日、`開始`＝16:30、`終了`＝18:30、`種別`＝練習 |

- `種別` は「練習」「試合」「大会」「体験会」「説明会」「休み」など。色はここで決まる（練習＝緑、試合・大会＝琥珀、体験会・説明会＝藍、休み＝白抜き）。
- **毎週のきまりは、祝日は自動でお休み**になる。祝日も練習する場合は `曜日` に「祝」も入れる（例：月水金祝）。
- 「休み」の予定がある日は、毎週の練習は出ない（テスト前・学校行事の日などに使う）。
- 日付は `2027-06-21` でも `2027/6/21` でもよい。

### 「設定」シートの項目

| 項目 | 値の例 | 何が変わるか |
|---|---|---|
| 相談URL | GoogleフォームやLINE公式アカウントのURL | すべての「相談する」ボタンが、そこへ飛ぶ |
| 照明CF状態 | 準備中／受付中／終了 | 照明プロジェクトの表示とボタン |
| 照明CF目標金額・現在金額・支援者数 | 1500000・620000・48 | 達成率のバーと数字（「1,500,000」「円」がついていてもよい） |
| 照明CF締切 | 2027-09-30 | 「のこり○日」 |
| 照明CFページURL | クラウドファンディングのページ | 「このプロジェクトを支援する」ボタンの行き先 |
| 金額目安：オフィシャル（サポート・応援団・照明も） | 年20万円〜 | パートナー募集の金額の目安（空なら「金額はご相談ください」） |
| パートナー（何行でも） | 佐賀○○株式会社｜オフィシャル｜https://… | 協賛企業の一覧（名前｜区分｜URL。URLはなくてもよい） |

### スプレッドシートを使わない場合

`index.html` の `CONFIG`（ファイルの下のほう、`<script>` のすぐあと）を直接書きかえる。中身は上の2つのシートと同じ形。

## 公開のしかた

まだ**公開しない**（下記「公開する前に」がそろってから）。いまは検索に出ない設定（`noindex`）と、上部の「公開前の下書きです」の帯がついている。

- **Cloudflare Pages**（ikkan と同じやり方）：Cloudflare の画面で新しいプロジェクトを作り、`index.html` をアップロードするだけ。
- **GitHub Pages**：`public/chienkan-fc/` にコピーして `npm run deploy`。ただし URL が `dora9991.github.io/math-dialogue/chienkan-fc/` になる。

クラブの正式なサイトにするなら、**クラブのアカウント（クラブのメールで作ったもの）で公開する**のがよい。特定の人の個人アカウントに依存しないため（構想の「運営：特定の教員に依存しない仕組み」と同じ考え方）。独自ドメイン（例：chienkan-fc.jp）を使う場合は、年に数千円かかる。

## 公開する前に（チェックリスト）

- [ ] 学校・県の了解：クラブ名に「致遠館」を使うこと、グラウンドを「活動場所（予定）」と書くこと、照明プロジェクトの書き方
- [ ] 代表・連絡先を決めて「概要」に書く（教員の個人連絡先は載せない）
- [ ] 相談窓口（Googleフォームなど）を作り、URLを設定する
- [ ] サンプルの予定を消し、本当の予定を入れる（サンプルには「（例）」がついている）
- [ ] 「調整中」の項目を、決まったものから更新する（下の一覧）
- [ ] `CONFIG` の `draft` を `false` に、`<meta name="robots" content="noindex,nofollow">` の行を消す
- [ ] 子どもの写真を載せるときは、保護者の同意をとる

## サイトの中の「調整中」＝これから決めること

ページを見た保護者が最初に聞きそうなことを、そのまま並べてある。決まったら、その項目の「調整中」の印を消す。

- 対象学年・募集人数・参加の条件
- 活動日数と曜日（平日は16:30〜18:30の案）
- 会費
- テスト前の活動の扱い
- 16:30に集合するための移動・集合の方法と、見守りの体制
- 出場する大会（中学校体育連盟の大会か、日本サッカー協会のリーグ・大会か）と登録
- 代表
- 照明プロジェクトの方式・目標金額・支援の方法（クラウドファンディング、ふるさと納税など）

## グラフの数字について

「空が暗くなる時刻」は、市民薄明の終わり（太陽の高さが −6°）。佐賀市（北緯33.28度・東経130.31度）について、NOAA の太陽位置の式でページの中で計算している（ネット不要）。
2027年4月〜2028年3月で計算すると、練習の終わり（18:30）が暗くなる時刻を過ぎるのは **10月1日ごろ〜2月16日ごろ**。12月は、17:00〜18:30の全体トレーニングのうち **平均およそ50分** が暗い時間になる。
場所や練習時間を変えるときは、`index.html` の `LAT`・`LON`・`PRAC_START`・`PRAC_END` を直す。
