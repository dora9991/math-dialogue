# データの活用の黒板（katsuyo）

電子黒板に映して、**グラフを動かしながら**考える「データの活用」（中1・第7章）の授業ページ。1時間＝1ページ、11時間ぶんと、学力推移調査型の類題 5題。
空間図形の黒板（`../kukan/`）と同じ黒板の画面で、授業の流れは ikkan の「データの活用（新しい形）」のワークシートとそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。
画面の土台は `../kukan/js/k3.js` と `../kukan/css/board.css` を使うので、公開するときは `kukan/` の2つのファイルもいっしょに置く。

## 11時間の中身

| 時間 | ページ | 図の動き（おもなもの） |
|---|---|---|
| 第1時 | `01.html` 度数分布表 | 30人の通学時間のカードが、5分ごとの階級へ飛んで積み上がる。考えようは、階級の幅をスライダーで変える |
| 第2時 | `02.html` ヒストグラム・度数折れ線 | 棒がのびてヒストグラム、まん中を結んで度数折れ線。2つの組を重ねてくらべる。チャレンジは、折れ線とヒストグラムの面積が等しい（三角形が回って重なる） |
| 第3時 | `03.html` 代表値 | 棒をならして平均値、カードをならべて中央値、いちばん多い値が最頻値。範囲。度数分布表からの平均値（階級値×度数） |
| 第4時 | `04.html` 相対度数 | 人数のちがう2学年の度数のグラフが、相対度数のグラフにのび縮みする。相対度数を積むと 1 |
| 第5時 | `05.html` 累積度数・累積相対度数 | 棒を左から積み上げて累積度数の階段。四捨五入した相対度数をたすと ずれる。考えようは、記録の位置に線を引く |
| 第6時 | `06.html` 調べる計画（問題→計画→整理→結論） | なわとびの記録を整理して、平均値・中央値・範囲。考えようは、ドットプロットとヒストグラムを切りかえ |
| 第7時 | `07.html` データを根拠に判断する | 目的（30回以上／20回未満）で、選ぶ作戦が変わる。考えようは、縦の軸のはじまりを変えると、グラフの見え方が変わる |
| 第8時 | `08.html` 実験と相対度数 | キャップを 10回投げた 6人の結果がばらつく。1000回まで投げると 0.61 に落ち着く。考えようは、5つの班の線（投げた回数をスライダーで） |
| 第9時 | `09.html` 確率 | 2000回なら 2000×0.61。確率の数直線（0〜1）。フリースロー、5人の 100回。チャレンジは種の発芽（603粒） |
| 第10時 | `10.html` 確率を根拠に判断する | おにぎりの仕入れ（売り切れる確率 0.30・0.06）。降水確率 30%。考えようは、晴れの日・雨の日に分けた記録 |
| 第11時 | `11.html` まとめ | 家庭学習の表、ことばの整理図、ソフトボール投げの代表値、ア〜エの説明（答えは出さない）、男女をあわせた平均値（38.0kg をならして見せる） |

## 類題（`ruidai.html`）

学力推移調査でよく出る5つの型を、**場面と数値をすべて自作して**作り直した。1題＝「問題（図と小問）→ 小問ごとの答え」。目次から、題ごとに開ける（`ruidai.html#step-1`・`5`・`9`・`13`・`17`）。

| 題 | 型 | 場面 | 小問 |
|---|---|---|---|
| 1 | ヒストグラムの読み取り | 40人のハンドボール投げ | 階級の幅・最頻値・20m以上の相対度数・「19m は中央値より大きい」といえるか（記述） |
| 2 | 代表値の選び方 | 10人が読んだ本の冊数（28冊がとびぬけている） | 平均値・中央値・最頻値・書きまちがいを直したときの変化・ふさわしい代表値（記述） |
| 3 | 人数のちがう集団の比較 | 1年 120人・2年 150人の睡眠時間 | 相対度数・累積相対度数の空らん・「人数が同じだから割合も同じ」は正しいか（記述） |
| 4 | 目的に応じた判断 | リレーの選手えらび（50m走 20回ずつ） | 階級値で平均値（どちらも 7.35秒）・7.2秒未満なら A・7.4秒未満なら B のわけ（記述） |
| 5 | 確率 | 画びょうを投げる実験 | 相対度数の空らん・確率・5000回の予想・「10回なら かならず 4回」は正しいか（記述） |

## 操作

空間図形の黒板と同じ（→・Enter・Space でつぎへ、← でもどる、R でもう一度、F で全画面）。グラフは回らない。下にスライダーが出る場面では、手で値を変えられる。
URL の最後に `#step-6` のように番号をつけると、そのステップから開く。考えようの答えは出さない（調べる道具だけ）。

## つくり（作り手向け）

- 画面とステップの進め方は `../kukan/js/k3.js`（`K3.run({ flat: true, steps: [...] })`。`flat` で、ドラッグで回さない）。
- グラフを描く道具は `js/chart.js`（`CH.axes`・`CH.bars`・`CH.path`・`CH.table`・`CH.numline`・`CH.dots`・`CH.grid`・`CH.tape`・`CH.stacks` など）。
- データはすべて自作。ページの中で、表の数・答えを計算し直して照らし合わせている（`CH.check`）。ちがうと、ブラウザのコンソールに「答えがちがう：…」と出る。
- 実験のシミュレーション（第8時の5つの班）は、たねつきの乱数（`CH.rng`）なので、毎回同じ線になる。
