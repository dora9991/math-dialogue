# iPhone のショートカットのつくり方（ひびの手帳）

> このファイルは `hibi/js/guide.js` から `node hibi/tools/make-guide.cjs` でつくっています（手で直さない）。
> アプリの「設定 → iPhone連携 → つくり方を見る」でも同じものが見られ、そちらでは URL・合言葉がタップでコピーできます。

## はじめに（3つのショートカット）

iPhone のカレンダー・リマインダーは、Web アプリからは直接さわれません。そこで、iPhone に最初から入っている「ショートカット」App を橋わたしに使います。つくるのは3つ。一度つくれば、あとは自動で動きます。

- ① 「ひびの手帳 同期」…… iPhone の予定とリマインダーを、アプリへ送る（毎朝 5:30 に自動）
- ② 「ひびの手帳へ送る」…… 写真・PDF を受信箱へ送る（撮ってすぐ／共有メニューから）
- ③ 「ひびの手帳から登録」…… アプリから iPhone のリマインダー・カレンダーへ登録する
- アクションは、画面の下の「アクションを検索」に名前の一部（例：URL、辞書）を入れると出てきます。英語の名前（かっこの中）でも探せます。
- 青い札（「繰り返し項目」「ショートカットの入力」など）は、入力欄をタップすると、キーボードの上に候補が出ます。札をもう一度タップすると、中の項目（タイトル・開始日など）や、日付の書き方を選べます。
- この画面の青い文字の値（URL・合言葉）は、タップするとコピーできます。iPhone で作るときは、この画面とショートカットApp を行ったり来たりすると楽です。

## ① 「ひびの手帳 同期」：iPhone の予定とリマインダーをアプリへ

iPhone のカレンダー（iCloud・Google など、iPhone に出ているもの全部）の、きのう〜60日後の予定と、終わっていないリマインダーを、ひびの手帳に送ります。毎朝の自動実行にしておくと、Claude の朝のまとめにも今日の予定が入ります。

1. ショートカットApp →「＋」→ 名前を「ひびの手帳 同期」にする。
2. 「日付」（Date）を追加する。そのままで「現在の日付」になる。
3. 「日付を調整」（Adjust Date）を追加 →「減算」「1」「日」にする。
4. 「変数を設定」（Set Variable）を追加 → 変数名「はじめ」、入力は「調整後の日付」。
5. もう一度「日付を調整」を追加 → 入力を「日付」にもどして、「加算」「60」「日」にする。
6. 「変数を設定」→ 変数名「おわり」、入力は「調整後の日付」。
7. 「カレンダーイベントを検索」（Find Calendar Events）を追加 →「フィルタを追加」→「開始日」「が次の範囲内」（is between）→「はじめ」と「おわり」を入れる。並べ替えは「開始日」、制限はオフ。
8. 「繰り返す（各項目）」（Repeat with Each）を追加（入力は「カレンダーイベント」）。その中に、次の2つを入れる：
   - 「辞書」（Dictionary）→「新規項目を追加」→ 種類「テキスト」で、次の6つをつくる（キーは半角英字のまま。値は青い札を入れて、もう一度タップして項目を選ぶ）：

      | キー・項目 | 入れるもの |
      |---|---|
      | `title` | 「繰り返し項目」→「タイトル」 |
      | `start` | 「繰り返し項目」→「開始日」→ 日付の形式「ISO 8601」、「時刻を含める」オン |
      | `end` | 「繰り返し項目」→「終了日」（start と同じく ISO 8601） |
      | `allDay` | 「繰り返し項目」→「終日」 |
      | `cal` | 「繰り返し項目」→「カレンダー」 |
      | `loc` | 「繰り返し項目」→「場所」 |

   - 「変数に追加」（Add to Variable）→ 変数名「予定」、入力は「辞書」。
9. 「繰り返しの終了」の下に「リマインダーを検索」（Find Reminders）を追加 →「フィルタを追加」→「完了」を「オフ」（終わっていないもの）。制限はオフ。
10. もう一度「繰り返す（各項目）」（入力は「リマインダー」）。その中に：
   - 「辞書」→ 種類「テキスト」で5つ：

      | キー・項目 | 入れるもの |
      |---|---|
      | `title` | 「繰り返し項目」→「タイトル」 |
      | `due` | 「繰り返し項目」→「期日」→ ISO 8601・時刻を含める |
      | `list` | 「繰り返し項目」→「リスト」 |
      | `prio` | 「繰り返し項目」→「優先度」 |
      | `flag` | 「繰り返し項目」→「フラグ付き」 |

   - 「変数に追加」→ 変数名「リマインダー一覧」、入力は「辞書」。
11. 「繰り返しの終了」の下に「URLの内容を取得」（Get Contents of URL）を追加 → URL に `（裏側の URL：/exec で終わるもの）` を貼る →「表示を増やす」→ 方法「POST」、本文を要求「JSON」。「新規フィールドを追加」で4つ（どれも種類は「テキスト」）：

   | キー・項目 | 入れるもの |
   |---|---|
   | `token` | `（合言葉）` |
   | `action` | ios.sync |
   | `events` | 変数「予定」 |
   | `reminders` | 変数「リマインダー一覧」 |

12. 「通知を表示」（Show Notification）を追加 →「ひびの手帳に同期しました」。
13. 右下の ▷ で実行。通知が出たら完成です。アプリの「今日」を開くと、予定とリマインダーが出ます（はじめて動かすときは、カレンダーとリマインダーを使う許可をたずねられるので「許可」）。

**できたら**

- 毎朝自動で：ショートカットApp の「オートメーション」→「＋」→「時刻」→「5:30」「毎日」→「すぐに実行」→「次へ」→「ひびの手帳 同期」を選ぶ。
- 昼や夕方にも新しくしたいときは、12:00 や 18:00 にも同じオートメーションをつくる。
- アプリの「今日」にある「iPhoneと同期」ボタンでも、いつでも動かせます（終わったら、左上の「◀」でアプリにもどる）。

## ② 「ひびの手帳へ送る」：写真・PDF を受信箱へ（撮ってすぐ／共有から）

写真を撮ってすぐ、または 写真App・ファイルApp・メールの添付・LINE などの「共有」から、ひびの手帳の受信箱（Google ドライブの「ひびの手帳／受信箱」）に入れます。次の朝、Claude が読んで分類し、日付があればその日に出します。

1. 新しいショートカット → 名前を「ひびの手帳へ送る」にする。
2. 画面の下の「ⓘ」（詳細）→「共有シートに表示」をオン。いちばん上にできた「入力」の行で、受けとる種類を「画像」と「PDF」（あれば「ファイル」も）にし、「入力がない場合」は「続ける」にする。
3. 「if文」（If）を追加 → 入力「ショートカットの入力」、条件「に任意の値がある」（has any value）。
4. if文の最初の枠に「変数を設定」→ 変数名「送るもの」、入力「ショートカットの入力」。
5. 「その他の場合」の枠に「写真を撮る」（Take Photo）→ その下に「変数を設定」→ 変数名「送るもの」、入力「写真」。
6. 「if文の終了」の下に「メニューから選択」（Choose from Menu）→ 質問「いつの日に出す？」、項目を4つ：「おまかせ」「今日」「明日」「日付を選ぶ」。それぞれの枠に：
   - おまかせ：「テキスト」（中は空のまま。日付は Claude が読みとる）
   - 今日：「日付をフォーマット」（Format Date）→ 日付「現在の日付」、日付のフォーマット「カスタム」、書式 yyyy-MM-dd
   - 明日：「日付を調整」で「現在の日付」に「1」「日」加算 →「日付をフォーマット」（カスタム・yyyy-MM-dd）
   - 日付を選ぶ：「入力を要求」（Ask for Input）→ 種類「日付」→「日付をフォーマット」（カスタム・yyyy-MM-dd）
7. 「メニューの終了」の下に「変数を設定」→ 変数名「表示する日」、入力「メニューの結果」。
8. 「繰り返す（各項目）」を追加 → 入力「送るもの」。その中に、次を順に入れる：
   - 「ファイルの詳細を取得」（Get Details of Files）→「ファイル拡張子」、入力「繰り返し項目」
   - 「if文」→ 入力「ファイル拡張子」、条件「が次と等しい」「pdf」。最初の枠に「変数を設定」→ 変数名「中身」、入力「繰り返し項目」
   - 「その他の場合」の枠に「画像を変換」（Convert Image）→ 入力「繰り返し項目」、形式「JPEG」。続けて「画像のサイズを変更」（Resize Image）→「最長辺」「2000」。続けて「変数を設定」→ 変数名「中身」、入力「サイズ変更後の画像」
   - 「if文の終了」の下に「Base64エンコード」（Base64 Encode）→ 入力「中身」、「表示を増やす」→ 改行「なし」
   - 「URLの内容を取得」→ URL `（裏側の URL：/exec で終わるもの）`、方法「POST」、本文を要求「JSON」。フィールドを7つ（どれも「テキスト」）：

      | キー・項目 | 入れるもの |
      |---|---|
      | `token` | `（合言葉）` |
      | `action` | item.upload |
      | `name` | 「繰り返し項目」→「名前」 |
      | `ext` | 「ファイル拡張子」 |
      | `data` | 「Base64エンコードされた結果」 |
      | `dates` | 変数「表示する日」 |
      | `source` | shortcut |

9. 「繰り返しの終了」の下に「通知を表示」→「受信箱に入れました」。
10. ▷ で実行 → カメラが開く → 撮る →「おまかせ」→ 通知が出たら完成。アプリの「資料」の「受信箱」に出ます。

**できたら**

- アクションボタン（iPhone 15 Pro 以降）：設定 →「アクションボタン」→「ショートカット」→「ひびの手帳へ送る」。押すだけでカメラが開きます。
- 背面タップ：設定 →「アクセシビリティ」→「タッチ」→「背面タップ」→「ダブルタップ」→「ひびの手帳へ送る」。
- コントロールセンター・ロック画面・ホーム画面にも置けます（ショートカットApp で長押し →「共有」→「ホーム画面に追加」など）。
- 写真App・ファイルApp・メールの添付・LINE の画像は、「共有」→「ひびの手帳へ送る」。
- ドライブApp やファイルApp から、Google ドライブの「ひびの手帳／受信箱」に直接入れてもかまいません（アプリでは「資料」の「受信箱」に出ます）。

## ③ 「ひびの手帳から登録」：アプリから iPhone のリマインダー・カレンダーへ

メモの「iPhoneに登録」や、「確認してほしいこと」で「リマインダーに入れる」を選んだときに、アプリがこのショートカットを呼びます。名前はこのとおりにしてください（変えたときは、アプリの 設定 → iPhone連携 の名前も同じにする）。

1. 新しいショートカット → 名前を「ひびの手帳から登録」にする。
2. 「入力から辞書を取得」（Get Dictionary from Input）→ 入力「ショートカットの入力」。
3. 「if文」→ 入力に「辞書」を入れて、札をタップ →「キーの値を取得」に type と入れる。条件「が次と等しい」「reminder」。
4. if文の最初の枠に「新規リマインダーを追加」（Add New Reminder）。値はどれも「辞書」の札をタップ →「キーの値を取得」で：

   | キー・項目 | 入れるもの |
   |---|---|
   | `タイトル` | title |
   | `通知（「表示を増やす」→ オン）の日時` | due |
   | `メモ` | notes |
   | `リスト` | お好みで |

5. 「その他の場合」の枠に、もう1つ「if文」→ 入力「辞書」→ allDay、条件「が次と等しい」「1」。
   - その最初の枠に「新規イベントを追加」（Add New Event）→「終日」をオン。ほかは「辞書」→「キーの値を取得」で：

      | キー・項目 | 入れるもの |
      |---|---|
      | `タイトル` | title |
      | `開始日` | start |
      | `終了日` | end |
      | `メモ` | notes |

   - その「その他の場合」に「新規イベントを追加」（「終日」はオフ）：

      | キー・項目 | 入れるもの |
      |---|---|
      | `タイトル` | title |
      | `開始日` | start |
      | `終了日` | end |
      | `場所` | location |
      | `メモ` | notes |

6. いちばん下（2つの「if文の終了」の下）に「通知を表示」→「iPhoneに登録しました」。
7. （おこのみで）その下に「ショートカットを実行」→「ひびの手帳 同期」。登録したものが、すぐアプリにも出ます。
8. アプリでメモを開いて「iPhoneに登録 → リマインダー」を押し、リマインダーApp に入っていれば完成です。

**できたら**

- アプリは、日時を「2026-10-30 07:00」、終日の予定を「2026-10-30」の形で渡します（ショートカットが日時として読みます）。
- 「キーの値を取得」が見つからないときは、「辞書の値を取得」（Get Dictionary Value）アクションで、入力を「辞書」にしてキーを指定しても同じです。

## ④（おこのみで）iPhone のカレンダーにも、日付をつけたメモ・写真を出す

日付をつけたメモ・写真が、iPhone のカレンダーに「ひびの手帳」という終日の予定として出ます（見るだけ。iPhone が数十分〜1時間ごとに新しくします）。

1. 購読用の URL をコピーする：`（設定 → カレンダー購読 の URL）`
2. 設定App →「カレンダー」→「カレンダーアカウント」（iOS によっては「アカウント」）→「アカウントを追加」→「その他」→「照会するカレンダーを追加」。
3. 「サーバ」に貼りつけ →「次へ」→「保存」。

**できたら**

- うまく追加できないときは、使わなくても大丈夫です（アプリの中では、いつでも日付ごとに見られます）。

## 困ったとき

- 「合言葉がちがいます」：ショートカットの token と、アプリの 設定 の合言葉（裏側の showSetupInfo に出るもの）が同じか見くらべる。
- ショートカットの「URLの内容を取得」でエラー：URL が /exec で終わっているか。裏側のデプロイの「アクセスできるユーザー」が「全員」か。
- 同期で「予定の形が読めませんでした」：①の「辞書」の種類が「テキスト」か、「変数に追加」の入力が「辞書」か確かめる。
- 予定が出ない：①を ▷ で実行して、通知が出るか。出たら、アプリの「今日」で ⟳（更新）を押す。
- アプリから登録できない：③の名前が、アプリの 設定 → iPhone連携 の名前とまったく同じか（空白の有無も）。
- 写真が「確認待ち」に入った：Claude が分類を決めきれなかったもの。「今日」の「確認してほしいこと」か、「資料」で分類を選ぶ。
