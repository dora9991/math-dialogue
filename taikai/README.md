# 大会運営キット（taikai）

研究大会の **公開サイト** と **運営の管理画面** を、ひとつにまとめたブラウザのツール。
最初のサンプルは「**第109回 全国算数・数学教育研究（佐賀）大会**（日数教）」。会場校として、受付・参加者の確認・広報・大会冊子を、まとめて楽にすることをねらっている。
大会ごとにデータが分かれているので、県の大会・九州大会など、**ほかの研究大会にもそのまま使える**（管理画面の「データ・大会の切りかえ」→「新しい大会を作る」）。

- **これはサンプル**。回数・日程・会場・参加費・主題は、すべて「仮」。参加者・発表者・学校の名前は、すべて架空（乱数で作ったもの）。
- いまは **開いたブラウザの中だけ** にデータを保存する。参加者の申込を1か所に集めるには、サーバーにつなぐ必要がある（下の「本番で使うまでに」）。
- 作りはじめ：2026-10-23

## 開き方

| どこで | どうする |
|---|---|
| 手元のパソコン・タブレット | `taikai-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り。ネットにつながっていなくても動く。字体だけはネットから読む） |
| フォルダごと | `index.html` をブラウザで開く（ビルドもサーバーも要らない） |
| 手元のサーバーで | `python3 -m http.server 8794 --directory taikai` → http://localhost:8794/ （カメラでQRを読むときは、こちらか https で開く） |
| ウェブ（GitHub Pages） | https://dora9991.github.io/math-dialogue/taikai/ （だれでも開ける。データは開いた人のブラウザの中だけで、ほかの人の申込・受付は見えない） |

- 公開サイト：`#/`（ホーム）
- 管理画面：`#/admin`（サンプルの暗証番号は **1234**）
- マイページのサンプル：受付番号 **SG-0001**、メール **hanako@example.com**

GitHub では、`taikai-all-in-one.html` を開いて、右上の「Download raw file」（↓のボタン）で保存できる。

同じブラウザで、公開サイトと管理画面を別のタブで開くと、片方での変更（申込・受付など）が、もう片方にすぐ出る。

## 本番で使うまでに（まだのこと）

- **データを1か所に集める**：いまは開いたブラウザの中だけ。申込を集め、受付を何台もの端末でするには、サーバーにつなぐ。候補は ① Googleスプレッドシート＋Apps Script（学校のアカウントで完結・無料）、② Supabase（このリポジトリのほかのツールで使っている）。`js/core.js` の「保存先」（`T.store`）を差しかえる形にしてある。
- **管理画面のログイン**：いまは暗証番号だけの見本。本番では、学校・学会のアカウントでのログインにする。
- **メール**：`gas/mail.gs`（Gmail で送る Apps Script）は、**この環境では動かせておらず未検証**。本番の前に、運営の数人だけで必ず試す。1日に送れる数に上限がある（ふつうの Gmail は100通ほど、Google Workspace は1500通ほど。正確には Google の案内で確かめる）。50通ずつ送る途中で失敗すると、それまでの分は送られている。
- **カメラでの受付**：headless のブラウザでは試せていない。本物の端末（https か localhost で開く）で確かめる。
- **個人情報**：目的・保存期間・消す時期を、学会・実行委員会で決めてから公開する。冊子に名簿を載せるなら、申込フォームに同意の項目を足す。
- **名札の位置合わせ**：ラベル用紙のメーカーによって少しずれる。試し刷りをする。
- **領収書**：サンプルの形。発行者・但し書き・印は、会計の決まりに合わせて直す。
- 公開すると、URL を知っている人はだれでも開ける（検索に出ないよう noindex は入っている）。

## データの形

`localStorage` の `taikai.v1` に、次の形で保存する（PDF などのファイルは IndexedDB の `taikai-files`）。

```js
{ v: 1, current: 'sg109', events: { sg109: {
  info: { no, name, short, org, theme, start, end, applyOpen, applyClose, capacity, codePrefix, venues:[], hosts:[], office:{}, bank, color, pin, mailGasUrl, … },
  form: { fields: [{ id, type, label, required, options:[{ v, fee }] }], confirmTemplate, … },  // 参加費＝選んだ選択肢の fee の合計
  people: [{ id, code:'SG-0001', token, createdAt, a:{ 項目id: 答え }, paid, paidAt, checkin:{ 日id: 時刻 }, status:'ok'|'cancel', memo }],
  news, program:{ days:[{ id, date, label, items:[…] }] }, sections, faq, docs, videos, surveys, templates, mails, threads, board, tasks, staff, booklet, log,
} } }
```

- 本人用QRの中身は `TAIKAI:受付番号:合言葉`（合言葉は申込のときに作る6文字）。マイページのリンクは `#/mypage?c=受付番号&t=合言葉`。
- 申込フォームの `name` `kana` `email` `org` `pref` `kind` `bu` は、システムが使う項目（消せない。ラベルは直せる）。

### 画面を足す・直すときの約束

- 管理画面の1画面＝`js/admin/<id>.js` の `T.page('admin', id, { title, icon, group, order, render, mount, acts, forms })`。公開サイトは `T.page('site', …)`、印刷は `T.page('print', …)`。`index.html` に `<script>` を1行足す。書き方は `js/admin/shell.js` の先頭。
- ボタンは `data-act="名前"` → その画面の `acts.名前(el)`。フォームは `data-form="名前"` → `forms.名前(値, form)`。
- 文字は `T.html` で書く（自動でエスケープされる）。データを変えたら `T.save()` → `T.refresh()`。運営の記録に残すなら `T.logIt('…')`。
- 色は `css/base.css` の変数だけ（ダーク表示がそろう）。大会ごとの色は `--ev-*`（`T.THEMES`）。
- `alert` `confirm` は使わない → `T.toast` `T.confirm` `T.modal` `T.editRecord`。
- 直したら `node tools/bundle.cjs` で1ファイル版を作り直す。

## 検査

```bash
cd taikai
NODE_PATH=$(npm root -g) node tools/check.cjs                        # 全画面 × PC/スマホ。エラーと横のはみ出しを調べ、tools/_out/ に画面を保存
NODE_PATH=$(npm root -g) node tools/check.cjs --dark --no-shots      # 暗い表示で
NODE_PATH=$(npm root -g) node tools/check.cjs taikai-all-in-one.html # 1ファイル版を
node tools/bundle.cjs                                                # 1ファイル版を作り直す
node tools/publish-pages.cjs                                         # 作り直して GitHub Pages に公開（--dry で push しない）
python3 tools/make-sample-pdfs.py                                    # サンプルの PDF を作り直す（reportlab と IPAゴシック）
```

`check.cjs` は playwright を使う（`npm i -g playwright`）。

## 作り方と、出どころ

- 画面と文章は、作者の方針と指示のもとで、AI（Claude）を使って作成した。
- 大会名の形は、日本数学教育学会の大会案内（例：「第108回全国算数・数学教育研究（東京）大会」）に合わせた。佐賀大会の回数・日程は、2026年10月の時点では確かめられなかったので「仮」にしている。
- サンプルの PDF は、IPAゴシック（IPA フォントライセンス）を埋めこんで作っている。
- 配信のサンプルの動画は、Blender Foundation の短編映画「Big Buck Bunny」（CC BY 3.0）。埋めこみの見え方を確かめるためのもので、本番では差しかえる。
