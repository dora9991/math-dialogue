# スポーツ タップ記録

「バスケ タップ記録」（`basket-tap/`）で作った **「試合を見ながら、押した瞬間の時刻つきで記録する」しくみ** を、ほかの種目でも使えるようにしたブラウザアプリです。
1つの共通エンジンに、種目ごとのルール（ボタン・得点の数え方・試合の進み方・集計）を差し込む形にしています。
**サッカーは専用のアプリ「サッカー タップ記録」**（同じエンジンで、サッカーだけ。保存も別）、バスケは今までどおり「バスケ タップ記録」です。

| 種目 | 記録のしかた | 種目に合わせたところ |
|---|---|---|
| ⚽ サッカー（専用のアプリ） | 選手1人＝1行。行の「ゴール」「シュート」、チームの行の「ゴールキック」「フリーキック」「コーナーキック」 | 記録用（GK・FK の直接／間接とカード・CK）と分析用（シュート・あとでチェック）のボタンを選べる。前半・後半と延長、アディショナルタイム（「40+1:23」）、PK戦。撮影した動画で場面を見返す（下の「⚽ サッカー タップ記録」） |
| 🏐 バレーボール | 選手の行の「アタック」「ブロック」「サーブ」「ミス」 | ラリーポイント。点・セット・サーブ権が自動で進む（6人制・9人制・小学生）、サイドアウト率・ブレイク率 |
| 🥅 フットサル | 選手の行の「ゴール」「シュート」「ファウル」 | 累積ファウル（5つで黄・6つ目から赤＝第2PK。後半の数は延長へ）、退場はチームが2分間1人少ない時間を表示 |
| 🤾 ハンドボール | 選手の行の「ゴール」「×」 | シュートの決定率・7mスロー・セーブ・TF、2分間退場の残り時間（3回目で失格の印）、7mTC |
| 🎾 テニス | 側ごと・選手ごとの「エース」「ウィナー」「ミス」「ダブルフォルト」 | 硬式（アドあり・ノーアド・タイブレーク・マッチタイブレーク）とソフトテニス（5・7・9ゲームマッチ・ファイナルゲーム）。ゲーム・セット・サーブが自動 |
| ⚾ 野球 | 1球ずつ（ボール・ストライク・ファウル）と打席の結果 | カウント・アウト・イニング・打順・投球数（目安の球数で色が変わる）が自動。スコアボード、打者・投手の集計 |
| 🏉 ラグビー | 選手の行の「トライ」「ゴール」「PG」「DG」 | 得点 5・2・3・3・認定トライ 7、キックの成功率、タックル、シンビンの残り時間 |
| 🏊 水泳 | レーンごとの大きな「タッチ」 | 0.01 秒まで。スプリット・ラップ・順位、何組も続けて計れる、練習（サークル）の本ごとのタイム |

- インストール不要・通信なし。**記録はその端末のブラウザの中だけ**に保存し、どこにも送りません
- 公開ページ：**https://dora9991.github.io/math-dialogue/sports-tap/** 。種目ごとに `?s=volley`（`futsal` `handball` `tennis` `baseball` `rugby` `swim`）を付けると、その種目から開きます。iPhone は「共有」→「ホーム画面に追加」
- サッカー：**https://dora9991.github.io/math-dialogue/soccer-tap/** （「サッカー タップ記録」。種目を選ぶ画面の「サッカー」からも開けます）
- 1ファイル版：`public/sports-tap/index.html`・`public/soccer-tap/index.html`（`node sports-tap/build.mjs` で両方を作る）
- **撮影しながら記録する**（この端末のカメラ）：どの種目でも、録画しながら同じ画面でタップして記録できます。録画と記録は同じ時計なので、試合のあと「**🎬 場面を見る**」で、記録した場面（シュート・あとでチェック など）を、時刻あわせなしで、このアプリの中で見返せます（下の「撮影しながら記録する」「🎬 場面を見返す」）。ほかのアプリはいりません
- バスケは、専用の「バスケ タップ記録」へのリンクを、種目を選ぶ画面に置いています（バスケのアプリ・バスケ得点クリップには手を入れていません）

## どの種目でも同じ使い方

1. **種目を選ぶ** → **＋ 新しい試合を記録する** → 準備（チーム名・色・背番号。テニスは選手の名前、野球は打順、水泳はレーン）と**試合の形式**（前半の長さ・セット数 など）。自分のチームと形式は、次の試合で最初から入っています
2. **試合が始まる瞬間に「▶ スタート」**（キックオフ・最初のサーブ・プレイボール・スタートの合図）
3. **プレーが起きたら、ボタンを1回タップ**。押した瞬間の時刻で残ります。同じボタンの 0.45 秒以内の二度押しは1回に
4. まちがえたら **「↶ 取り消す」**（「やり直す」で戻せる）。**「≡ メニュー」→「記録の一覧」** で、どの記録でも時刻・チーム・番号・プレーを直す・消す
5. **集計**（選手ごと・ピリオドやセットごと）と **書き出す**（記録のファイル JSON・CSV。CSV は Excel でそのまま開ける BOM 付き UTF-8。スマホでは「共有」）

記録の途中で困らないように（バスケ タップ記録と同じ）：画面が自動で消えない（Wake Lock）・1つ記録するたびに保存（閉じても続きから）・「戻る」でページを離れない・押せたことが分かる（光る・回数・下の帯・振動・音）・ダブルタップの拡大や長押しのメニューが出ない・ホーム画面に追加すると電波の弱い体育館でも開ける（Service Worker）。

**ピリオド・セット・イニングなどは、記録から計算して決めます。** 記録を取り消したり、一覧で直したりすると、得点・セット・カウント・走者・一時退場の残り時間などが、自動で正しくなります（状態をべつに持たないので、ずれません）。

## 📹 撮影しながら記録する（この端末のカメラ）

バスケ タップ記録の「撮影しながら記録する」と同じしくみを、8種目すべての記録の画面に付けています（`js/livecam.js`。カメラ・録画・保存・MP4 への組み直しは、バスケ版と同じ `js/camera.js`・`js/vstore.js`・`js/fmp4.js`）。種目の画面には手を入れず、骨組みが、できあがった記録の画面に差しこみます。

1. スタート前の札の「**📹 撮影しながら記録する**」（または ≡ メニューの「撮影しながら記録」）→ 撮影の画面でカメラの向きを決める。**撮る向き**は「横向き（コート全体・ピッチ全体 など）」か「縦向き」。横向きなら端末を横に（画面の向きのロックを外す。ロックしたままなら「↻ 映像を回す」で、録れる動画だけ横向きにできます）
2. 試合が始まる瞬間（キックオフ・最初のサーブ・プレイボール・スタートの合図）に、赤い「**● 録画と記録をスタート**」。録画と記録の時計が同時に始まります（ウォーミングアップから撮るなら「● 録画だけ先に始める」）
3. 記録はいつもどおり。記録の画面に**カメラの映像（ワイプ）**：映像の「＋」「－」か、撮影の画面の「ワイプの大きさ」で **小・中・大**（はじめは中）
   - **中・大**：記録のボタンに**重ならない所**に出します。横長の画面（iPad・スマホの横向き）は右の列、縦長の画面は上の帯の下。記録のボタンは残りの広さに並べ直します（少し小さくなります）
   - **小**：上の帯の中の小さな映像（メニューの左）。録画中は赤いふち。押すと撮影の画面
4. 「**試合を終える**」で録画も止まり、動画が仕上がります。「試合終了」の札と「書き出す」に、動画ごとに **🎬 場面を見る**（下の「🎬 場面を見返す」）・**⬇ 保存**（写真・ファイルへ。MP4）・**🗑**

- 動画は**この端末（このブラウザ）の中に保存**します（IndexedDB `stap-media`。サッカー タップ記録は `ssoc-media`、バスケ版は `btap-media` で、それぞれ別。どこにも送りません）。1 秒ごとに保存するので、途中で画面が閉じても、そこまでは残り、次に開いたときに仕上げます
- 録画を止めて、また始めると、別の動画になります。ほかのアプリに切りかえたり画面を消したりすると録画は止まるので、戻ったときに新しい動画として続けます。録画中に映像の向きが変わったときも、そこから別の動画にします
- 画質は設定で 720p（1時間 約 1.4GB）／1080p（約 2.8GB）。音も入れるかを選べます。撮影の画面に、空き容量と「あと何時間撮れるか」
- 書き出す JSON には、記録ごとの呼び名（`text`：「致遠館 #10 たけし ゴール」）と場面の呼び名（`when`：「前半 23:41」「3回表」「第2セット」）、種類ごとに場面にするか（`types[].scene`）も入れます（ほかの道具で使うとき用）
- していないこと：バスケ版の「アプリごと横向き」（画面の向きのロックをしたまま、記録のボタンも横に回す）・ワイプの「特大」。得点の場面を動画から自動で探すのはバスケだけです

## 🎬 場面を見返す（動画で。このアプリの中だけで）

試合のあと、記録した場面を、試合の動画から「**前◯秒〜後◯秒**」で切り出して再生します（`js/review.js`）。「試合終了」の札の「🎬 場面を見る」、≡ メニューの「場面を見返す（動画）」、「書き出す」から開きます。

- **動画**：撮影しながら記録した動画なら、**時刻あわせはいりません**（録画を始めた時刻が分かるので、記録の 0:00 が動画の何秒かが決まる）。スマホやビデオカメラで別に撮った動画も「📂 試合の動画を選ぶ」で使えます。そのときは**1か所だけ**、動画をキックオフなどの瞬間で止めて、その記録を選んで「いまの位置に合わせる」。ほかの場面は全部、同じずれで並びます（±0.5 秒・±1 秒で直せる。合わせたずれは、ファイルの名前と大きさで覚えておくので、次に同じ動画を選べば合わせ直しなし。動画そのものは保存しません）
- **場面の長さ**：まとまりごとに前と後の秒数を選べます（前 5〜60 秒・後 3〜30 秒）。サッカーのはじめの値は **シュート・ゴール：30 秒前〜5 秒後**、**あとでチェック：10 秒前〜10 秒後**、そのほか（FK・CK など）：10 秒前〜10 秒後。選んだ秒数は種目ごとに覚えます
- **速さ（早送り）**：0.5・1・1.5・2・4 倍。場面を続けて見るときも、その速さのまま
- **再生**：一覧の場面を押すと、その場面だけ（終わりで止まる）。「▶ 続けて再生」で、絞り込んだ場面を順に（重なる場面は1つにつないで、同じところを2回見せない）。⏮ ⏭ で前・次の場面、−10 秒〜+10 秒
- **絞り込み**：場面の種類（ゴール・シュート・あとでチェック・カード など）・チーム・選手（「#10 たけし」の場面だけ）
- スマホ縦では、場面を押すと映像が見えるところまで戻ってから再生します。「場面の長さ」は、はじめはたたんで、いまの秒数を見出しに出します

## ⚽ サッカー タップ記録（専用のアプリ）

`soccer.html`（公開は `/soccer-tap/`）。エンジンはスポーツ タップ記録と同じで、`ST.CONFIG = { only: 'soccer', key: 'ssoc', db: 'ssoc-media' }` を先に置くだけで、サッカーだけのアプリになります（種目を選ぶ画面なし・保存の名前も別なので、スポーツ タップ記録の試合とは混ざりません）。

**使うボタンを選べます**（≡ メニュー →「設定」。「記録用」と「分析用」に分けて、1つずつ オン・オフ）：

| | ボタン | はじめ | 記録のしかた |
|---|---|---|---|
| 記録用（公式の記録・数を数える） | ゴール | オン | 選手の行 |
| | ゴールキック | オン | チームの行 |
| | フリーキック | オン | チームの行。押すと小窓で **直接・間接** と **カード（なし・🟨 イエロー・🟥 レッド）**、カードをもらった相手の背番号。直接・間接を分けるか、カードも選ぶかも、それぞれオン・オフ |
| | コーナーキック | オン | チームの行 |
| | イエロー・レッド（FK とは別に） | オフ | 選手の行 |
| | オフサイド | オフ | チームの行 |
| 分析用（ふり返り・動画で見返す） | シュート | オン | 選手の行（何番が打ったか）。動画では 30 秒前〜5 秒後 |
| | あとでチェック（★） | オン | 下の帯の大きなボタン。時刻だけ。動画では 10 秒前〜10 秒後 |
| | アシスト・セーブ（GK）・ファウル | オフ | 選手の行 |

- 集計に GK・FK（直接・間接）・CK・イエロー・レッドの数。フリーキックのカードは、もらったチーム（相手）のイエロー・レッドとして数えます
- 選手の行のボタンを全部オフにすると、選手の行は出さず、チームの行だけにします（記録用だけ・分析用だけ、という使い方もできます）

## 種目ごとのくわしいこと

### チームの行で記録する種目（サッカー・フットサル・ハンドボール・ラグビー）

記録の画面はバスケ タップ記録と同じ「選手1人＝1行」。画面の大きさと人数から、ボタンがいちばん押しやすい並べ方を自動で選びます（`ST.planLayout`。2チームを左右か上下か・チームの中を何列にするか）。

```
┌ ● 23:41 ┐┌前半┐  ┌ 1 ┐ − ┌ 0 ┐  ┌≡┐     ← 時計（いまのピリオドが始まってからの時間）・ピリオド・得点・メニュー
┌ 致遠館 −1 1:30  1 ＋番号 ┐┌ 城南      0 ＋番号 ┐   ← チームの帯：1人少ない時間（一時退場）・累積ファウル（フットサル）
│  1 [ゴール][シュート]    ││ チーム [ゴール][シュート] │
│  …                        ││ チーム [CK][FK][オフサイド] │  ← 「チーム」の行：チームとしての記録
│ 11 [ゴール][シュート]    │└───────────────────────┘
│  ？[ゴール][シュート]    │   ← だれか分からないとき
│ チーム [CK][FK][オフサイド] │
└───────────────────────┘
[★ あとで見る]  後半 1:05 ゴール +1 / 城南  [↶ 取り消す]
```

- **時計**：いまのピリオドが始まってからの時間。前半の長さ（形式で選ぶ）を過ぎると「40+1:23」（アディショナルタイム）。時計の右の「前半」を押して「前半を終える」「後半を始める」。延長・PK戦（7mTC）も同じところから。ハーフタイムの間は「HT」で時計が止まって見えます（記録の時刻は止まらずに進む）
- **PK戦**：選手の行のボタンが「成功」「×」に変わり、上の帯に「PK 4−3」。試合の得点には入れません
- **設定で足せるボタン**：サッカー（上の「⚽ サッカー タップ記録」）、フットサル（アシスト・警告と退場）、ハンドボール（7mスロー・セーブ・TF・警告／2分／失格）、ラグビー（キックの失敗の「×」・タックル・反則・シンビンと退場）。「チーム」の行も設定で消せます
- **一時退場**：ハンドボールの2分間退場・ラグビーのシンビン・フットサルの退場（チームが2分間1人少ない）・ハンドボールの失格は、選手の行とチームの帯に残りの時間。ハーフタイムの間は減りません。**記録の時計は止まらないので、タイムアウトなどで試合の時計が止まったぶんは、目安より早く終わります**
- **ボタンの文字**：幅が狭いときは短い呼び名（「シュート」→「×」、「アシスト」→「A」、「タイムアウト」→「TO」）

### バレーボール

- 記録1つ＝ラリー1つの結果。アタック・ブロック・サーブ（エース）・チームの「得点」はそのチームの点、ミスは相手の点。レシーブ・タイムアウトは点が動きません
- 形式：6人制（25点・最終セット15点）・9人制（21点）・小学生（21点・最終セット15点）、3・5・1セットマッチ、デュースのあり・なし、最初のサーブ
- セットが決まると下の帯で知らせ、次の点から次のセット。試合が決まると「試合を終える」。サーブ権はラリーを取ったチームへ。セットごとに最初のサーブは交互。最終セットなどで入れかえたいときは、チームの帯の 🏐 を押す（'srv' の記録）
- 集計：セットごとの点、選手ごとの得点とミス、相手のミスでの得点、サイドアウト率（相手のサーブのラリーを取った割合）・ブレイク率（自分のサーブのラリーを取った割合）、セットごとのタイムアウト
- していないこと：ローテーション（だれがサーブか）は追いません。9人制の細かいサーブのルールも扱いません（点とセットだけ）

### テニス（硬式・ソフトテニス）

- 準備：硬式／ソフトテニス、シングルス／ダブルス、選手の名前・学校名・色、最初のサーブ
- 記録1つ＝ポイント1つ：エース・ウィナー・「ポイント」（理由なし）はその側、ミス・ダブルフォルトは相手のポイント。エース・ダブルフォルト・フォルトは、サーブしている側だけ押せます。設定で「フォルト（1stサーブ）」を出すと、1stサーブの入った割合が出ます
- 硬式：0・15・30・40・デュース・アドバンテージ（ノーアドも）、6ゲーム・4ゲーム（ショートセット）・8ゲーム（プロセット）、同じゲーム数で並んだら7ポイントのタイブレーク、最終セットを10ポイントのマッチタイブレークにも。ソフトテニス：4ポイント先取・デュース、5・7・9ゲームマッチ、ファイナルゲーム（7ポイント・2ポイント差）
- サーブはゲームごとに交代、タイブレーク・ファイナルゲームは2ポイントずつ。ゲーム・セット・試合が決まると知らせます（奇数ゲームのあとのチェンジコートも）
- 集計：セットごとのゲーム数、取ったポイント、エース・ダブルフォルト・ウィナー・ミス、1stサーブ、サービスゲームのキープ・ブレイク
- していないこと：ダブルスでサーブする人は「その側のサービスゲームごとに交代」の目安です（セットごとの順番の入れかえには追いつきません）

### 野球

- 準備：チームごとに打順（背番号・名前。人数は足せる・減らせる）、先発投手、先攻。形式：イニング（9・7・6・5回）、投球数の目安（70・80・100球。10球前から黄、届くと赤）
- 記録1つ＝1球（ボール・ストライク・ファウル）か打席の結果（単打〜本塁打・四球・死球・失策・野選・三振・ゴロ・フライ・ライナー・犠打・犠飛・併殺）。4ボールで四球・3ストライクで三振、3アウトでチェンジ、打順は自動で進みます。1球ずつ記録しない設定も
- 走者：**確かな動きだけ自動**（押し出し、本塁打・三塁打の生還、犠飛の1点。犠打は全員1つ先へ・併殺はいちばん後ろの走者を消す、という「よくある形」）。それ以外は、ダイヤモンドの塁をタップで直す・「＋1点」（いちばん先の走者を消して1点）・「アウト＋1」
- 代打・打順を直す・投手の交代（投球数は0から）・チェンジは小窓から。集計：スコアボード（R・H・E）、打者ごと、投手ごと（投球回も）。CSV は3種類
- していないこと：振り逃げ・打撃妨害・暴投などの細かいルール、打点・自責点

### 水泳

- 時刻は 0.01 秒まで（`prec: 100`）。タイムは「1:02.35」。**人が押すので、本当のタッチから 0.1〜0.2 秒くらいずれます**（公式記録の代わりにはなりません）
- 準備：計るもの（レース＝記録会・大会／練習＝サークル）、泳ぎ方、距離（25〜1500m）、プール（25m・50m）、レーンの数（1〜10）とレーンごとの名前・学校名。入れた名前は次も入っています
- 記録の画面：上の帯の時計は 0.01 秒まで動き、全員ゴールすると止まります。レーンごとの大きな「タッチ」（壁にさわった瞬間。最後の1回は緑の「ゴール」）、何回目か（2/4）・前のスプリットとラップ・ゴールしたらタイムと順位。1 秒以内の二度押しは1回に。レーンの「…」で失格・棄権・欠場・最後のタッチの取り消し・名前の変更
- **組を続けて計る**：「次の組へ」で距離・名前を入れかえ（前の組のまま・消す）、スタート待ちの札から「▶ 2組目 スタート」。どの組のタッチかは時刻から決まります（`heat` の記録）
- **練習（サークル）**：例「50m × 8本・1:00 サークル・5秒おき」。スタートは1回だけで、2本目からのスタートはサークルとずれから自動で決まり、本ごとのタイム・平均・ベストが出ます
- 結果：組ごとの順位・タイム・スプリット・ラップ、同じ種目の組をまとめた総合順位。CSV は「記録の一覧」と「結果（1人1行）」
- 設定：レーン1を上か下か、タッチのボタンを右側か左側か

## データの形

`js/core.js` の先頭コメントが仕様。書き出す JSON（サッカーの例）：

```json
{
  "format": "sports-tap", "version": 1, "sport": "soccer", "sportName": "サッカー", "app": "スポーツ タップ記録",
  "id": "g…", "title": "", "date": "2026-10-19", "startedAt": 1792391412000, "startedAtText": "2026-10-19 15:30:12 (UTC+09:00)", "endedAt": null, "tz": 540, "prec": 10,
  "opts": { "len": 40, "elen": 10 },
  "teams": [ { "name": "致遠館", "color": "#f4f4f4", "colorName": "白", "players": [{ "no": "10", "name": "たけし" }] }, { "name": "城南", "color": "#2f6fed", "colorName": "青", "players": [] } ],
  "events": [
    { "id": "e1", "t": 0, "type": "period", "period": 1 },
    { "id": "e2", "t": 125.4, "type": "goal", "team": 0, "no": "10", "period": 1 }
  ],
  "score": [1, 0], "scoreText": "1 − 0", "types": { "goal": { "label": "ゴール", "pts": 1 } }
}
```

- `t`：スタートを押してからの秒（`prec` が 10 なら 0.1 秒、水泳は 100 で 0.01 秒）。`startedAt`（エポックミリ秒）と足せば、その時刻。試合の動画の撮影時刻と合わせれば、場面を探せます
- `team`：0 = 自分、1 = 相手、`null` = チームなし（★ あとで見る など）。`no`：背番号（文字。`"0"` と `"00"` は別）。`null` は番号なし・チームの記録
- 種目ごとに足す項目：バレー（`set`・`pointTo`・`server`・`after`）、野球（イニングなど）、水泳（組・レーン）など。くわしくは各 `js/sp/<種目>.js` の先頭
- ブラウザの中の保存（localStorage）：`stap:games`（試合の一覧）・`stap:game:<id>`・`stap:teams`（チーム。種目ごと）・`stap:prefs`（設定。種目ごとのボタンの組み合わせ・前の試合の形式・場面の長さと速さも）。サッカー タップ記録は `ssoc:…`、バスケ タップ記録は `btap:…` で、それぞれ別です
- サッカーのフリーキック：`{ "type": "fk", "team": 0, "fk": "d"（直接）| "i"（間接）, "card": "n" | "y" | "r", "cno": "4"（カードをもらった相手の背番号） }`。あとで選んだ動画の時刻あわせは `syncs`（`"ファイル名|大きさ": 動画の秒 − 記録の秒`）

### 種目を足すとき

1. `js/sp/<種目>.js` で `ST.addSport({ id, name, icon, desc, family, TYPES, score, scoreText, optFields, defaultOpts, … })`（チームの行で記録する種目なら `ST.teamSport({…})` で、ボタンとピリオドの名前を書くだけ）
2. `js/v/<family>.js` で `ST.addView(family, { build(ctx), stats(ctx, game), setup?, editExtra?, settings?, menuItems?, coverExtra?, endSummary? })`。`ctx` は骨組みが貸すもの（`record`・`say`・`undo`・`elapsed`・上の帯と下の帯の部品 など。`js/app.js` の終わりの `ctx`）
3. `index.html` に script と css を足す

## 開発

```bash
node sports-tap/build.mjs                    # 1ファイル版を作り直す（公開するのはこれ）
node sports-tap/tests/unit.cjs               # 共通の核とチームの行の種目（unit-volley.cjs などは種目ごと）
node sports-tap/tests/e2e.cjs built          # 画面を通した確認（骨組みとチームの行の種目）。dev で開発版
node sports-tap/tests/e2e-volley.cjs         # バレー（e2e-tennis・e2e-baseball・e2e-swim も同じ）
node sports-tap/tests/e2e-camera.cjs built   # 撮影しながら記録する・場面を見返す（先に build.mjs。ffmpeg も使う）
SHOTS=/tmp/shots node sports-tap/tests/e2e.cjs dev   # 画面の写真も撮る（見た目の確認用）
node sports-tap/tests/server.cjs             # 開発用サーバー → http://127.0.0.1:5194/
python3 sports-tap/tools/make_icons.py       # アイコンを作り直す（Pillow が必要）
bash sports-tap/tools/deploy-ghpages.sh      # 公開（gh-pages の sports-tap/ と soccer-tap/ だけを入れかえる。ほかの公開物は変えない）
```

e2e は Playwright（`npm i -g playwright` など）と、その Chromium を使います。日本語のファイル名を確かめるため、`LANG` がない環境では `C.UTF-8` にしてから Chromium を動かします。

## 確かめたこと（正直な範囲）

- **Chromium（Playwright・画面なし）で、スマホ縦（390×664）・iPhone SE（375×553）・スマホ横（844×390）・iPad 縦横（820×1180・1180×820）の大きさ（タッチ）にして操作**。時計は Playwright の clock で進め、記録の時刻が 0.1 秒（水泳は 0.01 秒）まで合うことを確かめた
- サッカー タップ記録：記録用・分析用のボタンの オン・オフ（選手の行のボタンが全部オフなら、選手の行は出ない）・フリーキックの小窓（直接・間接・カード・背番号）と集計・保存がスポーツ タップ記録と別であること（`tests/e2e.cjs`・`tests/unit.cjs`）
- チームの行の種目：種目を選ぶ → 準備（形式・「1〜11」・名前）→ スタート → 選手の行・チームの行・★ で記録（二度押しの防止）→ 取り消す・やり直す → 前半を終える（HT で時計が止まって見える）→ 後半 → アディショナルタイム「30+1:23」→ PK戦（ボタンが「成功」「×」に・得点に入れない）→ 一覧で時刻・番号・プレーを直す（得点も直る）→ 集計 → 書き出す（JSON・CSV 2種類・日本語のファイル名）→ 開き直すと続きから → 試合を終える → 次の試合で自分のチームと前の形式が入っている → ハンドボールの2分間退場（行とチームの帯に残り時間・2分で戻る）・7mスロー・決定率 → フットサルの累積ファウル（5つで黄・6つ目で赤・後半は0から）→ ラグビーの得点・シンビンの残り時間 → 書き出したファイルを開く。サッカー 18人ずつ・ボタン 7 つでも、どの画面の大きさでもボタンが画面からはみ出さず、文字がボタンに収まる
- バレー・テニス・野球・水泳も、それぞれの `unit-*.cjs`・`e2e-*.cjs` で、点・セット・ゲーム・カウント・アウト・タイムの計算と、スマホ縦・iPad 横の画面を確かめた（件数はテストの出力）
- **撮影しながら記録する**（`tests/e2e-camera.cjs`）：Chromium のカメラを「その瞬間の時刻を白黒の模様で描いた映像」に差しかえて録画し、録れた動画のコマから時刻を読んで、**記録と動画の時刻のずれが ±0.15 秒以内**であることを確かめた。サッカー（iPad 横）：撮影の画面 → ワイプ（中・大・小）→ 録画と記録を同時にスタート → 記録 → 画面を離れて戻ると動画2 → 試合を終えると2本の MP4 が仕上がる → ⬇ 保存した MP4 が ffprobe で読め、ふつうの MP4（moof なし）→ 書き出す JSON に動画と記録ごとの呼び名・フリーキック（間接・イエロー）→ 「🎬 場面を見る」で、時刻あわせなしにゴール・シュート・あとでチェック・FK・CK が並び、**場面のコマに映っているのがボタンを押した瞬間**（ずれ ±0.15 秒以内）→ 場面の長さ（シュート 30 秒前〜5 秒後・あとでチェック 10 秒前〜10 秒後）と選び直し・速さ 2 倍・1場面の再生が終わりで止まる・絞り込み（種類・カード・選手）・続けて再生・動画2への切りかえ → 保存した MP4 を「📂 試合の動画を選ぶ」で選び、1か所合わせると全部の場面が並び、同じファイルを選び直すと合わせたずれを覚えている → スマホ縦でも横にはみ出さない。**8種目すべて**で、スマホ縦・iPad 横に、録画しながらワイプ（中・大・小）を出しても、記録のボタンに重ならず、上の帯もはみ出さない
- **していないこと**：本物の iPhone・iPad・Android での操作。とくに、小さなボタン（スマホでボタンを全部出したとき、細い「×」は約 25px）が試合中に押しやすいか、振動・画面を消さない仕組み・ホーム画面に追加したときの動き、本物の試合での記録。本物の端末での撮影（Safari の録画の形と時刻のずれ・長い試合での容量と電池・発熱）

## 注意

- iPhone の Safari は、**しばらく（7日ほど）開かないサイトの保存を消す**ことがあります。大事な試合は「書き出す」でファイルにも残してください（ホーム画面に追加したアプリは、この消え方をしにくくなります）
- ホーム画面に追加したアプリと、Safari で開いたページは、保存場所が別です
- 時計は「試合の時計（残り時間）」ではなく、スタートからの経過時間です（チームの種目は、ピリオドが始まってからの時間を見せます）。止めずに進むので、動画と同じ時間の流れになります
