# 授業ライブ（中1数学：小テスト・振り返り・授業の反応）

授業中に生徒の端末（PC・タブレット・スマホ）をつないだままにしておく前提で、
**小テスト・振り返り・授業の反応ボタン**を1つにまとめたツール。旧 `quiz/`（比例反比例のみ）を
中1全7章に広げてリニューアルしたもの。旧版のよいところ（数式の同値判定・声かけ文・配布制御）は引き継いでいる。

- 生徒 `index.html` ／ 先生 `teacher.html` ／ 投影 `screen.html`
- 問題：中1の全7章・45回・小問314問＋★チャレンジ45問。**すべてこのツールのために自作**（教科書・市販問題集の問題文は使っていない）
- 生徒の名前・学校名は保存しない（ID＝学校コード＋学年・組・番号。例 `E-101205`）
- デザイン「Astra 教室版」：数学ラボ3（Astra Academy）の星空・方眼・ガラスの枠・金の細線・明朝の見出しを教室向けにしたもの（下の「デザイン」）

## できること

### 生徒
| 機能 | 内容 |
|---|---|
| 反応ボタン（下に常に表示） | 👍いいね・💡なるほど・🤔わからない（押しっぱなし）・🐢ゆっくり・✋手をあげる・🆘ヘルプ・❓質問・💬コメント |
| みんなの質問 | 名前なしで表示。同じ疑問なら「🙋わたしも」。多い質問から先生がとり上げる |
| 先生からの質問（投票） | 理解度4段階・A〜D・○×・数値や式・ひとこと。結果が公開されると分布と正解が見える |
| 課題の「できた！」 | 先生が出した課題ごとに、終わったら押す |
| タイマー・めあて・お知らせ | 先生の操作がすぐ画面に出る（全員の時計をそろえる） |
| 小テスト | 1問ずつ表示・問題番号から移動・見直し画面・制限時間・**途中で閉じても続きから**・通信が切れても端末に保管して自動で送り直す |
| 数式入力 | 入力中に「読み取り」で分数・累乗をきれいに表示（打ちまちがいに気づける）。答えの種類に合った記号キー。タブレットでは数字パッド |
| 結果と解説 | ○×・正解・**よくある間違いへのヒント**（例「−(−8) は ＋8」）・解説。★チャレンジは基本が満点のとき＋1 |
| 類題でれんしゅう | 数字を変えた問題をその場で答え合わせ（計算系の15回分）。記録されない |
| 振り返り | ふだん（2〜3分）／じっくり（単元末）。**前回決めた「次にやること」を表示して「できた？」**を聞く（学びをつなげる）。書き出しボタンで書きやすく |
| 光ったところ | 送信すると、観点のうち光ったところ（Niceな問い・予測を立てた など）と、先生の口調の声かけが返る。A/B/C は見せない |
| わたしの記録 | 小テストの点数と解説、振り返り、**先生からのひとこと**、理解度の変化、光ったところの回数 |

### 先生
| 機能 | 内容 |
|---|---|
| 授業の開始・切りかえ | 回を選んで「始める」→ めあてが配信される |
| いまの教室 | 接続数・わからない人数・挙手とヘルプの**順番待ち**・座席表（番号ごとの状態）・未接続の番号・できた！の進みぐあい・🎲ランダム指名 |
| 反応の流れ | いいね・なるほど・ゆっくり・わからないの直近1分／5分、1分ごとのグラフ |
| クイック投票 | 5種類。数値・式の答えは**同じ値どうしをまとめて**集計し、正解に✅。途中式のままの答えは別に分かれる |
| 小テストの配布 | 回と制限時間を選んで配布（「前回の内容で」ボタンもある）。提出状況と**設問ごとの正答率**がその場で見えて、解説すべき問題がわかる |
| 小テストの結果 | 生徒×回の一覧表、設問ごとの分析（**誤答をまとめて、誰が何と答えたか**・つまずきの理由）、やり直しの許可、CSV（Excel） |
| 点数の検証 | 生徒の端末から来た点数を、**先生の画面で解答から採点し直して照合**（改ざんがあれば⚠） |
| 振り返りの観点評価 | 下の10観点を −／○／◎ で自動判定し、**根拠の文を強調**。チップをクリックで先生が直せる。心配なことば（SOS）・要フォロー・使い回しの検出 |
| 観点マップ・生徒ごと | 生徒×観点の表、粘り強さ・自己調整・思考の手がかり、「主体的に学習に取り組む態度」の**下書き**（2回以上たまってから） |
| AIに見てもらう | 番号だけの振り返りと観点をまとめたプロンプトをコピー（Claude などに貼る） |
| 反応ログ | 授業ごとに、何分ごろ「わからない」が増えたか・質問の一覧 → 授業改善に |
| 問題 | 配布前に問題と答えを確認。**印刷**すれば紙の小テスト（問題用紙／解答）になる |
| 生徒・参加 | 参加コードとQR、登録の受付の開け閉め、仮パスワードの発行、アカウントの削除 |
| 投影画面 | めあて（単元の色と紋章）・大きなタイマー・参加QR・わからない人数・名前なしの質問・投票結果・提出状況。投票や質問があるときは左に教室のまとめ、右に投票・質問を大きく出す（キー：F 全画面／Q QR／D 夜空⇔昼） |

### 振り返りの観点（自動判定は下書き。最終判断は先生）
| 観点 | 見ているもの（例） |
|---|---|
| まとめ | その時間・単元の言葉を使って自分の言葉でまとめているか |
| 簡潔 | 要点を短く（12〜70字・2文以内）言い切れているか |
| Niceな問い | 「なぜ」「もし〜なら」「いつでも〜？」など次につながる問い（「わからない」だけは問いにしない） |
| Niceな見方・考え方 | 比べる・きまり・一般化・図や式で表す・逆から・関連づけ・具体例・着目（＋理由があれば◎） |
| 予測 | 予想を立てたか（予想＋確かめ／理由で◎）。「難しいと思う」のような気持ちは予測にしない |
| 関心 | おもしろさ・不思議さ・生活とのつながり（「楽しかった」だけでは判定しない） |
| 学び方 | 図・表・説明・見直し・例をつくる など（工夫＋効果で◎） |
| 改善の主体性 | 次に何を・どうするか（「頑張る」だけは行動ではないので−） |
| つまずきの自覚 | どこで・なぜつまずいたかを具体的に言えているか |
| 前回との接続 | 前回の「次にやること」をふり返ったか・内容でつないでいるか（設計メモの核 #5） |

文章のうまさ・前向きさは評価しない（書くのが苦手な子を守る）。判定には必ず根拠の一文を添える。
設計のもと：Obsidian `20_Ideas/1_AI下地/設計メモ_振り返りシートAI評価_2026-07-10.md`。

## セキュリティ（旧 quiz/ から直したこと）

| 旧版の問題 | 授業ライブでの対策 |
|---|---|
| 生徒用の関数がIDだけで呼べ、**他人の振り返り・点数を読めた** | ログインでランダムなトークンを発行し、すべてトークン必須（DBにはハッシュだけ保存） |
| 先生PINが4桁で**総当たりできた**（回数制限なし） | 8文字以上の合言葉（bcrypt）＋12時間トークン。接続元ごと・全体でのログイン回数制限 |
| 内部関数（`quiz_check_pin` など）を外から直接呼べた | 内部関数は anon から実行不可にした |
| 「パスワードを保存」で端末に**平文のパスワード**を保存 | パスワードは保存しない。トークンだけを保存（ログアウトで無効化） |
| 生徒のログイン失敗に制限なし | 8回で5分ロック。IDの有無もエラーから分からないようにした |
| 計算問題に**式をそのまま書くと正解**になった（`(+5)+(-8)` → −3 と評価） | 「答えの形」を検査。数の問題は数だけ、文字式は同類項・×÷の省略・約分まで確認 |
| 点数はブラウザが送る値をそのまま信用 | 先生の画面で解答から採点し直して照合し、不一致を表示 |
| 文字数・データ量の上限なし | サーバー側で上限と制御文字の除去 |
| 画面の埋め込み（クリックジャッキング）対策なし | CSP（外部スクリプト禁止）＋ `_headers` で frame-ancestors 'none' など |

旧 quiz/ をすぐ止められない場合は、`quiz/security_patch.sql` を当てると、先生PINの総当たり対策と内部関数の保護だけは入る
（IDだけで読めてしまう問題は旧画面の作りのため直せない → 授業ライブへの移行を推奨）。

※採点はブラウザ内で行うため、問題データ（答え）は生徒の端末にも読み込まれる。成績のための厳密な試験には使わず、
「その場のフィードバック」と「先生の画面での検証」で運用する前提。

## セットアップ（本番・初回だけ）

1. Supabase（math-labo-second：`mtzhbiadzqjhvhzzdsbn`）の **SQL Editor** に `schema.sql` の全文を貼って **Run**
   （`live_*` だけが作られ、既存の quiz_* などには触れない。何度実行してもよい）
2. 同じ SQL Editor で、先生の合言葉を設定（8文字以上。この関数は SQL Editor からしか実行できない）
   ```sql
   select live_admin_set_teacher_pass('ここに合言葉');
   ```
3. 公開（Cloudflare Pages）
   ```bash
   sh lesson-live/build.sh && npx wrangler pages deploy lesson-live/.deploy --project-name math-live
   ```
4. `teacher.html` を開いてログイン →「＋ クラスを追加・管理」でクラス（学校コード・学年・組）を作る
5. 「生徒・参加」タブの参加コード／QRを生徒に見せて登録してもらう。全員そろったら受付を止める

旧 quiz/ のアカウント（同じID・同じパスワード）でもログインでき、初回ログイン時に自動で移る（そのクラスを先に作っておくこと）。

## 授業での使い方（例）

1. 授業のはじめ：先生が「ライブ」で回を選んで「始める」。投影画面を開く
2. 前回の内容で小テスト（「前回の内容で」→ 配布）。提出状況と正答率の低い設問を見て、その場で解説
3. 講義・演習中：生徒は反応ボタン。先生は「わからない」の人数と挙手・ヘルプの順番を見ながら机間指導。
   課題を出したら「できた！」の進みぐあいで次へ進むタイミングを決める。理解度の投票で確認
4. 授業のおわり：振り返りの受付開始（単元末は「じっくり」）。授業を終えても振り返りの受付は続く（家で書ける）
5. 放課後：振り返りタブで ⚠ から確認、ひとことを返す。反応ログで「わからない」が増えた時刻をふり返る

## 自分のPCで試す（検証用のローカルサーバー）

本番のDBを使わずに試せる。Docker が必要。

```bash
docker network create ll-net
docker run -d --name ll-db --network ll-net -p 127.0.0.1:54432:5432 -e POSTGRES_PASSWORD=postgres public.ecr.aws/supabase/postgres:17.6.1.171
docker exec ll-db psql -U supabase_admin -d postgres -c "alter role authenticator with password 'postgres';"
docker exec -i ll-db psql -U postgres -d postgres < lesson-live/schema.sql
docker exec ll-db psql -U postgres -d postgres -c "select live_admin_set_teacher_pass('test-pass-1234');"
docker run -d --name ll-rest --network ll-net -p 127.0.0.1:54433:3000 -e PGRST_DB_URI="postgres://authenticator:postgres@ll-db:5432/postgres" -e PGRST_DB_SCHEMAS=public -e PGRST_DB_ANON_ROLE=anon -e PGRST_JWT_SECRET="super-secret-jwt-token-with-at-least-32-characters-long" public.ecr.aws/supabase/postgrest:v16.3
python3 lesson-live/serve.py 8794
```

`http://127.0.0.1:8794/teacher.html`（合言葉 `test-pass-1234`）と `http://127.0.0.1:8794/index.html` を開く。
localhost で開くと自動で検証用サーバーにつながる（本番につなぐときは URL に `?server=prod`）。
生徒30人分の動きを流すには `LL_JOIN=参加コード node lesson-live/test/simulate.js 30`。

## デザイン（Astra 教室版）

- 背景は夜空（方眼・星・軌道の輪）。枠はガラス風のパネルに金の細線。見出しは明朝（Shippori Mincho）、英字の小見出しは Cinzel
- **読む部分（問題・結果・振り返り・先生の表やデータ）は白い紙面**（`.paper`）にして、長く読んでも疲れないようにしている
- 夜空（既定）と昼（明るい表示）の2つ。生徒はメニュー、先生は「設定」、投影画面は D キーで切りかえ。明るい教室で投影が見にくいときは昼にする
- 生徒のホームは、単元の色と紋章の「今日の授業」カード＋めあて、そのとき使うもの（投票・課題・小テスト・振り返り）を色つきのタイルで出す。小テストの結果は星3つ・紙吹雪、振り返りは「光ったところ」のメダル
- アイコンは線画（`js/icons.js`、絵文字に頼らない）。反応ボタンだけは子どもに分かりやすい絵文字のまま
- フォントは Google Fonts から読み込む（CSP で `fonts.googleapis.com` / `fonts.gstatic.com` だけ許可）。読み込めない環境でもヒラギノ・游ゴシックなど端末のフォントで表示される
- 動きを減らす設定（prefers-reduced-motion）の端末ではアニメーションを止める

### 問題の書き方（`js/bank/u*.js`）
```js
{ type: "input", mode: "num", lead: "次の計算をしましょう。",
  subs: [{ lb: "(1)", p: "$(-7)+(-5)$", a: -12, v: 1, miss: { "12": "負の数どうしの和は −" } }],
  sol: "解説" }
```
- `mode`：`num`（数・分数・π）/ `lin`（文字式・まとめた形まで）/ `expr`（式・形は問わない）/ `form`（表し方そのもの）/
  `rel`（等式・不等式）/ `ineq`（変域）/ `coord`（座標）/ `list`（順番つき）/ `set`（順番なし）/ `text`（ことば）/ `factor`（素因数分解）
- `$...$` の中は数式として表示。`v: 1` を付けると、テストで問題文の式を計算して答えを確かめる（`v: "eq"` は方程式の解を代入して確認）
- `type`：`input` / `choice` / `multi`（すべて選ぶ）/ `graph`（グラフが通る点を選ぶ）/ `plot`（点をかき入れる）
- 問題を変えたら `node lesson-live/test/run-all.js` で確認
