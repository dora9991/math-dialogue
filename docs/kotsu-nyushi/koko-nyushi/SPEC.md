# 高校入試（中3）4択問題づくりの決めごと（時間制限：8分）

コツコツくん（数学の練習アプリ）に足す、**公立高校入試レベルの4択問題**を、たくさん作ります。授業には結びつけず、分野ごとのまとまり（A〜G）にします。
見本は `samples-j.json`（すでに公開中の問題。書き方・まちがい選択肢の理由 `w` の付け方を、そろえる）。

## 担当の分野（7つ）
A 式の計算・因数分解・式の利用（文字式による説明・規則性・整数の性質）／B 平方根・二次方程式（文章題を含む）／C 関数 y=ax²（放物線と直線、交点、面積、変域、動点）／D 一次関数・連立方程式・方程式の文章題（中1・中2の範囲を使う入試の小問・大問）／E 平面図形（合同・平行四辺形・相似・円周角・座標平面の図形）／F 三平方の定理・空間図形（体積・表面積・最短距離・切断）／G データの活用（確率・標本調査・箱ひげ図・資料の整理）。
中1〜中3の範囲を、どれも使ってよい（入試は全範囲）。

## 問題オブジェクトの形（1問）
```json
{"id":"ex3-C-007","u":"J3-XC","s":"J3-XC-01","l":"ex3-C","d":4,"q":"問題文",
 "c":[{"t":"選択肢A","w":"この答えを選ぶ人の、まちがえ方（中学生に向けた一文）"},{"t":"選択肢B","k":1},{"t":"選択肢C","w":"…"},{"t":"選択肢D","w":"…"}],
 "e":"解説。1行1ステップ。\n最後の行に答え。","h":"ヒント（答えそのものは書かない）"}
```
- `id`＝`ex3-<分野の記号>-<NNN>`（001から順に。1分野内で重ならない）。`u`＝`J3-X<記号>`、`s`＝`J3-X<記号>-01`、`l`＝`ex3-<記号>`、`d`＝3（標準の入試小問）か4（やや難しい入試問題・大問の後半）。**半分ずつくらい**。
- `c`：ちょうど4つ。正解は `"k":1` を1つだけ。正解の位置は、問題ごとにばらつかせる。`w` は、まちがい3つのうち2つ以上に付ける（正解には付けない）。
- JSON なので、バックスラッシュは `\\`（例 `"$\\frac{1}{2}$"`、`"$\\sqrt{3}$"`）。数式は `$…$`（見本と同じ書き方）。選択肢の書き方（`$` の有無・表記）はそろえる。
- **図は出せない。**「図のように」と書かず、点・座標・辺・角・長さを**文章ですべて書き**、図が無くても解けるようにする。
- 解説 `e`：3〜6行、**最後の行に答え**。ヒント `h`：1〜2文、答えも答えの数値も書かない。
- 選択肢は、正解と同じ値・同じ式になるものを入れない。まちがいは本当にまちがい。「正しいのはどれか」の問題は、正解以外の3つがはっきり誤りになるように確かめる。条件があいまいで答えが2通りに読める問題は作らない。中学の範囲だけ（高校の内容は出さない）。

## 正しさの確かめ
**正解は、python3（sympy・fractions・itertools・math）で計算して決める**（頭の中で決めない）。1回に5問ずつ、問題を作る python スクリプトを書いて、そこで答えを計算し、JSON に書き出すのが速い。確率は全部数え上げる。
