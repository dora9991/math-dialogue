# 大学入試（高1〜高3の範囲）4択問題づくりの決めごと（時間制限：8分）

コツコツくん（数学の練習アプリ）に足す、**大学入試レベルの4択問題**を、たくさん作ります。授業には結びつけず、分野ごとのまとまり（A〜H）にします。
見本：`samples-h1.json`（高1の公開中の問題）・`samples-h3.json`（高3の公開中の問題）・`samples-j.json`（中学の公開中の問題）。書き方・まちがい選択肢の理由 `w` の付け方を、そろえる。

## 担当の分野（8つ）
A 数学Ⅰ：数と式・集合と命題・2次関数（最大最小・解の配置・不等式）／B 数学Ⅰ・A：図形と計量（正弦・余弦定理・面積）・図形の性質（チェバ・メネラウス・円・方べき）・データの分析／C 数学A：場合の数と確率（条件付き確率・期待値を含む）・整数の性質（互除法・不定方程式・n進法）／D 数学Ⅱ：式と証明・複素数と方程式（解と係数の関係・高次方程式）・図形と方程式（軌跡・領域・円と直線）／E 数学Ⅱ：三角関数・指数関数・対数関数／F 数学Ⅱ・B：微分・積分（数Ⅱ）・数列（漸化式・和・数学的帰納法）／G 数学Ⅲ：極限・微分法・積分法（面積・体積）／H 数学C：ベクトル（平面・空間）・複素数平面・平面上の曲線（2次曲線・媒介変数表示）。
難しさ：共通テスト〜国公立二次・私大の小問〜標準。マーク式の「空欄補充」は、答えの値を選ぶ4択の形に直す。

## 問題オブジェクトの形（1問）
```json
{"id":"exu-E-007","u":"H-XE","s":"H-XE-01","l":"exu-E","d":4,"q":"問題文",
 "c":[{"t":"選択肢A","w":"この答えを選ぶ人の、まちがえ方（高校生に向けた一文）"},{"t":"選択肢B","k":1},{"t":"選択肢C","w":"…"},{"t":"選択肢D","w":"…"}],
 "e":"解説。1行1ステップ。\n最後の行に答え。","h":"ヒント（答えそのものは書かない）"}
```
- `id`＝`exu-<分野の記号>-<NNN>`（001から順に。1分野内で重ならない）。`u`＝`H-X<記号>`、`s`＝`H-X<記号>-01`、`l`＝`exu-<記号>`、`d`＝3（標準の入試小問）か4（やや難しい入試問題）。**半分ずつくらい**。
- `c`：ちょうど4つ。正解は `"k":1` を1つだけ。正解の位置は、問題ごとにばらつかせる。`w` は、まちがい3つのうち2つ以上に付ける（正解には付けない）。
- JSON なので、バックスラッシュは `\\`（例 `"$\\frac{1}{2}$"`、`"$\\sqrt{3}$"`、`"$\\sin 30^{\\circ}$"`）。数式は `$…$`（見本と同じ書き方）。選択肢の書き方（`$` の有無・表記）はそろえる。
- **図は出せない。**「図のように」と書かず、点・座標・辺・角・長さ・式を**文章ですべて書き**、図が無くても解けるようにする。
- 解説 `e`：3〜6行、**最後の行に答え**。ヒント `h`：1〜2文、答えも答えの数値も書かない。
- 選択肢は、正解と同じ値・同じ式になるものを入れない（例：`\\frac{\\sqrt{2}}{2}` と `\\frac{1}{\\sqrt{2}}`）。まちがいは本当にまちがい。「正しいのはどれか」の問題は、正解以外の3つがはっきり誤りになるように確かめる。
- 場合の数・確率は、数え方の条件（区別する／しない・もどす／もどさない・順序）を問題文に書く。データの分析の分散は、データそのものの分散（偏差の2乗の平均）。四分位数は、教科書の定め方（中央値で半分に分け、奇数個のときは中央値を含めない）。数Ⅲでロピタルの定理は使わない。定義域・範囲・条件を忘れない。条件があいまいで答えが2通りに読める問題は作らない。

## 正しさの確かめ
**正解は、python3（sympy・fractions・itertools・math・numpy）で計算して決める**（頭の中で決めない）。1回に5問ずつ、問題を作る python スクリプトを書いて、そこで答えを計算し、JSON に書き出すのが速い。場合の数・確率は、全部数え上げる。
