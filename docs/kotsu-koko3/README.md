# コツコツくん 高3（数学Ⅲ・数学C）「解説ごとの演習」（52本・1,040問）

中1〜中3・高1・高2と同じ形（解説1本につき、4段階 × 5問、4択）の演習を、高3の全52本（数学Ⅲ 30本・数学C 22本）につくった。

## 状況（2026-11-22）

| 段階 | 状況 |
|---|---|
| 作る | 5人で分担（`SPEC.md` の決めごと）。機械検査（`tools/check_h3.mjs`）エラー 0・警告 0。各担当の検算スクリプトは `verify/`（全問を、sympy・数え上げ・数値積分などで、別の方法でも計算して照合） |
| 解き直す | 正解を伏せて、別の5人が全問を解き直した（`resolution.md`）。1,040問すべて一致・「問題あり」0 |
| 本体に入れる | 公開用のファイル（`chunks/`）と、公開中の solo バンドルに足すパッチ（`tools/patch_h3.py.txt`）を作った |
| 確かめる | 公開中のバンドル＋パッチで、高3の11単元すべてに「📺 解説ごとの演習」が出る／52本すべてが出る／6科目（7本）から1本ずつ、5問を解いて結果の画面まで／コンソールのエラーなし。中3・高1・高2のテストも、同じバンドルで通る |

- `data/h3a.json`〜`h3e.json`：1,040問。形は `{ id, u, s, l, d, q, c:[{t, k|w}], e, h }`。`u`＝`H3-T`＋科目の記号（A〜F）。
- `chunks/h3*.js`：科目ごとの公開用ファイル 6つ。`chunks/lessons.json`：索引（`Wn` に足す授業ごとの `{f, u, n}`）。
- `units.json`：高3の授業が属する11単元の名前・説明・要点。
- `tools/`：検査・解き直しの照合・公開用ファイルの作成・パッチ・テスト。
- `verify/`：作った人の検算スクリプト（`python3 h3?.verify.py` で全問の一覧）。

## 注意

- 高校の解説の本文は、外部のサイトにあって読めない。そのため、**解説の題と、単元の要点（公式）**から、授業で教える範囲を推測して作った。ロピタルの定理は使わない。
- **アプリの単元の置き方**：アプリでは、平面ベクトル（HC-vector）・空間ベクトル（HC-kukan）の単元は学年が **高2**、データの分析（HI-data）は学年なし（高1）の置き方になっている。そのため、ベクトル（mc1-01〜10）と、mc3-02（行列、HC-vector に属する）の演習は、その単元のページ（高2の画面）に出る。mc3-01 は「データの分析」のページに出る。数Ⅲの授業と、複素数平面・2次曲線は、高3の単元に出る。
- 四分位数は、日本の教科書の定め方（中央値で半分に分け、データが奇数個のときは中央値を含めない）に統一している（高1と同じ）。
- 本体に入れるときは、中3・高1・高2と同じ（解説の索引 `Wn` と、読みこみの表 `./<キー>.json` に足す）。次に本体から公開すると、この 2か所は元にもどるので、本体のソースにも入れること。
- 公開の手順：`node tools/build-chunks_h3.mjs <出力>` → `python3 tools/patch_h3.py.txt <公開中の solo-*.js> <出力> <新しい solo-*.js>`（anchor が1回ずつ出ることを assert する）→ 新しい名前（sha256 の先頭8字）にして、`solo/index.html` の参照を差し替える → gh-pages に push。
