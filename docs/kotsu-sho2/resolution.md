## 直したところ・判定したところ

- hyo-04-L2-04（e2a）：不一致（作者「正が 1つと 1画」・解き手「正が 1つと 2画」）。6人＝5人（正 1つ）＋1人（1画）。**作った側が正しい**。正の字は 授業（hyo-01・hyo-04）で あつかう。直さない。
- hitasu-02-L3-04（e2a）：「問題あり」。くり上がりの 1を 書く ばしょ（十のくらいの 上か 下か）は 教科書で ちがう。「38 + 25 の くり上がりは、どの くらいから どの くらいへ」に 作りかえた。
- nagasa-03-L3-01（e2b）：「問題あり」。「ありの 長さ」の 選択肢 3cm は、大きな ありなら ありえる（授業では「ありは mm」）。3cm を 10cm に かえた。
- suu3-02-L4-01・suu3-03-L3-02（e2c）：不一致。449（百4・十4・一9）と「10が 10こで 100」は 計算で 正しい。解き手が 答えを id の じゅんに ならべなおす ときに ずれた（解き手 自身が 報告）。直さない。
- kake2-04-L1-03（e2e）：「問題あり」。九九の ひょうの「たて」が かけられる数か かける数かは 教科書で ちがう。「3のだんは 右へ 1つ すすむと いくつずつ ふえる」（3）に 作りかえた。
- e2e：正解の いち（A〜D）の ならびが、どの 授業でも 同じだった。アプリは 選択肢の じゅんばんを まぜて 出すので、子どもには 見えない。直さない。
- ほうがん紙の 図（e2d・e2f の 41問）：形を ぬりつぶして いたので、形の 中の マス目が 見えなかった。ぬりを うすく（fill-opacity 0.5）して、マス目が 見えるように した（e2d の 解き直しは 直す前の 図で 行い、すべて 一致）。
- hako-01-L4-05（e2f）：問題文の「ずは、…」を「図の 長方形 2まいは、はこの めんです」に 書きなおした（答えは かわらない：あ 4×3cm・い 6×3cm → のこり 4×6cm）。
- e2f の 不一致 8問：suu4-02-L1-02（3425）・suu4-02-L1-05（2534）・suu4-02-L2-05（8052）・hako-02-L2-05（4本）・hako-03-L2-03（4本）・hako-03-L2-05（12本とも 同じ）・meter-02-L1-05（3m 40cm）は、計算で **作った側が正しい**。
- meter-03-L2-05（e2f）：不一致（作者「やく 1m 80cm」・解き手「やく 2m」）。「やく」が あると、いちばん 近い m（2m）とも 読めた。「やく」を とり、「はしが 1m 80cmの めもりの ところ」に 直し、選択肢の「やく 2m」を「180m」に かえた。

## 作業の 記録

- 作業の とちゅうで、解き直し係の 1人が 作業フォルダを まちがえて 消した。小2の 問題は、6人の 作成係が 実行した コマンドの 記録を 同じ じゅんに 実行し直して 作り直し、解き直し係が 読んだ 問題文の 記録と 1問ずつ 照らして、元と 同じで あることを 確かめた（作り直した 公開用ファイルの ハッシュも、消える 前と 同じ）。その e2f の 解き直しは、消したあとに 記憶で 書き直された 答えだったので、別の 解き手で やり直した（上の 表は やり直しの 結果）。
