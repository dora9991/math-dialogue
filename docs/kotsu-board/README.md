# コツコツくん 電子黒板：5分未満の子を、一人ずつは出さない（引き渡し）

コツコツくんの本体（`src/solo`）はこのリポジトリに無いので、ここには**変更の内容と依頼文**を置きます。

## なぜ

生徒から、ご意見ばこに次の声が来ました（2026-11-16）。

> これをやった時間をクラスの前で見せるので、自分が全然やってないことがバレて、馬鹿にされたりするので困ってる。

公開版（2026-11-16）の電子黒板の「⏱ 一人ずつの帯」スライドは、クラス全員を学籍番号の順に並べ、5分未満の子に「📣 がんばれ！」を付けて出しています。学籍番号はクラスのみんなが知っているので、だれがやっていないかが分かります。

## 変えること

| 場所 | いま | 変えたあと |
|---|---|---|
| ⏱ 一人ずつの帯（スライド） | 全員。5分未満は「📣 がんばれ！」 | **5分以上（ブロンズ以上）の子だけ**。見出しは「きょうの コツコツ（5分以上）」。凡例から「がんばれ」「用事」をはずす。5分以上がだれもいなければ、スライドを出さない |
| 🥇 ランキング（スライドと最初の画面） | 学習した子から上位10人（1分の子も出る） | **5分以上の子だけ**（最大10人） |
| 最初の画面の帯ごとの人数 | ゴールド○人・…・がんばれ○人・用事○人 | そのまま（人数だけで、だれかは分からない） |
| 👏 がんばりボード・ベスト | 学習した子に「ありがとう」 | そのまま |
| ⚙ の説明文 | 「ランキング・帯は 学籍番号だけ。…」 | 「…5分以上 がんばった人だけを出します（5分未満の人・学習していない人は、一人ずつは出しません）」を足す |

決まり：**一人ずつ名前（番号）が出るのは、ほめる場面だけ。少なかった子は、人数でしか出さない。**

## 確かめたこと

公開版のビルド済みファイル（`assets/board-DTZZdhQB.js`）に同じ変更を入れ、手もとのブラウザで、作った12人分のデータ（0分〜1時間）を読ませて表示を確かめました。

- 元の画面：帯のスライドに「1201 📣 がんばれ！」〜「1205 📣 がんばれ！」が並ぶ。ランキングの8〜10位に「約4分」「約3分」「約1分」の子が出る。
- 変えた画面：帯のスライドは 1206〜1212（5分以上）だけ。ランキングは7位（約5分）まで。最初の画面の「がんばれ 5人」は人数だけ残る。画面のエラーなし。

公開版への反映（gh-pages）は、まだしていません。

## すぐできること（公開しなくてよい）

電子黒板の端末で、⚙（せってい）→「⏱ 一人ずつの帯を出す」のチェックを外す。設定は、その端末・そのクラスごとに残るので、クラスごとに外す。

## 追加（2026-11-17）：見るだけの画面にする

教室の電子黒板で、生徒が画面をさわって、ほかの日・ほかのスライド・ほかのクラスに行けないようにします。

| 場所 | 変えたあと |
|---|---|
| 出す画面 | いつも最初の画面（ぜんたい）だけ。スライドショーも出さない |
| クラス | 切りかえボタンを出さない。黒板の合言葉で開いたときは、そのクラス。先生のログインで開いたときは、担当のクラス |
| 日付 | **◀ ▶・きょうへ・自動 のボタンは出す（日付の切りかえだけはできる）**。🌸（おやすみの日の印）は出さない。はじめは自動（朝は前の学習日・ふだんはきょう） |
| 右上のボタン | ⟳・記録する・🥇⏱👏🏅📈・▶・⚙・⛶・ログアウトを出さない。「○:○ 更新」の時刻だけ出す（1分ごとの自動の読みなおしはそのまま） |
| キー操作 | ← → は日付の切りかえだけ。スライドには変わらない |
| 先生が操作したいとき | アドレスの最後に `?tools`（ほかの指定があるときは `&tools`）を付けて開くと、いままでのボタンが出る |

確かめたこと：公開版のビルド済みファイルに同じ変更を入れ、手もとのブラウザで作ったデータを読ませて開きました。見るだけの画面では、押せるもの（ボタン・リンク・入力）が0個で、← → スペースを押しても、日付も画面も変わりませんでした。`?tools` を付けると、いままでの13個のボタンが出て、← で前の日に動きました。

依頼文に足すこと：

````text
6. 電子黒板（solo/board）を、見るだけの画面にする（日付の切りかえだけはできる）。docs/kotsu-board/README.md の「追加（2026-11-17）」のとおり。先生は、アドレスに ?tools を付けたときだけ、いままでのボタンを使える。
````

日付の切りかえを戻した版も、手もとのブラウザで確かめました。はじめに出るボタンは ◀ ▶ の2つで、前の日にすると「きょうへ」「自動」が出ます。◀ で、きのうの最初の画面になり、← → キーでも日付だけが動き、スライドには変わりませんでした。
