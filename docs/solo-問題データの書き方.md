# 数学ラボ ソロ — 問題データの書き方

小1〜高3の「単元」と、その単元の問題テンプレート（毎回数字が変わる問題）を書くためのルール。
データは `src/solo/content/` にある。

| フォルダ | 中身 |
|---|---|
| `elem/e1.js` 〜 `e6.js` | 小学1〜6年の単元（新規） |
| `jhs/index.js` | 中学1〜3年の単元（既存の数学ラボ `src/data/grade1〜3` をそのまま包んで使う） |
| `high/hI.js` `hA.js` `hII.js` `hB.js` `hC.js` `hIII.js` | 高校 数学I・A・II・B・C・III（新規） |

書いたら必ず検査する：

```bash
node scripts/solo-verify.mjs src/solo/content/elem/e3.js   # そのファイルだけ
node scripts/solo-verify.mjs                               # 全部（前提単元のつながりも）
```

## 2. テンプレートの形

```js
t("E3-warizan-1a", (r) => {
  const b = r(2, 9), a = r(2, 9);          // r(min,max) は整数の乱数
  return {
    q: `${a * b} ÷ ${b} を計算しよう。`,
    ans: a,                               // 入力式（choices なし）
    hint: `${b}のだんで、こたえが ${a * b} になるのは？`,
    steps: [`${b} × ${a} = ${a * b} だから`, `${a * b} ÷ ${b} = ${a}`],
  };
}),
```

| キー | 必須 | 内容 |
|---|---|---|
| `q` | ○ | 問題文。数式は `$...$`（KaTeX の LaTeX）。日本語は `$` の外に書く |
| `ans` | ○ | 正解。下の「答えの形」を参照 |
| `choices` | | 4択の選択肢。あると4択、ないと入力式 |
| `unit` | | 入力欄の後ろに出す単位（`"cm"` `"個"` `"度"` など） |
| `hint` | ○ | 考え方のヒント1行（答えそのものは書かない） |
| `steps` | ○ | 解き方の解説（1〜4行の配列）。間違えたとき・解説ボタンで出る |
| `skip` | | `true` で作り直し（割り切れない等）。skip はなるべく少なく（半分を超えると警告） |

### 答えの形

- **入力式（choices なし）**：`ans` は
  - 数値（整数か、有限小数。小数は `round()` で誤差を消す）
  - 約分済みの分数文字列 `"3/4"` `"-5/2"`（`fracAns(n, d)` を使うと安全。整数になれば数値が返る）
  - 生徒は数字キーパッド（0〜9・−・.・分数）で答える。√ や π や文字式は打てない → 4択にする
- **4択（choices あり）**：`ans` は `choices` のどれか1つとまったく同じ値。
  - `choices4(r, 正解, [ありがちな誤答...])` で作る。誤答は「よくある間違い」を優先する
  - 数値なら `numChoices(r, 正解, [誤答...])`

### 数式の書き方（KaTeX）

- 分数 `$\frac{3}{4}$`、根号 `$\sqrt{2}$`、累乗 `$x^{2}$`、かける `$\times$`、わる `$\div$`
- ≦ ≧ は `$\leqq$` `$\geqq$`、ベクトル `$\vec{a}$` `$\overrightarrow{AB}$`
- 数列 `$a_{n}$`、Σ `$\sum_{k=1}^{n} k$`、積分 `$\int_{0}^{1} x^{2}\,dx$`、極限 `$\lim_{n \to \infty}$`
- 組合せ `$_{5}\mathrm{C}_{2}$`、順列 `$_{5}\mathrm{P}_{2}$`、対数 `$\log_{2} 8$`
- **`$` の中に日本語を入れない**（検査でエラーになる）
- JS の文字列ではバックスラッシュを2つ書く：`"$\\frac{1}{2}$"`
- 小学校の簡単な計算（`23 + 48`、`6 × 7`、`12 ÷ 3`）は `$` なしでよい
- `$` の外で `/` を使わない（`1/2` は分数として表示されるため）。速さは「時速60km」と書く

### 良い問題のための約束

1. **答えはプログラムで計算する**（手で書いた答えを埋め込まない）
2. 割り切れない・答えが大きすぎる・選択肢が作れない組み合わせは `skip: true`
3. 問題文だけで答えが1つに決まるように書く（単位・何を答えるかを明記）
4. 4択の誤答は「よくある間違い」から作る（符号ミス、公式の取り違え、約分忘れ…）
5. `hint` は入口だけ、`steps` は途中式つきで最後に答えまで
6. 図が必要な問題は文章で状況を言い切れるものだけ（図の表示はまだない）
7. 各レベルに型を **4〜5種類以上** 用意する（演習・確認テストは1レベル5問なので、同じ型が続かないように）。足すときは数字だけ違う同じ型ではなく、問い方・場面・考え方の違う型にする
8. 高校は **2022年度〜の学習指導要領の科目** に合わせる（例：3次の乗法公式・因数分解は数学II、集合の要素の個数は数学A）。教科書で「発展」扱いの内容は、新しい問題では使わない
9. 乱数のどの組み合わせでも条件が成り立つか確かめる（実数解が存在する・図形が成り立つ・数列の項が定義される・誤答が正解と同じ値にならない など）。検査（solo-verify）は書式しか見ないので、答えは別の方法で解き直して突き合わせる
