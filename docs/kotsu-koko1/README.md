## 中身

- `data/h1a.json`〜`h1i.json`：1,880問。形は `{ id, u, s, l, d, q, c:[{t, k|w}], e, h }`（`SPEC.md`）。`u`＝`H1-T`＋科目の記号（A〜H）。
- `chunks/h1*.js`：科目ごとの公開用ファイル 8つ（`default = { v:1, key, talks, items }`。中3の `g3*.js` と同じ形）。`chunks/lessons.json`：索引。
- `units.json`：高1の16単元の名前・説明・要点（問題づくりの入力に使った）。
- `tools/`：検査・解き直しの照合・公開用ファイルの作成・パッチ・テスト。

## 注意

- 高校の解説の本文は、外部のサイト（`math-talk.pages.dev`）にあって読めない。そのため、**解説の題と、単元の要点（公式）**から、授業で教える範囲を推測して作った。授業の中身とずれている問題があれば、直す。
- 解説 `e` の最後の行が、答えの行でない問題が、数学A 整数の性質（`h1i`）に約45問ある（内容は正しい）。
