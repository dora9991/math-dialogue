## 直したところ・判定したところ

- awase-03-L3-02（e1b）：選択肢 D「3 + 3 = 6」は、式としては正しいので、「ただしい しき」が2つに読めた（解き手の指摘）。D を「3 + 2 = 1」（+ を − と まちがえた）に かえた。
- kazu100-03-L3-04・L3-05・L4-03（e1f）：100の ひょうの ならべかたで 答えが かわる（行の はし・100）。解き直しの前に、問題文に「1から 100までの ひょう（1ぎょうに 10こずつ）」を書き足した。
- ookii-01-L2-04（e1f）：不一致（作者 70・解き手 7）。問題文に「10の ぼう」と書いていなかったので、ぼうの本数（7）とも読めた。「1ぽんで 10の ぼう」と書き、選択肢の 7 を 40（みどりだけ かぞえた）に かえた。
- ookii-02-L4-04（e1f）：不一致（作者 50・解き手 5）。「のこりは いくつ」が、ぼうの本数（5）とも かず（50）とも読めた。「のこりの ぼうで、かずは いくつ」に し、選択肢の 5 を 40（とった ぶん）、20 を 30（3かい とった）に かえた。
- kazu10-02-L1-01（e1a）：不一致（作者 6こ・解き手 7こ）。図（blind/figs/kazu10-02-L1-01.png）は ● が 5こ＋1こ＝6こ（SVG の circle も 6つ）。**作った側が正しい**（解き手の数えまちがい）。直さない。
- tashi-01-L2-03・tashi-02-L2-04（e1d）：解き手の「問題あり」。「10と □で いくつ」が、□の かず（4・2）とも こたえ（14・12）とも 読めた。答えは一致していたが、問題文を「9 + 5 の こたえは いくつですか。」の形に なおした（選択肢は そのまま。4・2 は「10を わすれた」まちがい）。
- okisa-01-L1-04（e1c）：解き手の「問題あり」。ひもは ほんの ながさを うつした ものなので、「ながいのは どっち」に「ほん」も「ひも」も あてはまった。問いを「ほんと ノートでは、どちらが ながいですか」に し、選択肢の「ひも」を「くらべられない」に かえた。
- tokei-01-L3-05・tokei-01-L4-04（e1e）：答えは一致。ただ「さして いる かずが おおきい のは どちらの はり」は、とけいの よみかたと つながらない 問いなので、作りかえた（L3-05：12から 6までの あいだの かずの かず＝5こ。L4-04：図の 6じから ながい はりが 1まわり＝7じ。python で 確認）。
- tokei-02-L4-02・tokei-04-L4-02（e1e）：「あさ・ひる・おやつ・よる」で いちばん はやい じかん。答えは一致、そのまま。
