# コツコツくん 小1「解説ごとの演習」（62本・1,240問）

中1〜高3と同じ形（解説1本につき、4段階 × 5問、4択）の演習を、小1の全62本（ホー先生の授業）につくった。アプリでは、小学生向けに **基本・練習・応用・チャレンジ** と表示される。

- `data/e1a.json`〜`e1f.json`：1,240問。形は `{ id, u, s, l, d, q, c:[{t, k|w}], e, h, f? }`（`f` は図の SVG）。`u`＝`E1-T`＋単元の記号（A〜N）。

## 注意

- ことばは、ひらがな・分かち書き・1年で ならう 漢字だけ（検査で確かめる）。
- 授業の順番（くりあがり → くりさがり → とけい → …）より あとの 内容は 出していない。
- アプリの 4つの ボタンのうち「チャレンジ」は、スマホの はばでは 2行に おりかえして 表示される（いまの アプリの 見た目のまま。気になる なら、ボタンの 文字の 大きさを 直せる）。
- 本体に入れるときは、中3〜高3と同じ（解説の索引 `Wn` と、読みこみの表 `./<キー>.json` に足す）。次に本体から公開すると元にもどるので、本体のソースにも入れること。
