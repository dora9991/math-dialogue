# 小1「解説ごとの演習」問題づくりの決めごと

コツコツくん（算数・数学の練習アプリ）に、**小学1年の解説（ホー先生の授業）1本ごとの演習**を足します。
解説1本につき、**4段階 × 5問 ＝ 20問**。すべて4択（正解1つ）の固定問題です。
中1〜高3は、すでに同じ形で公開されています（中学の見本 `samples-j.json`）。小1の、いま公開中の練習問題の見本が `samples-e1.json` です（ことばづかい・図の入れ方の見本。ただし、`w` に 1年で ならわない 漢字が まざっているので、漢字は この決めごとに したがう）。

## 1. 入力と出力

- 入力：`in/<担当名>.json`（配列。1要素＝1本の授業）。各要素：
  - `id`（例 `kazu10-03`）／`title`（授業の題）／`unitName`（単元）／`code`（単元の記号 A〜N）／`no`（単元の中の番号）
  - `summary`：**授業の流れ**（台本の はじめに 書いてある説明）。**ここに書いてある内容が、その授業で教える範囲**。
  - `script`：授業の せりふ・問題・ボタンの文字（台本から ぬきだした 文。順番どおり）。授業で 出てくる 数・もの・ことばが わかる。**そのままは つかわない**（数や ものを かえて つかう）。
  - `before`：この授業より **前** の授業（ならった こと）。`after`：この授業より **あと** の授業（**まだ ならって いない こと。出さない**）。
- 出力：授業ごとに `out/<担当名>/<授業のid>.json`（20問の配列）。

## 2. 問題オブジェクトの形

```json
{
  "id": "kazu10-03-L2-04",
  "u": "E1-TA",
  "s": "E1-TA-03",
  "l": "kazu10-03",
  "d": 2,
  "q": "6と 4では、どちらが おおきいですか。",
  "c": [ {"t":"6","k":1},
         {"t":"4","w":"ちいさい ほうを えらんだ"},
         {"t":"おなじ","w":"かずの おおきさを くらべなかった"},
         {"t":"10","w":"2つの かずを たした"} ],
  "e": "6は 4より 2 おおきい。\nこたえ 6",
  "h": "ブロックを ならべて、ながい ほうを さがそう。",
  "f": "<svg class=\"fig\" …>…</svg>（図が いる ときだけ。figs.py で つくる）"
}
```

- `id`＝`<授業のid>-L<段階>-<NN>`（NN＝01〜05）。`u`＝`E1-T`＋`code`、`s`＝`u`＋`-`＋`no` の2けた（例 `E1-TA-03`）、`l`＝授業の id、`d`＝段階（数）。
- `c`：**ちょうど4つ**。正解は `"k":1` を **1つだけ**。正解の位置は、問題ごとに ばらつかせる。
- `w`：まちがい選択肢に付ける「なぜ そう こたえたくなるか」（子どもに 見せる、やさしい ひとこと）。**まちがい3つのうち、2つ以上に付ける**。正解には付けない。
- `f`：**図が いる 問題だけ**（とけい・かずの せん・10の ぼうと ブロック・○●の ならび・マスの ひろさ など）。`figs.py`（このフォルダ）で つくった SVG を、そのまま 入れる。**手で SVG を 書かない**。図が ある ときは、問題文で「とけいは なんじですか。」「▼の ところの かずは？」のように、図を さす。

## 3. 4段階（アプリの 表示は「基本・練習・応用・チャレンジ」。各段階 5問）

| d | 表示 | 内容 |
|---|---|---|
| 1 | 基本 | 授業の いちばん はじめの 例と おなじ 形。1つの ステップで とける。かずは 小さく、ものは 少なく |
| 2 | 練習 | 授業の 基本の 問題を、かずや ものを かえて。授業で やった やりかたで とける |
| 3 | 応用 | おはなしの 問題（ことばの 問題）、2つの ことを くみあわせる、「どれが ただしい？」 |
| 4 | チャレンジ | すこし かんがえる 問題（きまりを みつける・ぎゃくに かんがえる・かくれた かずを さがす）。ただし **その授業までに ならった こと** だけで とける |

- 同じ段階の5問は、**型を かえる**（かずを いれかえた だけに しない）。
- 20問は、その授業の 内容に あわせる。**`after` の 授業で ならう ことは 出さない**（例：くりあがりの 授業より 前に、くりあがりの ある たしざんを 出さない。とけいの「なんじはん」の 授業より 前に、はんを 出さない）。
- ほかの 授業の 問題と、おなじ・ほぼ おなじ 問題に しない。

## 4. 書き方（1年生が よむ）

- **ひらがな と カタカナ と すうじ**。ことばの まとまりごとに **半角スペースで 分かち書き**（見本と おなじ。例「りんごが 3こ あります。」）。文は みじかく（問題文は 1〜3文、120字まで）。
- **漢字は、1年で ならう 漢字だけ**（一〜十・百・円・人・子・大・小・上・下・左・右・中・本・日・月・火・水・木・金・土・山・川・花・犬・目・手・足・口・名・字・先・生・年・早・白・赤・青・入・出・立・休・見・音・正・車・村・町 など）。**つかわなくて よい**（ひらがなで よい）。`check_e1.mjs` が、ほかの 漢字を エラーに する。`w`・`e`・`h` も おなじ。
- すうじは 半角（`3`、`12`）。しきは `3 + 4 = 7`、`9 − 2 = 7`（ひくは「−」）、`□`（はいる かず）。TeX（`$`）は つかわない。
- こたえの 選択肢は、たんいも そろえる（`3こ`、`5人`、`7本`、`4じはん`、`2じ30ぷん` など）。1つの 問題の 選択肢は、書きかたを そろえる。
- 解説 `e`：1〜4行（改行は `\n`）。**さいごの 行に こたえ**（「こたえ 7こ」など）。ヒント `h`：1〜2文。**こたえ（の かず）は 書かない**。「ブロックで ためそう」「10の まとまりを つくろう」の 形。
- 選択肢の 注意：
  - 正解と **おなじ ものを あらわす 選択肢を 入れない**（例「7」と「7こ」を ならべない）。
  - 4つとも、まちがいは 本当に まちがい。「どれも 正解／正解が ない」を 作らない。「どれが ただしい？」は、正解いがいの 3つが はっきり まちがいに なるように たしかめる。
  - かぞえる 問題は、かぞえる ものが 1とおりに きまるように（「ぜんぶで」「のこりは」「ちがいは」を はっきり）。
  - おおきさくらべ（ながさ・かさ・ひろさ）は、くらべかたが 1つに きまる 条件を 書く（「1マスは おなじ 大きさ」「おなじ コップで」など）。
  - とけいは、「なんじ」「なんじはん」（その授業で ならう はんいだけ。「なんぷん」は 授業に 出て くる ときだけ）。図は `figs.clock(じ, ぷん)`。
  - かたち（はこ・つつ・たま、いろいた）は、身の まわりの ものの 名前で 書いてよい（「ボール」「ジュースの かん」「ティッシュの はこ」）。図が いる ときは、ことばで はっきり 書けば 図なしで よい。

## 5. 正しさの 確かめ（必須）

1. **すべての 正解を、計算で 確かめる。** `python3` で 正解を 出し、問題の 正解と 一致することを 確かめる（かぞえる・たす・ひく・くらべる・とけいの よみ など）。確かめる スクリプトは `out/<担当名>.verify.py` に 残す（全問「問題 → 計算した 答え」を 一覧に 出し、正解の 選択肢と 突き合わせる。まちがいの 選択肢が 正解と 一致しないことも）。
   - 図が ある 問題は、図を 作った ときの 数（とけいの じ・ぷん、▼の いち、ぼうと ブロックの かず、○●の かず、マスの かず）から 正解を 出す。
2. `node merge_e1.mjs <担当名> && node check_e1.mjs out/<担当名>.json --lessons=…` を 実行して、**エラー 0** に する（警告も、理由が なければ 直す）。
3. このあと、別の人が 正解を 伏せた 状態で 解き直して、あなたの 正解と 一致するかを 確かめます。**一致しない 問題は、直すことに なります。**

## 6. 最後の 報告（短く）
