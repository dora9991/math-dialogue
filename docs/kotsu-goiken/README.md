## 1. まちがっていた問題（7問）

きっかけは、生徒の「半径2cmの半円と直径4cmの半円は同じはずなのに✖になった」という声です。調べると、同じ組の問題にほかの誤りもありました。

| 問題 | まちがい | 直し方 |
|---|---|---|
| J1-SP-142（半球のもとの図形） | 「半径2cmの半円」が正解で、同じ図形の「直径4cmの半円」が✖。さらに、半円を直径のまわりに回すと球になるので、正解そのものがちがう（教科書どおりなら、中心角90°のおうぎ形）。解説の「断面は円になって」もまちがい | 丸ごと置きかえ |
| J1-SP-143（バケツ形のもとの図形） | 立体の高さは8cmなのに、正解が「高さ4cmの台形」。本当の正解（高さ8cm）が✖になる。解説の「下底を軸にして回す」もまちがい（軸は、上底と下底に垂直な辺） | 丸ごと置きかえ |
| J1-SP-141・144（円錐・円柱のもとの図形） | 問題文は「(1)(2)それぞれ答えよ」なのに、選択肢は片方の分しかない | 1つの立体だけを聞く問題に置きかえ（答えは変えない） |
| J1-DT-110〜112（男女の平均値） | 「(1)男子 (2)女子 (3)全体の平均値を求めよ」なのに、選択肢は (3) の分しかない | 問題文を「男女合わせた30人の平均値を求めよ」にし、解説・ヒントの「(1)(2)」「(3)」の言い方も直す |

- `replace` の4問は、`id`・`u`・`s`・`d` をそのままにして、`q`・`c`・`e`・`h` を置きかえます。誤答には、いままでと同じ形で `m`（まちがいの種類）と `w`（理由）を付けてあります。
- `text_replace` の3問は、`old` の文を `new` に置きかえます。`old` が公開版（2026-11-16）の文に、ちょうど1か所ずつあることを確かめてあります。
- 選択肢が4つで正解が1つ、文面の重なりがないことも確かめてあります。

**ほかにも同じ形の問題が無いか**：中学の固定問題 4,239問のうち、問題文に「(1)(2)」がある 82問を、正解の選択肢が片方の分しかないかで機械的に調べました。この7問のほかに引っかかったものは、正解が「a=2, 10」のように両方を並べた形で、問題はありませんでした。ただ、機械的な調べ方なので、見落としはありえます（J1-SP-143・144 も、この調べ方では引っかからず、目で見て気づいたものです）。82問を人の目で見直すと確実です。

## 2. 使いにくさの直し

| 生徒の声 | 直し方 |
|---|---|
| 数字を打つ問題で、「答える」と「解説」のボタンが近くて、押しまちがえる | 「解説」「ヒント」のボタンを、キーパッドの「答える」から離す（問題のカードの上の方など）。指で押しても、となりにならないこと |
| 選択肢を押すと、すぐ採点されてしまう | せっていに「選択肢は えらんでから 決定で答える」を足す（はじめは切っておく）。入れたときは、押すと選んだ印が付き、「決定」で採点。キーボードの 1〜4 で選び、Enter で決定もできる |
| 「先生からのひとこと」が、前のものまでずっと出ている | ホームには、まだ読んでいないものだけを出す。読んだものは「前の ひとこと（○こ）」にたたむ |
| 「💌 先生から」のページを開くと、もどるボタンがない | ほかの画面と同じ場所に「← もどる」を付ける |
| 「解説ごとの演習」が下にあって、毎回スクロールが面倒（「なくしてほしい」という声） | なくさずに、単元ページの上の方に「📺 解説ごとの演習へ ↓」ボタンを置き、押すとそこまで動く |
| 分数を、分母から入れたい | 「分数」を押したら、分子と分母の2つのます を出し、どちらから入れてもよいようにする |

小さな直し（あれば）：

- 「1問解いたあと、次の問題が入力できるまで少し待たされる」：問題が出てから 0.5秒は押しても反応しない（10/20 の押しまちがい対策）ため。数字のキーパッドとキーボードだけ 0.3秒に縮めてもよい。選択肢は 0.5秒のまま。
- ご意見ばこの「すこし まってから、また おくってね」：「1時間に5こまで おくれます。あと ○分で また おくれるよ」と、理由と待つ時間を出す。
- 「ooコツ の使い方がわからない」：ホームに、コツが何で、何に使えるかを1行で出す。

「ホームに きょう ○分 を出してほしい」は、`docs/kotsu-hyoka/` の依頼文に入っています。

## 3. 📣 お知らせ欄（新しく作る）

ねらいは、「ご意見ばこに書いたことが、ちゃんと届いて、直った」が生徒に見えるようにすることです。生徒からも「アップデートしたら知らせてほしい」「みんなの意見を少し見たい」という声が来ています。

- ホームに「📣 お知らせ」のカード。新しいものから3件と、まだ見ていない数の印。「ぜんぶ見る」で一覧へ。
- 1件ごとに、題・日付・本文。ご意見ばこから来たものには「💬 ご意見ばこから」の印と、その声（言いかえたもの）を出す。
- 中身は、本体の中に置くデータ（`news.json` の形）で、公開のたびに足す。最初の中身は `news.json` のとおり（直したこと6件。`status: "planned"` の5件は、その直しを公開したときに日付を入れて出す）。
- **ご意見の声は、そのまま写さない。** だれが書いたか分からないように言いかえる。人を傷つける言葉や、特定の人についての声は、のせない。
- 電子黒板にも、新しいお知らせがあれば1行出してよい（「📣 ご意見ばこの声で、○○を直しました」）。

## 4. 🧮 計算トレーニング（新しく作る）

声：「九九ができないので、九九だけのモードがほしい」「四則の基本の計算だけのものも」「100マス計算がほしい」「難しすぎるので、初心者向けの簡単なものも」。

小学校の計算の単元はもうありますが、中学の生徒からは見つけにくいようです。新しく問題を作るより、**入口を作る**のが中心です。

- ホームに「🧮 計算トレーニング」のカード。中の一覧は次のとおり（いまある単元につなぐ）。

| 一覧の名前 | つなぐ単元（公開版 2026-11-10 の ID） |
|---|---|
| たし算・ひき算 | E1-kuri（くりあがり・くりさがり）、E2-hissan（筆算） |
| 九九 | E2-kuku |
| かけ算の筆算 | E3-kakezan |
| わり算 | E3-warizan、E3-amari、E4-warihissan |
| 計算のきまり | E4-keisan |
| 小数 | E4-shosu、E5-shosukake |
| 分数 | E5-bunsu、E6-bunsukake |
| 正の数・負の数 | 中1の、正負の数の加減・乗除の単元（本体の ID に合わせる） |

- **100マス計算**（新しく作る）：たし算・ひき算・かけ算から選ぶ。10×10 のますを、上から順に入力していく。かかった時間と正解の数を出し、自分の前の記録とだけくらべる（ランキングや電子黒板には出さない）。
- **やさしいところから**：どの計算も、レベル1のいちばんやさしい問題から始められるように。
- **評価の時間**：`docs/kotsu-hyoka/` のルールのとおり。下の学年の計算は、たしかめ5問でつまずきがあれば「学び直し」として評価に入り、もうできていれば「じゆう練習」になる。100マス計算も同じ扱い。
