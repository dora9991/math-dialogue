# 解き直しの結果と、直したところ

正解を伏せた別の解き手（作った人の答え・`out/`・`keys/` は見ない）が、全問を自分で解き直し、作った側の答えと照合した。

## 選択肢の順を混ぜた（今回から）

1回目の解き直しで、解き手から「正解の位置が C・D・A・B… と規則的にくり返している」と申し出があった（e5a・e5c・e5h は授業ごとに CDAB のくり返し、e5e は20問ごとに同じ並び）。これでは、解き手が位置の並びに引っぱられるおそれがある。そこで、解き直し用の問題ファイル（`tools/blind_e5.cjs`）で、**問題ごとに選択肢の順を混ぜ**（id から決まる順）、その4チームと、まだだった e5f・e5g を、混ぜた版で解き直した。e5b・e5d は、もともと位置が不規則だったので、1回目の結果を使う。

アプリは選択肢の順を毎回まぜて出すので、生徒には位置の並びは見えない（データはそのまま）。

| id | 理由 | 直し |
|---|---|---|
| kakuchu5-03-L3-01 | 「底面を 側面と 同じ 数 だけ かいた」が、まぎらわしい（解き手の申し出） | 「底面を 4つ かいて しまいました。正しい 展開図に かく 底面と 側面の 数は」 |
| kakuchu5-04-L4-05 | 側面の長方形の「たて・横」は、展開図の置き方で入れかわり、正解の選択肢と、たて横を逆にした選択肢の両方が正しく読める | 「底面の まわりに あたる 辺」「高さに あたる 辺」で書く |
| showari-03-L1-04 | わる数が整数のとき、「商の 小数点の 真下」も「わられる数の 小数点の 真下」と同じ列になり、どちらも正しく読める（解き手の申し出） | まちがいの選択肢を「小数点を うつした あとの、わられる数の 小数点の 真下」（授業の 5.3÷0.7 で あまりを 4 とする まちがい）に。正解は「わられる数の **もとの** 小数点の 真下」 |

### 表記をそろえたもの

- 「展開図 の」「見取図 で」などに入っていたすき間（45か所）を取った（検査が「図の」を「図を指す言い方」と見ていたため。検査のほうを直した）。
- 四捨五入：「捨」は6年の漢字なので、授業の台本と同じ「四しゃ五入」にそろえた（e5e の「ししゃごにゅう」13か所）。

## 作者が申し出た、判断が分かれうる点（そのまま）

- hirei5-02・hirei5-04：授業の台本が「○＝3×□」の式を教えるので、その式の問題を入れた（y・x は使わない）。
- hirei5-03：「紙 1まい＝0.02kg」のような小数×整数の計算がある（授業の台本でも同じ計算をしている）。
- heikin-02-L3-02・showari の文章題：どこまで求めるか（小数第1位まで・四しゃ五入など）を問題文に書いた。
- wariai-02-L4-02（1りん＝0.1%）・wariai-05-L4-02（25% ねあげの後、もとにもどすには 20% ねさげ）は、授業の例より一歩進んだチャレンジ。
- 各担当の検算スクリプト（`verify/`）は、書き直した問題の新しい文ではなく、作ったときの文で照合している。
