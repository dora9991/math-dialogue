（担当名を <tag>、授業の一覧を <lessons> とする。作業フォルダは この ファイルが ある フォルダ＝ e5/）
**大事な約束：ファイルを消さない。`rm`・`mv`・`rmdir` など、消す・うごかす コマンドは ぜったいに 使わない。** 書くのは `e5/out/<tag>/`・`e5/out/<tag>.json`・`e5/out/<tag>.verify.py` と、scratchpad の `<tag>_work/` の 中だけ。ほかの人のフォルダは 見ない・書かない。インターネットは 使わない。

最初に必ず、次の順に読む。
1. `e5/SPEC-E5.md`（決めごと。形・4段階・その学年向けの書き方・漢字・図・確かめ方）
2. `e5/samples-e1.json`（小学校の公開中の問題。ことばづかい・図の入れ方の見本）
3. `e5/figs.py` の説明（図を作る道具。図は必ずこれで作る）
4. `e5/in/<tag>.json`（担当の授業すべて。`summary` が授業の流れ、`script` がせりふ・問題。`after` の授業の内容は出さない）

進め方：
- 授業ごとに20問を作って、`e5/out/<tag>/<授業のid>.json` に、20問の配列として書く（1回に1授業）。問題を作る python スクリプトを `<tag>_work/` に書き、正解をそこで計算して JSON を書き出すのが確実（図も `figs` で作る）。
- 確かめのスクリプトを `e5/out/<tag>.verify.py` に残す（全問「問題 → 計算した答え」を一覧にし、正解の選択肢と突き合わせる。まちがいの選択肢が正解と一致しないことも）。
- 全部できたら `cd e5 && node merge_e5.mjs <tag> && node check_e5.mjs out/<tag>.json --lessons=<lessons>` を実行して **エラー0** にする。

最後の報告は短く：作った授業と問題の数、check の結果、自信が持てない問題（id と理由）。
