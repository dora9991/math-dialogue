# 中3「解説ごとの演習」問題づくりの決めごと

コツコツくん（中学生向けの数学の練習アプリ）に、**中3の解説（授業）1本ごとの演習**を足します。
解説1本につき、**4段階 × 5問 ＝ 20問**。すべて4択（正解1つ）の固定問題です。
中1・中2は、すでに同じ形で公開されています（その見本が `samples.json`）。

## 1. 入力と出力

- 入力：`in/g3uN.json`（N＝章。配列。1要素＝1本の解説）。各要素：
  - `id`（例 `g3u1-03`）／`kick`（3年1章 第3時）／`title`（授業の題）／`meate`（めあて）
  - `body`：その授業の本文（板書・公式・例題）を文字にしたもの。**ここに書いてある内容が、その授業で教える範囲**。
  - `ownQuestions`：授業の中で出る問題（4〜5問）。**そのままは使わない**（似た型は、数や条件を変えて使ってよい）。
  - `group`・`units`：参考。
- 出力：`out/<あなたの担当名>.json`。**問題オブジェクトの配列**（担当した授業ぶん全部）。

## 2. 問題オブジェクトの形

```json
{
  "id": "g3u1-03-L2-04",
  "u": "J3-T1",
  "s": "J3-T1-03",
  "l": "g3u1-03",
  "d": 2,
  "q": "問題文",
  "c": [ {"t":"選択肢A","w":"この答えを選ぶ人の、まちがえ方（子どもに向けた一文）"},
         {"t":"選択肢B","k":1},
         {"t":"選択肢C","w":"…"},
         {"t":"選択肢D","w":"…"} ],
  "e": "解説。1行1ステップ。\n最後の行に答え。",
  "h": "ヒント（答えそのものは書かない）"
}
```

- `id`＝`g3uN-LL-Ld-NN`。N＝章（1〜8）、LL＝授業の番号2けた、`L`のあとの d＝段階（1〜4）、最後の NN＝01〜05。
- `u`＝`J3-T`＋章の番号（例 `J3-T1`）。`s`＝`u`＋`-`＋授業の番号2けた（例 `J3-T1-03`）。`l`＝授業の id。`d`＝段階（数）。
- `c`：**ちょうど4つ**。正解は `"k":1` を **1つだけ**。正解の位置は、問題ごとにばらつかせる（A〜Dが偏らないように）。
- `w`：まちがい選択肢に付ける「なぜそう答えたくなるか」。**まちがい3つのうち、2つ以上に付ける**のを基本にする（まちがえ方が思い当たらない、答えに近い数だけの選択肢は、付けなくてよい）。正解には付けない。例：「符号を取りちがえた。」「かっこの中の 2つ目の項にかけ忘れた。」「…と考えた。」。
- JSON なので、バックスラッシュは `\\` と書く（例 `"$\\frac{1}{2}$"`、`"$\\sqrt{3}$"`）。

## 3. 4段階の意味（各段階 5問）

| d | 名前 | 内容 |
|---|---|---|
| 1 | 基礎 | その授業の最初の例のレベル。1ステップで解ける。用語・公式の確認も入れてよい |
| 2 | 標準 | 授業の例題・基本問題。2〜3ステップ |
| 3 | 応用 | 条件が複合した問題、文章題、式の利用、「どの説明が正しいか」を選ぶ問題 |
| 4 | 入試レベル | 公立高校入試の小問〜大問の一部の難しさ。考える力が要る。ただし、その授業までに習った範囲で解けること |

- 同じ段階の5問は、**型を変える**（数を入れかえただけの問題にしない）。
- 20問は、その授業の内容に合わせる。**授業で扱っていないこと（先の単元）は出さない**。
- 前の授業の内容を使うのは、段階3・4で、必要なときだけ。
- 別の授業の問題と、同じ問題・ほぼ同じ問題にならないように。

## 4. 書き方

- 日本語。中学生が読める文。問題文は、1〜4文。
- 数式は `$…$`（TeX）で書く。分数 `\\frac{a}{b}`、平方根 `\\sqrt{a}`、累乗 `x^{2}`、× `\\times`、÷ `\\div`、≠ `\\neq`、≦ `\\leqq`。かっこは `(` `)`。負の数は `-3`（半角ハイフン）。
  - 見本（`samples.json`）と同じ書き方にそろえる。
  - 選択肢も、数式なら `$…$` で包む。1つの問題の選択肢は、書き方（`$` の有無・表記）をそろえる。
  - 「3cm」のような単位つきの数は、`$` なしで `3cm` と書いてよい（見本のとおり）。
- **図は出せない。** 「図のように」「右の図で」と書かない。図形の問題は、点・辺・角・長さを**文章ですべて書き**、図が無くても解けるようにする（例：「△ABC で AB＝6cm、BC＝8cm、∠B＝90° である」）。
- 解説 `e`：1行に1ステップ、改行は `\n`。式の変形の流れが分かるように。**最後の行に、答え（正解の選択肢と同じ値）**を書く。3〜6行。
- ヒント `h`：1〜2文。**答えも、答えの数値も書かない**。「〜に目をつけよう」「〜を使おう」の形。
- 選択肢の注意：
  - 正解と、**同じ値・同じ式になる選択肢を入れない**（例：`2\\sqrt{3}` と `\\sqrt{12}`、`\\frac{1}{2}` と `0.5`、因数の順がちがうだけの式）。
  - 4つとも、**まちがいは本当にまちがい**であること。「どれも正解になる／正解がない」を作らない。
  - 「正しいものはどれか」の形の問題は、正解以外の3つが**はっきり誤り**になるように、数学的に確かめる。
- 難しすぎて、3年の範囲を超える問題は作らない。

## 5. 正しさの確かめ（必須）

1. **すべての正解を、計算で確かめる。** 数・式で出る問題は、`python3`（`sympy`・`fractions` が使える）で正解を出し、問題の `c` の正解と一致することを確かめる。確かめるスクリプトは、`out/<担当名>.verify.py` に残す（全問の「問題 → 計算した答え」を一覧にして出し、正解の選択肢と突き合わせる）。
   - 図形・証明・「正しいのはどれか」の問題は、根拠を `e` に書き、書いた根拠を自分で見直す。
2. `node check.mjs out/<担当名>.json` を実行して、**エラー0**にする（警告も、理由がなければ直す）。
3. このあと、別の人（問題を解くだけの人）が、正解を伏せた状態で解き直して、あなたの正解と一致するかを確かめます。**一致しない問題は、直すことになります。**

## 6. 最後の報告（短く）

- 作った授業と問題の数
- `check.mjs` の結果
- 自信が持てない問題（id と理由）があれば、1行ずつ
