# 小4「解説ごとの演習」問題づくりの決めごと

コツコツくん（算数・数学の練習アプリ）に、**小学4年の解説（ホー先生の授業）1本ごとの演習**を足します。
解説1本につき、**4段階 × 5問 ＝ 20問**。すべて4択（正解1つ）の固定問題です。
小1・中1〜高3は、すでに同じ形で作られています（中学の見本 `samples-j.json`、小1の練習問題の見本 `samples-e1.json`：ことばづかい・図の入れ方の見本。小4は、4年までの 漢字を つかってよい）。

## 1. 入力と出力

- 入力：`in/<担当名>.json`（配列。1要素＝1本の授業）。各要素：
  - `id`（例 `kaku-03`）／`title`（授業の題）／`unitName`（単元）／`code`（単元の記号 A〜N）／`no`（単元の中の番号）
  - `summary`：**授業の流れ**（台本の はじめに 書いてある説明）。**ここに書いてある内容が、その授業で教える範囲**。
  - `script`：授業の せりふ・問題・ボタンの文字（台本から ぬきだした 文。順番どおり）。授業で 出てくる 数・もの・ことばが わかる。**そのままは つかわない**（数や ものを かえて つかう）。
  - `before`：この授業より **前** の授業（ならった こと）。`after`：この授業より **あと** の授業（**まだ ならって いない こと。出さない**）。
- 出力：授業ごとに `out/<担当名>/<授業のid>.json`（20問の配列）。

## 2. 問題オブジェクトの形

```json
{
  "id": "wari41-03-L2-04",
  "u": "E4-TC",
  "s": "E4-TC-03",
  "l": "wari41-03",
  "d": 2,
  "q": "75 ÷ 4 を 筆算で 計算します。商と あまりは どれですか。",
  "c": [ {"t":"18 あまり 3","k":1},
         {"t":"18 あまり 1","w":"4 × 18 = 72 の 計算を まちがえた"},
         {"t":"19 あまり 1","w":"商を 1 大きく した（4 × 19 = 76 は 75 より 大きい）"},
         {"t":"17 あまり 7","w":"あまりが わる数より 大きい"} ],
  "e": "7 ÷ 4 = 1 あまり 3、35 ÷ 4 = 8 あまり 3。\nたしかめ：4 × 18 + 3 = 75\nこたえ 18 あまり 3",
  "h": "十の位から じゅんに わろう。あまりは わる数より 小さいかな。",
  "f": "<svg class=\"fig\" …>…</svg>（図が いる ときだけ。figs.py で つくる）"
}
```

- `id`＝`<授業のid>-L<段階>-<NN>`（NN＝01〜05）。`u`＝`E4-T`＋`code`、`s`＝`u`＋`-`＋`no` の2けた（例 `E4-TC-03`）、`l`＝授業の id、`d`＝段階（数）。
- `c`：**ちょうど4つ**。正解は `"k":1` を **1つだけ**。正解の位置は、問題ごとに ばらつかせる。
- `w`：まちがい選択肢に付ける「なぜ そう こたえたくなるか」（子どもに 見せる、やさしい ひとこと）。**まちがい3つのうち、2つ以上に付ける**。正解には付けない。
- `f`：**図が いる 問題だけ**（とけい（何時何分）・ものさし・○の グラフ・かけ算の ●の ならび・100の かたまりと 10の ぼう・分数の テープ・ほうがん紙の 三角形と 四角形・数の せん など）。`figs.py`（このフォルダ）で つくった SVG を、そのまま 入れる。**手で SVG を 書かない**。図が ある ときは、問題文で「とけいは なんじですか。」「▼の ところの かずは？」のように、図を さす。
  - 図の 道具（`figs.py`）：`clock(時, 分)`・`ruler(cm, tape_mm=…, arrow_mm=…)`・`numline(はじめ, おわり, 1めもり, 大きい めもりの はば, arrow=…)`（小数・分数の 数直線。例 `numline(0, 2, 0.1, 1, arrow=1.3)`・`numline(0, 1, "1/5", 1, arrow="3/5", labels=[0, 1])`）・`bar(名前, 数, step=…, vmax=…, unit="人")`（ぼうグラフ）・`linegraph(名前, 数, 下, 上, めもり, unit="度")`（折れ線グラフ）・`protractor(度, label)`（分度器を あてた 角）・`angle(度, label)`（角）・`circle(半径cm, "radius"|"diameter", label)`（円）・`graph(名前の リスト, 数の リスト)`・`array(だん, こ)`・`blocks3(百, 十, 一)`・`tape(わける 数, ぬる 数)`・`poly({"あ": [(x,y),…]})`・`numberline(…)`・`dots(…)`・`grid(…)`。

## 3. 4段階（アプリの 表示は「基本・練習・応用・チャレンジ」。各段階 5問）

| d | 表示 | 内容 |
|---|---|---|
| 1 | 基本 | 授業の いちばん はじめの 例と おなじ 形。1つの ステップで とける |
| 2 | 練習 | 授業の 基本の 問題を、かずや ものを かえて。授業で やった やりかたで とける |
| 3 | 応用 | おはなしの 問題（ことばの 問題）、2つの ことを くみあわせる、「どれが ただしい？」 |
| 4 | チャレンジ | すこし かんがえる 問題（きまりを みつける・ぎゃくに かんがえる・かくれた かずを さがす）。ただし **その授業までに ならった こと** だけで とける |

- 同じ段階の5問は、**型を かえる**（かずを いれかえた だけに しない）。
- 20問は、その授業の 内容に あわせる。**`after` の 授業で ならう ことは 出さない**（例：2けたで わる 筆算の 授業より 前に、2けたで わる わり算を 出さない。仮分数・帯分数の 授業より 前に、帯分数を 出さない。面積の 授業より 前に、cm² を 出さない）。
- ほかの 授業の 問題と、おなじ・ほぼ おなじ 問題に しない。

## 4. 書き方（4年生が よむ）

- **4年までに ならう 漢字**＋ひらがな。ことばの まとまりごとに **半角スペースで 分かち書き**（例「りんごが 3こ あります。」）。文は みじかく（問題文は 1〜4文、150字まで）。
- **漢字は、1〜4年で ならう 漢字だけ**（4年で：辺・径・積・約・側・位・億・兆・単・末・満・未・以・置・変・料・量・類・例・器・機・試・差・最・各・低・底・的・典・伝・達・連・労・録・覚・関・観 など）。5年より あとの 漢字は **ひらがな** で 書く（例：比→ひ、率→りつ）。ただし、4年の 教科書で つかう 算数の ことばの 漢字「仮」（仮分数）・「垂」（垂直）・「頂」（頂点）・「展」（展開図）は つかって よい（アプリが ふりがなを つける）。帯分数・真分数の「帯」「真」は 4年・3年の 漢字。`check_e4.mjs` が、ほかの 漢字を エラーに する。`w`・`e`・`h` も おなじ。
- すうじは 半角（`3`、`427`、`1000`）。しきは `3 + 4 = 7`、`9 − 2 = 7`（ひくは「−」）、`2 × 3 = 6`（かけるは「×」）、`□`（はいる 数）。わり算は `75 ÷ 4 = 18 あまり 3`、小数は `2.35`、分数は `7/5`、帯分数は `1と2/5`（「1と5分の2」と 書いても よい）、角は `70°`、面積は `24cm²`（`cm2` と 書かない）、がい数は「やく」。( ) の ある 式は `(12 + 8) × 3`。TeX（`$`）は つかわない。
- ひっ算は、たての 形を 文で 書けないので、「47 + 38 を ひっ算で します。一のくらいの 計算は 何ですか。」のように、くらいごとの 計算を ことばで きく。
- こたえの 選択肢は、たんいも そろえる（`3こ`、`5人`、`7cm`、`4mm`、`2L`、`3dL`、`200mL`、`1m20cm`、`8時25分`、`午後3時`、`40分` など）。1つの 問題の 選択肢は、書きかたを そろえる。
- 解説 `e`：1〜4行（改行は `\n`）。**さいごの 行に こたえ**（「こたえ 7こ」など）。ヒント `h`：1〜2文。**こたえ（の かず）は 書かない**。「ブロックで ためそう」「10の まとまりを つくろう」の 形。
- 選択肢の 注意：
  - 正解と **おなじ ものを あらわす 選択肢を 入れない**（例「7」と「7こ」を ならべない）。
  - 4つとも、まちがいは 本当に まちがい。「どれも 正解／正解が ない」を 作らない。「どれが ただしい？」は、正解いがいの 3つが はっきり まちがいに なるように たしかめる。
  - かぞえる 問題は、かぞえる ものが 1とおりに きまるように（「ぜんぶで」「のこりは」「ちがいは」を はっきり）。
  - おおきさくらべ（ながさ・かさ・ひろさ）は、くらべかたが 1つに きまる 条件を 書く（「1マスは おなじ 大きさ」「おなじ コップで」など）。
  - 角は、分度器の 図（`figs.protractor`）で 読む か、三角じょうぎの 角（30°・45°・60°・90°）や 180°・360° から 計算で 出す。図の 角を 目で 見て はかる だけの 問題は 出さない（図は 正しい 角度で かく）。
  - 垂直・平行・台形・平行四辺形・ひし形は、ほうがん紙の 図（`figs.poly`、ちょう点は マスの 点）か、へんの 長さ・平行な へんを ことばで はっきり 書く。
  - がい数は「四捨五入で 上から 2けた」「百の位までの がい数」のように、どこで 四捨五入 するかを かならず 書く。
  - 折れ線グラフは `figs.linegraph`。直方体・立方体は、たて・よこ・高さ・面・辺・ちょう点の 数を ことばで 書く（展開図は ほうがん紙で かいても よい）。
  - 長さ・かさの たんいの かんけい（1cm＝10mm、1m＝100cm、1L＝10dL、1L＝1000mL、1dL＝100mL）は、その授業で ならってから つかう。
  - 三角形・四角形・長方形・正方形・直角三角形は、ほうがん紙の 図（`figs.poly`）か、へんの 長さ・かどの ようすを ことばで はっきり 書く。はこの 形は、めん・へん・ちょう点の 数を ことばで きいてよい。
  - ひょうと グラフは、`figs.graph` で 図に するか、ひょうの 数を 文に 書く。

## 5. 正しさの 確かめ（必須）

1. **すべての 正解を、計算で 確かめる。** `python3` で 正解を 出し、問題の 正解と 一致することを 確かめる（たす・ひく・かける・たんいの かんさん・時こくと 時間・数の 大小 など）。確かめる スクリプトは `out/<担当名>.verify.py` に 残す（全問「問題 → 計算した 答え」を 一覧に 出し、正解の 選択肢と 突き合わせる。まちがいの 選択肢が 正解と 一致しないことも）。
   - 図が ある 問題は、図を 作った ときの 数（とけいの 時・分、ものさしの mm、グラフの 数、●の だんと こ、ブロックの 数、テープの わけかた、ちょう点の いち）から 正解を 出す。
2. `node merge_e4.mjs <担当名> && node check_e4.mjs out/<担当名>.json --lessons=…` を 実行して、**エラー 0** に する（警告も、理由が なければ 直す）。
3. このあと、別の人が 正解を 伏せた 状態で 解き直して、あなたの 正解と 一致するかを 確かめます。**一致しない 問題は、直すことに なります。**
