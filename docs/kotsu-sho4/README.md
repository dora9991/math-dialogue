# コツコツくん 小4「解説ごとの演習」（65本・1,300問）

小1〜小3と同じ形（解説1本につき、4段階 × 5問、4択）の演習を、小4の全65本（ホー先生の授業）につくった。アプリでは **基本・練習・応用・チャレンジ** と表示される。

## 状況（2026-11-26）

| 段階 | 状況 |
|---|---|
| 作る | 7人で分担（`SPEC.md`、`tools/AUTHOR.md`）。授業の台本（ho-sansu の `lessons/<id>.js`）から、授業の流れ・せりふ・問題を ぬきだして、授業の範囲どおりに作った。機械検査（`tools/check_e4.mjs`：形・4択・正解1つ・4年までに ならう 漢字だけ（算数の ことば「仮分数」「垂直」「頂点」「展開図」の 仮・垂・頂・展は よい）・図の形）エラー 0 |
