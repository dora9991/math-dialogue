# 数学ラボ ソロ — 設計メモ（試作版）

小学1年〜高校3年の数学を、**授業とは別に、一人で習熟する**ためのアプリ。
「目標（志望校）→ 現在地（診断）→ 毎日のおすすめ」の流れで、講義・演習・確認テスト・復習を自動で回す。

- 入口：`solo/index.html` → `src/solo/main.jsx`
- 公開URL（GitHub Pages）：`https://<ユーザー>.github.io/math-dialogue/solo/`
- 開発：`npm run dev` → `http://localhost:5173/math-dialogue/solo/`
- 数学ラボ本体（ゲーム）の「学習」メニューからもリンクしている

## 1. 学習の流れ

```
はじめの設定 ─→ 理解度診断 ─→ ホーム（今日のおすすめ）─→ 単元：講義 → 演習 → 確認テスト
 学年・志望校       さかのぼり         ↑                         │
 文理・習った単元   で根っこを探す      └──── 理解度を更新 ←──────┘（復習は 3→7→16→35日後）
```

| 機能 | 画面 | しくみ（ファイル） |
|---|---|---|
| 目標設定 | はじめの設定 | 志望校 → 目標レベル（基礎／共通テスト・中堅／国公立・上位私大／難関／最難関）→ 小・中・高それぞれ必要なレベル（`engine/goals.js`） |
| 理解度診断 | 診断 | 最近習った単元から出題。まちがえたら前提の単元へさかのぼる。分野ごとの系統を順番に回す（`engine/diagnosis.js`） |
| 理解度の推定 | 全体 | レベルごとに「次も正解できる見込み」を移動平均で。3問以上で80%以上、または確認テスト合格で「習得」（`engine/mastery.js`） |
| おすすめ | ホーム | ①つまずきの根っこ ②目標未達 ③復習の時期 ④未確認 ⑤予習。土台になる単元ほど優先（`engine/recommend.js`） |
| 講義 | 単元 → 講義 | ホー先生の解説（スライド）／無ければ要点＋例題＋葉一さんの動画（`components/Lecture.jsx`, `lectures/`） |
| 演習 | 単元 → 演習 | 5問。2連続正解でレベルアップ、2連続不正解でダウン。最下層でつまずくと前提へのさかのぼりを提案（`screens/Practice.jsx`） |
| 確認テスト | 単元 → 確認テスト | 5問ヒントなし、4問以上で合格＝そのレベルを習得 |
| おすすめ10問 | ホーム | おすすめ上位の単元を混ぜて出題（交互練習）。復習の間隔も更新 |
| 可視化 | マップ／記録 | 理解度マップ（小1〜高3×4分野）・単元一覧・分野レーダー・毎日の問題数・バッジ |
| モチベーション | 全体 | XP・学習者レベル・連続日数・今日の目標・バッジ（つまずき克服、さかのぼり名人 など）・ホー先生の声かけ |

## 2. レベル（4段階）

| | 名前 | 目安 |
|---|---|---|
| 1 | 簡単 | 教科書の例題 |
| 2 | 標準 | 教科書の練習問題〜共通テストの基本 |
| 3 | 応用 | 入試標準（地方国公立・MARCH・関関同立） |
| 4 | 難関 | 難関大二次（旧帝大・早慶・医学部） |

中学の既存データは easy/standard/advanced/oni をそのまま 1〜4 に対応させている。

## 3. データの置き場所

```
src/solo/
├── content/          … 単元と問題（小1〜高3）
│   ├── kit.js          問題テンプレートを書く道具
│   ├── elem/e1〜e6.js  小学校（新規）
│   ├── jhs/index.js    中学（既存の src/data/grade1〜3 を包む。前提のつながりもここ）
│   ├── jhs/_points.js  中学の要点
│   ├── high/*.js       高校 数学I・A・II・B・C・III（新規）
│   └── index.js        全部を束ねる窓口（中1は教科書由来の実問題 problem_bank.json も混ぜる）
├── lectures/         … ホー先生の解説（1単元1ファイル）
├── engine/           … 目標・診断・理解度・おすすめ・記録・保存（画面に依存しない）
├── components/       … 数式表示（KaTeX）・問題・講義・小部品
└── screens/          … 画面
```

- 問題データの書き方：[solo-問題データの書き方.md](solo-問題データの書き方.md)
- 講義の書き方：[solo-講義データの書き方.md](solo-講義データの書き方.md)
- 検査：`node scripts/solo-verify.mjs`（全テンプレートを数百回ずつ生成して、答え・選択肢・数式をチェック）

## 4. 保存

いまはブラウザの localStorage（`mathlab-solo-v1`）。設定画面からファイルに書き出し／読み込みできる。
サーバー保存にするときは `engine/store.js` の `load` / `save` を差し替える（数学ラボ本体の Supabase と同じ考え方）。

## 5. 試作の割り切りと、これから

- **解説（ホー先生）**：見本は3単元（小5 分数のたし算、中1 正負の数のたし算、高1 平方完成）。ほかは要点＋例題＋（中学は）葉一さんの動画。
- **図**：図形問題は文章で状況が決まるものだけ。図の表示（SVG）は未対応。
- **答え方**：数値・分数は入力式、式・√・π などは4択。式の入力（数式キーボード）は数学ラボ本体のものを将来移植できる。
- **大学と目標レベルの対応**は目安。`engine/goals.js` の `UNIVERSITIES` と `TIERS` を直せば変えられる。
- **先生・保護者向けの画面**（クラス全体の理解度・つまずき）はサーバー保存のあとで。
