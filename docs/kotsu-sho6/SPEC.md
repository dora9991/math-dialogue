# 小6「解説ごとの演習」問題づくりの決めごと

コツコツくん（算数・数学の練習アプリ）に、**小学6年の解説（ホー先生の授業）1本ごとの演習**を足します。
解説1本につき、**4段階 × 5問 ＝ 20問**。すべて4択（正解1つ）の固定問題です。
小1・中1〜高3は、すでに同じ形で作られています（中学の見本 `samples-j.json`、小1の練習問題の見本 `samples-e1.json`：ことばづかい・図の入れ方の見本。小6は、6年までの 漢字（小学校で ならう 漢字 ぜんぶ）を つかってよい）。

## 1. 入力と出力

- 入力：`in/<担当名>.json`（配列。1要素＝1本の授業）。各要素：
  - `id`（例 `hi-03`）／`title`（授業の題）／`unitName`（単元）／`code`（単元の記号 A〜K）／`no`（単元の中の番号）
  - `summary`：**授業の流れ**（台本の はじめに 書いてある説明）。**ここに書いてある内容が、その授業で教える範囲**。
  - `script`：授業の せりふ・問題・ボタンの文字（台本から ぬきだした 文。順番どおり）。授業で 出てくる 数・もの・ことばが わかる。**そのままは つかわない**（数や ものを かえて つかう）。
  - `before`：この授業より **前** の授業（ならった こと）。`after`：この授業より **あと** の授業（**まだ ならって いない こと。出さない**）。
- 出力：授業ごとに `out/<担当名>/<授業のid>.json`（20問の配列）。

## 2. 問題オブジェクトの形

```json
{
  "id": "hi-03-L2-04",
  "u": "E6-TE",
  "s": "E6-TE-03",
  "l": "hi-03",
  "d": 2,
  "q": "75 ÷ 4 を 筆算で 計算します。商と あまりは どれですか。",
  "c": [ {"t":"18 あまり 3","k":1},
         {"t":"18 あまり 1","w":"4 × 18 = 72 の 計算を まちがえた"},
         {"t":"19 あまり 1","w":"商を 1 大きく した（4 × 19 = 76 は 75 より 大きい）"},
         {"t":"17 あまり 7","w":"あまりが わる数より 大きい"} ],
  "e": "7 ÷ 4 = 1 あまり 3、35 ÷ 4 = 8 あまり 3。\nたしかめ：4 × 18 + 3 = 75\nこたえ 18 あまり 3",
  "h": "十の位から じゅんに わろう。あまりは わる数より 小さいかな。",
  "f": "<svg class=\"fig\" …>…</svg>（図が いる ときだけ。figs.py で つくる）"
}
```

- `id`＝`<授業のid>-L<段階>-<NN>`（NN＝01〜05）。`u`＝`E6-T`＋`code`、`s`＝`u`＋`-`＋`no` の2けた（例 `E6-TE-03`）、`l`＝授業の id、`d`＝段階（数）。
- `c`：**ちょうど4つ**。正解は `"k":1` を **1つだけ**。正解の位置は、問題ごとに ばらつかせる。
- `w`：まちがい選択肢に付ける「なぜ そう こたえたくなるか」（子どもに 見せる、やさしい ひとこと）。**まちがい3つのうち、2つ以上に付ける**。正解には付けない。
- `f`：**図が いる 問題だけ**（とけい（何時何分）・ものさし・○の グラフ・かけ算の ●の ならび・100の かたまりと 10の ぼう・分数の テープ・ほうがん紙の 三角形と 四角形・数の せん など）。`figs.py`（このフォルダ）で つくった SVG を、そのまま 入れる。**手で SVG を 書かない**。図が ある ときは、問題文で「とけいは なんじですか。」「▼の ところの かずは？」のように、図を さす。
  - 図の 道具（`figs.py`）：`clock(時, 分)`・`ruler(cm, tape_mm=…, arrow_mm=…)`・`numline(はじめ, おわり, 1めもり, 大きい めもりの はば, arrow=…)`（小数・分数の 数直線。例 `numline(0, 2, 0.1, 1, arrow=1.3)`・`numline(0, 1, "1/5", 1, arrow="3/5", labels=[0, 1])`）・`bar(名前, 数, step=…, vmax=…, unit="人")`（ぼうグラフ）・`linegraph(名前, 数, 下, 上, めもり, unit="度")`（折れ線グラフ）・`protractor(度, label)`（分度器を あてた 角）・`angle(度, label)`（角）・`circle(半径cm, "radius"|"diameter", label)`（円）・`band(名前, ％)`（帯グラフ）・`pie(名前, ％)`（円グラフ）・**小6で 新しく**：`poly2({"": [(x,y),…]}, cols, rows, lines=[((x1,y1),(x2,y2))], points=[(x,y,"O")], labels={"A": (x,y)})`（ほうがん紙の 図形に、対称の じく（点線）・対称の 中心（点）・ちょう点の 記号を かく）・`xygraph(xの 最大, yの 最大, xの めもり, yの めもり, line=決まった数, curve=決まった数, points=[(x,y)])`（比例の 直線 y＝決まった数×x／反比例の 曲線 y＝決まった数÷x）・`dotplot(データ, 下, 上)`（ドットプロット）・`hist(階級の さかい, 度数, unit="kg", yunit="人")`（柱状グラフ）・`graph(名前の リスト, 数の リスト)`・`array(だん, こ)`・`blocks3(百, 十, 一)`・`tape(わける 数, ぬる 数)`・`poly({"あ": [(x,y),…]})`・`numberline(…)`・`dots(…)`・`grid(…)`。

## 3. 4段階（アプリの 表示は「基本・練習・応用・チャレンジ」。各段階 5問）

| d | 表示 | 内容 |
|---|---|---|
| 1 | 基本 | 授業の いちばん はじめの 例と おなじ 形。1つの ステップで とける |
| 2 | 練習 | 授業の 基本の 問題を、かずや ものを かえて。授業で やった やりかたで とける |
| 3 | 応用 | おはなしの 問題（ことばの 問題）、2つの ことを くみあわせる、「どれが ただしい？」 |
| 4 | チャレンジ | すこし かんがえる 問題（きまりを みつける・ぎゃくに かんがえる・かくれた かずを さがす）。ただし **その授業までに ならった こと** だけで とける |

- 同じ段階の5問は、**型を かえる**（かずを いれかえた だけに しない）。
- 20問は、その授業の 内容に あわせる。**`after` の 授業で ならう ことは 出さない**（例：分数 ÷ 分数の 授業より 前に、分数 ÷ 分数を 出さない。反比例の 授業より 前に、反比例を 出さない。中央値・最頻値の 授業より 前に、中央値・最頻値を 出さない）。
- ほかの 授業の 問題と、おなじ・ほぼ おなじ 問題に しない。

## 4. 書き方（6年生が よむ）

- **6年までに ならう 漢字**＋ひらがな。ことばの まとまりごとに **半角スペースで 分かち書き**（例「りんごが 3こ あります。」）。文は みじかく（問題文は 1〜4文、150字まで）。
- **漢字は、小学校（1〜6年）で ならう 漢字だけ**（6年で ならう 漢字の 例：拡・縮・値・樹・模・層・存・誤・射・針・届・預・宇・宙・延・沿・枚・俵・割・捨・並・異 など）。中学より あとの 漢字は **ひらがな** で 書く。ただし、6年の 教科書で つかう 算数の ことばの 漢字「称」（線対称・点対称）・「頻」（最頻値）・「偶」「奇」（偶数・奇数）は つかって よい（アプリが ふりがなを つける）。四捨五入は「四捨五入」と 漢字で 書いて よい。`check_e6.mjs` が、ほかの 漢字を エラーに する。
- すうじは 半角（`3`、`427`、`1000`）。しきは `3 + 4 = 7`、`9 − 2 = 7`（ひくは「−」）、`2 × 3 = 6`（かけるは「×」）、`□`（はいる 数）。小数は `2.35`、分数は `7/5`・帯分数 `1と2/5`、分数の 計算は `2/3 × 3/4`・`5/6 ÷ 2/3`、文字の 式は `x × 4`・`a × 3 + 5`（6年は `×` を はぶかない）、比は `3:4`（半角の コロン）、比の値は `3/4`、縮尺は `1/1000` か `1:1000`、面積は `78.5cm²`、体積は `24cm³`（`cm3` と 書かない）、円周率は 3.14、角は `70°`、百分率は `25%`。
- ひっ算は、たての 形を 文で 書けないので、「47 + 38 を ひっ算で します。一のくらいの 計算は 何ですか。」のように、くらいごとの 計算を ことばで きく。
- こたえの 選択肢は、たんいも そろえる（`3こ`、`5人`、`7cm`、`4mm`、`2L`、`3dL`、`200mL`、`1m20cm`、`8時25分`、`午後3時`、`40分` など）。1つの 問題の 選択肢は、書きかたを そろえる。
- 解説 `e`：1〜4行（改行は `\n`）。**さいごの 行に こたえ**（「こたえ 7こ」など）。ヒント `h`：1〜2文。**こたえ（の かず）は 書かない**。「ブロックで ためそう」「10の まとまりを つくろう」の 形。
- 選択肢の 注意：
  - 正解と **おなじ ものを あらわす 選択肢を 入れない**（例「7」と「7こ」を ならべない）。
  - 4つとも、まちがいは 本当に まちがい。「どれも 正解／正解が ない」を 作らない。「どれが ただしい？」は、正解いがいの 3つが はっきり まちがいに なるように たしかめる。
  - かぞえる 問題は、かぞえる ものが 1とおりに きまるように（「ぜんぶで」「のこりは」「ちがいは」を はっきり）。
  - おおきさくらべ（ながさ・かさ・ひろさ）は、くらべかたが 1つに きまる 条件を 書く（「1マスは おなじ 大きさ」「おなじ コップで」など）。
  - **対称**：線対称は 対称の じく（`poly2` の `lines` で 点線）、点対称は 対称の 中心（`poly2` の `points`）を 図に かく。「対応する 点・辺・角」は、ちょう点の 記号（`labels`）と 名前を 問題文で はっきり 書く。正多角形・アルファベットの 形・身の まわりの 形の 対称は、じくの 本数・点対称か どうかを ことばで きいて よい。
  - **文字と式**：x・a などの 文字を つかう。式は `x × 4`・`a × 3 + 5` のように 書き、`×` を はぶかない。x に あてはまる 数を 求める 問題は、答えが 1つに きまる ように する。
  - **分数の かけ算・わり算**：答えは 約分した 形。帯分数か 仮分数かは 問題文で 指定するか、選択肢を どちらかに そろえる。逆数は「□の 逆数」と はっきり 書く。整数や 小数は、分数に なおして 計算して よい。
  - **比**：`3:4` の 形。比の値は 分数か 整数。「比を かんたんに する」は、いちばん かんたんな 整数の 比（最大公約数で わる）。比を つかう 文章題は、どの 量と どの 量の 比かを はっきり 書く。
  - **拡大図と縮図**：`poly2` で、もとの 図と 拡大図・縮図を ならべて かいて よい（ちょう点は マスの 点）。「2倍の 拡大図」「1/2の 縮図」と 書く。縮尺は `1/1000`・`1:1000` と 書き、実際の 長さは たんいを そろえて（cm と m）答えさせる。
  - **円の面積**：半径 × 半径 × 3.14。半円・円の 1/4・色を ぬった 部分は、`figs.circle` か ことばで 形と 長さを はっきり 書く（どこを もとめるかが 1とおりに きまる ように）。
  - **角柱・円柱の 体積**：底面積 × 高さ。底面の 形と 長さ、高さを ことばで ぜんぶ 書く（立体の 図は 作らない）。
  - **比例と 反比例**：比例は「y ＝ 決まった数 × x」、反比例は「x × y ＝ 決まった数」「y ＝ 決まった数 ÷ x」（教科書の 書き方）。表は 問題文に 数を 書く。グラフは `xygraph`（比例は 直線、反比例は 曲線）。グラフの 点は マスの 交わる ところに なる 数に する。
  - **場合の数**：ならべ方と 組み合わせを 区別して、「A と B」と「B と A」を 同じと みるか、同じ ものを 2回 つかって よいかを、問題文で はっきり 書く。樹形図や 表は ことばで（「図を かいて」とは 書かない）。
  - **データの 調べ方**：平均値・中央値・最頻値は、データを ぜんぶ 問題文か 図に 書く。中央値は、データが 偶数こ なら 真ん中の 2つの 平均。度数分布表は、階級を「20kg 以上 25kg 未満」と 書く。ドットプロットは `dotplot`、柱状グラフは `hist`。いちばん 多い 階級・ある 階級までの 人数・割合を 読む 問題に する。
  - 長さ・かさの たんいの かんけい（1cm＝10mm、1m＝100cm、1L＝10dL、1L＝1000mL、1dL＝100mL）は、その授業で ならってから つかう。

## 5. 正しさの 確かめ（必須）

1. **すべての 正解を、計算で 確かめる。** `python3` で 正解を 出し、問題の 正解と 一致することを 確かめる（たす・ひく・かける・たんいの かんさん・時こくと 時間・数の 大小 など）。確かめる スクリプトは `out/<担当名>.verify.py` に 残す（全問「問題 → 計算した 答え」を 一覧に 出し、正解の 選択肢と 突き合わせる。まちがいの 選択肢が 正解と 一致しないことも）。
   - 図が ある 問題は、図を 作った ときの 数（ちょう点の いち、じく・中心の いち、グラフの 決まった数・点、データの 数）から 正解を 出す。
2. `node merge_e6.mjs <担当名> && node check_e6.mjs out/<担当名>.json --lessons=…` を 実行して、**エラー 0** に する（警告も、理由が なければ 直す）。
3. このあと、別の人が 正解を 伏せた 状態で 解き直して、あなたの 正解と 一致するかを 確かめます。**一致しない 問題は、直すことに なります。**
