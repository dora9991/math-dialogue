# 高2（数学Ⅱ・数学B）「解説ごとの演習」問題づくりの決めごと

コツコツくん（数学の練習アプリ）に、**高2（数学Ⅱ・数学B）の解説（授業）1本ごとの演習**を足します。
解説1本につき、**4段階 × 5問 ＝ 20問**。すべて4択（正解1つ）の固定問題です。
中1〜中3・高1は、すでに同じ形で公開されています（見本が `samples-j.json`）。高校の既存の固定問題の見本が `samples-h2.json` です（`m` の項目は、この仕事では付けません）。

## 1. 入力と出力

- 入力：`in/<科目>.json`（科目＝`m2a`〜`m2e`・`mb1`〜`mb3`。配列。1要素＝1本の解説）。各要素：
  - `id`（例 `m2a-04`）／`title`（授業の題）／`section`（節）／`subject`（数学Ⅰ　数と式 など）
  - `units`：その授業が属する単元。`name`・`desc`・`points`（**その単元の要点・公式**）。授業の中身は、題と、この `points` から読み取る。
  - `groupOrder`：その科目の授業の一覧（順番どおり）。**その授業より先の授業の内容は出さない**。前の授業の内容を使うのは、段階3・4で必要なときだけ。
  - `groupCode`：`A`〜`H`（`u` と `s` に使う）
  - 授業の本文は、外部のサイトにあって読めません。題と `points` と `groupOrder` から、その授業で教える範囲を考えて作ってください。教科書（数学Ⅱ・数学B）の標準的な内容に合わせます。
- 出力：`out/<あなたの担当名>.json`。**問題オブジェクトの配列**（担当した授業ぶん全部）。

## 2. 問題オブジェクトの形

```json
{
  "id": "m2a-04-L2-03",
  "u": "H2-TA",
  "s": "H2-TA-04",
  "l": "m2a-04",
  "d": 2,
  "q": "問題文",
  "c": [ {"t":"選択肢A","w":"この答えを選ぶ人の、まちがえ方（高校生に向けた一文）"},
         {"t":"選択肢B","k":1},
         {"t":"選択肢C","w":"…"},
         {"t":"選択肢D","w":"…"} ],
  "e": "解説。1行1ステップ。\n最後の行に答え。",
  "h": "ヒント（答えそのものは書かない）"
}
```

- `id`＝`<授業のid>-L<段階>-<NN>`（NN＝01〜05）。例：`m2a-04-L2-03`。
- `u`＝`H2-T`＋`groupCode`（例 `H2-TA`）。`s`＝`u`＋`-`＋授業の番号2けた（例 `H2-TA-04`）。`l`＝授業の id。`d`＝段階（数）。
- `c`：**ちょうど4つ**。正解は `"k":1` を **1つだけ**。正解の位置は、問題ごとにばらつかせる。
- `w`：まちがい選択肢に付ける「なぜそう答えたくなるか」。**まちがい3つのうち、2つ以上に付ける**のを基本にする（答えに近い数だけの選択肢は付けなくてよい）。正解には付けない。例：「符号を取りちがえた。」「二乗の公式の 2ab を落とした。」「場合分けの片方を忘れた。」
- JSON なので、バックスラッシュは `\\` と書く（例 `"$\\frac{1}{2}$"`、`"$\\sqrt{3}$"`、`"$\\sin 30^{\\circ}$"`）。

## 3. 4段階の意味（各段階 5問）

| d | 名前 | 内容 |
|---|---|---|
| 1 | 基礎 | 教科書の例・公式の直接の適用。1ステップ。用語・定義・公式の確認も入れてよい |
| 2 | 標準 | 教科書の例題・章末の基本問題。2〜3ステップ |
| 3 | 応用 | 条件が複合した問題、場合分け、文章題、「どの記述が正しいか」を選ぶ問題。入試の基本〜標準 |
| 4 | 入試レベル | 共通テスト・大学入試（標準〜やや難）の小問。考える力が要る。ただし、**その授業までに習った範囲**で解けること |

- 同じ段階の5問は、**型を変える**（数を入れかえただけにしない）。
- **数学Ⅱ・数学Bの範囲だけ**（数学Bは、数列と統計的な推測）。**数学Ⅲ・数学C**（数列の極限・関数の極限、積の微分・商の微分・合成関数の微分などの発展、置換積分・部分積分、ベクトル、複素数平面、2次曲線、媒介変数表示 など）は出さない。数学Ⅰ・数学Aの内容は、前提として使ってよい。
- 別の授業の問題と、同じ問題・ほぼ同じ問題にならないように。

## 4. 書き方

- 日本語。高校生が読める文。問題文は、1〜4文。
- 数式は `$…$`（TeX）で書く。分数 `\\frac{a}{b}`、平方根 `\\sqrt{a}`、累乗 `x^{2}`、× `\\times`、÷ `\\div`、≠ `\\neq`、≦ `\\leqq`、≧ `\\geqq`、三角比 `\\sin A`・`\\cos A`・`\\tan A`、度 `30^{\\circ}`、組合せ `{}_{5}\\mathrm{C}_{2}`、絶対値 `|x|`、弧度法・三角関数 `\\sin\\theta`・`\\frac{\\pi}{3}`、対数 `\\log_{2} 8`、指数 `2^{x}`・`a^{\\frac{1}{2}}`、微分・積分 `f'(x)`・`\\int_{0}^{1} x^{2}\\,dx`、数列 `a_{n}`・`\\sum_{k=1}^{n} k`、確率変数 `E(X)`・`V(X)`・`\\sigma(X)`、二項分布 `B(n, p)`、正規分布 `N(m, \\sigma^{2})`、複素数 `i`。
  - 見本（`samples-j.json`・`samples-h2.json`）と同じ書き方にそろえる。選択肢も、数式なら `$…$` で包む。1つの問題の選択肢は、書き方（`$` の有無・表記）をそろえる。
  - 「3cm」のような単位つきの数は、`$` なしで `3cm` と書いてよい。
- **図は出せない。** 「図のように」「右の図で」と書かない。図形・グラフの問題は、点・辺・角・長さ・式を**文章ですべて書き**、図が無くても解けるようにする。
- 解説 `e`：1行に1ステップ、改行は `\n`。式の変形の流れが分かるように。**最後の行に、答え（正解の選択肢と同じ値）**を書く。3〜6行。
- ヒント `h`：1〜2文。**答えも、答えの数値も書かない**。「〜に目をつけよう」「〜を使おう」の形。
- 選択肢の注意：
  - 正解と、**同じ値・同じ式になる選択肢を入れない**（例：`2\\sqrt{3}` と `\\sqrt{12}`、`\\frac{1}{2}` と `0.5`、因数の順がちがうだけの式、同じ集合を別の書き方にしたもの）。
  - 4つとも、**まちがいは本当にまちがい**であること。「どれも正解になる／正解がない」を作らない。
  - 「正しいものはどれか」の形の問題は、正解以外の3つが**はっきり誤り**になるように、数学的に確かめる。
  - 場合の数・確率：**数え方の条件を明記する**（「区別する／しない」「同じ数字を使ってよい／よくない」「順序を考える／考えない」「取り出したものをもどす／もどさない」）。条件があいまいで答えが2通りに読める問題は作らない。
  - データの分析：分散・標準偏差は、**データそのものの（母集団の）分散**＝偏差の2乗の平均で定義する。四分位数は、教科書の定義（中央値で2つに分け、前半・後半の中央値）に従う。データの値は、問題文に全部書く。
  - 2次関数・図形と計量：式・座標・長さ・角を問題文に明記する。範囲（定義域）を忘れない。
  - 集合と命題：必要条件・十分条件・対偶・逆・裏は、定義どおり。反例を挙げる問題は、反例が1つに決まるようにする。

## 5. 正しさの確かめ（必須）

1. **すべての正解を、計算で確かめる。** 数・式・確率・集合で出る問題は、`python3`（`sympy`・`fractions`・`itertools`・`math` が使える）で正解を出し、問題の `c` の正解と一致することを確かめる。場合の数・確率は、**全部数え上げて**確かめる（`itertools`）。確かめるスクリプトは、`out/<担当名>.verify.py` に残す（全問「問題 → 計算した答え」を一覧にして出し、正解の選択肢と突き合わせる）。
   - 証明・「正しいのはどれか」の問題は、根拠を `e` に書き、書いた根拠を自分で見直す。
2. `node check_h2.mjs out/<担当名>.json --lessons=…` を実行して、**エラー0**にする（警告も、理由がなければ直す）。
3. このあと、別の人（問題を解くだけの人）が、正解を伏せた状態で解き直して、あなたの正解と一致するかを確かめます。**一致しない問題は、直すことになります。**

## 6. 最後の報告（短く）

- 作った授業と問題の数
- `check_h2.mjs` の結果
- 自信が持てない問題（id と理由）があれば、1行ずつ

## 7. 科目ごとの注意（数学Ⅱ・数学B）

- **式と証明・複素数・高次方程式**：恒等式・二項定理・相加相乗平均は、sympy で確かめる。「証明の穴埋め」型は、正解以外が、はっきり誤りになるようにする。
- **図形と方程式**：直線・円・軌跡・領域は、式・座標・条件を文で書く（図は出せない）。領域の問題は、「（x, y）が領域に含まれる／含まれない」の判定で確かめられる形にする。
- **三角関数**：**弧度法**を使う（度数法の問題だけにしない）。加法定理・2倍角・合成。値は `\\frac{\\sqrt{3}}{2}` などのきれいな形にする。方程式・不等式は、`0 \\leqq \\theta < 2\\pi` などの範囲を問題文に書く。
- **指数関数・対数関数**：底・真数の条件を忘れない。同じ値になる選択肢（例 `\\log_{2} 8` と `3`）を重ねない。桁数・最高位の数字は、常用対数の値を問題文に与える。
- **微分・積分**：数学Ⅱの範囲（多項式の微分・積分）だけ。接線・増減・極値・最大最小・面積は、sympy で確かめる。
- **数列**：等差・等比・Σ・階差・漸化式・数学的帰納法。一般項は、`a_{n}=` の形にそろえる。
- **統計的な推測**：確率変数・期待値・分散・二項分布・正規分布・標本平均・信頼区間・仮説検定。**正規分布表の値は、問題文に与える**（表を見ないと解けない問題は作らない）。区間推定は 95％ の `1.96`、99％ の `2.58` を、問題文に与える。小数の答えは、四捨五入のけた数を問題文に明記する。仮説検定は、片側・両側を問題文に明記する。
