中1〜中3・高1と同じ形（解説1本につき、4段階 × 5問、4択）の演習を、高2の全77本（数学Ⅱ 52本・数学B 25本）につくった。

## 状況（2026-11-21）

| 段階 | 状況 |
|---|---|
| 作る | 7人で分担（`SPEC.md` の決めごと）。機械検査（`tools/check_h2.mjs`）エラー 0 |

| **公開** | **まだ**（先生の「公開して」を待つ） |

## 中身

- `data/h2a.json`〜`h2g.json`：1,540問。形は `{ id, u, s, l, d, q, c:[{t, k|w}], e, h }`。`u`＝`H2-T`＋科目の記号（A〜H）。
- `chunks/h2*.js`：科目ごとの公開用ファイル 8つ。`chunks/lessons.json`：索引。
- `units.json`：高2の13単元の名前・説明・要点。
- `tools/`：検査・解き直しの照合・公開用ファイルの作成・パッチ・テスト。

## 注意

- 高校の解説の本文は、外部のサイトにあって読めない。そのため、**解説の題と、単元の要点（公式）**から、授業で教える範囲を推測して作った。授業の中身とずれている問題があれば、直す。
- 統計的な推測では、正規分布表の値・1.96・2.58・1.64 を問題文に与えた。正規分布近似は、連続性補正を使わない。
- 本体に入れるときは、中3・高1と同じ（解説の索引 `Wn` と、読みこみの表 `./<キー>.json` に足す）。次に本体から公開すると、この 2か所は元にもどるので、本体のソースにも入れること。
