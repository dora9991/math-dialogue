# ログイン：組織コードの自動入力と、Face ID など での ログイン

## 1. 組織コードの 自動入力（生徒の ログイン画面）— 作った（公開は まだ）

先生・管理者の ログイン画面（`solo/teacher/`・`solo/admin/`）は、もともと「前回の 組織コード・ID」と「URL の `?org=`」で 組織コードが 入る。生徒の ログイン画面（設定 → 学校・塾のアカウント）は、毎回 空だったので、同じように した（`patch_login.py.txt`）。

- **前回の 組織コードを 覚える**：生徒が ログインに 成功すると、組織コードだけを その 端末に 覚える（ID・パスワードは 覚えない）。次から ログイン画面を 開くと 入って いる。
- **URL で わたす**：`https://dora9991.github.io/math-dialogue/solo/?org=K7Q3PX` のように 組織コードを つけた URL（QR コード）で 開くと、組織コードが 入る（アプリが URL を 書きかえる 前に、読みこみの ときに 拾う）。
- 組織コードが 入って いる ときは、ID の 欄に カーソルが 出る。
- 入力欄に `name`（organization・username・password）を つけ、form を ふつうの ログインフォームの 形（method=post）に した。iPhone・iPad・Mac の「パスワード」に 保存・自動入力 されやすく なる。

確かめ：`test_login.cjs`（URL の 組織コード・前回の 組織コード・ログイン成功で 覚える・入力欄の 形・エラーなし）8件 PASS。「カードで学ぶ」の テストも 通る。

## 2. Face ID など での ログイン

### 2a. いますぐ 使える 方法（サーバーの 変更なし）
iPhone・iPad・Mac の「パスワード」（iCloud キーチェーン）に ID と パスワードを 保存して おくと、次から ID の 欄を タップ → Face ID（Touch ID・パスコード）→ ID と パスワードが 入る。生徒・先生・管理者の ログイン画面は、この 自動入力に 対応する 形に なって いる（1. の 直しで 生徒の 画面も そろえた）。組織コードも 自動で 入るので、「Face ID → ログイン」の 2タップで 入れる。

### 2b. 「Face ID で ログイン」ボタン（パスキー）— 作って いない（先生の 判断待ち）
パスワードを 使わずに、顔認証だけで 入る しくみ（WebAuthn・パスキー）。作るには、
- データベースに「端末の かぎ（公開鍵）」を しまう 表を 足す
- 顔認証の 結果（署名）を サーバーで 確かめる プログラム（Supabase の Edge Function）を 足す
- 設定画面に「この 端末で Face ID を 使う」登録と、ログイン画面に ボタンを 足す。先生・管理者が、なくした 端末の かぎを 消せる ように する
が いる。注意：学校の 共有 iPad では、端末の パスコードを 知って いる 人が、その iPad に 登録された 生徒の かぎで 入れて しまう ので、生徒は 自分専用の 端末だけに する のが よい。先生・管理者から 始めるのが おすすめ。
