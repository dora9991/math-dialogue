## 2. 使い方

1. 生徒全体に、記名にすることを伝える（管理職の了承もとる）。
2. 運営の画面（`/solo/ops`）→「📮 ご意見」→ 右上の **「🔒 いまは匿名（記名にする）」** を押す。確認の画面で OK。
3. それ以降に届く意見に **「👤 1123」**（1年1組23番）のような番号が付く。番号にカーソルを当てると、クラス・番号・ニックネーム・ログインID が出る。
4. もどすときは「👤 いまは記名（匿名にもどす）」を押す。

番号の作り方：クラス名の数字だけ ＋ 出席番号2けた（`1-1` の 23番 → `1123`、`1-2` の 5番 → `1205`）。クラスに入っていない生徒は、ニックネーム（無ければログインID）。

## 3. 約束を破らないための決まり

- **スイッチを入れる前の意見は、匿名のまま。** 送り主をそもそも記録していないので、あとから分かるようになることもない。
- **生徒の画面が記名の説明を見せていなかったときは、記録しない。** 生徒の画面は、送るときに「記名の説明を見せていたか」（`p_named`）をいっしょに送る。スイッチが入っているのに `p_named` が true でなければ、サーバーは**記録せずに** `named` を返して止める。生徒の画面は、それを受けて説明を記名用に切りかえ、「下の せつめいを よんでから、もういちど おくってね」と出す（書いた文は残る）。
  - スイッチを入れた直後に、開きっぱなしの古い画面から送られた場合も、これで守られる。
- スイッチを入れても、**ログインしていない送信は、匿名のまま**受けとる（運営の画面では「ログインなし」と出る）。→ **2026-11-18：止めることにした（下の「5b」）。**
- スイッチを切りもどしても、記名のあいだに届いた意見の番号は残る（記名だと伝えて集めたものなので）。

## 4. 変えたこと

### サーバー（本番に入れ済み）

1. `kotsu.orgs.fb_named`（boolean、既定 false）＝スイッチ。
2. `kotsu.feedback.user_id`（生徒のID。アカウントを消したら空になる）。
3. `_org_json` が `fb_named` を返す（`me`・`login` の `org` に入る）。
4. `fb_send` に引数 `p_named boolean default null` を足した（古い 8 引数の形は消した）。
   - スイッチ切：送り主は記録しない（いままでどおり）。
   - スイッチ入・ログインあり・`p_named = true`：送り主を記録。戻り値に `named: true`。回数の上限（1時間5件・1日15件）を、端末ごとに加えて**生徒ごと**にもかける。
   - スイッチ入・ログインあり・`p_named` が true でない：記録せず `{error: "named"}`。
5. `op_fb_list` が、1件ごとに `who`（`code`・`class`・`no`・`nick`・`login`。送り主が無ければ null）と、全体の `named`（スイッチの状態）を返す。
6. `op_fb_named(p_token, p_on)`：スイッチを入れる・切る（運営のトークンだけ。いまは、使っている全部の塾・学校をまとめて切りかえる）。
