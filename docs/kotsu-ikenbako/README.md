# コツコツくん「ご意見ばこ」：だれが送ったかを見られるようにする（引き渡し）

コツコツくんの本体（`src/solo`）はこのリポジトリに無いので、ここには**変更の内容と依頼文**を置きます。本体を持っているセッションが、これを読んで入れます。

サーバー側の変更用 SQL（`ikenbako-migration.sql`）と、その動作テストは、このリポジトリには置いていません（公開リポジトリのため）。先生の手もとにファイルで渡してあります。依頼するときに、いっしょに渡してください。

## 1. いまの作り

- ご意見ばこは、**だれが送ったかを保存しない**作りです。保存しているのは、学校（塾）、種類、気持ち、文、学年、画面、版、端末のしるし（端末ごとの文字列を、元に戻せない形にしたもの）だけです。
- 生徒の画面には、3か所で「**名前は おくられないよ**」「名前は、いっしょに おくられないよ」「（名前は とどかないよ）」と書いてあります。運営の画面にも「（名前は、ありません）」とあります。
- 意見を見られるのは、運営の画面（`/solo/ops`）だけです。先生の画面には、ご意見ばこはありません。

## 2. これまでの意見は、だれのものか分かりません

送り主を保存していないので、これまでの意見（58件）から、送った生徒を確かめることはできません。分かるのは「同じ端末から来た」ということまでです。いたずらに見える送信（文字のない送信が、短い時間に続いたもの）は、1台の端末から来ていました。

ログインの記録と時刻を突き合わせて当たりをつける方法は、とっていません。「名前は おくられないよ」と約束して集めた意見であること、当たりが外れるおそれがあることの、2つが理由です。

## 3. 変えること

**生徒の画面の文と、サーバーの記録を、同時に変えます。** 画面が「名前は おくられないよ」のまま、裏で送り主を記録することはしません。

### サーバー（データベース）

1. 意見の表に、送り主の列（生徒のID）を足す。生徒のアカウントを消したときは、意見は残して送り主だけ空にする。
2. 送るとき、ログインしている生徒なら、送り主を記録する。ログインしていない送信は、いままでどおり送り主なし。
3. 運営の一覧に、送り主（**クラス・番号・ニックネーム・ログインID**）を付けて返す。切りかえ前の意見は「送り主なし」。
4. いたずら対策を足す。
   - 文字のない送信（顔だけ）は、10分に1回まで。
   - 1時間に5件・1日に15件の上限を、端末ごとに加えて、**生徒ごと**にもかける（端末のしるしは生徒の端末が決めるので、変えれば上限をすり抜けられるため）。

本名は、名簿の合言葉で暗号化されていて、サーバーには読める形でありません。運営の画面に出るのは、クラスと番号までです（先生は、番号で分かります）。

保護者や生徒に向けた説明の文（個人情報の扱いなど）に「ご意見ばこは名前が送られない」と書いてあれば、そこも直します。

### 見せ方は2つから選べます

- **いつも出す**（この引き渡しの既定）：一覧に、送り主がそのまま出る。
- **必要なときだけ開く**：ふだんは隠しておき、「だれが書いたか見る」を押したときだけ出す。生徒への文は「ふだんは 名前は 出ないよ。いたずらや、しんぱいなことが あったときは、先生が たしかめるよ。」にする。

ご意見ばこには、ほかの生徒の不正の報告や、数え方への不満など、名前が出ないから書けた意見が入っています。書きにくくなることが心配なら、後者が向いています。サーバーの変更は、どちらでも同じです。

## 4. 切りかえの前に、生徒に伝える

これまで「名前は おくられない」と言ってきたので、切りかえる前に、授業か「💌 先生から」で伝えてください。

- ◯月◯日から、ご意見ばこは、だれが書いたかが先生に分かるようになります。
- これまでに送ってくれた意見は、だれのものか分かりません。調べることもしません。
- コツコツくんを良くするための意見は、これからも歓迎です。

## 5. 確かめたこと

変更用の SQL を、手もとのテスト用データベース（PostgreSQL 16。本番のご意見ばこまわりの写し、データなし）に入れて、19項目を確かめました。すべて通っています。

- 切りかえ前の意見は残り、送り主は空のまま。変更を2回流しても同じ。
- 切りかえ後は、送り主が記録され、一覧に「1-2・15番・ニックネーム」が出る。
- クラスに入っていない生徒は、ニックネームだけが出る。
- ログインなしでも、いままでどおり送れる（送り主なし）。
- 文字のない送信の連打は、2回めから止まる。端末のしるしを変えても止まる。
- 同じ生徒の、1時間に6件めは止まる。端末のしるしを変えても止まる。
- 電話番号などを含む文は、いままでどおり止まる。
- 運営のトークンでなければ、一覧は見られない。
- 生徒のアカウントを消しても、意見は残る。

**確かめていないこと**：本番のデータベースには入れていません。画面（生徒の文、運営の一覧）は、本体が無いので変えていません。
