## 動画ページの時間（`kotsu-ganbari/credit.js`）

見ていた時間を、学習時間（`state.daily[今日].sec`）に足します。上限は、本体の時間の仕組み（`kotsu-time-credit-v1`）と同じ入れ物を共有します。

- 画面が見えていて、動画が再生中か、最後の操作から45秒以内のあいだだけ数える。
- 動画は1日 40分まで（全体 90分の上限にも含まれる）。1つの動画は、1日に長さの2倍まで（くり返して稼げない）。
- 同じ時刻は1回だけ数える（`at` より前は数えない）。アプリのタブと二重にならない。
- 解いた問題数（`daily.n`）・経験値・バッジには触らない。
- 学習の記録が無い（ログインしていない）ときは、何も書かない。

## 確かめたこと

- 動画ページ：全42本をブラウザで動かして、エラーなし（`tools/shots.mjs`）。一覧→再生→最後→「つぎ」の通し確認（`tools/flow-test.mjs`、PC・スマホ）。時間の反映 12項目（`tools/credit-test.mjs`）。
- 答え：全42問を、動画を作った人とは別のエージェントが写真だけから独立に解き直して、**全問一致**。
- 時間の改善：Playwright の 127項目（解答の時間・読む時間・非表示・上限・2タブ・診断／模試の n・c・今日の分・ひとこと・マップ）。
- 通し：ホームのリンク → 動画ページ → 12秒見る → ホームにもどると「⏱ 今日」が増える（実時間、6項目）。

**確かめていないこと**：実機のスマホ・タブレット。ホー先生の授業の外部プレイヤーの実際の動き（この環境から届かない）。

## 注意（時間の改善）

- 動画ページとアプリを**別々のタブで同時に**開いていると、あとから保存したほうが勝つ（もともとの動き）。時間が失われることはあっても、取りすぎにはならない。
- 先生の画面で「時間のわりに解答が少ない」生徒が見えるようにするのが、ずるへの現実的な手当てです（`docs/kotsu-hyoka/README.md` の「残る抜け道」）。
