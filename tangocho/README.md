# 計算単語帳（1分トレーニング）

頭の中で計算できる力を、**1分ずつ**きたえる単語帳。ひとりでも、**ペア学習**でも使える。
画面で使うことも、**紙に印刷**して配ることもできる。数学ラボの別ツール（`ikkan/` などと同じ並び）。

## いちばん簡単な開き方

`tangocho-all-in-one.html`（全部を1つにまとめたファイル）をダウンロードして、ダブルクリックでブラウザで開く。サーバーもビルドも要らない。印刷もできる。
フォルダごと持っているときは、`index.html` を開いてもよい。

すぐ印刷したいときは `pdf/` の PDF：

| ファイル | 中身 |
|---|---|
| `pdf/計算単語帳_ペア用_セット1.pdf` | 全単元・全STEPの「セット1」。**両面印刷（長辺とじ）**で、おもて＝問題（回答者に見せる）／うら＝問題と答え（出題者が見る）。A4を半分に切るとA5のカード |
| `pdf/計算単語帳_ハンドブック_小3-中3.pdf` | ハンドブック（読み物）。先生メモつき |
| `pdf/数学の単語帳_小3-中3.pdf` | **本**（B5・縦・左とじ・216ページ）。読み物＋語彙カード＋1分トレーニング。下の「本（PDF）」を見る |

## 1セットのつくり（20問・1分）

- **前半10問**：そのSTEPのふつうの問題。
- **後半10問**：同じSTEPの中で、**少しだけむずかしい**問題（早く解き終わった子は、そのまま後半へ）。語彙カードは**逆向き**（変換の往復）。
- 1分で何問できたかを数える。**目標（合格ライン）**は、STEPごとに決めてある（`js/units-*.js` の `goal`。生徒の様子で変えてよい）。
- **セット番号**は、同じ番号なら、いつ・どの端末でも同じ問題（紙と画面が一致する）。「セット3ね」と言い合える。🎲で新しい問題も出せる。

## 3つの使い方

| 画面 | 使い方 |
|---|---|
| **1分トレーニング** | 単元 → STEP → セット。「スタート」で、よーい（3秒）→ 60秒。終わると答えが出るので、問題をタップして ○ → ✗ → なし。○の数が得点。最高記録は、このブラウザに残る（ホームの●が合格の印） |
| **ペア学習** | **出題者**は「答えを見る」にして問題を読み上げ、○をつける。**回答者**は問題だけ見て（または耳で聞いて）答える。1分たったら交代。紙なら、ペア用（両面）を印刷する |
| **印刷・配布シート** | ホームの「プリント・配布シート」。形式（ペア用／問題だけ／問題と答え）・単元・STEP・セット番号の範囲をえらんで、印刷する。図つきの単元（面積・体積）は、前半カードと後半カードの2枚にして、同じ紙にそろえる |

📖 **ハンドブック**（`#/book`）：「数学の単語帳 — 計算効率ハンドブック v2」のうち、小3〜中3の部分を読めるページ。各ブロックから、対応する語彙カードへ飛べる。「先生メモを表示」で、先生向けのメモが出る。

## 単元（28）

| まとまり | 単元 | STEP |
|---|---|---|
| 1けたの計算 | たし算／ひき算／かけ算（九九）／わり算（九九のぎゃく） | 各3 |
| 2けたの計算 | たし算／ひき算／かけ算（2けた×1けた）／わり算（2けた÷1けた） | 各3 |
| 分数・小数 | 分数のかけ算／分数のわり算／小数のたし算／小数のひき算（小数第1位・第2位） | 各3 |
| 割合・単位・図形・時間 | 割合／単位の変換／面積（長方形・三角形・平行四辺形・台形・円・半円）／体積（直方体・角柱・円柱・すい体）／時間 | 各3 |
| **語彙カード**（ハンドブック 小3〜中3） | 九九の弱点・キリ番・計算の作法／小数⇔分数 変換表／360の約数感覚／時間と単位の語彙／3.14の段／平方数（11〜25）／べき乗・立方数／平方根の語彙と作法／素数っぽい合成数・倍数判定／有名直角三角形／作法ドリル（÷0.5・代入・分配） | 2〜3 |

「小数の2けた」は、小数第1位（STEP1・2）と、小数第2位のかんたんなもの（STEP3）の両方にした。
ハンドブックの高校基礎・入試編（§4〜§6）は、まだ入れていない（`js/handbook.js` の `later`）。

## 問題の作り方（ふやす・直す）

問題は固定の表ではなく、**「単元・STEP・セット番号」から作る**（乱数の種が決まっているので、同じ番号なら同じ問題）。

```
js/core.js         土台（乱数・分数と小数の道具・makeSet）
js/units-basic.js  1けた・2けたの四則        js/units-frac.js  分数・小数
js/units-misc.js   割合・単位・時間          js/units-geo.js   面積・体積    js/figs.js  図（SVG）
js/units-vocab.js  語彙カード・作法ドリル     js/handbook.js    ハンドブック本文（読み物）
js/app.js          画面                       css/tangocho.css  見た目（紙は実寸mm）
```

単元は `TG.addUnit({ id, cat, name, note, n, goal, steps:[…] })`。各STEPは `gen`（前半）と `gen2`（後半。`name2` がその説明）。
条件に合わないときは `null` を返すと作りなおす。種類のまざるSTEPは `mix: [[重み, 関数], …]`（種類を先に決めてから作りなおすので、割合が偏らない）。
候補の少ないSTEPだけ、`n`（問題数）を小さくできる（語彙カードの「2のべき」「近似値」）。

## 検算（問題を直したら、必ず）

```bash
node tools/verify.cjs        # 単元×STEP×セット1〜40（約6万問）。ブラウザなしで動く
```

- 答えは、**作ったときとは別の道すじ**で確かめる（式は文字から読み直して分数で計算／面積・体積は寸法から／語彙カードは meta から問題文と答えをもう一度つくって見比べる）。
- **前半・後半それぞれの条件**（くり上がり・約分・答えの大きさ・逆向きになっているか など）、約分ずみか、同じ問題がかぶらないか、同じ番号で同じ問題になるか。
- 検算ツール自体も、わざと壊した版で落ちることを確かめてある。

```bash
node tools/bundle.cjs              # → tangocho-all-in-one.html（作り直し。できたファイルは手で直さない）
node tools/bundle.cjs --artifact   # → dist/artifact.html（Claude の Artifact 用。枠なし）
node tools/make-pdf.cjs            # → pdf/*.pdf（ペア用・ハンドブック。Playwright が要る）
```

開発用の起動は `.claude/launch.json` の `tangocho`（`python3 -m http.server 8794 --directory tangocho`）。

## 本（PDF）

`pdf/数学の単語帳_小3-中3.pdf` は、この道具と同じ問題づくりから組んだ**本**（B5・縦・左とじ、216ページ）。表紙 → はじめに・つくりと使い方・もくじ → 序章 → 第1章（小3〜小4）・第2章（小5〜小6）・第3章（中1〜中3）→ 合格チェック表・奥付・裏表紙。各章は「**読む**（ハンドブック）→ **覚える**（語彙カード）→ **計算する**（1分トレーニング）」の順で、1STEPにつきセット1〜2（各20問）を載せる。答えは同じページに**赤字**で印刷してある（赤シートでかくせる）ので、ひとりでも、本を持つ出題者と回答者のペアでも使える。

```bash
bash book/get-fonts.sh       # 書体を用意する（Noto Sans JP・Noto Serif JP・BIZ UD ゴシック。book/fonts/ に置く。git には入れない）
node book/build.cjs          # → book/dist/book.html（ブラウザで開いて見られる）
node book/build.cjs --pdf    # → はみ出しの検査のあと pdf/数学の単語帳_小3-中3.pdf（Playwright が要る）
```

- 著者・発行者・発行日・版・1STEPあたりのセット数は `book/config.json`（空の項目は奥付に出さない）。
- 問題は `js/` の「単元・STEP・セット番号」から作るので、`node tools/verify.cjs` が通っていれば、本の問題と答えも合っている。
- ページ番号（もくじ・「p.13」のような参照）は、組んだときの実際のページから自動で入る。
- 「はじめに」「この本のつくりと使い方」「先生・保護者の方へ」は、ハンドブックの考え方から起こした下書き。自分の言葉に直して使う。
- 印刷用のとんぼ（裁ち落とし）はつけていない。画面で読む・家庭やコピー機で印刷する用。製本所に出すときは、仕上がり寸法 182×257mm を伝えて相談する。

## しくみの注意

- 記録（最高の○の数・先生メモの表示・音）は、**このブラウザの中だけ**。サーバーには送らない。ブラウザが保存を許さないときは、開いているあいだだけ。
- 目標は目安。「1分で何問できるか」は生徒によって大きくちがう。
- 印刷は、ブラウザの印刷から。用紙は A4 縦・余白なし（`@page`）。両面なら「長辺とじ」。
