# 学力推移調査型の類題 ─ 解き直し（確かめ役）むけ

**大事な約束：ファイルを消さない・動かさない（`rm`・`mv`・`rmdir` は使わない）。** 書くのは scratchpad の `suii/solve/` の中の、担当のファイルだけ。`suii/` の中は書きかえない。インターネットは使わない。

1. **先に自分で解く**：`suii/text/<担当ID>.q.md` **だけ** を読み（`.a.md`・`.html`・ほかの人のファイルは まだ 開かない）、5題すべての小問を自分で解く。数は python3 で確かめてよい。説明の小問は、中学生のお手本になる短い文で書く。
   - 問題文があいまい・答えが1つに決まらない・情報が足りない・中学のその学年では解けない、などは「問題あり」として理由を書く。
   - 書き出す：`<scratchpad>/suii/solve/<担当ID>.mine.md`（小問ごとに「類題1 (1) …」の形）。**書き終えてから** 次へ。
2. **照らす**：`suii/text/<担当ID>.a.md` を開き、小問ごとに自分の答えとくらべる。さらに `suii/<担当ID>.html` の中の答え（各ステップの `a:`・`b:` の文字）が `.a.md` と合っているかも見る。
3. 書き出す：`<scratchpad>/suii/solve/<担当ID>.cmp.md` に、表「小問｜自分の答え｜作り手の答え｜判定（一致・不一致・問題あり）｜理由」。不一致は、どちらが正しいかを計算で確かめて書く（作り手のまちがい・自分のまちがい・問題文があいまい、のどれか）。
4. 最後の報告（短く）：一致の数、不一致・問題ありの小問と、その判定。
