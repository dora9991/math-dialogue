# 学力推移調査型の類題（suii/）— 作り手向けの決めごと

数学の黒板（電子黒板に映す授業ページ）に、**学力推移調査でよく出る形の問題（類題）** を、学年×分野ごとに足す。
見本は `katsuyo/ruidai.html`（中1 データの活用 5題）。同じ形・同じ道具で作る。

**大事な約束：ファイルを消さない・動かさない（`rm`・`mv`・`rmdir` は使わない）。** 書くのは、自分の担当の `suii/<担当ID>.html`・`suii/text/<担当ID>.q.md`・`suii/text/<担当ID>.a.md` と、scratchpad の自分の作業フォルダだけ。ほかの人のファイル・ほかのフォルダは書きかえない。インターネットは使わない。

## 1. 1ページの中身

- 1ページ＝**5題**（類題1〜5）。1題＝「問題のステップ（場面・図・小問の一覧）」＋「小問ごとの答えのステップ」。
- 1題に **小問 3〜4つ**。**少なくとも1つは説明する小問**（「正しいか判断し、その理由を説明しなさい」「〜であることを、式を使って説明しなさい」「〜さんの考えのまちがいを説明しなさい」など）。説明の答えは、生徒が書くお手本の文（1〜3文）を `a`・`b`・`sub` に出す。
- 5題は **型（パターン）をすべてかえる**（下の「型の例」から、担当の分野で 5つ以上ちがう型）。
- 難しさは学力推移調査と同じくらい：はじめの小問は読み取り・計算（だれでも取れる）、あとの小問は活用・説明。
- **場面も数値もすべて自作**。学力推移調査・教科書・問題集の問題を写さない（「数字だけ変える」もしない）。
- 学年の範囲：その学年までに習うこと（前の学年の内容は使ってよい）。

## 2. つくり（見本 `katsuyo/ruidai.html` と同じ）

```html
<link rel="stylesheet" href="../kukan/css/board.css">
<script src="../kukan/js/k3.js"></script>
<script src="../katsuyo/js/chart.js"></script>
<script src="../heikou/js/geo.js"></script>   <!-- 図形を かく ときだけ -->
<script>
(function () {
  var C = CH.C;
  /* 類題ごとの データ と、答えの 確かめ（CH.check）を はじめに 書く */
  ...
  K3.run({
    no: '類題', title: '学力推移調査型の類題　中2 関数（5題）', flat: true, hint: '',
    links: [{ href: 'index.html', label: '目次' }],
    steps: [
      { tag: '類題1', bh: '類題1　（場面の名前）', q: '（問題文）', notes: ['(1) …', '(2) …', '(3) …'], draw: function (D) { … } },
      { tag: '類題1', q: '(1) …？', a: '（答え）', sub: '（考え方・式）', dur: 2.5, b: { t: '（板書の まとめ）', col: C.yel }, draw: function (D) { var t = D.ph ? D.t : 0; … } },
      …
    ]
  });
})();
</script>
```

- 道具：`../katsuyo/js/chart.js` の `CH.*`（グラフ・表・数直線・ドット・関数の式 `CH.fn`・双曲線 `CH.hyp`・√ `CH.root` など）、図形は `../heikou/js/geo.js` の `GE.*`（点・線分・角・円・図形・ラベル）。使い方は、見本のページと、その分野の黒板のページ（下の表）を読んで まねる。
- 答えのステップの `draw` は、`D.t`（0→1）で 少しずつ見せる（線が のびる・色が かわる・数が 出る）。答えの前（`D.ph` が 0）は答えを見せない。
- **答えの確かめ（必須）**：表の数・計算の答えは、ページのはじめで計算し直して `CH.check(条件, '類題1')` で照らす（ちがうとコンソールに「答えがちがう」）。むずかしい計算は python3（`sympy`・`fractions`）でも確かめる。
- ことば：中学生が読む。です・ます でなく、問題集の形（「〜を求めなさい」「〜を説明しなさい」）。数字は半角、式は `2x＋3`・`x²`・`√2` のように。

## 3. 文字だけの問題文（ほかの人の解き直し用）

- `suii/text/<担当ID>.q.md`：5題ぶんの **問題文と小問だけ**（答えは書かない）。図・グラフ・表は、**それだけで解けるように** 数・座標・長さ・目もりを文で書く（例「グラフは原点と (4, 6) を通る直線」「長方形 ABCD で AB＝6cm、BC＝8cm」）。
- `suii/text/<担当ID>.a.md`：小問ごとの答え（数・式・説明のお手本）と、確かめ方（python の式など）。

## 4. 検査（必須）

```bash
node suii/tools/check_board.cjs suii/<担当ID>.html --shots <scratchpadの作業フォルダ>/shots
```
- 「OK」になるまで直す（エラー 0、最後のステップまで進む）。
- 写真のうち、各題の問題のステップと、答えのステップを **Read で開いて見る**：字が重ならない・はみ出さない・図が問題文と合っている・答えの前に答えが見えていない。

## 5. 型の例（分野ごと。担当の分野から 5つ以上の ちがう型を）

- **数と式**：きまりを見つける（碁石・マッチ棒・カレンダー → 文字式）／文字式で説明する（連続する数・2けたの数・偶数奇数）／方程式の文章題（過不足・割合・速さ）／計算のまちがいを見つけて説明／料金プランなど日常の比較／数の性質・素因数分解／式の値を工夫して求める
- **関数**：表・式・グラフを結ぶ／2つのプランをグラフで比べる（交点の意味）／図形の上を動く点と面積（変域）／水そう・ろうそく・ばねなど実験のデータから式を作る／グラフから読み取って判断・説明／比例・反比例か一次関数かを見分けて理由を説明
- **図形**：作図の手順と理由／図形の移動（平行・回転・対称）／展開図・投影図・体積・表面積／証明の穴埋め・まちがいの指摘／条件を変えても成り立つか／相似・三平方・円周角を日常の場面（影の長さ・はしご・展望台）で使う
- **データの活用**：ヒストグラム・度数折れ線・累積相対度数の読み取り／代表値の選び方／人数のちがう集団の比較／箱ひげ図とヒストグラムの対応・四分位範囲／確率（さいころ2個・くじ・樹形図）と「同じといえるか」の判断／標本調査（無作為抽出の方法・母集団の推定）／目的に応じた判断の説明

## 6. 最後の報告（短く）

作った5題の型と場面、小問の数、検査の結果、自信が持てない小問（理由）。
