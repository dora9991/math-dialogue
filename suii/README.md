# 学力推移調査型の類題（suii）

数学の黒板（電子黒板に映すページ）に、**学力推移調査でよく出る形の問題** を、学年・分野ごとに足した。
中1〜中3 × 数と式・関数・図形・データの活用 の 12ページ・60題（中1 データの活用は、`katsuyo/ruidai.html` の 5題とあわせて 65題）。場面も数値もすべて自作（学力推移調査・教科書・問題集の問題は写していない）。

- 目次：`index.html`（`python3 suii/tools/build_index.py` で各ページから作る）。総目次（`kokuban/index.html`）の右上から開ける。
- 1題＝問題のステップ（場面・図・小問の一覧）＋小問ごとの答えのステップ。どの題にも「説明する小問」があり、答えではお手本の文を出す。
- 操作は、ほかの黒板と同じ（→・Enter でつぎへ、← でもどる、F で全画面。URL の `#step-N` でそのステップから）。

## 確かめ

- 作る：12人で分担（`AUTHOR.md`）。答えはページの中で計算し直して `CH.check` で照らす（ちがうとコンソールに「答えがちがう」）。
- 検査：`node suii/tools/check_board.cjs suii/*.html`（最後のステップまで進む・エラー 0）。12ページすべて OK。目次の 65本のリンクも、それぞれの題の最初のステップが開くことを確かめた。
- 解き直し：正解を伏せた別の人が、`text/<ID>.q.md`（文字だけの問題）から全小問を解き、`text/<ID>.a.md` とページの答えに照らした（`SOLVER.md`）。**12ページ・223小問すべて一致、問題あり 0**。
