# 学力推移調査型の類題　中1 図形（5題）— 答えと確かめ方

## 類題1
- (1) 5cm より大きく。半径がちょうど 5cm（AB の半分）だと、2つの弧は AB の中点でふれるだけで交点が 1つしかできない。
- (2) A と B から同じ半径の弧をかいた。C は、A を中心とする弧の上にあるので AC は半径に等しく、B を中心とする弧の上にもあるので BC も半径に等しい。だから AC＝BC。
- (3) C も D も A・B から等しいきょりにあるので、直線 CD は線分 AB の垂直二等分線である。垂直二等分線の上の点は線分の両はしから等しいきょりにあるので、その上の点 P も PA＝PB。
- 確かめ：M＝(6, 5)、AB＝10、半径 6 とすると CM＝√(36−25)＝√11。C＝M＋√11×(0.8, 0.6)、D＝M−√11×(0.8, 0.6)。直線 CD と y＝0 の交点 P＝(−2/3, 0)。PA²＝(11/3)²＋81＝850/9、PB²＝(29/3)²＋1＝850/9 で PA＝PB。

## 類題2
- (1) A′(9, 1)（m：x＝5 までが 4、反対側へ 4 進んで x＝9）。
- (2) C″(11, 1)（C′(9, 3) は A′ の真上 2。時計まわり 90°で A′ の右へ 2）。
- (3) 正しくない。△ABC は A→B→C が反時計まわり、△A′B′C′ は A′→B′→C′ が時計まわりで向きが逆（裏返し）になっている。平行移動・回転移動では図形は裏返らないので、回転移動では重ねられない（重ねるには対称移動が必要）。
- 確かめ：T2＝(9,1),(6,1),(9,3)、T3＝(9,1),(9,4),(11,1)。向きの判定 (B−A)×(C−A)：△ABC は＋6、△A′B′C′ は −6、△A″B″C″ は −6。

## 類題3
- (1) 2π×6×(120/360)＝4π　→ 4π m
- (2) π×6²×(120/360)＝12π　→ 12π m²
- (3) π×r²×(1/3)＝27π より r²＝81、r＞0 なので r＝9　→ 9m
- (4) 正しくない。半径 12m のときの面積は π×12²×(1/3)＝48π で、もとの 12π の 4倍。おうぎ形の面積は半径の 2乗に比例するので、半径を 2倍にすると面積は 2²＝4倍になる。
- 確かめ：python3 -c "print(2*6*120/360, 6*6*120/360, 9*9*120/360, 12*12*120/360)" → 4.0 12.0 27.0 48.0（どれも π の係数）

## 類題4
- (1) 4×4×6＝96　→ 96 cm²
- (2) オ（ウの上下左右に ア・カ・イ・エ がつながり、残る オ が向かい側）
- (3) Q と R（P・Q・R が立方体の同じ頂点に集まる。S と T は別の頂点で重なる）
- (4) ｅ と ｆ の 2まいが、組み立てると どちらも「上の面」に重なってしまい、向かい合う面（底）になる 1まいが足りないから。

## 類題5
- (1) π×3²×5＝45π　→ 45π cm³
- (2) 底面 π×3²×2＝18π、側面 (2π×3)×5＝30π、あわせて 48π　→ 48π cm²
- (3) (1/3)×π×5²×6＝50π　→ 50π cm³
- (4) あふれる。B に入る水は 50π cm³、A の容積は 45π cm³ で、50π＞45π なので、50π−45π＝5π cm³ の水があふれる。
