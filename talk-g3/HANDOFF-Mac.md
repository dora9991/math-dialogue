## Mac での手順

> 作業中の Mac の作業ツリー（未コミットの `lesson-navi/` など）には触らず、このブランチを別の場所に取り出してから使う。**`git add -A` はしない。頼まれない限り commit しない。公開（デプロイ）しない。作業中は音を出さない（`--mute-audio`）。VOICEPEAK は同時に1本。`build-play.mjs` は直接実行せず `sh voice-queue.sh` だけ使う。**

```bash
# 1. このブランチの talk-g3/ だけを、一時フォルダに取り出す（作業ツリーは変わらない）
cd "<math-dialogue のリポジトリ>"
git fetch origin claude/eloquent-hypatia-j3tgfl
rm -rf /tmp/g3 && mkdir -p /tmp/g3 && git archive FETCH_HEAD talk-g3 | tar -x -C /tmp/g3

# 2. 台本を scenes/ にコピー（既にあるファイルは上書きしない）
sh /tmp/g3/talk-g3/install-g3.sh "<…>/lesson-navi/video/talk"

# 3. lessons.js に行を足す（ready:false）。/tmp/g3/talk-g3/lessons-g3-rows.txt の行を、既存の行の形と見くらべて貼る
```

4. **1本ずつ検査（音なし）**：`node check.mjs <ID> --shots`（⚠・✗ をなくす）。図のある授業は `python3 sheet.py <ID>` で写真を見て、重なり・はみ出しを直す。直すのは**レイアウトだけ**（図の高さ・左の列の行数・ページ分け `clear:true`・ラベルの位置）。**数学の中身（答え・数値・説明）は変えない。** 直したら `.check/<ID>.say.txt`（読み上げ一覧）も見る。
5. `.check/<ID>.say.txt` で、下の「耳で確認してほしい読み」にあたる行を見て、おかしければ `say:` で読みを直す。
6. 台本が最終になったものから、**章の順に** `sh voice-queue.sh <ID> …`（既存の順番待ちの後ろに並ぶ）。1つの `voice-queue.sh` に複数のIDを渡すと、その順に作られる。
7. 声ができたら `python3 sync_ready.py`（`ready:true` にする）、`node test-play.mjs <ID>`（音なしの通しテスト）。
8. 朝の報告：声ができた授業・FAILED の授業・直したレイアウト・耳確認が必要な点を、短くまとめる。**公開（math-talk へのデプロイ）は、ユーザーが決めてから。**

## 耳で確認してほしい読み

`say:` を付けた行が多い（根号・累乗・記号・英字を含む行はほぼすべて）。付けていない行で、読みがこわれやすそうなもの：

- **根号**：「√」→「ルート」、`2√3`（「2ルート3」）、`√2/2`、`3√2` の「3」と「ルート」の続き、`√(a²)`、`(√3)²`、`√a×√b＝√(ab)`、「かっこ…かっことじ」（`g3ch7-o02`・`o05`・`o08`）、`√` の中の分数。
- **累乗・式**：`x²`（エックスの2乗）、`(x＋y)²` と `x²＋y²` の読み分け、`a²−b²`、`(a＋b)(a−b)` の読み（かっこを続けて読む）、`−x²` と `(−x)²`、`y＝ax²`、「ax²」の「エーエックスにじょう」。
- **記号**：「∽」→「そうじ」、「△ABC∽△DEF」、「∠」→「かく」、「⌒」（弧）、「⊥」→「垂直」、「≠」→「イコールではない」、「：」→「たい」（比 `a：b`、`1：√3：2` の読み）、不等号を「しょうなり／だいなり」と読ませた所（`g3ch7-o02`・`o10`）、「A′」（エーダッシュ。`g3ch7-n02` の「エーエーダッシュ」）。
- **言葉**：「平方根」「根号」「有理化」「分母の有理化」「因数分解」「乗法公式」「共通因数」「解の公式」、「放物線」「変域」「変化の割合」「円周角」「中心角」「弦」「接線」「接点」「相似比」「面積比」「体積比」「標本」「母集団」「無作為」「全数調査」「標本調査」、「三平方」「斜辺」「対角線」「斜高」。
- **数の読み**：`g3ch5` の「1：2」「2：3」の比、「√2」「√3」の近似値（1.41、1.73）、`g3ch8` の「母平均」「推定」の数値、「約1200個」のような概数。
- 単独の英大文字1字（A、B、P、Q）、小文字 a・b・c・x・y・t・r、`g3ch2-o10`・`n03` の文字。
