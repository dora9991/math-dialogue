## 3. ことばの書き方
- 字幕（`sub`）は、ふつうの日本語で書く。**読み上げは字幕から自動でつくる**。式は `y＝2x＋1`、分数は `[[2/3]]`（→「3分の2」）、累乗は `x²`（`x^2`でも）、単位は `cm²` `cm³`、角度は `60°`、円周率は `π`、三角形は `△ABC`、プライムは `A′`（U+2032）、不等号は `＜ ＞ ≦ ≧`。
- 負の数：数や文字の前の `−` は「マイナス」、2つの数のあいだの `−` は「ひく」と読む。まぎらわしい所は `say:` で上書き。
- 読みがおかしくなりそうな所（長い式・特殊な語・固有名詞）は、`T('字幕…', { say: 'ひらがなまじりの読み…' })` で読みを直接書く。`.check/<ID>.say.txt` を読んで、読みを確かめる。数字は `say` の中でも数字のままでよい。小数点は「3.2」と書けば「3点に」と読む。
- JS の文字列は `'…'`。中に `'`（半角アポストロフィ）を入れない（`′` を使う）。字幕の中の `{{…}}` は色つき（答え）、`**…**` は太字。
- 「ポンタ」「ホー先生」の名前は、そのまま書く。

## 4. 黒板（`add` と `draw`）
- `add: [要素…]`：そのステップで黒板に足す物。`col: 0` が左（めあて・メモ・式）、`col: 1` が右（図・表）。
  - `{ col:0, type:'box', color:'y'|'p'|'b'|'g', size:'xs'|'sm'|'lg', label:'めあて', text:'…\n…', t:4.0 }`（枠つき）／`{ col:0, type:'text', size:'xs', label:'式', text:'…', t:3.0 }`（枠なし）。`t` はその物が出る長さの目安（秒）。左の列は **10行ていどまで**（左下のホー先生の頭より上）。
  - 表：`tbl([[…],[…]], { style:'font-size:38px; align-self:center; margin-top:10px', t:1.0 })`（先頭の行と列が黄色の見出し）。セルの `{{…}}` は色つき。
  - 図：`FIG('id', [x0,y0,x1,y1], w, h, [], { col:1, plane:[…] })` を `Object.assign(f1,{prims:[]})` で `add` する。**図はページごとに別**。
- `draw: [{ fig:'id', items:[…] }]`：図に描き足す物（アニメで描かれる）。`temp:true` を付けた物は、そのステップだけ表示される。
- 図の部品（`talk.js` の primitives）：`{k:'seg',a,b,c,wd,dash,arrow}`／`{k:'segs',list:[[a,b],…]}`／`{k:'poly',pts,close,c,fill,alpha,wd,dash}`（close なしは折れ線）／`{k:'pt',at,name,dir,off,c,r}`（点と名前）／`{k:'pts',list,c,r}`／`{k:'label',at,text,c,size,anchor,dx,dy}`／`{k:'ell',o,rx,ry,a1,a2,c,wd,dash,fill,alpha}`（円・弧・だ円。角度は反時計まわり）／`{k:'right',at,u,v,s}`（直角の印）／`{k:'plane',lab,size}`（座標軸と目もり）／`{k:'fn',a,b,c,label,lat,lanchor,size}`（直線 y＝ax＋b）。色は `w`（白）`y`（黄）`p`（桃）`b`（青）`g`（緑）`d`（うす）。
  - ショートカット（`KL.`）：`FIG` `lbl(x,y,text,o)` `rect(x0,y0,x1,y1,o)` `poly(pts,o)` `seg(a,b,o)` `arc(x,y,r,a1,a2,o)` `pt(x,y,name,dir,o)` `circle` `sector(x,y,r,a1,a2,o)` `arrow(a,b,o)` `cells` `hist({x0,y0,cw,hu,freqs,bounds,ymax,ystep,…})`（ヒストグラム）`tbl` と立体 `S3.*`。
  - 図のラベルの文字は `{{ }}` や `[[1/2]]` が使えない（普通の文字だけ）。分数は `1/2` と書く。
- **サイズ**：図の `w×h` と `view` の縦横比をそろえる（そろっていないと、はみ出しや小さい図になる）。図だけなら `1180×600` まで。表の下に図を置くときは図の高さを `480` くらいに。ホー先生（左下）・ポンタ（右下）・字幕（下）に隠れないよう、図は黒板の上 3/4 に。
- 分岐（`Q` の誤答の解説）の中の `draw` は、その選択肢を選んだときだけ出る。後ろの共通のステップで必要な図は、共通のステップで描く。
- ページを変える：`T('…', { clear: true, cols: [0.34, 0.66], part: '…', add: […] })`。ページごとに左右の列・図がリセットされる。

## 5. 授業の種類ごとの書き方
- **探**（発見）：身近な場面→予想（4択）→確かめ→きまりを言葉にする。
- **例**（例題）：問題→ホー先生が1つずつ解く→ポンタがつまずく→類題を4択で。
- **遊**（ゲーム）：クイズ番組・ゲーム仕立て。ポンタが挑戦者。4択を連続で。
- **練**（練習）：まちがい探し・速さ・正確さ。ポンタの誤答を直す役に。
- **活**（活用）：身のまわりの場面の問題を、図・表・式で解く。「根拠を言う」。
- **確**（まとめ）：その章のまとめクイズ。ことば・公式・典型問題を4択で総ざらい。
- **応用問題**（ID が `ch◯-o01〜o10`）：その章の重要な考え方を1つ選び、自作の1問を、問いを分けて（3〜5問の4択で）解説。**入試レベル**（`ch◯-n01〜n03`）は、2つの考え方を組み合わせる少しむずかしい自作問題。誤答の理由を丁寧に。
- 見本は下の「見本」の節。問題の一覧は `problems/g2-ouyou.md`。

- ID・ラベル：授業の解説 `g2u4-…`〜`g2u7-…`、応用・入試 `g2ch4-…`〜`g2ch7-…`。`unit` は `中2　平行と合同`・`中2　三角形と四角形`・`中2　確率`・`中2　データの比較`。`kick` などは、一覧 JSON（`problems/unit-lessons-g2.json`・`problems/g2-problems.json`）の値をそのまま使う。
- **範囲（先取りしない）**：4章は 相似・三平方の定理・円周角を使わない。5章は 4章までの内容（平行線の性質・合同条件・証明）を使ってよい。6章は 順列・組合せの公式（nPr・nCr）を使わず、樹形図と表で数える。7章は 四分位数・箱ひげ図まで（標準偏差・分散は使わない）。連立方程式・一次関数・式の計算は学習済みでよい。
- **図形の図（4・5章）**：`FIG('g', [x0,y0,x1,y1], w, h, [], { col: 1 })`（`view` の縦横比＝`w:h`）。三角形・四角形は `{ k:'poly', pts:[[x,y],…], close:true, c:'w', wd:3, fill:'y', alpha:0.12 }`、辺は `{ k:'seg', a, b, c, wd, dash }`、点と名前は `{ k:'pt', at:[x,y], name:'A', dir:[-0.7,0.7], off:24, c:'y' }`（`dir` は名前を置く向き）、角の印は `{ k:'ell', o:[x,y], rx:0.5, ry:0.5, a1:20, a2:75, c:'p', wd:3 }`（角度は度・反時計まわり。円弧）か `KL.arc(x, y, r, a1, a2, o)`、直角の印は `{ k:'right', at:[x,y], u:[1,0], v:[0,1], s:16 }`、角の大きさの文字は `{ k:'label', at:[x,y], text:'70°', c:'p', size:26 }`。等しい長さの印（辺に小さな短い線）や平行の印（辺に `>`）は、**自分の台本の中で `seg` や `poly` の小さな部品として描く関数を定義して使う**（`tick` のような部品はない）。色の使い分け：等しい辺・角は同じ色で。
- **図の正確さ**：図の点の座標は、**python で計算して、図が数学的に正しくなるようにする**（平行な2直線は本当に平行、「70°」と書いた角は本当に約70°、二等辺三角形の2辺は本当に等しい、平行四辺形は本当に平行四辺形）。座標の計算スクリプトを `/tmp/claude-0/…/scratchpad/g2/…` に置き、図の点が `view` の中にあることも確かめる。
- **記号の読み**（`say:` で読みを書く）：`△ABC` →「さんかく エービーシー」、`≡` →「合同」、`∠ABC` →「かく エービーシー」、`AB∥CD` →「エービー へいこう シーディー」、`⊥` →「垂直」、`°` →「度」、`＝`→「イコール」。
- **証明の黒板（4章第11〜14時・5章・各章の入試）**：「仮定」「結論」を box で示し、「証明」は1行ずつ（根拠をそえて）左の列に足す。1ページ10行まで。長いときは `clear:true` でページを分ける。書式は、`△ABC と △DEF において`／`仮定より　AB＝DE　…①`／`対頂角は等しいから　∠AOC＝∠BOD　…②`／`①②③より、2組の辺とその間の角が、それぞれ等しいから　△ABC≡△DEF`（番号の丸数字は、字幕では「①」と書いてよいが、読み上げは `say:` で「いち」「に」にする）。合同条件の言い方：「3組の辺がそれぞれ等しい」「2組の辺とその間の角がそれぞれ等しい」「1組の辺とその両端の角がそれぞれ等しい」、直角三角形は「斜辺と他の1辺がそれぞれ等しい」「斜辺と1つの鋭角がそれぞれ等しい」。4択では、証明の「穴うめ」（根拠・合同条件・次の1行を選ぶ）を使い、選択肢は20字以内にする。「例を確かめただけでは証明にならない」「図から見た目で言うのは根拠にならない」を、ポンタのボケで気づかせる。
- **確率（6章）**：樹形図・表は、`tbl`（表）か、`seg`・`pt`・`lbl` で描く枝分かれで見せる。確率は分数 `[[a/b]]`（数／数）で。「同様に確からしい」を、ことばで確かめる。「すべての場合の数」を先に数えてから、あてはまる場合を数える。さいころの表（6×6）は `tbl` で。
- **データ（7章）**：四分位数の求め方は、データを小さい順にならべ、中央値で前半・後半に分け、前半の中央値＝第1四分位数、後半の中央値＝第3四分位数（個数が奇数のときは、中央値を前半・後半に入れない）。箱ひげ図は、数直線（`seg` と目もりの `lbl`）の上に、`rect`（箱）・`seg`（ひげ・中央値の線）・`lbl`（数）で自分で描く。ヒストグラムも `rect` で描く（`hist` の部品は、引数がわからなければ使わない）。データの数値は、台本の中に配列で書き、**python で中央値・四分位数・平均を計算して台本の数と一致させる**。
- **4択の正解の位置**：1番目に偏らないよう、**正解の位置を問ごとに変える**（あとで機械でも均等にするが、最初から偏らせない）。選択肢が数のときは、小さい順か大きい順にならべる。**正解以外の選択肢が、別の見方では正しい文になっていないか**（たとえば「9の倍数」と「99の倍数」の両方を選択肢に入れると、どちらも正しい、のような）を、必ず確かめる。


## 9. 中3（1〜8章）のための補足
- **ID・ラベル**：授業の解説 `g3u<章>-<時>`（例 `g3u2-05`）、応用 `g3ch<章>-o01〜o10`、入試レベル `g3ch<章>-n01〜n03`。`KL.lesson` の `id`・`unit`（例 `中3　平方根`）・`kick`（例 `3年2章　第5時`）・`title` は、一覧 JSON（`problems/unit-lessons-g3.json`・`problems/g3-problems.json`）の値をそのまま使う。章：1 式の展開と因数分解／2 平方根／3 二次方程式／4 関数 y＝ax²／5 相似な図形／6 円／7 三平方の定理／8 標本調査。
- **入試レベル（`n01〜n03`）は、公立高校入試で実際に出る水準の、自作の問題**（実際の入試問題をうつさない）。2つの考え方を組み合わせる、図と式・関数と図形を行き来する、など。応用（`o01〜o10`）は1つの考え方を、問いを分けて丁寧に。
- **範囲**：中3の内容だけ。**高校の内容は使わない**（三角比 sin・cos・tan、二次関数の一般形 y＝ax²＋bx＋c、判別式、解と係数の関係、方べきの定理、相加相乗平均、数列、順列・組合せの公式、微分・積分）。章の順に学ぶので、**第k時が、まだ習っていない内容を前提にしない**（各章が前提にしてよいのは、中2までと、そのまえの章）。1章：中2まで／2章：1章まで／3章：1・2章まで（平方根・展開・因数分解）／4章：3章まで／5章：4章まで（比例式・平行線の性質・合同）／6章：5章まで（相似を使ってよい）／7章：5・6章まで（相似・円を使ってよい）／8章：全部。**三平方の定理は7章**（それまでの章で使わない）。**円周角は6章**（それまでの章で使わない）。
- **字幕・読み上げ**：根号は `√3`、`√（12n）`（かっこつき）、`2√3`、分数は `[[a/b]]`（数／数）。2乗は `x²`、3乗は `x³`、比は `AD：DB`（全角コロン）、相似は `△ABC∽△DEF`、円周率は `π`、角は `∠ABC`。**`say:` に書く読み**：`√`→「ルート」（`√3`→「ルート3」、`2√3`→「2ルート3」、`√（12n）`→「ルート、12エヌ」）、`²`→「の2乗」、`³`→「の3乗」、`π`→「パイ」、`∽`→「相似」（「そうじ」）、`：`→「たい」（`2：3`→「2たい3」）、`∠`→「かく」、`△`→「さんかく」、`≡`→「合同」、`∥`→「へいこう」、`⊥`→「垂直」、`°`→「度」。**根号・累乗・比・記号・英字を含む行は、すべて `say:` を付ける**（読みがこわれやすい）。`say:` の中の数字は字幕と同じにする（`node say-check.mjs <ID>` が数のずれを見つける）。
- **関数 y＝ax²（4章）の図**：座標平面は中2の3章と同じ（`FIG(…, { col: 1, plane: […] })` と `{ k:'plane' }`）。**放物線は `fn`（直線専用）では描けない**ので、`{ k:'poly', pts:[[x, a*x*x], …], c:'y', wd:3.6 }`（`close` なし＝折れ線）に、**x を 0.25 刻みなどで python で計算した点を並べて**描く（点は `view` と `plane` の範囲内に切る）。直線は `fn`。交点・頂点の座標は目もりの上にのる数値にする。ラベルは `{ k:'label', at, text:'y＝x²' }`。
- **円（6章ほか）の図**：円は `{ k:'ell', o:[x,y], rx:r, ry:r, c:'w', wd:3 }`（全周）、弧は `a1`・`a2`（度・反時計まわり）。円周上の点は、中心と角度から python で座標を計算し、`pt` で名前をつける。円周角・中心角は `seg` で結び、角の弧は小さな `ell`。接線・直径・弦は `seg`。
- **立体（5章の相似な立体、7章）の図**：自分の台本の中に、斜投影の関数（`proj(x, y, z)`＝`[x＋0.5·y·cos45°, z＋0.5·y·sin45°]` など）を定義し、`poly`・`seg` で描く（**見えない辺は `dash: true`**）。`S3.*` は、見本 `example-kukan-15.js.verbatim.js` の使い方どおりなら使ってよいが、**寸法が数値とずれるので、辺の長さを問う問題では自作の投影で描く**。展開図（円錐のおうぎ形など）は `ell`（弧）と `seg` で。
- **証明の黒板（5章・6章・各章の入試）**：中2版の「8」の書式（仮定・結論の box、証明を1行ずつ根拠つき、1ページ10行まで、`clear:true`）。相似の証明の書式：`△ABC と △ADE において`／`共通な角だから　∠A＝∠A　…①`／`平行線の同位角は等しいから　∠ABC＝∠ADE　…②`／`①②より、2組の角がそれぞれ等しいから　△ABC∽△ADE`。相似条件の言い方：「3組の辺の比がすべて等しい」「2組の辺の比とその間の角がそれぞれ等しい」「2組の角がそれぞれ等しい」。円周角の定理の使い方：「同じ弧に対する円周角は等しいから」「半円の弧に対する円周角は90°だから」。
- **標本調査（8章）**：表と数値の台本。乱数表・標本の数値は、python で乱数の種を固定して作り、台本の数と一致させる。「標本の割合を、母集団の割合とみなす」「推定する」「だいたい」を使い、断定しない。標識再捕獲・袋の玉は、比例式 `a：b＝c：d` で。
- **数学の検算**：平方根・二次方程式の解・放物線と直線の交点・面積・円の角・三平方の長さは、`sympy` で検算する（`nsimplify`・`solve`・`sqrt` が使える）。図の座標は、台本を実行して取り出し、辺の長さ・角・平行・面積を python で再計算して、本文の数値と合わせる。二次方程式の文章題は、**解が問題の条件に合うか**（正・整数・範囲内）を必ず確かめる。
- **4択の正解の位置**：問ごとに変える（1番目に偏らせない）。正解以外の選択肢が別の見方で正しくならないように注意（約分違いの同値、`√8` と `2√2` のように同じ数の別の書き方、「2x（x＋1）」と「2x²＋2x」など）。数の選択肢は小さい順か大きい順に。
