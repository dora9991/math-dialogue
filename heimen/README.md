# 平面図形の黒板（heimen）

電子黒板に映して、**図やグラフを動かしながら**考える「平面図形」（中1）の授業ページ。1時間＝1ページ、15時間ぶん。
授業の流れは ikkan の `ikkan/data/lesson_heimen_NN.js` とそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。考えようは答えを出さず、スライダーなどの「調べる道具」だけ。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。全単元の総目次は `../kokuban/index.html`。
画面の土台は `../kukan/js/k3.js`・`../kukan/css/board.css`・`../katsuyo/js/chart.js`・`../heikou/js/geo.js` を使うので、公開するときはいっしょに置く。

## 15時間

| 時間 | ページ | 題 |
|---|---|---|
| 第1時 | `01.html` | 直線や角を、記号を使って表そう |
| 第2時 | `02.html` | 図形を、形と大きさを変えずに動かそう |
| 第3時 | `03.html` | 移動した図形をかいて、対応する点の関係を調べよう |
| 第4時 | `04.html` | 移動を組み合わせて、図形をぴったり重ねよう |
| 第5時 | `05.html` | 2点から等しいきょりにある点を、すべて見つけよう |
| 第6時 | `06.html` | 角の2辺から等しいきょりにある点を見つけよう |
| 第7時 | `07.html` | 直線に垂直な直線を、作図しよう |
| 第8時 | `08.html` | 作図を組み合わせて、条件に合う点を見つけよう |
| 第9時 | `09.html` | 定規とコンパスで、いろいろな大きさの角をつくろう |
| 第10時 | `10.html` | 円と直線の関係を調べよう |
| 第11時 | `11.html` | おうぎ形の弧の長さと面積は、どう求められるだろう |
| 第12時 | `12.html` | π を使って、おうぎ形の計算をしよう |
| 第13時 | `13.html` | 弧の長さや面積から、中心角を求めよう |
| 第14時 | `14.html` | 図形を動かして、面積や長さをくふうして求めよう |
| 第15時 | `15.html` | 「平面図形」で学んだことを、整理して確かめよう |

## 操作

空間図形の黒板（`../kukan/README.md`）と同じ：→・Enter・Space でつぎへ（問い → 答え → 次の問い）、← でもどる、R でもう一度動かす、F で全画面。下にスライダーが出る場面は、手で値を変えられる。URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる。

## つくり（作り手向け）

- 1ページ＝1つの HTML（外部ライブラリなし）。`K3.run({ flat: true, steps: [...] })` を呼ぶだけ。ステップの書き方は `../kukan/README.md`。
- グラフ・表・数直線・カード・タイルは `../katsuyo/js/chart.js`（CH.*）。分数は `CH.fr`（文の中の [1/2]）・`CH.frac`（図の中）、√ は `CH.root`、負の数は `CH.mnum`。
- 図形は `../heikou/js/geo.js`（GE.*）：座標から図を描く（GE.fit・GE.seg・GE.arc・GE.right・GE.circ・GE.labels）。長さ・角は座標から計算し直して確かめる（GE.verify）。
- 答えや表の数は、ページの中で計算し直して照らし合わせている（`CH.check`）。ちがうと、ブラウザのコンソールに「答えがちがう：…」と出る。
- × と ÷ は、黒板の字体だと x と見分けにくいので、土台が自動で見分けやすい字体にする。
- データ・場面は ikkan の数値か、自作（各ページの頭のコメントに書いてある）。
