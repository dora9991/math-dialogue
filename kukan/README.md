# 空間図形の黒板（kukan）

電子黒板に映して、**図を動かしながら**考える空間図形（中1）の授業ページ。1時間＝1ページ、15時間ぶん。
`seitamentai/`（正多面体は、なぜ5種類？）と同じ黒板の画面で、授業の流れは ikkan の「空間図形（新しい形）」のワークシートとそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。公開先：https://dora9991.github.io/math-dialogue/kukan/

## 15時間の中身

| 時間 | ページ | 図の動き（おもなもの） |
|---|---|---|
| 第1時 | `01.html` 立体の仲間分け | 6つの立体が回る。底面の数・曲面の有無で、うすくなって分かれる。五角柱の辺を、底面と側面に分けて数える。考えようは、角柱・角錐と底面の辺の数をスライダーで変えて、頂点・辺・面を数える |
| 第2時 | `../seitamentai/` | 正多面体は、なぜ5種類？／辺・頂点の数え方（別のページ） |
| 第3時 | `03.html` 2直線の位置関係 | 辺 AB と交わる・平行・ねじれの位置の辺に色。AB をふくむ面を扉のように回し、ねじれの位置の辺は面を1点でつきぬけるだけ。チャレンジは 12×4÷2＝24 |
| 第4時 | `04.html` 直線と平面・平面と平面 | 面を広げて、辺を点線でのばす。面上の直線を回しても AE とはいつも 90°。点 P を動かして、垂線がいちばん短い |
| 第5時 | `05.html` 回転体 | コインが積み重なって円柱、長方形が回って円柱。三角形・半円・台形を回す（母線に色）。考えようは、直角三角形の斜辺を軸に回す（スライダーで軸と角度）。チャレンジは軸からはなれた長方形 → まん中があいた立体と切り口 |
| 第6時 | `06.html` 投影図 | 正面・真上から見ると形が変わる。立体のうしろと下のスクリーンに、平行な光で立面図・平面図を映し、下のスクリーンをたおすと投影図。例題は投影図から立体が起き上がる |
| 第7時 | `07.html` 展開図 | 缶のラベルが開いて長方形（横＝円周 6π）。円錐の側面が開いておうぎ形（中心角 120°）。考えようは、直方体の面を開いて、A から G へのひもの長さをくらべる道具 |
| 第8時 | `08.html` 立体当て | ヒントを出すたびに、あてはまらない立体がうすくなる。真上・正面から見たときの形も |
| 第9時 | `09.html` 柱の表面積 | 三角柱が開いて展開図（面積 18・24・30・6・6）。円柱が開いて 80π＋16π×2。考えようは、高さを変えると展開図がのびる。チャレンジは穴のあいた立方体 |
| 第10時 | `10.html` 錐の表面積 | 正四角錐が開く。円錐のおうぎ形は円の 1/3。チャレンジは、円錐が頂点 O のまわりをころがって 4回転 |
| 第11時 | `11.html` 錐の体積 | 円錐の容器の水を、円柱に 3回うつす。考えようは、紙を重ねた角錐をかたむける。チャレンジは立方体から角の三角錐を切りとる |
| 第12時 | `12.html` 球 | 半球の容器の水を、円柱に 3回うつす（球は円柱の 2/3）。円柱の側面を開いて、球の表面積 4πr² |
| 第13時 | `13.html` 表面積と体積の練習 | 円錐の半径・高さ・母線を、どの式に使うかで色分け。円柱＋半球（はり合わせた面はふくめない）。チャレンジは水そうにおもりをしずめる |
| 第14時 | `14.html` 見積もり | 砂の山に円錐、ペットボトルに円柱のモデルを重ねる。考えようは、紙コップを何cmの円柱とみなすか（スライダー）。チャレンジはたらい＝大きい円錐−小さい円錐 |
| 第15時 | `15.html` まとめ | 1つの円錐を、動かす・方向を決めて見る・切り開く・面で分ける の4つの見方で。チャレンジは立方体から三角錐を4つ切りとる |

## 操作

| 操作 | キー | 画面 |
|---|---|---|
| つぎへ（問い → 答え → 次の問い） | → ・ Enter ・ Space ・ PageDown | つぎへ ▶（動いている途中なら、まず最後まで進める） |
| もどる | ← ・ PageUp | ◀ もどる |
| もう一度動かす | R | ↻ もう一度 |
| 全画面 | F | 全画面 |
| 図を回す | — | ドラッグ。ダブルクリックで元の向き |
| 手で動かす | — | 下のスライダー（場面によって出る） |

URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる（もどると消える）。考えようの答えは出さない（調べる道具だけ）。

## つくり（作り手向け）

- `js/k3.js` が土台（画面・ステップの進め方・カメラ・描く道具）。`css/board.css` が見た目。授業のページは `K3.run({ steps: [...] })` を呼ぶだけ。外部ライブラリなし（canvas 2D に自前で透視投影）。
- ステップは `{ tag, q, a, sub, dur, b, view, model, sliders, draw(D) }`。`a` があると「問い → 答え」の2段。`b` が板書の1行。`draw(D)` で図を描く（`D.t` は答えの動きの進み 0→1、`D.V` はスライダーの値）。
- 立体：`K3.prism`・`K3.pyramid`・`K3.revolve`（断面を回す。円柱・円錐・球・円錐台も）・`K3.polyhedron`。`D.mesh(m, o)` で描く（見えない辺は点線）。
- 展開：`K3.unfold`（多面体の面を、となりの面との辺のまわりに回す）、`K3.cylNet`（円柱の側面を、手前の線を動かさずに平らに）、`K3.coneNet`（円錐の側面を、手前の母線にそって接する平面まで開く）。開いたあとの長さ・角・面積が正しいことは、数で確かめてある（円柱の横＝2πr、円錐の中心角、展開図の面積の和＝表面積）。
- 投影：`K3.viewEdges`（ある向きから平行に見たときの、見える辺・見えない辺）。
- 辺・面の仲間分けときょり（第3・4時）、面積（第9・10時）、面・辺・頂点の数（第1時）は、図の形から計算して、ページに書いた答えと照らし合わせている。ちがうと、ブラウザのコンソールに「答えがちがう」などと出る。
