# 空間図形の黒板（kukan）

電子黒板に映して、**図を動かしながら**考える空間図形（中1）の授業ページ。1時間＝1ページ。
`seitamentai/`（正多面体は、なぜ5種類？）と同じ黒板の画面で、授業の流れは ikkan の「空間図形（新しい形）」のワークシートとそろえてある。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。できた時間だけ押せる。

| 時間 | ページ | 中身 |
|---|---|---|
| 第2時 | `../seitamentai/index.html`・`kazoekata.html` | 正多面体は、なぜ5種類？／辺・頂点の数え方 |
| 第3時 | `03.html`（11ステップ） | 空間にある2つの直線の位置関係 |
| 第4時 | `04.html`（12ステップ） | 直線と平面、平面と平面の位置関係 |

## 第3時の流れ（直方体 AB＝4・AD＝3・AE＝2）

| 場面 | 発問 | 図の動き |
|---|---|---|
| 今日の問い | 辺 AB と、ほかの 11本の辺を仲間分けしよう | 辺 AB だけ光る |
| | 交わる辺は？ → AD、AE、BC、BF | 1本ずつ黄色に。交わる点 A・B |
| | 平行な辺は？ → DC、EF、HG | AB と同じ平面（底面・手前・ななめ）を順に出して、その上の辺が青く |
| | のこりの4本は？ → どちらでもない | AB と4本を、点線でのばしても交わらない |
| ことば | 3種類 → 交わる・平行・ねじれの位置 | 色分けした直方体が回る |
| | ねじれの位置の2直線は、同じ平面上にある？ → ない | AB をふくむ面を、扉のように回す（スライダーでも）。平行な辺は面の上にのるが、ねじれの位置の辺は1点でつきぬけるだけ |
| 例題 | 辺 BC と平行・垂直に交わる・ねじれの位置 | 直角のしるし。ねじれの位置は「交わる辺を消す → 平行な辺を消す → のこり」 |
| 考えよう | 教室の中のねじれの位置（答えは出さない） | 教室に見立てた直方体と黒板 |
| チャレンジ | 立方体で、ねじれの位置の組は何通り？ → 24 | 12本を1本ずつ、ねじれの4本と一緒に → 12×4＝48 → 同じ組を2回 → 48÷2 |

## 第4時の流れ（同じ直方体）

| 場面 | 発問 | 図の動き |
|---|---|---|
| 今日の問い | 面 ABCD と、12本の辺を仲間分けしよう | 面 ABCD に色 |
| | 面の上・1点で交わる・交わらない | 面を広げた平面を出し、辺を点線でのばす |
| ことば | 直線と平面の位置関係 → ある・交わる・平行 | 色分けした直方体が回る |
| | 辺 AE と面 ABCD は垂直？ | 点 A を通る面上の直線を回しても、いつも 90°（スライダーでも） |
| | 2つの平面 → 平行・交わる（垂直） | 面 EFGH、面 ABFE を順に出す |
| | 点 D と面 ABFE のきょりは？ → DA ＝ 3cm | 面上の点 P を動かすと、DP がいちばん短くなるのは P＝A のとき |
| 例題 | 面 ABFE と平行な辺・垂直な辺・平行な面 | 1本ずつ色。直角のしるし |
| 考えよう | ℓ ⊥ P を確かめるには、P 上の直線を何本調べればよい？（答えは出さない） | P 上の直線（1〜3本）と、ℓ のかたむき・たおす向きをスライダーで変えて、角度を見る |

## 操作

| 操作 | キー | 画面 |
|---|---|---|
| つぎへ（問い → 答え → 次の問い） | → ・ Enter ・ Space ・ PageDown | つぎへ ▶（動いている途中なら、まず最後まで進める） |
| もどる | ← ・ PageUp | ◀ もどる |
| もう一度動かす | R | ↻ もう一度 |
| 全画面 | F | 全画面 |
| 図を回す | — | ドラッグ。ダブルクリックで元の向き |
| 手で動かす | — | 下のスライダー（場面によって出る） |

URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる（もどると消える）。

## つくり（作り手向け）

- `js/k3.js` が土台（画面・ステップの進め方・カメラ・直方体と位置関係の計算・描く道具）。`css/board.css` が見た目。授業のページは `K3.run({ steps: [...] })` を呼ぶだけ。
- ステップは `{ tag, q, a, sub, dur, b, draw(D) }`。`a` があると「問い → 答え」の2段。`b` が板書の1行。`draw(D)` で図を描く（`D.box`・`D.seg`・`D.poly`・`D.label`・`D.right` など。`D.t` は答えの動きの進み 0→1、`D.V` はスライダーの値）。
- 外部ライブラリなし。canvas 2D に自前で透視投影。字は Google Fonts（Klee One・BIZ UDPゴシック）、つながらないときは端末の丸ゴシック。
- 辺・面の仲間分けと、きょりの答えは、直方体の座標から計算している（`K3.group`・`K3.edgesBy`・`K3.facesBy`・`K3.dist`）。ページに書いた答えと計算がちがうと、ブラウザのコンソールに「答えがちがう」と出る。
