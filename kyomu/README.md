# 教務・時間割（週行事・月行事・年間行事・時数）

教務の時間割づくりを、ブラウザだけでできるようにしたもの。
いま Excel でつくっている「週行事（週案）」と**同じ見た目**のシートの上で、入れ替え・行事・時数をまとめて扱う。

- **公開しないで使う**：`kyomu-all-in-one.html` を自分のパソコンに保存して、ダブルクリックで開く。インターネットにつながっていなくても動く。
- **データはそのブラウザの中だけ**（localStorage）。どこにも送らない。ブラウザの「閲覧データを削除」で消えるので、上の「バックアップ」でときどき JSON に書き出す（別のパソコンへ移すときも、この JSON を「バックアップから戻す」で読みこむ）。
- このフォルダは GitHub Pages には出ない（`npm run deploy` は `public/` とトップの React アプリだけ）。

## はじめ方

1. `kyomu-all-in-one.html` を開く
2. 「今の Excel（週行事）から取り込む」→ 週行事の .xlsx を選ぶ（1学期・2学期のファイルをまとめて選べる）
3. 基本時間割（R8の前期・R8の後期）をどの期間に使うかを確かめて「取り込む」

取り込むもの：基本時間割のシート、週のシート（時間割・行事欄・出張等・結合した枠・セルの色と太字・図形の吹き出し・「火曜校時」・短縮日課・土曜授業）。
期間（1学期／2学期前期／2学期後期／3学期後期）の日付は、週のシートの日付から自動で合わせる。

## できること

| 画面 | できること |
|---|---|
| 週行事 | Excel と同じ形のシート（A4 縦 1 枚）。コマをクリックで変更、**ドラッグで入れ替え**。入れ替えると右の欄と「出張等」の欄に「1-1国は28日分」のような記録が残る（取り消し・文の手直しもできる）。学年・全校で 1 くくり。色。行事欄・出張等の欄に直接書きこみ。吹き出し。下に「この週の時数／累計」 |
| 月行事 | 1 か月を 1 日 1 行で。行事・職員の予定・授業日数 |
| 年間行事 | 4〜3 月を 1 枚に（A4 横で印刷）。月ごとの授業日数。一覧で探す。**まとめて入力**（1 行に 1 つ、Excel から貼りつけ可） |
| 時数 | 累計／年度末の見込み／計画／見込み−計画／**学年内の差**（時間数調整が必要なクラスに色）。期間ごと。標準授業時数を入れるボタン |
| 基本時間割 | 期間ごとに月〜金をつくる（ドラッグで入れ替え・1 くくり）。定例の会議（④運営委員会など）を書くと毎週の出張等の欄に出る。週の時数 |
| 先生 | 担当表（Excel から貼りつけ可）。全員の週の空き時間、先生ごとの時間割。担当表があると、入れ替えのとき**先生があいているコマが緑に光る**／同じ先生が 2 クラスに重なると赤い枠／出張の先生の授業に ⚠ |
| 設定 | 学校名・年度・期間・クラス・校時（曜日ごと・7 限）・教科（まとめる先・数えるか・合同可）、バックアップ、全消去 |

年間・月・週は 1 つのデータ。どこで行事を足しても 3 つの表に出る。
行事に「学年」と「校時」を入れると、その時間の時間割が自動で行事になり（学年で 1 くくり）、時数も数えなおされる。

### まとめて入力の書き方（年間行事・月行事）

```
4/6 全校 1-6校時 始業式
10/14〜10/16 2年 5-6校時 職場体験 #総
11/3 休 文化の日
9/24 火曜校時
7/13〜7/16 短縮4 三者面談
職員: 9/24 ④ 運営委員会 山田、佐藤
```

`#総` は「総合として数える」、`#なし` は時数に数えない（ふつうは「行事」として数える）。

### 印刷・PDF

各画面の「印刷・PDF」。PDF にするときは、印刷の画面の送信先で「PDF に保存」。
週行事は範囲を選んでまとめて印刷できる（第16週〜第33週など）。Ctrl+P でも、いま開いている画面が印刷される。

## つくり

ビルドなし。`index.html` をそのまま開いても動く（`kyomu-all-in-one.html` はそれを 1 ファイルにまとめたもの）。

```
kyomu/
├── index.html              … 部品を読む順番
├── kyomu-all-in-one.html   … 配る 1 ファイル（tools/bundle.cjs で作る。手で直さない）
├── css/sheet.css           … Excel と同じ見た目のシート（列幅・行の高さ・罫線・明朝/ゴシック）
├── css/app.css             … 画面
├── js/util.js              … 日付・祝日（振替休日・国民の休日も計算）・画面部品
├── js/model.js             … データの形と「そのコマに何が入るか」「時数」の計算
├── js/store.js             … 保存（localStorage）・元に戻す・バックアップ
├── js/ops.js               … 入れ替え・変更・1 くくり・記録
├── js/sheet.js             … 週行事・基本時間割のシート（画面と印刷で同じもの）
├── js/xlsx.js              … .xlsx を読む（外の部品なし。ブラウザの DecompressionStream）
├── js/import-core.js       … 週行事の Excel を読み取ってデータにする
├── js/print.js             … 印刷
└── js/views/               … 各画面（週・月・年・時数・基本・先生・設定・取り込み・行事の入力）
```

そのコマに入るもの（強い順）：手で変えたコマ（入れ替え・変更・まとめ） → 行事で埋まるコマ → 基本時間割（○曜校時ならその曜日）。

## 直したら

```bash
node kyomu/tools/bundle.cjs        # kyomu-all-in-one.html を作りなおす
node kyomu/tests/smoke.cjs         # 動作確認（架空のデータ。Playwright が必要）
```

学校の実データ（Excel・バックアップの JSON）はリポジトリに入れない（このリポジトリは公開されている）。
