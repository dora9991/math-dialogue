# 立方体の切り口（danmen）

立方体の上に **3点 P・Q・R** を置いて、その3点を通る平面で切った **切り口** を、点を動かしながら調べるブラウザ教材。
`seitamentai/`・`kukan/` と同じ黒板の画面。

## 開き方

`index.html` をダブルクリックするだけ（ビルド・サーバー不要）。字は Google Fonts（ネットがなければ端末の丸ゴシック）。

## 操作

- **P・Q・R をドラッグ** … 点を動かす（スマホ・タブレットのタッチも可）
- **空いているところをドラッグ** … 立方体を回す／ホイール・ピンチで拡大／ダブルクリックで向きをもどす
- **点の動かし方** … 「面の上を自由に」（うらの面にも置ける。辺・頂点に吸いつく）／「辺の上だけ」
- **そろえる** … なし／1/2／1/3／1/4／1/6／1/12 ずつ（初めは 1/4。「なし」でなめらかに動く）
- **立体を2つに分ける** … スライダーで2つの立体を切り口から引きはなす。どちら側を見るかも選べる
- **切り口を正面から** … 平面に垂直な向きにカメラが回り、切り口の本当の形が見える
- **やってみよう** … 正三角形・二等辺三角形・長方形・正方形・ひし形・台形・平行四辺形・五角形・正六角形になる3点の例

## 板書に出るもの

- 切り口の形の名前（三角形〜六角形。正三角形・長方形・ひし形・平行四辺形・台形・正六角形などは、辺の長さ・平行・直角を調べて判定）
- 3点の座標（A を原点、1辺を 1）と、辺上なら「A から 1/2・中点」などの位置
- 切り口の頂点（「辺 AB を 1：3 に分ける点」のように）
- 切り口の面積（√ の形で。1辺 a の cm を入力すると cm² も）と、2つの立体の体積の比・体積
- 3点が一直線上のときは「平面が決まりません」、同じ面の上のときは「面そのもの」と知らせる

## しくみ

- 外部ライブラリなし。canvas に正射影で描く（平行な辺が平行に見える）。
- 切り口は、平面と12辺の交点を求めて並べ、立体は各面を半空間で切って体積を発散定理で計算している。
- ブラウザのコンソールから `DANMEN.setPoints([[x,y,z],[x,y,z],[x,y,z]])` で3点を指定できる。
