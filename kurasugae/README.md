# クラス替えシート（Excel）

名簿を貼り付けると、3クラスにバランスよく分けた案が自動で出るエクセルです。
決めたクラスは1枚のシートに3クラス並べて表示し、入れ替えながら仕上げられます。

## ファイル

| ファイル | 中身 |
|---|---|
| `クラス替えシート.xlsx` | 実際に使う空のシート |
| `クラス替えシート_サンプル入り.xlsx` | 架空の105人入り（動きを見る用） |
| `クラス替えマクロ.bas` | Excel に取り込むマクロ（入れ替え・移動・1つ戻す・おまかせ最適化） |
| `ClassChange_utf8.bas` | 上のマクロの元（UTF-8。GitHub で読む・直す用） |
| `make_kurasugae.py` | 上の3つを作り直すスクリプト |

## シートの流れ

1. **①名簿入力** … 4行目から名簿を貼り付け、5教科・50m走・ピアノ〇×・ムードメーカー・注意・休みがち・分けたい人・備考を入れる。U列に **自動案** が出る
2. **②クラス編成** … 自動案（A〜B列）をコピーして D9 に「値」で貼り付け。ここが決定欄。E列（組）は直接書き換えOK
3. **③クラス一覧** … 3クラスを横に並べて表示。分けたい人が同じ組なら **赤**、3クラスの差が目安より大きい項目は **オレンジ**

自動案（数式だけで動く）は、注意→ピアノ→ムードメーカー→休みがち→その他の順に、成績が平均から離れている人から1人ずつ、
「同じ性別の人数」→「同じ特記事項の人数」→「成績・50m走のかたよりと旧クラスの人数」がいちばん少ない組へ入れていきます。
分けたい人だけは考えないので、③の赤いところを手で直すか、マクロの［おまかせ最適化］を使います。

## マクロの入れ方（はじめに1回だけ）

1. エクセルを開いて `Alt + F11`
2. ［ファイル］→［ファイルのインポート］→ `クラス替えマクロ.bas`
3. `Alt + F8` → `Setup_Buttons` →［実行］（②と③にボタンが出る）
4. ［名前を付けて保存］で「Excel マクロ有効ブック（*.xlsm）」にする

`.bas` は日本語版 Excel 用に Shift_JIS・CRLF で保存しています（`.gitattributes` で改行を変えないようにしています）。

## 作り直し方

```bash
python3 kurasugae/make_kurasugae.py
```

LibreOffice（`soffice`）があれば、計算済みの値もファイルに保存します（ダウンロード直後の「保護ビュー」でも中身が見えるように）。
LibreOffice がない場合は `--no-values` を付けてください。Excel で開けば計算されます。
