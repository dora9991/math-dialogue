# 生徒指導 対応ナビ（seitoshido-navi）

生徒指導の場面で迷ったときに開く、**分かれ道の地図**。
場面を選び、問いに答えて進むと、その状況での**対応の手順・声かけの例・避けたい言葉・連携先・記録すること**が出る。

- 場面は15、分かれ道はぜんぶで149。場面ごとの「分岐マップ」（路線図のような図）で、全体を見わたせる。
- 基本のページ：初期対応の基本・声かけの基本・記録の書き方（コピーできる記録の枠つき）・連携先と相談窓口（電話番号）。
- 場面やことばで探せる（例：「LINE」「リストカット」「189」）。
- **これは「例」**。各校の生徒指導規程・いじめ防止基本方針・管理職の判断に合わせて、直して使う。
- 作りはじめ：2026-10-22

## 開き方

| どこで | どうする |
|---|---|
| 手元のパソコン・タブレット | `seitoshido-navi-all-in-one.html` をダウンロードして、ダブルクリック（1ファイルで全部入り。インターネットにつながっていなくても動く。印刷もできる） |
| フォルダごと | `index.html` をブラウザで開く（ビルドもサーバーも要らない） |
| Claude の Artifact | `node tools/bundle.cjs --artifact` でできる `dist/artifact.html` を公開する（Artifact の中では印刷ボタンは出ない） |

GitHub では、`seitoshido-navi-all-in-one.html` を開いて、右上の「Download raw file」（↓のボタン）で保存できる。

## 画面

| 画面 | 場所（# のあと） |
|---|---|
| 一覧（ホーム）と検索 | `#top` |
| 場面のはじめの分かれ道 | `#ijime` など（場面の id） |
| 場面の中の分かれ道 | `#ijime~honnin~jijitsu`（はじめから `~` でつなぐ） |
| 場面の分かれ道を、すべて1ページで（印刷向き） | `#ijime.all` |
| 基本のページ | `#kihon`（初期対応の基本）・`#kotoba`（声かけの基本）・`#kiroku`（記録の書き方）・`#renkei`（連携先と相談窓口） |

Artifact で開くときも、リンクのうしろに `#ijime` のような # をつけると、その場面から開く（中で移っても、アドレスは変わらない）。

分かれ道の画面でできること：

- 「対応の手順」は、終わったものを押すと印がつく（ページを閉じると消える。どこにも保存しない）
- 「連携・報告先」の名前を押すと、その人・機関の役割が出る
- ほかの場面へ移ったときは、上に「← もどる」が出る
- 右（スマホでは下）の分岐マップから、どの分かれ道へも移れる。● がいまの道すじ、↪ はほかの枝との合流、↗ は別の場面へ

## 場面の足し方・直し方

1. `data/` に `<id>.js` を作る（`data/ijime.js` が見本）。
2. `data/common.js` の `SN.cats` の分類に、id を1つ書く（一覧の並び順になる）。
3. `index.html` に `<script src="data/<id>.js"></script>` を1行足す。
4. `node tools/check.cjs` で調べてから、`node tools/bundle.cjs` で1ファイル版を作り直す。

データの形（くわしくは `js/core.js` の先頭）：

```js
SN.scenario({
  id: 'ijime', title: 'いじめの訴え・発見', lead: '一覧のカードの説明', example: '架空の場面の例',
  words: ['検索で見つけてほしい言いかえ'], related: ['sns', 'futoukou'],
  nodes: {
    start: {
      title: '見出し（18字まで）', alert: '赤い注意（命・安全のときだけ）', text: '考え方（です・ます）',
      steps: ['対応の手順'], say: ['「声かけの例」'], avoid: [['避けたい言葉・対応', 'その理由']],
      team: ['gakunen', 'shido'], record: ['記録すること'], points: ['ポイント'], basis: ['根拠・参考'],
      question: '次の分かれ道の問い',
      options: [{ label: '同じ場面の中へ', to: 'honnin' }, { label: 'ほかの場面へ', jump: 'sns' }],
    },
  },
});
```

| 項目 | 画面での出方 |
|---|---|
| `alert` | 赤い「緊急」の枠 |
| `text` | はじめの説明 |
| `steps` | 対応の手順（番号つき。押して印をつけられる） |
| `say` | 声かけの例（○） |
| `avoid` | 避けたい言葉・対応（× と理由） |
| `team` | 連携・報告先（校内・家庭・校外に分けて出る。id は `data/common.js` の `SN.team`） |
| `record` | 記録すること |
| `points` | ポイント |
| `basis` | 根拠・参考 |
| `question`・`options` | 次の分かれ道。`to` は同じ場面の中、`jump` はほかの場面へ（`'sns~seiteki'` のように道すじも書ける） |

`**太字**` と、`\n`（改行）が使える。学校に合わせて直すとよいところ：連携先の名前と役割（`data/common.js` の `SN.team`）、校内の窓口、懲戒など規程にかかわる書き方。

## 検査

```bash
node tools/check.cjs                            # データ：行き先があるか・はじめからたどり着けるか・連携先の id・項目名・見出しの長さ
NODE_PATH=$(npm root -g) node tools/look.cjs    # ブラウザ：全部の分かれ道と全体・基本のページを開く／スマホの幅（390px）ではみ出し／押して進む・もどる／検索／画像（tools/_out/）
node tools/bundle.cjs                           # 1ファイル版（seitoshido-navi-all-in-one.html）を作り直す
```

`look.cjs` は playwright を使う（`npm i -g playwright`。Chromium は PLAYWRIGHT_BROWSERS_PATH にあればそれを使う）。`node tools/look.cjs seitoshido-navi-all-in-one.html` で、1ファイル版も調べられる。

## 作り方と、まだのこと

- 文章は、作者の方針と指示のもとで、AI（Claude）を使って作成した。文部科学省「生徒指導提要」（2022年改訂）や、下の法律・通知・手引きの考え方をもとに新しく書いたもので、資料の文章を写したものではない。
- 法律・通知は、各分かれ道の「根拠・参考」に名前を書き、条文の番号は確かなものだけを書いた。電話番号と受付時間は、2026年10月に各機関の案内で確かめた。
- **まだのこと**：作者・生徒指導の担当者・管理職による全体の読み直し、各校の規程との照らし合わせ、実際の場面での試用。まちがいや、学校によって合わないところが残っているかもしれない。使う前に、内容を確かめる。
