# 買った人に届けるセット（パッケージ）

バスケ タップ記録を申し込んだ人に渡すものの一覧と、渡し方です。届いたら、すぐ使える形にしています。

## セットの中身

| もの | 形 | どこにあるか | 決めること |
| --- | --- | --- | --- |
| ① はじめ方カード | A4 1枚（点線で切ると2枚） | `kit/start-card.pdf`（元は `kit/card.html`） | 【販売事業者名】【連絡先】【代理店】【説明書・規約のリンク】を入れる |
| ② 合言葉の控え | ①の2枚目の欄 | 買った人がアプリの「⚙ 設定」を見て書く | — |
| ③ 説明書 | ウェブの文書 | 「バスケ タップ記録 説明書」（Claude の文書） | 共有の設定（リンクを知っている人が見られるように）・お問い合わせ先 |
| ④ 利用規約 | ウェブの文書（利用規約・個人情報の扱い・特定商取引法に基づく表記） | 「バスケ タップ記録 利用規約」（Claude の文書） | 【 】の所・兼業規程の確認・専門家の確認 |
| ⑤ 使い方のデモ | アプリの中 | ホームの「▶ デモ」 | — |
| ⑥ 問い合わせ先 | ①と③に書く | — | 窓口（はじめの1か月は代理店が窓口の案） |

## 渡し方（代理店さん向け）

1. 申し込みと支払いを確かめる（利用規約に同意してもらう）
2. はじめ方カードを渡し、その場で QR を読んでホーム画面に追加してもらう
3. 「▶ デモ」を一緒に見る（約2分）
4. 合言葉をカードの控えに書いてもらう
5. 1週間後に「使えていますか」と声をかけ、感想（前と後）を聞く

## カードを作り直すとき

`kit/card.html` をブラウザで開き、印刷（A4・余白なし・背景のグラフィックを印刷）か「PDF に保存」。
QR コードはアプリの公開ページ（https://dora9991.github.io/math-dialogue/basket-tap/ ）を指しています。

## 売り始める前に（まだのこと）

- 兼業規程の確認と、販売事業者の名前
- 値段：**決まった**。クラブ 年 3万円（人数は数えない・1 クラブにコード 1 つで何台でも）、はじめの 3 試合は無料。個人の買い切り案は、やめた。代理店の取り分は、まだ決めていない（案：20〜30％）
- 買った人だけが使えるしくみ（購入コード）：**作ってあるが、スイッチは切ってある**（`js/license.js` の `MODE = 'off'`）。売り始めるには：`cloud/license.sql` を Supabase に流す → `MODE` を `'on'` → 申し込みの窓口（`CONTACT`）を入れる → 作り直して公開（くわしくは `basket-tap/README.md` の「場面パック」）。それまでは、URL を知っていれば、だれでも使える
- 消した試合をクラウドから完全に消すしくみ（いまは「消した印」を付けるだけ。個人情報の扱いに「【 】日以内に完全に消す」と書くので、その前に作る）
