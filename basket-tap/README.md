# バスケ タップ記録

バスケの試合を見ながら、**だれが・何をしたか**（シュートを入れた・外した、リバウンド、パスミスなど）を**タップで記録する**ブラウザアプリです。
記録には「スタートを押してからの時刻」が付くので、あとで **「バスケ得点クリップ」に試合の動画と一緒に読み込むと、その場面を切り出せます**（選手ごと・プレーごとに、続けて見たり、1本の動画にしたり）。

- インストール不要・通信なし。**記録はその端末のブラウザの中だけ**に保存し、どこにも送りません
- 公開ページ：**https://dora9991.github.io/math-dialogue/basket-tap/** （iPhone は「共有」→「ホーム画面に追加」で、画面いっぱいに使えます）
- 1ファイル版：`public/basket-tap/index.html`

## 使い方

1. **＋ 新しい試合を記録する** → **試合の準備**
   - チーム名・ユニフォームの色を選ぶ（なくても大丈夫）
   - **背番号は「4〜15」「4〜18」などのボタンでまとめて選ぶ**。番号のマスをタップして足す・外す。「4-15, 23」のように直接入れることも
   - 選手の名前（ニックネーム）も入れられます（なくてもOK）。入れると、番号のボタンに小さく出ます
   - 自分のチームは保存され、**次の試合からは最初から入っています**。相手のチームも、名前を付ければ「前のチームから」選べます
2. **ティップオフ（試合開始のジャンプボール）の瞬間に「▶ スタート」** → 左上の時計が動き出す
3. **プレーが起きたらタップ**。押した瞬間の時刻で記録されます

### 記録のしかた（どれでもOK）

| 順番 | 例 | 時刻 |
|---|---|---|
| **番号 → プレー** | 「7」→「2P 成功」 | プレーを押した瞬間 |
| **プレー → 番号** | 「2P 成功」→（7 秒以内に）「7」 | プレーを押した瞬間（番号はあとから付く） |
| **プレーだけ** | 「リバウンド」 | 番号なし（チームの記録。あとで一覧から番号を付けられる） |

- プレーを先に押すと、そのチームの帯が「**だれの『2P成功』？**」に変わり、番号のボタンが光ります。7 秒たつか「番号なし」で終わり
- 番号を選んだまま 12 秒たつと、選んだ印は外れます（選んだのを忘れて、別の人の記録に付かないように）
- 名簿にない番号が出たら、番号の並びの「**＋**」で足せます（待っていた記録にも、その番号が付きます）
- 同じボタンを 0.45 秒以内に2回押したときは、1回として数えます（二度押しの防止）

### 画面

- **左上**：時計（スタートからの時間。止まらずに進みます）・ピリオド・得点・メニュー
- **2つのパネル**：自分と相手。帯の色はユニフォームの色。それぞれに背番号とプレーのボタン
- **プレーのボタン**：成功は緑、失敗は白（×）、リバウンドは青、ミスはオレンジ、★（あとで見る）は黄色
- **下の帯**：いま記録したもの（時刻・チーム・番号・プレー）と「**↶ 取り消す**」（取り消したら「やり直す」で戻せます）
- 画面の大きさに合わせて、背番号の並べ方を自動で変えます（折り返して並べる／2段で横にすべらせる／1段で横にすべらせる／左に縦に並べる）。iPhone SE の縦でも、横向きのスマホでも、プレーのボタンは全部画面に収まります

### メニュー（≡）

| | |
|---|---|
| 記録の一覧 | どの記録でも、番号・プレー・チーム・時刻（±0.5〜5 秒）を直す・消す |
| 集計 | ピリオドごとの得点、選手ごとの得点・2P／3P／FT（成功/打った数）・リバウンド（オフェンスの数）・アシスト・スティール・ブロック・パスミス・ミス・ファウル・★ |
| チーム・背番号を直す | 試合の途中でも |
| ボタン・設定 | ボタンの組み合わせ（ふつう／くわしく／得点だけ／自由に）をチームごとに。名前の表示・タップ音・画面の色（端末に合わせる／明るい／暗い） |
| 書き出す | **記録のファイル（JSON）**＝動画の切り出し用・開き直し用、**記録の一覧（CSV）**、**選手ごとの集計（CSV）**。CSV は Excel でそのまま開ける形（BOM 付き UTF-8）。スマホでは「共有」（AirDrop・ファイルに保存・LINE など） |
| 試合を終える | 時計を止めて、集計を見る（まちがえて終えたら「続きを記録する」） |

ピリオドは、時計の右の「1Q」を押して「**2Q を始める**」。始めた時刻が記録に残ります（動画で場面を探すときの目印にも）。
押し忘れても、一覧で「2Q 開始」の時刻を直せば、それより後の記録は全部 2Q になります（ピリオドは記録ごとに持たず、「その時刻より前のいちばん新しいピリオドの始まり」で決めるため）。

### 記録の途中で困らないように

- **画面が自動で消えないように**しています（Screen Wake Lock。できない端末では、端末の自動ロックを長めに）
- 1つ記録するたびに、すぐ保存。画面を閉じても、開き直せば続きから（時計もスタートから進んだまま）
- 記録中に「戻る」（スワイプ・戻るボタン）をしても、ページを離れません
- 押せたことが分かるように：ボタンが光る・下の帯に出る・振動（Android は vibrate、iPhone は iOS 18 からのスイッチの振動を使う）・音（設定でオン）
- ダブルタップの拡大・長押しのメニュー・文字の選択が出ないように
- ホーム画面に追加すると、電波が弱い体育館でも開き直せます（Service Worker。https で公開しているときだけ）

## 動画から場面を切り出す（バスケ得点クリップ）

1. 「書き出す」→「**記録のファイル（JSON）**」で保存（同じ端末・同じブラウザなら、ファイルにしなくても読み込めます）
2. **バスケ得点クリップ**（https://dora9991.github.io/math-dialogue/basket-clips/ ）で、試合の動画を開いて「📋 記録を読み込む」
3. **時刻を合わせる**：動画の撮影時刻から自動で合わせる目安が出ます（iPhone など）。手で合わせるときは、記録の1つ（ふつうは「スタート」）を選んで、動画の同じ場面（ジャンプボールの瞬間）で止めてボタンを押すだけ
4. **場面を選ぶ**：チーム・プレー（得点・シュート失敗・リバウンド・パスミス・★…）・選手で絞り込み、▶ で1場面ずつ、「▶ 続けて再生」でまとめて、「🎬 動画にする」で1本の動画に

くわしくは `basket-clips/README.md` の「記録（バスケ タップ記録）から切り出す」。

## 記録のデータの形

`js/core.js` の先頭コメントが仕様。書き出す JSON の例：

```json
{
  "format": "basket-tap", "version": 1, "app": "バスケ タップ記録",
  "id": "g…", "title": "", "date": "2026-10-19",
  "startedAt": 1792391412000, "startedAtText": "2026-10-19 15:30:12 (UTC+09:00)", "endedAt": null, "tz": 540,
  "teams": [
    { "name": "致遠館", "color": "#f4f4f4", "colorName": "白", "players": [{ "no": "7", "name": "たけし" }] },
    { "name": "城南", "color": "#2f6fed", "colorName": "青", "players": [{ "no": "4", "name": "" }] }
  ],
  "events": [
    { "id": "e1", "t": 0, "type": "period", "period": 1 },
    { "id": "e2", "t": 125.4, "type": "fg2", "team": 0, "no": "7", "period": 1 }
  ],
  "score": [2, 0],
  "types": { "fg2": { "label": "2P成功", "pts": 2 } }
}
```

- `t`：スタートを押してからの秒（0.1 秒まで）。`startedAt`（エポックミリ秒）と足せば、その時刻
- `team`：0 = 自分、1 = 相手。`no`：背番号（文字。`"0"` と `"00"` は別）。`null` は番号なし
- `type`：`fg2` `fg3` `ft`（成功）、`fg2x` `fg3x` `ftx`（失敗）、`reb` `ast` `stl` `blk` `pass`（パスミス）`tov`（その他のミス）`foul` `mark`（★あとで見る）、`period`（ピリオドの始まり）
- ブラウザの中の保存（localStorage）は `btap:games`（試合の一覧）・`btap:game:<id>`（試合）・`btap:teams`（チーム）・`btap:prefs`（設定）

## ファイル

```
basket-tap/
  index.html        開発用（js/ と css/ を読み込む）
  build.mjs         1ファイル版を作る → public/basket-tap/（index.html・manifest・icons・sw.js）
  manifest.webmanifest・sw.js・icons/   ホーム画面に追加したとき用（アイコンは tools/make_icons.py で作る）
  css/app.css
  js/core.js        データの形・時刻・タップの順番（tapper）・集計・CSV・書き出しと読み込み（DOM なし）
  js/store.js       ブラウザへの保存（試合・チーム・設定）
  js/ui.js          画面の部品（下から出る小窓・お知らせ・振動と音・画面を消さない・保存と共有）
  js/app.js         画面（試合の一覧・準備・記録・一覧・集計・書き出す・設定）
  tests/unit.cjs    回帰テスト（node だけで動く）
  tests/e2e.cjs     画面を通した確認（Playwright の Chromium・スマホの大きさ・時計を進めて確かめる）
```

## 開発

```bash
node basket-tap/build.mjs                 # 1ファイル版を作り直す（公開するのはこれ）
node basket-tap/tests/unit.cjs            # 回帰テスト（50件）
node basket-tap/tests/e2e.cjs built       # 画面を通した確認（71件・約1分）。dev で開発版
SHOTS=/tmp/shots node basket-tap/tests/e2e.cjs dev   # 画面の写真も撮る（見た目の確認用）
node basket-tap/tests/server.cjs          # 開発用サーバー → http://127.0.0.1:5193/
python3 basket-tap/tools/make_icons.py    # アイコンを作り直す（Pillow が必要）
```

e2e は Playwright（`npm i -g playwright` など）と、その Chromium を使います。

## 確かめたこと（正直な範囲）

- **Chromium（Playwright・画面なし）で、スマホの大きさ（タッチ）にして操作**（`tests/e2e.cjs`）：準備（「4〜15」・番号のタップ・直接入力・名前）→ スタート → 3通りの記録（番号 → プレー／プレー → 番号／プレーだけ）→ 二度押しの防止 → 取り消す・やり直す → その場で番号を足す → ピリオド → 一覧で直す・消す → 集計 → 書き出す（JSON・CSV 2種類）→ 開き直すと続きから → 試合を終える・続きを記録する → 次の試合で自分のチームが入っている。時計は Playwright の clock で進め、記録の時刻が 0.1 秒まで合うことを確かめた
- **画面の大きさ**：背番号 15 人ずつ・ボタン 9 個ずつで、iPhone SE の縦（Safari の見える範囲 375×553）・大きいスマホ（430×800）・スマホの横向き（750×340・667×320）・iPad 縦・横で、プレーのボタンが全部画面に収まり、上の帯（時計・ピリオド・得点・メニュー）が重ならない。1時間を超えた時計（1:02:05）と 3 けたの得点でも
- **していないこと**：本物の iPhone・iPad（Safari）での操作。とくに、iPhone の振動（スイッチの振動を使う方法は iOS 18 から）・画面を消さない仕組み（Wake Lock）・ホーム画面に追加したときの動き・本物の試合での記録は、まだ確かめていません
- 「バスケ得点クリップ」との受け渡し（このアプリが書き出した JSON を、そのまま読み込めるか）は、`basket-clips/tests/unit.cjs` と `basket-clips/tests/e2e-log.cjs` で確かめています

## 注意

- iPhone の Safari は、**しばらく（7日ほど）開かないサイトの保存を消す**ことがあります。大事な試合は「書き出す」でファイルにも残してください（ホーム画面に追加したアプリは、この消え方をしにくくなります）
- ホーム画面に追加したアプリと、Safari で開いたページは、保存場所が別です（「バスケ得点クリップ」から「この端末で記録した試合」を読むときは、同じ Safari で開いてください。読めないときはファイルで）
- 時計は「試合の時計（残り時間）」ではなく、スタートからの経過時間です。止めずに進むので、動画と同じ時間の流れになります
