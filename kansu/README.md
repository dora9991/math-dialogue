# 関数 y＝ax²の黒板（kansu）

電子黒板に映して、**図やグラフを動かしながら**考える「関数 y＝ax²」（中3）の授業ページ。1時間＝1ページ、14時間ぶん。
授業の流れは ikkan の `ikkan/data/lesson_kansu_NN.js` とそろえてある（今日の問い → ことば → 例題 → 考えよう → チャレンジ）。考えようは答えを出さず、スライダーなどの「調べる道具」だけ。

## 開き方

`index.html`（目次）をダブルクリック。ビルド・サーバー不要。全単元の総目次は `../kokuban/index.html`。
画面の土台は `../kukan/js/k3.js`・`../kukan/css/board.css`・`../katsuyo/js/chart.js` を使うので、公開するときはいっしょに置く。

## 14時間

| 時間 | ページ | 題 |
|---|---|---|
| 第1時 | `01.html` | だんだん速くなる変化を、式で表そう |
| 第2時 | `02.html` | 1組の x、y の値から、y＝ax² の式を求めよう |
| 第3時 | `03.html` | y＝x² のグラフは、どんな形になるだろう |
| 第4時 | `04.html` | a の値を変えると、グラフはどう変わるだろう（a＞0） |
| 第5時 | `05.html` | a が負の数のときのグラフをかいて、特徴をまとめよう |
| 第6時 | `06.html` | 式・グラフ・通る点のカードを合わせて、同じ関数を見つけよう |
| 第7時 | `07.html` | x の変域から、y の変域を求めよう |
| 第8時 | `08.html` | 変化の割合は、一次関数とどうちがうだろう |
| 第9時 | `09.html` | 変化の割合から、平均の速さを求めよう |
| 第10時 | `10.html` | 車が止まるまでのきょりを、y＝ax² とみなして予測しよう |
| 第11時 | `11.html` | 放物線と直線が交わる点を、式から求めよう |

| 第13時 | `13.html` | 図形の中を動く点がつくる面積を調べよう |
| 第14時 | `14.html` | 「関数 y＝ax²」で学んだことを、整理して確かめよう |

## 操作

空間図形の黒板（`../kukan/README.md`）と同じ：→・Enter・Space でつぎへ（問い → 答え → 次の問い）、← でもどる、R でもう一度動かす、F で全画面。下にスライダーが出る場面は、手で値を変えられる。URL の最後に `#step-6` のように番号をつけると、そのステップから開く。右の板書は、答えた順に1行ずつたまる。

## つくり（作り手向け）

- 1ページ＝1つの HTML（外部ライブラリなし）。`K3.run({ flat: true, steps: [...] })` を呼ぶだけ。ステップの書き方は `../kukan/README.md`。
- グラフ・表・数直線・カード・タイルは `../katsuyo/js/chart.js`（CH.*）。分数は `CH.fr`（文の中の [1/2]）・`CH.frac`（図の中）、√ は `CH.root`、負の数は `CH.mnum`。
- 座標平面は `CH.plane`・`CH.lin`（直線）・`CH.fn`（放物線など）・`CH.hyp`（双曲線）・`CH.pt`（点）・`CH.slopeTri`（傾きの三角形）。
- 答えや表の数は、ページの中で計算し直して照らし合わせている（`CH.check`）。ちがうと、ブラウザのコンソールに「答えがちがう：…」と出る。
- × と ÷ は、黒板の字体だと x と見分けにくいので、土台が自動で見分けやすい字体にする。
- データ・場面は ikkan の数値か、自作（各ページの頭のコメントに書いてある）。
