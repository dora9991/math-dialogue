# 正多面体は、なぜ5種類？（seitamentai）

電子黒板に映して、**図を動かしながら**「正多面体が 5種類しかない理由」を考える教材。
1つの頂点に正多角形のカードを集め、**並べる → 折り曲げる → 立体になる（ならない）** を、ブラウザで一歩ずつ見せる。

## 開き方

`index.html` をダブルクリックするだけ（ビルド・サーバー不要）。
字は Google Fonts（Klee One・BIZ UDPゴシック）。ネットにつながらないときは、端末の丸ゴシックで表示される。

右側の表（板書）が、進むにつれて埋まっていく。もどると、表ももどる。

## 図のつくり方（作り手向け）

- 外部ライブラリなし。canvas 2D に、自前で透視投影して描いている。
- **折り曲げ**：k 枚の面の辺を、頂点を中心とする円すいの上に等間隔に置く。面の角 α が変わらないように、円すいの開き β を決める（cos α = sin²β cos Δ + cos²β、Δ は辺どうしの方位の差）。すき間が閉じたときの形は、正多面体の1つの頂点のまわりと一致する（ずれは 10⁻¹⁵ 程度）。
- **持ち上げる**（角の和が 360° 以上のとき）：β を小さくすると Δ が α より大きくなり、合計が 360° をこえて、最後の面が最初の面に重なる（赤で表示）。
- **正多面体**：頂点の座標から凸包で面を求め、辺の長さを 1 にそろえる。見えない辺は点線（教科書と同じ）。
