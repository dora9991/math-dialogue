1. 単元カード

10までのかず
លេខរហូតដល់ 10
いくつといくつ・かずのならび
ការផ្សំលេខ · លំដាប់នៃលេខ
・10 は「1 と 9」「2 と 8」「3 と 7」「4 と 6」「5 と 5」に わけられるよ。
・10 អាចបំបែកបានជា «1 និង 9» «2 និង 8» «3 និង 7» «4 និង 6» «5 និង 5»។
・かずは 0、1、2、3、… と 1ずつ おおきく なって いくよ。
・លេខកើនឡើងម្តងមួយៗ៖ 0, 1, 2, 3, …
・「いくつと いくつ」が すぐに いえると、たしざんや ひきざんが らくに なるよ。
・បើអ្នកអាចប្រាប់បានភ្លាមៗថា «ប៉ុន្មាន និងប៉ុន្មាន» នោះការបូក និងការដកនឹងងាយស្រួលឡើង។

5. 決めてほしいこと（翻訳以外）

  • 数字をクメール数字（០១២３…）にするか
    今は半角（0 1 2 …）のまま。小学生にはクメール数字のほうが自然かもしれない。表示側で切りかえられる作りにしたい。現地の先生に確認。
  • 「ទី（〜番目）」は数の前に付く
    答え欄の「単位」は後ろに付く仕組みなので、「ばんめ」は今は単位なしにした。前に付ける仕組みが要るか、問題文で言えば十分か。
  • 名前・ものの置きかえ
    ゆい・けん → សុខា・ដារ៉ា、おはじき → ビー玉。現地で自然な名前・もの（かずを数える題材）に、先生に選んでもらう。
  • 語調（子ども向けのていねいさ）
    クメール語は話し方の丁寧さの段階がある。いまは中立的なていねい体。1年生に向けた親しみのある言い方にするか。
  • 図・動画・音声
    数直線の図（「↓の ところの かず」）の中の文字と、「ホー先生の授業」の動画（日本語の音声）は、この試訳に入っていない。字幕・吹き替えが要る。
  • 現地のカリキュラムとの対応
    「10までのかず」を、カンボジアの1年生の最初の単元（範囲・順序）とどう対応させるか。
